# 第 6 章 行列式、特征值与特征向量：找出变换里「不转向」的方向

> **本章定位**：前五章我们把线性代数当成「空间 + 变换 + 几何」的语言一步步立了起来——向量空间与基（第 2 章）、矩阵即线性变换（第 3 章）、内积与正交投影（第 4 章）、解方程与分解（第 5 章）。但有两个概念我们一路上反复欠债：第 5 章里写条件数 $\kappa=\sigma_{\max}/\sigma_{\min}$ 时借了「奇异值」、判正定时借了「特征值」、说对角化是「换坐标让变换变成纯缩放」时也只给了直觉。本章就来把其中两位主角正式请上台：**行列式（determinant）** 与 **特征值 / 特征向量（eigenvalue / eigenvector）**。它们一个回答「这个变换把体积放大了多少倍、还可不可逆」，一个回答「这个变换里，哪些方向只被拉伸、不被转向」。后者是全课**暗线二（谱视角）** 的真正起点：一旦你学会用特征值 / 特征向量去「看穿」一个矩阵的本征结构，你会发现此前散落各处的东西——对角化、矩阵幂、动力系统的长期行为、马尔可夫链的稳态、Hessian 的稳定性、协方差的主轴、PCA、简正模式、图拉普拉斯谱——全都是同一把钥匙开的锁。本章分六步：先用「有向体积缩放因子」给行列式一个几何灵魂，顺手把第 5 章埋的可逆判据收掉（§6.1）；接着兑现第 3 章关于**雅可比行列式**的伏笔，把它接到《概率与统计》第 2 章的密度变量替换与归一化流——这正是生成式蛋白设计的数学心脏（§6.2）；然后正式定义特征值 / 特征向量，配套交互页面 `06_eigen_explorer.html` 让你亲手转动矩阵、实时看特征方向如何「钉」在原地（§6.3）；再讲对角化 $A=PDP^{-1}$——相似变换 = 换到特征基看同一个变换变成纯缩放，以及它何时失败（不可对角化与 Jordan 标准形，只给直觉，§6.4）；随后用迹 = 特征值之和、行列式 = 特征值之积把谱与两个标量量联系起来，并讲矩阵幂 $A^k$、线性动力系统 $\mathbf x_{t+1}=A\mathbf x_t$ 的长期行为、以及马尔可夫链稳态 = 特征值 1 的特征向量（直连《概率与统计》第 10 章 MCMC 收敛、PageRank，§6.5）；最后讲复特征值 = 旋转，并为第 7 章「对称矩阵特征值必为实、特征向量可取正交」的谱定理埋下伏笔（§6.6）。读完本章，凡你遇到「这个矩阵反复作用会怎样」「这条链多久收敛」「这个生成模型的密度怎么变」「这个变换的本征方向在哪」，都能用谱的语言一眼看穿。

## 6.1 行列式：有向体积的缩放因子

很多人对行列式的全部记忆是「$2\times2$ 是 $ad-bc$、$3\times3$ 按对角线交叉相减、更大的按某一行展开」。这是把行列式当成一个**计算配方**记住了，却完全错过了它是什么。本节要把它的几何灵魂找回来：**行列式是线性变换对「有向体积」的缩放因子。** 一旦抓住这一点，它的全部性质——可逆判据、$\det(AB)=\det A\det B$、雅可比行列式——都变成几何上一目了然的事，再也不用死记。

### 6.1.1 几何定义：单位立方体被映成了多大的（有向）体积

回忆第 3 章的核心观念：一个 $n\times n$ 矩阵 $A$ 就是 $\mathbb R^n$ 上的一个线性变换 $\mathbf x\mapsto A\mathbf x$，而它的**列**就是标准基向量 $\mathbf e_1,\dots,\mathbf e_n$ 的像。于是，由 $\mathbf e_1,\dots,\mathbf e_n$ 张成的**单位立方体**（在 $\mathbb R^2$ 是单位正方形，体积 = 面积 = 1），被 $A$ 映成由 $A$ 的各列张成的**平行多面体**（在 $\mathbb R^2$ 是平行四边形）。

> **行列式的几何定义。** $\det A$ 是这个被映出来的平行多面体的**有向体积（signed volume）**，也即 $A$ 把任意区域的体积缩放的倍数。「有向」指它带符号：$\det A>0$ 表示变换**保持定向（orientation）**（右手系还是右手系），$\det A<0$ 表示**翻转定向**（照了镜子、左右手互换），$\det A=0$ 表示把整个空间**压扁**到一个更低维的子空间里（体积塌成 0）。

ASCII 图（$\mathbb R^2$，$A=\begin{bmatrix}2&1\\0&1\end{bmatrix}$ 把单位正方形剪切+拉伸成平行四边形）：

```
   变换前（单位正方形，面积=1）        变换后（平行四边形，面积=|det A|=2）
   y                                  y
   1 +-----+                          1 +-----+----+
     |     |                            |    /    /
     |     |              A             |   /    /
   0 +-----+---> x        ===>        0 +--+----+----> x
     0     1                            0  1    2  3
   e1=(1,0), e2=(0,1)                 Ae1=(2,0), Ae2=(1,1)
```

那个平行四边形的面积正是 $|\det A|=|2\cdot1-1\cdot0|=2$：变换把所有面积放大了 2 倍。这就是行列式的全部含义——**一个数，告诉你这个变换把体积放大（或缩小）了多少倍，并通过符号告诉你有没有照镜子。**

> **给数学 / CS 读者的视角（行列式是「体积缩放」这个泛函的唯一答案）**：你可以反过来理解：我们想给「$n$ 个向量张成的平行多面体的有向体积」找一个公式 $D(\mathbf a_1,\dots,\mathbf a_n)$，并要求它满足三条最朴素的几何公理——(1) **多线性（multilinear）**：体积对每一条边线性（把一条边拉长 2 倍，体积变 2 倍；两条共边向量相加，体积相加）；(2) **交替（alternating）**：两条边相同则体积为 0（退化成低维，没体积），等价于交换两列体积变号（定向翻转）；(3) **归一化**：单位立方体体积为 1，即 $D(\mathbf e_1,\dots,\mathbf e_n)=1$。**满足这三条的函数唯一存在，它就是行列式。** 那些「按行展开」「逆序数求和」的公式不过是从这三条公理推出来的**计算表达式**，本身没有更深的意义。把行列式理解成「满足几何公理的唯一体积泛函」，比记任何展开式都更接近它的本质——这正是 Strang 和 Axler 都强调的视角。

### 6.1.2 从几何性质直接读出代数性质

一旦接受「行列式 = 体积缩放因子」，下面这些性质就不是要背的公式，而是几何常识：

| 性质 | 几何理由 |
|---|---|
| $\det I = 1$ | 恒等变换不改变体积。 |
| $\det(AB)=\det A\cdot\det B$ | 先做 $B$ 把体积放大 $\det B$ 倍，再做 $A$ 放大 $\det A$ 倍，**复合变换的总缩放 = 缩放之积**。这是行列式最重要、最深刻的性质。 |
| $\det(cA)=c^n\det A$（$n\times n$） | 把每个坐标轴方向都拉伸 $c$ 倍，$n$ 维体积变 $c^n$ 倍。 |
| $\det(A^{-1})=1/\det A$ | 逆变换把体积缩放回去，缩放因子互为倒数（故 $\det A\ne0$ 才有逆）。 |
| $\det(A^T)=\det A$ | 转置不改变行列式（按行的体积 = 按列的体积，几何上不那么显然，但可由展开式证）。 |
| $\det A=\prod \lambda_i$ | 行列式 = 全部特征值之积（§6.5，谱视角下体积缩放 = 各本征方向缩放之积）。 |
| 三角矩阵 $\det=$ 对角元之积 | 上 / 下三角变换把体积只沿对角方向缩放，缩放因子是对角元之积（这也是为什么算行列式实践上走 LU：$\det A=\pm\prod U_{ii}$）。 |

> **可逆判据（兑现第 5 章伏笔）。** 对方阵 $A$，下列等价：
> $$\det A\ne 0 \iff A\text{ 可逆} \iff \text{列}（\text{行}）\text{线性无关} \iff \text{满秩} \iff \mathcal N(A)=\{\mathbf 0\} \iff A\mathbf x=\mathbf b\text{ 唯一可解}.$$
> 几何上一句话：**$\det A=0$ 意味着变换把空间压扁到更低维**（体积塌成 0），于是信息不可逆地损失了一个维度，没法还原——这就是「奇异（singular）」。

这些性质里，$\det(AB)=\det A\cdot\det B$ 值得单独驻足，因为它是行列式之所以「有用」的灵魂，也是后面无数推导的支点。它说的是：**行列式是一个把「矩阵乘法」翻译成「数的乘法」的同态（homomorphism）**——复杂的矩阵世界里「先变换 $B$ 再变换 $A$」，在行列式眼里就退化成两个数相乘。正因如此：相似变换 $\det(PDP^{-1})=\det P\det D\det P^{-1}=\det D$ 不改变行列式（§6.4 相似不变量的来源）；正交矩阵 $Q^TQ=I$ 故 $(\det Q)^2=1$、$\det Q=\pm1$（旋转 $+1$、反射 $-1$，第 4 章正交变换保体积的代数证明，也是 §6.6、第 10 章 Kabsch 排除镜像的依据）；$\det A=\prod\lambda_i$（§6.5）也是这条乘性在特征基下的体现。可以说，**这一条乘性性质比所有展开公式加起来都重要**——记住它，忘掉余子式也无妨。

### 6.1.3 怎么算、以及为什么不该手算大行列式

为完整起见，给出小阶的显式公式（仅当工具，不必当主角）：

$$
\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc,\qquad
\det\begin{bmatrix}a&b&c\\d&e&f\\g&h&i\end{bmatrix}=a(ei-fh)-b(di-fg)+c(dh-eg).
$$

对一般 $n\times n$，有**按行（列）展开（Laplace expansion / cofactor expansion）**：沿某一行 $\det A=\sum_j (-1)^{i+j}a_{ij}M_{ij}$，其中 $M_{ij}$ 是划去第 $i$ 行第 $j$ 列的**子式（minor）** 的行列式。这个递归公式理论上完备，但**代价是 $O(n!)$**——对 $n=20$ 就要算 $20!\approx2.4\times10^{18}$ 项，宇宙级别地慢。

> **CS 读者陷阱（永远不要用余子式展开算大行列式）**：你在数学课上学的 cofactor 展开是 $O(n!)$ 的，完全不能用于计算。实践中算行列式走 **LU 分解**（第 5 章 §5.2）：$A=PLU$，则 $\det A=\det P\cdot\det L\cdot\det U=(\pm1)\cdot1\cdot\prod_i U_{ii}$（$P$ 是置换，行列式 $\pm1$；$L$ 单位下三角，行列式 1；$U$ 上三角，行列式 = 对角元之积）。这是 $O(n^3)$，和解一个方程组同阶。`np.linalg.det(A)` 内部就是这么做的——它先 LU 再乘对角元，绝不做余子式展开。**记住：行列式是用来「思考」（体积、可逆、雅可比）的概念，不是用来「手算」的负担。**

> **诚实的边界（行列式判可逆在数值上是个坏主意）**：「$\det A=0$ 等价于奇异」是**精确算术**下的真理，但在**浮点**世界里它会骗你。原因有二：(1) **对缩放极敏感**——$\det(cA)=c^n\det A$，把矩阵整体乘 $0.1$，行列式就乘 $0.1^n$，$n=50$ 时 $\det$ 变成 $10^{-50}$，但矩阵的可逆性 / 病态程度毫无变化。所以「$\det$ 很小」既不代表病态、也不代表接近奇异。(2) 一个完美良态的矩阵（如 $0.001\,I$，条件数 $\kappa=1$）行列式可以极小；一个病态矩阵的行列式可以不小。**判一个矩阵是否（接近）奇异 / 病态，要看条件数 $\kappa=\sigma_{\max}/\sigma_{\min}$（第 5 章 §5.6、第 9 章），绝不要看行列式。** 这一条第 3 章 §3.6、第 5 章 §5.6 都钉过，本章再钉一次，因为它是行列式最常见的误用。

> **与你的研究的连接（行列式在折叠场景里出现在哪）**：你日后真正会碰到行列式的地方不是「判可逆」（那用条件数 / 秩），而是这几处具体场景：(1) **概率密度的变量替换 / 归一化流的雅可比行列式**（§6.2，生成式蛋白设计的核心）；(2) **多元高斯的归一化常数**含 $\det\Sigma$——$p(\mathbf x)=\frac{1}{(2\pi)^{d/2}|\det\Sigma|^{1/2}}\exp(-\tfrac12(\mathbf x-\boldsymbol\mu)^T\Sigma^{-1}(\mathbf x-\boldsymbol\mu))$（《概率与统计》第 5 章），这里 $\det\Sigma=\prod\lambda_i$ 度量了高斯椭球的「总体积 / 不确定度」，对它取对数（$\log\det\Sigma$）是各种信息量（微分熵、《信息论》第 8 章）和高斯过程边际似然里的常客；(3) **Kabsch / Procrustes 结构叠合**里用 $\det$ 的符号来排除「带镜像翻转的旋转」（确保求出的是真旋转 $\det=+1$ 而非反射 $\det=-1$，第 10 章 §10.6）。这三处都用到行列式的**几何含义**（体积 / 定向），而非它的手算。

> **要点（§6.1）**：行列式 = 线性变换对**有向体积的缩放因子**（符号 = 是否翻转定向，0 = 压扁降维）。由「多线性 + 交替 + 归一化」三条几何公理唯一确定。关键性质 **$\det(AB)=\det A\det B$**（复合 = 缩放之积）。可逆判据 **$\det A\ne0\iff$ 可逆 $\iff$ 满秩**。计算走 LU（$O(n^3)$），不用余子式（$O(n!)$）。**判病态 / 奇异看条件数不看行列式。** 折叠里行列式出现在雅可比、多元高斯归一化、Kabsch 定向。

## 6.2 雅可比行列式：多维变量替换的体积因子

第 3 章我们提到过：当一个变换不是线性而是**非线性**时，它在每一点附近的「最佳线性近似」是雅可比矩阵，那一点的局部体积缩放就是**雅可比行列式（Jacobian determinant）**。本节把这个伏笔正式接上，并连到《概率与统计》第 2 章的密度变量替换、以及生成式蛋白设计里的归一化流——这是行列式在你研究里最重要、最「活」的一次出场。

### 6.2.1 雅可比矩阵 = 非线性变换的局部线性近似

设光滑映射 $g:\mathbb R^n\to\mathbb R^n$，$\mathbf y=g(\mathbf x)$。它在点 $\mathbf x$ 附近的一阶泰勒展开是

$$
g(\mathbf x+\delta\mathbf x)\approx g(\mathbf x)+J_g(\mathbf x)\,\delta\mathbf x,\qquad
[J_g]_{ij}=\frac{\partial y_i}{\partial x_j},
$$

其中 $J_g(\mathbf x)\in\mathbb R^{n\times n}$ 是**雅可比矩阵（Jacobian matrix）**——它的第 $j$ 列是「沿 $x_j$ 方向走一小步，输出怎么动」，正是 §6.1 里「列 = 基向量的像」在局部的体现。于是由 §6.1，$g$ 在 $\mathbf x$ 处把一个无穷小体积元 $\mathrm d\mathbf x$ 缩放为

$$
\mathrm d\mathbf y = |\det J_g(\mathbf x)|\,\mathrm d\mathbf x.
$$

**雅可比行列式 = 非线性变换在每一点的局部体积缩放因子。** 它逐点变化（不同地方拉伸不同），但每一点处仍是行列式那个老含义。这正是第 3 章那句「非线性变换在每一点用它的最佳线性近似（导数）来理解」的高维版本：标量函数的导数 $g'(x)$ 告诉你「这一点附近被拉伸多少」（一维体积 = 长度），向量值函数的雅可比行列式 $\det J_g$ 告诉你「这一点附近的 $n$ 维体积被拉伸多少」。微积分里的链式法则 $J_{f\circ g}=J_f\,J_g$ 配合行列式乘性 $\det(AB)=\det A\det B$，立刻给出 $\det J_{f\circ g}=\det J_f\cdot\det J_g$——**复合变换的体积缩放 = 各步体积缩放之积**，这正是 §6.2.3 归一化流把对数似然写成「各步对数雅可比之和」的根据。

### 6.2.2 概率密度的变量替换：质量守恒，密度按体积反缩放

这是雅可比行列式在概率里的核心用途。《概率与统计》第 2 章 §2.5 讲过一维情形：$Y=g(X)$，$f_Y(y)=f_X(x)/|g'(x)|$。多维版本就是把 $1/|g'|$ 换成 $1/|\det J_g|$：

> **多维变量替换公式。** 设 $\mathbf X$ 有密度 $f_{\mathbf X}$，$g$ 是可微双射（diffeomorphism），$\mathbf Y=g(\mathbf X)$。则
> $$\boxed{f_{\mathbf Y}(\mathbf y)=f_{\mathbf X}(\mathbf x)\,\bigl|\det J_g(\mathbf x)\bigr|^{-1}=f_{\mathbf X}\!\bigl(g^{-1}(\mathbf y)\bigr)\,\bigl|\det J_{g^{-1}}(\mathbf y)\bigr|.}$$

直觉是**概率质量守恒**：变换前后落在对应小区域里的概率必须相等，$f_{\mathbf Y}(\mathbf y)\,\mathrm d\mathbf y=f_{\mathbf X}(\mathbf x)\,\mathrm d\mathbf x$。既然变换把体积放大了 $|\det J_g|$ 倍（$\mathrm d\mathbf y=|\det J_g|\,\mathrm d\mathbf x$），同样多的概率质量被摊到更大的体积上，密度就要**除以**这个体积因子——**拉得越开，密度越稀**。这正是 §6.1「行列式 = 体积缩放」与「概率密度 = 单位体积的概率」两件事的相乘。

> **CS 读者陷阱（变换密度必须乘雅可比行列式，漏了它积分就不是 1）**：初学者最常犯的错是写 $f_{\mathbf Y}(\mathbf y)=f_{\mathbf X}(g^{-1}(\mathbf y))$，**漏掉 $|\det J|$ 因子**。这会让你的「密度」积分不等于 1，是手推归一化流、在 MCMC 里换坐标算接受率时的头号杀手（《概率与统计》第 2 章 §2.5 同样三令五申）。记忆口诀：**密度是「每单位体积的概率」，换坐标改变了体积的尺度，所以密度必须按体积反缩放。**

### 6.2.3 归一化流：把雅可比行列式变成生成模型的引擎

现在到了与你研究最直接的连接。**归一化流（normalizing flow）** 是一类生成模型：它用一串可逆可微变换 $g=g_K\circ\cdots\circ g_1$，把一个简单的基分布（通常是标准高斯 $\mathbf z\sim\mathcal N(0,I)$）变形成复杂的目标分布（比如「合理的蛋白构象 / 骨架」的分布）。要训练它（最大化数据的对数似然），就必须能算出变换后样本的密度——而这正是变量替换公式。对组合变换，行列式的乘性（$\det(AB)=\det A\det B$，§6.1）让对数似然变成各步对数雅可比行列式之和：

$$
\log p_{\mathbf x}(\mathbf x)=\log p_{\mathbf z}(\mathbf z)-\sum_{k=1}^{K}\log\bigl|\det J_{g_k}\bigr|.
$$

> **与你的研究的连接（归一化流与 Boltzmann generator）**：归一化流是生成式蛋白 / 分子设计的一条重要技术线。最著名的是 **Boltzmann generator**（Noé et al., *Science* 2019，《概率与统计》第 10 章也提到）：它训练一个归一化流，把高斯噪声映成蛋白 / 分子的构象，使得生成样本服从**玻尔兹曼分布** $p(\mathbf x)\propto e^{-\beta E(\mathbf x)}$——于是可以**一步采样**热力学系综，绕过 MD/MCMC 漫长的遍历。整个方法能成立，全靠「能精确算出每个生成构象的密度」，而那就是变量替换 + 雅可比行列式。这也是为什么归一化流的架构设计（耦合层 coupling layer、自回归流）都在追求一件事：**让雅可比矩阵是三角的，从而 $\det$ = 对角元之积，$O(n)$ 可算**——否则 $O(n^3)$ 的行列式会拖垮训练。你看，§6.1.2 那条「三角矩阵行列式 = 对角元之积」在这里直接决定了一个生成模型能不能跑得动。

> **诚实的边界（雅可比要求可逆 + 同维，扩散模型走了另一条路）**：变量替换公式要求 $g$ 是**同维可微双射**——输入输出维度必须相同、必须可逆。这限制了归一化流的表达力（不能降维、每层都要可逆）。正因如此，后来的**扩散模型（diffusion model）**（《蛋白质折叠》第 9 章的 RFdiffusion）放弃了「精确算密度」，改用得分匹配 / 随机微分方程，不再需要算雅可比行列式——表达力更强，但失去了精确似然。所以「雅可比行列式」是归一化流这一支的命门，却不是所有生成模型的必需品。知道哪类模型靠它、哪类不靠它，是读这片文献的基本盘。

> **给数学 / CS 读者的视角（雅可比行列式 = 自动微分能拿到的「局部体积变化率」）**：在 PyTorch / JAX 里，雅可比矩阵就是 `jacobian(g)(x)`，对它取 `logabsdet`（`torch.linalg.slogdet`）就是变量替换里要的那一项。`slogdet` 返回 `(sign, logabsdet)`——直接给对数绝对行列式，避免行列式本身上溢 / 下溢（高维时 $\det$ 动辄 $10^{\pm100}$，必须在对数域算，呼应 §6.1.3 数值边界）。理解了这一点，你读归一化流代码时那一行 `log_det_jacobian` 就不再神秘：它就是 §6.2.1 的局部体积缩放，在对数域、用自动微分算出来的。

> **要点（§6.2）**：雅可比矩阵 = 非线性变换的局部线性近似（列 = 各方向的像），其行列式 = **局部体积缩放因子**。多维变量替换：$f_{\mathbf Y}(\mathbf y)=f_{\mathbf X}(\mathbf x)|\det J_g|^{-1}$（质量守恒，密度按体积反缩放，**必须乘雅可比，否则积分≠1**）。归一化流靠它精确算似然（对数似然 = 基分布对数密度 − 各步对数雅可比行列式之和），是生成式蛋白设计（Boltzmann generator）的引擎；架构追求三角雅可比让 $\det=O(n)$ 可算。扩散模型走另一条路、不用雅可比。

## 6.3 特征值与特征向量：变换里「不转向」的方向

现在请出本章——也是全课暗线二——的真正主角。前面行列式告诉我们「变换把体积放大多少」，是一个整体的标量。但一个变换在**不同方向**上做的事情可以完全不同：某些方向被狠狠拉长、某些方向被压扁、某些方向被转向。**特征向量 / 特征值** 就是用来精确刻画「哪些方向被变换以最简单的方式（只缩放、不转向）对待」的工具。这是从「数表」到「本征结构」的观念跃迁。

### 6.3.1 定义：被变换只拉伸、不改变方向的向量

> **定义（特征值 / 特征向量）。** 设 $A$ 是 $n\times n$ 方阵。若存在**非零**向量 $\mathbf v\ne\mathbf 0$ 和标量 $\lambda$ 使得
> $$\boxed{A\mathbf v=\lambda\mathbf v,}$$
> 则称 $\mathbf v$ 是 $A$ 的**特征向量（eigenvector）**，$\lambda$ 是对应的**特征值（eigenvalue）**。

读这个方程的正确方式是几何的：**$A\mathbf v$（把 $\mathbf v$ 经变换后的像）与 $\mathbf v$ 共线**——变换没有改变 $\mathbf v$ 的方向（顶多反向，若 $\lambda<0$），只把它拉伸 / 压缩了 $\lambda$ 倍。绝大多数向量被 $A$ 一作用就既转向又改变长度；而特征向量是那些「特立独行」的方向：**变换对它们而言退化成了一个纯粹的数乘 $\lambda$。** 这就是为什么它们叫「特征」（eigen，德语「自有的、本征的」）——它们是这个变换**自己固有的、不依赖坐标系**的方向。

ASCII 直觉（一个把 $x$ 方向拉 2 倍、$y$ 方向拉 0.5 倍的对角变换 $A=\mathrm{diag}(2,0.5)$）：

```
   一般向量 u 被转向了              特征向量沿坐标轴，只被缩放
        Au                          
         \                          e1 ---->  2·e1   (λ=2, 方向不变)
          \                         
   u ------\                        e2 |       e2 |   缩到一半
            \                          |  --->     ·   (λ=0.5, 方向不变)
   (方向变了)                          v           v
```

注意几个要点：
- 特征向量**只定方向，不定长度**：若 $A\mathbf v=\lambda\mathbf v$，则任意 $c\ne0$ 都有 $A(c\mathbf v)=\lambda(c\mathbf v)$。所以「一个特征值对应的是一整条方向线（一维特征子空间）」，通常我们取单位长度的代表。
- 特征值**可以是 0**（$A\mathbf v=0\cdot\mathbf v=\mathbf 0$，即 $\mathbf v\in\mathcal N(A)$，零空间方向）；**$\lambda=0$ 是特征值 $\iff A$ 奇异 $\iff\det A=0$**——这把 §6.1 的可逆判据接到了谱上。
- 特征值**可以是负数**（方向反转）、甚至**复数**（§6.6，对应旋转）。

还有一个常被忽略却极重要的直觉，值得专门强调：**特征值 / 特征向量是「变换本身」的属性，与你用什么坐标系无关。** 矩阵 $A$ 写出来的那些数字会随基的选择而变（同一个变换换套基就是另一个矩阵，第 3 章的相似），但它的特征值集合（谱）、它的不变方向，是钉死在变换里的客观事实——这就是「eigen（本征 / 自有的）」一词的分量。这一点是暗线一（矩阵 = 变换）与暗线二（谱）交汇的核心：**当你想问「这个变换究竟在干什么」，不要盯着矩阵里的数字看，要去找它的谱。** 谱是变换的「指纹」，比任何具体的矩阵表示都更接近它的本质。后面的对角化（§6.4）正是把这个「指纹」明明白白摆出来的操作。

> **建议现在打开 `06_eigen_explorer.html` 边读边玩。** 这个交互页面让你拖动改变一个 $2\times2$ 矩阵的元素，实时看到：一个随你旋转的「探针向量」何时与它的像 $A\mathbf v$ 共线（那一刻它就落在了特征方向上）、特征方向如何「钉」在平面里不随你乱转、以及当矩阵变成旋转时特征方向如何「消失」（变复，§6.6）。亲手感受「特征向量 = 被钉住的方向」一次，胜过读十遍定义。有几个值得你亲手验证的现象：把矩阵调成对称（让两个非对角元相等），你会看到两条特征方向**总是互相垂直**（谱定理，§6.6）；把它调成纯旋转，两条特征方向**一起消失**（复特征值，无实不变方向）；把某一列调成另一列的倍数（行列式变 0），你会看到一条特征方向对应的拉伸因子**变成 0**（那条方向被压进了零空间）。这三个现象分别对应本章 §6.6、§6.6、§6.1.2 的三个核心结论——玩出来比读出来记得牢。

### 6.3.2 怎么找：特征多项式 $\det(A-\lambda I)=0$

怎么把满足 $A\mathbf v=\lambda\mathbf v$ 的 $\lambda$ 和 $\mathbf v$ 找出来？把方程改写成

$$
A\mathbf v=\lambda\mathbf v\iff (A-\lambda I)\mathbf v=\mathbf 0.
$$

这是一个齐次线性方程组。它有**非零解 $\mathbf v$**（我们要的就是非零特征向量）当且仅当系数矩阵 $A-\lambda I$ **奇异**——由 §6.1 的可逆判据，这恰好是

> **特征方程（characteristic equation）。**
> $$\boxed{\det(A-\lambda I)=0.}$$
> 左边 $p(\lambda)=\det(A-\lambda I)$ 是关于 $\lambda$ 的 $n$ 次多项式，称为 **特征多项式（characteristic polynomial）**。它的根就是 $A$ 的全部特征值；这 $n$ 个根（含重数、含复根）的集合称为 $A$ 的**谱（spectrum）**。

找特征向量的两步法：(1) 解 $\det(A-\lambda I)=0$ 得到各 $\lambda$；(2) 对每个 $\lambda$，解齐次方程 $(A-\lambda I)\mathbf v=\mathbf 0$，求出零空间（即该 $\lambda$ 的**特征子空间（eigenspace）**）。

**$2\times2$ 例子。** 取 $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$。

$$
\det(A-\lambda I)=\det\begin{bmatrix}2-\lambda&1\\1&2-\lambda\end{bmatrix}=(2-\lambda)^2-1=\lambda^2-4\lambda+3=(\lambda-1)(\lambda-3).
$$

特征值 $\lambda_1=3,\ \lambda_2=1$。对 $\lambda_1=3$：$(A-3I)\mathbf v=\begin{bmatrix}-1&1\\1&-1\end{bmatrix}\mathbf v=\mathbf 0\Rightarrow\mathbf v_1\propto(1,1)^T$。对 $\lambda_2=1$：$\begin{bmatrix}1&1\\1&1\end{bmatrix}\mathbf v=\mathbf 0\Rightarrow\mathbf v_2\propto(1,-1)^T$。

注意 $\mathbf v_1\perp\mathbf v_2$（$(1,1)\cdot(1,-1)=0$）——这不是巧合：$A$ 对称，而**对称矩阵的特征向量可取正交**（第 7 章谱定理的核心，§6.6 预告）。这个 $A$ 的几何画面：沿 $(1,1)$ 方向（主对角线）拉 3 倍、沿 $(1,-1)$ 方向（反对角线）拉 1 倍——一个沿斜轴的拉伸。

> **代数重数 vs 几何重数。** 一个特征值 $\lambda$ 在特征多项式中作为根的重数叫**代数重数（algebraic multiplicity）**；它对应的特征子空间 $\mathcal N(A-\lambda I)$ 的维数叫**几何重数（geometric multiplicity）**——即「独立特征向量个数」。永远有 $1\le$ 几何重数 $\le$ 代数重数。两者相等与否，决定了矩阵能否对角化（§6.4）。

> **CS 读者陷阱（别真去解特征多项式找特征值）**：特征多项式是**定义性**工具（理解「特征值 = 特征方程的根」），但**不是计算工具**。原因：(1) 五次及以上多项式没有求根公式（Abel–Ruffini 定理），$n\ge5$ 时根本没有解析解；(2) 多项式求根对系数极度病态（Wilkinson 的著名反例），数值上灾难。实际的特征值算法（QR 迭代、用于对称阵的 Jacobi / 分而治之、用于少数极端特征值的幂法 / Lanczos，第 9 章）**根本不构造特征多项式**，而是用一系列正交相似变换把矩阵逐步逼成（拟）三角 / 对角形。`np.linalg.eig`（一般阵）/ `np.linalg.eigh`（对称 / Hermite 阵，更快更稳）背后是 LAPACK 的这些迭代法。**手算特征多项式只在 2×2、3×3 的教学例子里做；真实矩阵交给 `eigh`。**

> **与你的研究的连接（特征向量 = 不变方向，是后面一切「主方向」的母概念）**：「被变换只缩放、不转向的方向」这个朴素几何概念，是你研究里几乎所有「主方向 / 模式」的母体——(1) **协方差矩阵的特征向量 = 数据涨落的主轴（PCA，第 8 章）**：分子动力学（MD）轨迹的协方差矩阵，其大特征值对应的特征向量就是蛋白的**主要构象运动方向（essential dynamics）**；(2) **Hessian 的特征向量 = 简正模式（normal mode，第 7 章）**：势能面在极小点的二阶导矩阵（Hessian）的特征向量是蛋白的振动 / 集体运动模式，小特征值（软方向）= 低频集体运动（呼吸、铰链开合）；(3) **图拉普拉斯的特征向量 = 图的「振动模式」/ 谱聚类坐标**：把蛋白残基接触网络当图，其拉普拉斯矩阵的低频特征向量能揭示结构域划分（domain decomposition）。这三者在第 7、8 章会展开，但它们共用的就是本节这一个定义：**特征向量是变换 / 算子自己固有的、不随坐标系变的特殊方向。** 把这个直觉焊牢，后面全是它的变奏。

> **要点（§6.3）**：特征向量 $\mathbf v$ 是被 $A$ **只缩放（×$\lambda$）、不转向**的非零方向，$\lambda$ 是缩放倍数（可负、可零、可复）。$\lambda=0\iff A$ 奇异。找法：$\det(A-\lambda I)=0$（特征方程，根的集合 = 谱）求 $\lambda$，再解 $(A-\lambda I)\mathbf v=\mathbf 0$ 求 $\mathbf v$；但这只是**定义性**工具，**真实计算用 `np.linalg.eig/eigh`（QR 迭代等），绝不解多项式**。对称阵特征向量正交（第 7 章）。特征向量是 PCA 主轴、简正模式、图谱坐标的共同母概念。

## 6.4 对角化：换到特征基，看同一个变换变成纯缩放

特征向量真正的威力在于：如果一个变换有「足够多」独立的特征向量，我们就能**换一套坐标系（用特征向量当基）**，让这个本来复杂的变换在新坐标下变成最简单的样子——**沿各坐标轴的纯缩放（对角矩阵）**。这就是对角化，是「同一个线性变换在不同基下长相不同」（第 3 章相似变换思想）的最优雅运用。

### 6.4.1 $A=PDP^{-1}$：相似变换的几何意义

> **对角化（diagonalization）。** 若 $A$（$n\times n$）有 $n$ 个**线性无关**的特征向量 $\mathbf v_1,\dots,\mathbf v_n$（对应特征值 $\lambda_1,\dots,\lambda_n$），把它们作为列拼成 $P=[\mathbf v_1\ \cdots\ \mathbf v_n]$，把特征值放进对角阵 $D=\mathrm{diag}(\lambda_1,\dots,\lambda_n)$，则
> $$\boxed{A=PDP^{-1},\qquad\text{等价地}\quad P^{-1}AP=D.}$$
> 此时称 $A$ **可对角化（diagonalizable）**。

证明骨架：$AP=A[\mathbf v_1\cdots\mathbf v_n]=[\lambda_1\mathbf v_1\cdots\lambda_n\mathbf v_n]=[\mathbf v_1\cdots\mathbf v_n]\,\mathrm{diag}(\lambda_i)=PD$；因 $P$ 列无关故可逆，右乘 $P^{-1}$ 得 $A=PDP^{-1}$。$\square$

这个分解的几何读法是本节的灵魂。$A\mathbf x=PDP^{-1}\mathbf x$ 是三步复合，从右往左读：

```
   x  --P^{-1}-->  [换坐标：把 x 用特征基表示]  --D-->  [在特征基里沿各轴纯缩放]  --P-->  [换回标准坐标]
```

- **$P^{-1}$**：把向量从标准坐标「翻译」成「用特征向量当基」的坐标——问「$\mathbf x$ 在各特征方向上各占多少」。
- **$D$**：在特征基这套坐标里，变换是最简单的——第 $i$ 个特征方向的分量乘以 $\lambda_i$，**各方向互不干扰、纯缩放**。
- **$P$**：把缩放后的结果翻译回标准坐标。

> **一句话总结对角化。** **对角化 = 找到一套「正确的坐标系」（特征基），在这套坐标里，那个看似复杂的线性变换其实只是沿各坐标轴的独立拉伸。** $D$ 是这个变换「素颜」的样子，$P$ 只是化妆（坐标系）。换坐标不改变变换本身（这叫**相似（similar）**：$A$ 与 $D$ 相似，是同一个变换在不同基下的两个矩阵），但能让它的结构一目了然。这是暗线一（矩阵 = 变换）与暗线二（谱）的交汇点。

相似的矩阵共享所有「不依赖坐标系」的量：相同的特征值、相同的行列式（$\det A=\det D=\prod\lambda_i$）、相同的迹（$\mathrm{tr}A=\mathrm{tr}D=\sum\lambda_i$，§6.5）、相同的秩。这些叫**相似不变量（similarity invariant）**——它们是变换的「真实属性」，与你用什么坐标系无关。

> **诚实的边界（对角化是「解耦」，但只解耦线性变换的迭代，不是万能简化）**：对角化的全部威力来自一件事——**让矩阵幂、矩阵指数、线性 ODE 这些「反复 / 连续作用同一个变换」的运算在特征基里解耦成独立标量**（§6.5 会用满这一点）。但要清醒：它对角化的是**一个固定的线性算子**。如果你的系统是非线性的、或每步用不同的矩阵（时变系统）、或你关心的不是 $A$ 的幂而是 $A$ 与别的矩阵的复杂组合，对角化未必帮得上忙——因为不同矩阵一般**不共享特征基**（除非它们对易 $AB=BA$，这是它们可同时对角化的充要条件，量子力学里「可同时测量的可观测量对易」就是这件事）。所以别把对角化当成「化简一切」的银弹；它精准地服务于「同一个线性变换反复 / 连续作用」这一类问题，而那恰好覆盖了动力系统、马尔可夫链、PCA、简正模式——你研究里最常见的一大类。知道它的适用边界，才不会在不对易、非线性的场景里硬套。

### 6.4.2 何时可对角化：特征向量够不够多

不是每个矩阵都能对角化。能否对角化的判据是：

> **可对角化判据。** $A$（$n\times n$）可对角化 $\iff$ 它有 $n$ 个线性无关的特征向量 $\iff$ **每个特征值的几何重数 = 代数重数**。

两个有用的充分条件：
1. **$n$ 个互异特征值 $\Rightarrow$ 可对角化**（不同特征值的特征向量自动线性无关，故凑齐 $n$ 个）。这是「典型」情形——随机矩阵几乎总有互异特征值，几乎总可对角化。
2. **对称（实）矩阵 $\Rightarrow$ 一定可对角化，且可用正交矩阵对角化**（$A=Q\Lambda Q^T$，$Q$ 正交）——这是第 7 章**谱定理**，是折叠研究里最重要的情形（协方差、Hessian、图拉普拉斯都对称），§6.6 预告。

### 6.4.3 不可对角化与 Jordan 标准形（只给直觉）

当某个特征值的几何重数 **小于** 代数重数时——即「该特征值按重数应该贡献那么多独立特征向量，但实际凑不齐」——矩阵就**不可对角化（defective，亏损）**。典型例子是**剪切（shear）**：

$$
A=\begin{bmatrix}1&1\\0&1\end{bmatrix}.
$$

特征多项式 $(1-\lambda)^2=0$，$\lambda=1$ 代数重数 2。但解 $(A-I)\mathbf v=\begin{bmatrix}0&1\\0&0\end{bmatrix}\mathbf v=\mathbf 0$ 只得 $\mathbf v\propto(1,0)^T$ ——**只有一条特征方向**，几何重数 1 < 代数重数 2。几何上：剪切把水平方向 $(1,0)$ 钉住不动（$\lambda=1$），但其他所有方向都被「推斜」了，没有第二条不变方向。所以它无法用「两条独立缩放方向」描述，对角化失败。

对这类亏损矩阵，能做到的「最简形式」不是对角阵，而是**Jordan 标准形（Jordan normal form）**：对角线放特征值、紧邻的上对角线放一些 1（**Jordan 块**），表示「缩放 + 一点不可消除的耦合 / 剪切」。上面的 $A$ 本身就是一个 $2\times2$ Jordan 块 $\begin{bmatrix}\lambda&1\\0&\lambda\end{bmatrix}$（$\lambda=1$）。

> **诚实的边界（Jordan 标准形理论上美、数值上几乎没用）**：Jordan 标准形在理论上完美回答了「任何方阵能化简到什么程度」，但在**数值计算里几乎不用**，原因是它**对扰动不连续**：剪切矩阵 $\begin{bmatrix}1&1\\0&1\end{bmatrix}$ 不可对角化，但把右下角扰动成 $\begin{bmatrix}1&1\\0&1+\epsilon\end{bmatrix}$（任意小 $\epsilon\ne0$）就有两个互异特征值、立刻可对角化——Jordan 结构在 $\epsilon\to0$ 时「突变」。浮点世界里你永远分不清「真的有重特征值的 Jordan 块」和「两个挨得极近的互异特征值」。所以**数值线性代数避开 Jordan，用更稳的 Schur 分解 / SVD**（第 8、9 章）。好消息是：你研究里的核心矩阵——对称的协方差、Hessian、拉普拉斯——由谱定理**一定可对角化**（且正交对角化），根本碰不到 Jordan 这块暗礁。Jordan 主要在分析非对称动力系统（如某些反应网络、含阻尼的振动）时作为理论工具出现，知道它存在、知道它意味着「缩放之外还有不可消的耦合」即可，不必深究细节。

> **给数学 / CS 读者的视角（对角化 = 找到让问题解耦的坐标系，和 SVD / PCA 同源）**：对角化的精神和你在算法里「换个表示让问题变简单」是一回事——傅里叶变换让卷积变成逐点相乘（卷积定理），是在「频率基」下对角化了卷积算子；动态规划换状态表示让转移变简单；这里换到「特征基」让线性变换变成各轴独立缩放，于是 $A^k$、$e^{tA}$、解线性 ODE 都变成对每个 $\lambda$ 单独算标量（§6.5）。一个核心区别要记住：**对角化用的 $P$ 一般不正交**（特征向量未必互相垂直），而对称矩阵的谱定理给的 $P=Q$ **正交**（第 7 章），SVD 给的更是两组正交基（第 8 章）——「能不能找到正交的好坐标」正是从一般对角化通往谱定理、SVD 的主线。**对角化是它们的'非对称、可能不正交'的祖先。**

> **要点（§6.4）**：对角化 $A=PDP^{-1}$ = **换到特征基（$P^{-1}$）→ 沿各轴纯缩放（$D$）→ 换回（$P$）**，让复杂变换显出「各方向独立拉伸」的素颜；$A$ 与 $D$ **相似**（同一变换的两副坐标长相），共享特征值 / 迹 / 行列式 / 秩等**相似不变量**。可对角化 $\iff$ 有 $n$ 个独立特征向量 $\iff$ 几何重数处处 = 代数重数；**互异特征值** 或 **对称** 是充分条件。亏损矩阵（如剪切）凑不齐特征向量，最简形是 **Jordan 标准形**（缩放 + 不可消剪切），但它对扰动不连续、数值上避开。你研究的对称核心矩阵一定可（正交）对角化。

## 6.5 迹、行列式与矩阵幂：谱决定一切的「长期行为」

有了对角化，我们能把一个矩阵的两个最常用标量量（迹与行列式）、以及它「反复作用」的长期行为，全部用谱（特征值）一句话说清。这一节是本章折叠连接最密集的一节：矩阵幂直通马尔可夫链稳态与 MCMC 收敛速度。

### 6.5.1 迹 = 特征值之和，行列式 = 特征值之积

> **两个基本恒等式。** 对任意 $n\times n$ 方阵 $A$（特征值 $\lambda_1,\dots,\lambda_n$，含重数、含复值）：
> $$\boxed{\operatorname{tr}A=\sum_i A_{ii}=\sum_i\lambda_i,\qquad \det A=\prod_i\lambda_i.}$$
> 其中 **迹（trace）** 是对角元之和。

可对角化时一行证明：$\operatorname{tr}A=\operatorname{tr}(PDP^{-1})=\operatorname{tr}(DP^{-1}P)=\operatorname{tr}D=\sum\lambda_i$（用了迹的循环性 $\operatorname{tr}(XY)=\operatorname{tr}(YX)$）；$\det A=\det(PDP^{-1})=\det P\cdot\det D\cdot\det P^{-1}=\det D=\prod\lambda_i$（用了 $\det(AB)=\det A\det B$，§6.1）。一般情形（含亏损）由特征多项式的 Vieta 公式也成立。$\square$

直觉：**行列式 = 各本征方向缩放因子之积 = 总体积缩放**（§6.1 体积含义在谱视角下的重述）；**迹 = 各本征方向缩放因子之和**，是「总缩放量」的线性度量。两者都是相似不变量，是「不看坐标、直接读谱」就能拿到的两个数。

这两个恒等式还提供了极实用的「廉价探针」：你常常**不必算出全部特征值**，就能用迹和行列式套出关于谱的信息。例如对 $2\times2$ 矩阵，特征多项式恰好是 $\lambda^2-(\operatorname{tr}A)\lambda+\det A=0$——迹和行列式直接就是两个系数，特征值是 $\lambda=\tfrac12\bigl(\operatorname{tr}A\pm\sqrt{(\operatorname{tr}A)^2-4\det A}\bigr)$，判别式 $(\operatorname{tr}A)^2-4\det A$ 的符号一眼告诉你特征值是实是复（负号 ⇒ 复 ⇒ 有旋转成分，§6.6）。又如：迹是负的意味着「特征值之和为负」，行列式是负的意味着「有奇数个负特征值」（对 $2\times2$ 即一正一负 ⇒ 鞍点，第 7 章正定性会用到）。**学会从迹和行列式「侧写」谱，是一种很省力的本事。**

> **与你的研究的连接（$\log\det\Sigma$、迹与有效维度）**：(1) 多元高斯归一化常数含 $\det\Sigma=\prod\lambda_i$（§6.1 已提），其对数 $\log\det\Sigma=\sum\log\lambda_i$ 是高斯微分熵（《信息论》第 8 章）和高斯过程边际似然的核心项——它度量了不确定性椭球的「总体积」，每个 $\log\lambda_i$ 贡献一个主轴方向的不确定度。(2) **迹常用来定义「有效维度 / 有效自由度」**：在岭回归里 $\operatorname{tr}\bigl(A(A^TA+\lambda I)^{-1}A^T\bigr)=\sum_i\frac{\sigma_i^2}{\sigma_i^2+\lambda}$ 是有效参数个数（第 5 章 §5.5 的延伸）；在 PCA 里 $\operatorname{tr}\Sigma=\sum\lambda_i$ 是「总方差」，$\lambda_k/\sum\lambda_i$ 是第 $k$ 主成分解释的方差比例（第 8 章）。**迹和行列式不是孤立的计算题，而是'把整个谱压成一个标量'的两种方式——一个用和（总量 / 熵的雏形），一个用积（体积）。**

### 6.5.2 矩阵幂 $A^k$：在特征基下就是 $\lambda^k$

「反复施加同一个变换」是动力系统、马尔可夫链、迭代算法的共同骨架，对应矩阵幂 $A^k=\underbrace{A\cdots A}_{k}$。对角化让它瞬间透明：

$$
A^k=(PDP^{-1})^k=PD^kP^{-1},\qquad D^k=\mathrm{diag}(\lambda_1^k,\dots,\lambda_n^k).
$$

中间的 $P^{-1}P$ 一对对消掉，只剩两端的 $P$ 和 $P^{-1}$ 夹着 $D^k$。而 $D$ 是对角阵，幂就是对每个对角元单独取幂——**在特征基里，「作用 $k$ 次」就是「把第 $i$ 个分量乘以 $\lambda_i^k$」。** 复杂的矩阵反复相乘，被还原成 $n$ 个独立的标量幂 $\lambda_i^k$。

把任意初始向量 $\mathbf x_0$ 按特征基展开 $\mathbf x_0=\sum_i c_i\mathbf v_i$（$c_i$ 是它在各特征方向的分量），则

$$
A^k\mathbf x_0=\sum_i c_i\,\lambda_i^k\,\mathbf v_i.
$$

这是本节的中心公式。它说：**反复作用 $A$，各特征方向上的分量按 $\lambda_i^k$ 独立地涨 / 落**——$|\lambda_i|>1$ 的方向指数增长、$|\lambda_i|<1$ 的方向指数衰减、$|\lambda_i|=1$ 的方向幅度保持。可以把它读成一句口诀：**任何线性迭代，本质上是 $n$ 条独立的几何级数（每条以一个特征值为公比）的叠加。** 矩阵反复相乘看起来纠缠不清，谱视角把它彻底拆成了互不干扰的标量动力学。

把这个写法再推一步，就得到**谱分解（spectral decomposition）** 的形式：$A^k=\sum_i\lambda_i^k\,\mathbf v_i\mathbf w_i^T$，其中 $\mathbf w_i^T$ 是 $P^{-1}$ 的第 $i$ 行（对偶 / 左特征向量），$\mathbf v_i\mathbf w_i^T$ 是一个秩-1 的「投影到第 $i$ 个特征方向」的算子。换言之，**矩阵的幂 = 各特征方向上的秩-1 投影，各自按 $\lambda_i^k$ 加权求和**。对称矩阵时 $\mathbf w_i=\mathbf v_i$（因为 $P=Q$ 正交，$P^{-1}=Q^T$），谱分解变成最干净的 $A=\sum_i\lambda_i\mathbf v_i\mathbf v_i^T$（第 7 章会反复用它，也是第 8 章 SVD $A=\sum\sigma_i\mathbf u_i\mathbf v_i^T$ 的对称特例）。这个「矩阵 = 一堆秩-1 投影的加权和」的图像，是谱视角最有生产力的心智模型之一——它让你把任何（对称）矩阵看成「沿一组主方向、各自缩放」的叠加。

### 6.5.3 线性动力系统 $\mathbf x_{t+1}=A\mathbf x_t$：谱半径决定命运

考虑离散线性动力系统 $\mathbf x_{t+1}=A\mathbf x_t$，则 $\mathbf x_t=A^t\mathbf x_0=\sum_i c_i\lambda_i^t\mathbf v_i$。长期（$t\to\infty$）行为完全由特征值的模决定。定义**谱半径（spectral radius）** $\rho(A)=\max_i|\lambda_i|$：

| 谱情形 | 长期行为 | 直觉 |
|---|---|---|
| $\rho(A)<1$（所有 $\|\lambda_i\|<1$） | $\mathbf x_t\to\mathbf 0$（**渐近稳定**） | 每步都在收缩，归于原点。 |
| $\rho(A)>1$（某 $\|\lambda_i\|>1$） | $\mathbf x_t$ 沿对应特征方向**指数爆炸** | 主导方向 = 最大 $\|\lambda\|$ 的特征向量。 |
| $\rho(A)=1$ 且**模最大特征值唯一、恰为 $\lambda=+1$（实正、单重）**，其余 $<1$ | 收敛到 $\lambda=1$ 方向的分量（**稳态**） | 其余方向衰减，留下唯一不变方向——下一节马尔可夫链的舞台。 |
| $\rho(A)=1$ 但模为 1 的特征值是 $\lambda=-1$ 或一对复数 $e^{\pm i\theta}$ | **不收敛**：持续振荡 / 转圈（不发散也不静止） | 反例 $A=\begin{bmatrix}0&1\\1&0\end{bmatrix}$（$\lambda=1,-1$，$\rho=1$）从 $(1,0)$ 出发在 $(1,0),(0,1)$ 之间永远跳动。 |

注意第三、四两行的区别很关键：**谱半径等于 1 只保证「不发散」，并不等于「收敛到稳态」。** 真正收敛到一个静止的稳态，需要那个模为 1 的特征值是**唯一的、且恰为 $\lambda=+1$（实正、单重）**；若模最大特征值是 $\lambda=-1$ 或一对单位模复数 $e^{\pm i\theta}$，那条分量会以 $(-1)^t$ 或 $e^{\pm it\theta}$ **永远振荡 / 转圈而不收敛**。这正是马尔可夫链「周期性（periodicity）」破坏收敛的代数根源——与 §6.5.4 要求的「**非周期**」前提一一对应，也正是下面 Perron–Frobenius 定理（不可约 + 非周期）所给的条件。

注意当 $t$ 很大、且**模最大特征值唯一且为实**（即 $|\lambda_1|>|\lambda_2|$、$\lambda_1\in\mathbb R$）时，$\sum_i c_i\lambda_i^t\mathbf v_i$ 被**模最大的那个特征值主导**：$\mathbf x_t\approx c_{\max}\lambda_{\max}^t\mathbf v_{\max}$（只要 $c_{\max}\ne0$）。即**系统的长期方向收敛到最大模特征值的特征向量**——无论从哪起步。这个观察直接催生了第 9 章的**幂法（power iteration）**：反复算 $\mathbf x\leftarrow A\mathbf x/\|A\mathbf x\|$，它会自动收敛到主特征向量（PageRank、谱聚类的主力算法）。**但请注意这个唯一性前提不可省**：若存在两个等模的主特征值（一对共轭复主特征值 $re^{\pm i\theta}$，或 $+\lambda$ 与 $-\lambda$ 成对），$\mathbf x_t$ 的方向不会收敛到单一向量，而是不停旋转 / 振荡——朴素幂法此时也不收敛。这正是为什么幂法常配 shift（位移）技巧、或主要用于有唯一主特征值的对称正定阵（其特征值全实，且实务中主特征值通常严格最大）。

> **给数学 / CS 读者的视角（矩阵幂 = 把递推关系'闭式求解'）**：你在算法课上见过用矩阵幂 + 快速幂在 $O(\log n)$ 算斐波那契第 $n$ 项——$\begin{bmatrix}F_{n+1}\\F_n\end{bmatrix}=\begin{bmatrix}1&1\\1&0\end{bmatrix}^n\begin{bmatrix}1\\0\end{bmatrix}$，对那个矩阵对角化（特征值是黄金比例 $\varphi$ 和 $1-\varphi$）立刻给出 Binet 闭式公式 $F_n=(\varphi^n-(1-\varphi)^n)/\sqrt5$。这正是 §6.5.2 的 $A^k=PD^kP^{-1}$ 在做的事：**对角化把'线性递推'解耦成 $n$ 个独立的几何级数 $\lambda_i^k$。** 任何线性递推 / 线性 ODE（连续版用矩阵指数 $e^{tA}=Pe^{tD}P^{-1}$，对角线是 $e^{\lambda_i t}$）都被特征值闭式化——这是谱视角在动力系统里最实用的威力。**稳定性分析（不动点附近线性化，看雅可比的特征值实部 / 模）是同一招的连续版**，你研究蛋白构象动力学、反应网络稳定性时会反复用到。

### 6.5.4 马尔可夫链稳态 = 特征值 1 的特征向量（直连 MCMC）

现在到了本章与《概率与统计》第 10 章咬合得最紧的地方。一条**马尔可夫链（Markov chain）** 由转移矩阵 $P$ 描述（$P_{ij}$ = 从状态 $i$ 转到 $j$ 的概率，每行非负、和为 1，称**随机矩阵 / stochastic matrix**）。（**记号提醒**：随机过程文献习惯用 $P$ 记转移矩阵，故本节沿用；它与 §6.4 对角化 $A=PDP^{-1}$ 里那个「特征向量矩阵 $P$」是两个完全不同的对象，请勿混淆——本节的 $P$ 一律指转移矩阵。）若用**行向量** $\boldsymbol\pi_t$ 表示 $t$ 时刻的分布，则一步演化是 $\boldsymbol\pi_{t+1}=\boldsymbol\pi_t P$，$t$ 步后 $\boldsymbol\pi_t=\boldsymbol\pi_0 P^t$——又是矩阵幂！

**稳态分布（stationary distribution）** $\boldsymbol\pi$ 是满足 $\boldsymbol\pi P=\boldsymbol\pi$ 的概率分布——演化一步不变。这恰恰说：

> **稳态 = $P^T$ 的特征值 1 的特征向量（归一化为概率）。** $\boldsymbol\pi P=\boldsymbol\pi\iff P^T\boldsymbol\pi^T=\boldsymbol\pi^T$，即 $\boldsymbol\pi^T$ 是 $P^T$ 对应特征值 $\lambda=1$ 的（右）特征向量。

为什么随机矩阵总有特征值 1？因为每行和为 1 意味着 $P\mathbf 1=\mathbf 1$（全 1 列向量 $\mathbf 1$ 是 $P$ 的特征值为 1 的右特征向量）；$P$ 与 $P^T$ 特征值相同，故 $P^T$ 也有特征值 1，其对应特征向量在 **Perron–Frobenius 条件下（见下）可取为非负**、归一化后即稳态 $\boldsymbol\pi$。准确地说：Perron–Frobenius 定理保证，对**不可约、非周期**的链，$\lambda=1$ 是**唯一的模最大特征值**（其余 $|\lambda_i|<1$）、且其特征向量可取**逐分量为正**，于是稳态**唯一存在**。注意非负性与唯一性都是 PF 在遍历条件下才给出的结论，不是无条件成立——脱离遍历前提，$P^T$ 即便有特征值 1，其特征向量也未必非负 / 唯一（详见本节末「诚实的边界」）。

把 §6.5.2 的展开用上：$\boldsymbol\pi_0 P^t=\sum_i c_i\lambda_i^t(\text{左特征向量})$。$\lambda_1=1$ 的项保持不变（= 稳态 $\boldsymbol\pi$），其余 $|\lambda_i|<1$ 的项以 $\lambda_i^t$ **指数衰减**到 0。于是**无论从哪个初始分布出发，链都指数地收敛到同一个稳态** $\boldsymbol\pi$，收敛速率由**第二大模特征值 $|\lambda_2|$** 控制：

$$
\|\boldsymbol\pi_t-\boldsymbol\pi\|\sim|\lambda_2|^{\,t}.
$$

（这里默认 $\lambda_2$ 处**可对角化**，即几何重数 = 代数重数；若转移矩阵在 $\lambda_2$ 处有 Jordan 块、几何重数 $<$ 代数重数（亏损，§6.4.3），收敛会多一个多项式因子，变成 $\sim t^{m}|\lambda_2|^t$，但仍由 $|\lambda_2|$ 主导衰减。）

> **与你的研究的连接（MCMC 收敛、混合时间、谱隙）**：这正是《概率与统计》第 10 章 MCMC 的谱地基。一个 Metropolis / Gibbs 采样器就是一条精心设计、以目标分布（如玻尔兹曼分布 $p\propto e^{-\beta E}$）为稳态的马尔可夫链。它**多久收敛**（混合时间 mixing time）由谱隙（spectral gap）$1-|\lambda_2|$ 决定：$|\lambda_2|$ 越接近 1，谱隙越小，收敛越慢——混合时间约 $\sim 1/(1-|\lambda_2|)$。蛋白构象空间的能量地形布满高能垒，把不同亚稳态「连通」的转移概率极小，导致 $|\lambda_2|$ 极度接近 1（谱隙趋零），于是 MCMC / MD **混合极慢、易困在单个模式里出不来**（《概率与统计》第 10 章反复强调的「伪收敛」核心病）。这也解释了为什么副本交换（replica exchange）有用：它通过引入高温副本增大谱隙、加速混合。**你看，「这条链多久收敛」这个采样实践里最要命的问题，答案就藏在转移矩阵的第二特征值里——这是谱视角对你最直接的一次馈赠。** 《概率与统计》第 10 章 §10.3.5 那个 $2\times2$ 例子里 $\lambda_2=0.7$ 控制收敛速度，正是本节的具体兑现。

> **与你的研究的连接（PageRank 一瞥）**：同一个数学也是 Google 的 PageRank：网页 = 状态，超链接 = 转移，加一点「随机跳转」保证不可约非周期；网页的重要性排名 = 这条链的**稳态分布** = 转移矩阵特征值 1 的特征向量，用**幂法**（§6.5.3）迭代求出。在生物里同样的「随机游走稳态 = 节点重要性」思想用于**蛋白相互作用网络 / 代谢网络的关键节点识别**（network propagation、扩散度量），底层都是「随机矩阵的主特征向量」。一个谱概念，横跨网页排序、蛋白网络、采样收敛。

> **诚实的边界（稳态存在与唯一需要条件，别默认）**：「链一定收敛到唯一稳态」要求**不可约（任意状态间可达）+ 非周期（不卡在固定循环里）**（合称遍历 ergodic）。若链可约（构象空间被高能垒切成互不连通的块），就有多个稳态、初始决定终点（这正是 MD 困在亚稳态的数学画像）；若周期，分布会震荡不收敛。$P^T$ 即便有特征值 1，其特征向量也未必非负 / 唯一——非负性 / 唯一性是 Perron–Frobenius 在遍历条件下的额外保证。**所以看到「稳态 = 特征值 1 特征向量」时，别忘了它背后那串遍历前提；折叠模拟里这些前提常常实质性地不满足，这恰是采样难题的根源。**

> **要点（§6.5）**：**迹 = 特征值之和**（总缩放 / 总方差 / 有效维度），**行列式 = 特征值之积**（总体积，$\log\det=\sum\log\lambda$ 进熵 / 边际似然），都是相似不变量。**矩阵幂 $A^k=PD^kP^{-1}$**：在特征基里反复作用 = 各分量乘 $\lambda_i^k$，$A^k\mathbf x_0=\sum c_i\lambda_i^k\mathbf v_i$。线性动力系统长期行为由**谱半径** $\rho=\max|\lambda_i|$ 定（<1 收敛、>1 爆炸、=1 稳态），长期方向 → 主特征向量（催生**幂法**，第 9 章）。**马尔可夫链稳态 = 转移矩阵特征值 1 的特征向量**；收敛由**第二特征值 $|\lambda_2|$ / 谱隙**控制 → 直连 MCMC 混合时间、蛋白采样困局、PageRank。稳态需遍历前提。

## 6.6 复特征值 = 旋转：实矩阵也能有「虚」本征结构

最后一节回答一个细心读者一定会问的问题：如果特征向量是「被变换不转向的方向」，那**纯旋转**怎么办？旋转把每个方向都转走了，岂不是没有特征向量？答案揭示了实特征值理论的边界，也为第 7 章谱定理（对称矩阵特征值必为实）划清了对照。

### 6.6.1 2D 旋转：实数里找不到不变方向，复数里找得到

平面旋转 $\theta$ 角的矩阵是

$$
R_\theta=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}.
$$

求特征值：$\det(R_\theta-\lambda I)=(\cos\theta-\lambda)^2+\sin^2\theta=\lambda^2-2\cos\theta\,\lambda+1=0$，解得

$$
\lambda=\cos\theta\pm i\sin\theta=e^{\pm i\theta}.
$$

只要 $\theta\ne0,\pi$，特征值就是一对**共轭复数**，没有实特征值——这与几何直觉完全吻合：**真正的旋转（非 0、非 180°）不存在被钉住的实方向，转动把每条实直线都转走了。** 实特征向量「消失」了，但在复数域 $\mathbb C^2$ 里特征结构依然存在：$e^{\pm i\theta}$ 这对复特征值，其**模 $|\lambda|=|e^{\pm i\theta}|=1$ 编码了「旋转不改变长度」（等距），辐角 $\theta$ 编码了「转了多少角度」**。

> **复特征值的几何意义。** 实矩阵的复特征值总成共轭对 $a\pm bi=re^{\pm i\theta}$，对应一个**二维实不变子空间**，在其中变换**相似于** $rR_\theta$——即在**某个适当（一般非正交）的实基**下，它精确等于「旋转 $\theta$ + 缩放 $r$」。$r=|\lambda|>1$ 向外螺旋发散、$r<1$ 向内螺旋收敛、$r=1$ 纯旋转（如 $R_\theta$）。**两点需说清楚**：(1) 在原始（标准）度量下，这个变换一般表现为「旋转 + 缩放 + 各向异性拉伸」，轨道是**椭圆螺旋**而非正圆，标准坐标里看到的逐圈转角也不一定等于 $\theta$；模 $r$ 仍是每圈的整体伸缩、辐角 $\theta$ 仍是「代数转速」（每步在那个非正交基里转过的角）。(2) 只有对**正规 / 正交矩阵**（如 $R_\theta$ 本身）才是标准意义下、在标准正交基里的**纯旋转 + 等比缩放**。即便如此，**复特征值仍是线性变换里「旋转 / 振荡 / 周期」成分的可靠指纹**：哪里有复特征值，哪里就有转动 / 周期行为。

> **给数学 / CS 读者的视角（复特征值 = 振荡 / 周期，欧拉公式把旋转和指数缝在一起）**：在动力系统 $\mathbf x_{t+1}=A\mathbf x_t$ 里，实特征值给单调增 / 减（$\lambda^t$），复特征值 $re^{i\theta}$ 给 $r^t(\cos t\theta\pm i\sin t\theta)$——**带衰减 / 增长包络的振荡**（阻尼 / 反阻尼振子）。这正是信号处理里「极点在单位圆内 = 稳定、在圆上 = 等幅振荡、在圆外 = 发散」的同一套语言（$z$ 变换的极点 = 系统矩阵的特征值）。$e^{\pm i\theta}$ 通过欧拉公式 $e^{i\theta}=\cos\theta+i\sin\theta$ 把「旋转」和「指数」缝成一体，这也是傅里叶分析的根：复指数 $e^{i\omega t}$ 是平移算子（一种特殊'旋转'）的特征函数。蛋白的振动模式（简正模式，第 7 章）、MD 里的周期 / 准周期运动，谱里都带着这种「旋转」结构。**看到复特征值，就该想到'这里有转动 / 振荡 / 周期'。**

### 6.6.2 对照与预告：对称矩阵的特征值必为实

旋转矩阵不对称（$R_\theta^T=R_{-\theta}\ne R_\theta$），它有复特征值。这恰好反衬出一个深刻而美好的事实，是第 7 章的核心：

> **谱定理预告（第 7 章）。** **实对称矩阵 $A=A^T$ 的特征值必为实数，且特征向量可取为一组标准正交基**——存在正交矩阵 $Q$（$Q^TQ=I$）使 $A=Q\Lambda Q^T$，$\Lambda$ 为实对角阵。即对称矩阵不仅一定可对角化（§6.4），还能**正交对角化**：它的本征方向互相垂直，变换 = 沿一组正交主轴的纯（实）缩放，**没有任何旋转成分**。

一句话对照：**对称 = 纯缩放（实特征值、正交特征向量、无旋转）；反对称 / 旋转 = 纯旋转（纯虚 / 单位模复特征值）；一般矩阵 = 缩放 + 旋转 + 剪切的混合。** 矩阵的「对称程度」直接决定了它的谱长什么样。

> **与你的研究的连接（为什么折叠里的核心矩阵都对称、都能正交对角化）**：你研究里真正反复出现的矩阵——**协方差矩阵 $\Sigma$**（MD 涨落 / PCA，第 8 章）、**精度矩阵 $\Sigma^{-1}$**（DCA 接触预测的直接耦合，《概率与统计》第 5 章）、**Hessian**（势能面二阶展开 / 简正模式，第 7 章）、**图拉普拉斯**（残基网络谱、结构域划分）、**Gram 矩阵 / 核矩阵**（内积结构，第 4 章）——**全都是对称的**。这绝非巧合：它们要么来自二次型（能量、方差都是二次的）、要么来自对称的成对关系（距离、相关、接触）。谱定理保证它们的特征值**全是实数**（可以谈「大 / 小」「正 / 负」，于是能定义正定性、能排序找主成分）、特征向量**互相正交**（可以当作一套干净的新坐标轴）。**正因为对称、正因为谱定理，PCA 的主轴才正交、简正模式才解耦、正定性判据才成立**——这是第 7、8 章一切「谱方法」能用的根本前提。本章 §6.6 这个「复特征值 = 旋转、对称 = 无旋转」的对照，就是为理解「为什么你最关心的矩阵这么'好'」铺的最后一块砖。

> **诚实的边界（非对称矩阵在折叠里也存在，且'好性质'随之消失）**：不要以为所有矩阵都对称。**转移矩阵 $P$**（马尔可夫链 / MCMC，§6.5.4）一般**不对称**（从 $i$ 到 $j$ 和从 $j$ 到 $i$ 的概率不等），所以它的特征值可以是复数（链可能有「转圈」倾向）、特征向量不正交、左右特征向量要分开谈。满足**细致平衡**的可逆链可经对称化（用稳态 $\pi$ 做相似变换）变成对称问题、特征值才保证为实——这是 MCMC 理论里用谱分析收敛的关键技巧（《概率与统计》第 10 章）。同理 AlphaFold 注意力里的 $QK^T$ 一般不对称。**所以：对称带来'实谱 + 正交 + 可排序'的全部好处，是该珍惜的特例；遇到非对称矩阵（转移、注意力、非保守动力学），要做好'复特征值、不正交、左右有别'的心理准备。** 分清手上的矩阵对不对称，是用谱工具前的第一道体检。

> **要点（§6.6）**：实矩阵可有**复特征值**，必成共轭对 $re^{\pm i\theta}$，几何上 = **旋转 $\theta$ + 缩放 $r$**（模 = 缩放、辐角 = 转角；单位模 = 纯旋转 / 等距）——是变换里「旋转 / 振荡 / 周期」成分的指纹。2D 旋转 $R_\theta$ 特征值 $e^{\pm i\theta}$，无实不变方向（旋转转走了一切实方向）。对照 **第 7 章谱定理**：**实对称矩阵特征值必为实、特征向量可正交（$A=Q\Lambda Q^T$）、无旋转成分**——这正是折叠核心矩阵（协方差、精度、Hessian、拉普拉斯、Gram）都「好」的根本原因。非对称矩阵（转移、注意力）则失去这些好处，要小心对待。

## 本章小结

- **行列式 = 有向体积缩放因子**：单位立方体经变换后的（带符号）体积；符号 = 是否翻转定向，0 = 压扁降维。由「多线性 + 交替 + 归一化」三公理唯一确定。关键性质 $\det(AB)=\det A\det B$（复合 = 缩放之积）、$\det A=\prod\lambda_i$。可逆判据 $\det A\ne0\iff$ 可逆 $\iff$ 满秩。计算走 LU（$O(n^3)$）不用余子式（$O(n!)$）；**判病态 / 奇异看条件数不看行列式**。（§6.1）
- **雅可比行列式 = 非线性变换的局部体积缩放**。多维变量替换 $f_{\mathbf Y}(\mathbf y)=f_{\mathbf X}(\mathbf x)|\det J_g|^{-1}$（质量守恒、密度按体积反缩放，**必须乘雅可比否则积分≠1**）。**归一化流**靠它精确算对数似然（= 基分布对数密度 − 各步对数雅可比之和），是生成式蛋白设计（Boltzmann generator）的引擎；架构追求三角雅可比让 $\det=O(n)$。扩散模型走另一条路、不用雅可比。（§6.2）
- **特征向量 = 被变换只缩放（×$\lambda$）、不转向的非零方向**，$\lambda$ = 缩放倍数（可负、可零 ⇔ 奇异、可复）。求法：$\det(A-\lambda I)=0$（特征方程，根集 = 谱）→ 解 $(A-\lambda I)\mathbf v=\mathbf 0$；但这是**定义性**工具，**真实计算用 `eig/eigh`，不解多项式**。代数重数 ≥ 几何重数。是 PCA 主轴、简正模式、图谱坐标的母概念。（§6.3）
- **对角化 $A=PDP^{-1}$ = 换到特征基看变换变成纯缩放**（$P^{-1}$ 换坐标 → $D$ 各轴缩放 → $P$ 换回）；$A$ 与 $D$ **相似**，共享特征值 / 迹 / 行列式 / 秩等**相似不变量**。可对角化 $\iff$ 有 $n$ 个独立特征向量 $\iff$ 几何重数 = 代数重数；**互异特征值** 或 **对称** 是充分条件。亏损矩阵（剪切）最简形是 **Jordan 标准形**（缩放 + 不可消剪切），对扰动不连续、数值上避开。（§6.4）
- **迹 = 特征值之和、行列式 = 特征值之积**（相似不变量；$\operatorname{tr}\Sigma$ = 总方差、$\log\det\Sigma=\sum\log\lambda$ 进熵 / 边际似然）。**矩阵幂 $A^k=PD^kP^{-1}$**：特征基里 = 各分量乘 $\lambda_i^k$。线性动力系统长期行为由**谱半径** $\rho=\max|\lambda_i|$ 定（<1 收敛 / >1 爆炸 / =1 稳态），长期方向 → 主特征向量（催生**幂法**，第 9 章）。**马尔可夫链稳态 = 转移矩阵特征值 1 的特征向量**，收敛由**第二特征值 $|\lambda_2|$ / 谱隙**控制 → MCMC 混合时间、蛋白采样困局、PageRank。需遍历前提。（§6.5）
- **复特征值 = 旋转**：实矩阵复特征值成共轭对 $re^{\pm i\theta}$，几何上 = 旋转 $\theta$ + 缩放 $r$（旋转 / 振荡 / 周期的指纹）；2D 旋转 $R_\theta$ 特征值 $e^{\pm i\theta}$ 无实不变方向。对照 **第 7 章谱定理**：实对称矩阵特征值必为实、特征向量可正交、无旋转——这是折叠核心矩阵（协方差 / 精度 / Hessian / 拉普拉斯 / Gram）都「好」的根本原因；非对称矩阵（转移、注意力）失去这些好处。（§6.6）

## 动手 / 思考小练习

> 编程题用 `numpy`（可选 `matplotlib`）。建议先自己推 / 写，再看答案要点。配合交互页面 `06_eigen_explorer.html` 玩特征方向。

**1.（思考·行列式的几何）** 不算具体数值，仅凭几何判断下列 $2\times2$ 矩阵的行列式是正、负还是 0，并说明它对单位正方形做了什么：(a) $\begin{bmatrix}3&0\\0&2\end{bmatrix}$；(b) $\begin{bmatrix}0&1\\1&0\end{bmatrix}$；(c) $\begin{bmatrix}1&2\\2&4\end{bmatrix}$；(d) 旋转 $R_{30°}$。（巩固 §6.1.1–§6.1.2）

*参考答案*：(a) $\det=6>0$，把正方形拉成 $3\times2$ 矩形（保定向、面积×6）；(b) $\det=-1<0$，交换 $x,y$ 轴 = 沿对角线镜像（**翻转定向**，面积不变）；(c) 第 2 列 = 2×第 1 列，列相关，$\det=0$，把平面压扁成一条直线（面积塌成 0、奇异）；(d) $\det=\cos^2+\sin^2=1>0$，纯旋转保面积保定向。**为什么**：行列式的符号读「定向是否翻转」、绝对值读「面积缩放」、0 读「降维压扁」——全是几何，不必硬算。*延伸思考*：(c) 这种「$\det=0$ = 列相关 = 压扁」正是第 5 章「秩亏 / 奇异」的几何面貌，也是 $\lambda=0$ 是特征值（零空间非平凡）的来源。

**2.（动手·行列式数值陷阱）** 取 $A=0.01\cdot I_{50}$（$50\times50$）。用 `np.linalg.det(A)` 算行列式、`np.linalg.cond(A)` 算条件数。行列式有多小？条件数是多少？据此说明「行列式小 ≠ 病态」。再造一个真正病态的矩阵（如 `np.diag([1, 1e-10])`）对比两者。（巩固 §6.1.3 边界）

*答案要点*：$\det(0.01 I_{50})=0.01^{50}=10^{-100}$（极小，甚至下溢），但 $\kappa(0.01 I)=1$（完美良态，所有奇异值相等）。而 `diag([1,1e-10])` 的 $\det=10^{-10}$（不算特别小），$\kappa=10^{10}$（严重病态）。**为什么**：行列式对整体缩放 $c^n$ 极敏感，与可逆 / 病态程度脱钩；判病态只能看条件数 $\sigma_{\max}/\sigma_{\min}$。*延伸思考*：高维时 $\det$ 动辄上溢 / 下溢，要在对数域用 `np.linalg.slogdet` 算——这也是归一化流为何用 `logabsdet`（§6.2.3）。

**3.（动手·雅可比与变量替换）** 极坐标变换 $g(r,\theta)=(r\cos\theta, r\sin\theta)$。(a) 手推雅可比矩阵 $J_g$ 并算 $\det J_g$；(b) 用它解释为什么二重积分换极坐标时要乘 $r$（即 $\mathrm dx\,\mathrm dy=r\,\mathrm dr\,\mathrm d\theta$）；(c) 用 `numpy` 在某点数值近似 $J_g$（有限差分）并对比解析值。（巩固 §6.2.1–§6.2.2）

*答案要点*：$J_g=\begin{bmatrix}\cos\theta&-r\sin\theta\\\sin\theta&r\cos\theta\end{bmatrix}$，$\det J_g=r\cos^2\theta+r\sin^2\theta=r$。所以局部面积元被放大 $r$ 倍，$\mathrm dx\,\mathrm dy=|\det J_g|\,\mathrm dr\,\mathrm d\theta=r\,\mathrm dr\,\mathrm d\theta$。**为什么**：离原点越远（$r$ 大），同样的 $\mathrm d\theta$ 扫过的弧越长、面积元越大——这就是雅可比行列式作为「局部体积缩放」的字面体现。*延伸思考*：把同样的逻辑用到密度，$f_{r,\theta}=f_{x,y}\cdot r$；这正是变量替换公式，也是归一化流里每一步在做的事——只不过那里的变换由神经网络给定。

**4.（思考+动手·手算 + 验证特征分解）** 对 $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$：(a) 手算特征值（解特征方程）与特征向量；(b) 验证 $\sum\lambda_i=\operatorname{tr}A$、$\prod\lambda_i=\det A$；(c) 用 `np.linalg.eigh` 验证，并检查两特征向量是否正交（为什么？）；(d) 构造 $P,D$ 验证 $A=PDP^{-1}$。（巩固 §6.3.2、§6.4.1、§6.5.1、§6.6.2）

*答案要点*：$\lambda=3,1$；$\mathbf v_{3}\propto(1,1),\ \mathbf v_1\propto(1,-1)$。迹 $=4=3+1$✓，行列式 $=3=3\times1$✓。两特征向量正交（$\because A$ 对称，谱定理）。$P=\frac{1}{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}$（正交！故 $P^{-1}=P^T$），$D=\mathrm{diag}(3,1)$，$PDP^T=A$。**为什么**：对称矩阵正交对角化 $A=Q\Lambda Q^T$（§6.6 预告 / 第 7 章），所以 $P$ 可取正交、$P^{-1}=P^T$——这是对称带来的红利。*延伸思考*：用 `np.linalg.eig`（非对称版）和 `eigh`（对称版）都试一遍，体会 `eigh` 更快更稳、且保证返回实特征值与正交特征向量。

**5.（思考·可对角化判据）** 判断能否对角化并说明：(a) $\begin{bmatrix}1&1\\0&2\end{bmatrix}$；(b) $\begin{bmatrix}1&1\\0&1\end{bmatrix}$；(c) 任意实对称矩阵；(d) 2D 旋转 $R_{45°}$（在 $\mathbb R$ 上 vs 在 $\mathbb C$ 上）。（巩固 §6.4.2–§6.4.3、§6.6）

*参考答案*：(a) 可——两个互异特征值 $1,2$（互异 ⇒ 可对角化）。(b) **不可**（实 / 复都不行）——唯一特征值 $\lambda=1$ 代数重数 2 但几何重数 1（亏损 / 剪切，最简形是 Jordan 块）。(c) 一定可——谱定理，且可正交对角化。(d) 在 $\mathbb R$ 上**不可**（无实特征值），在 $\mathbb C$ 上**可**（特征值 $e^{\pm i\pi/4}$ 互异）。**为什么**：可对角化 = 凑齐 $n$ 个独立特征向量；互异特征值 / 对称是充分条件；亏损（几何<代数）则失败；旋转在复数域才有完整特征结构。*延伸思考*：(b) 把右下角改成 $1+10^{-9}$ 立刻变可对角化——这就是 §6.4.3「Jordan 对扰动不连续、数值上不可靠」的实感。

**6.（动手·矩阵幂与稳态）** 给马尔可夫转移矩阵 $P=\begin{bmatrix}0.9&0.1\\0.2&0.8\end{bmatrix}$（行随机）。(a) 从 $\boldsymbol\pi_0=(1,0)$ 出发迭代 $\boldsymbol\pi_{t+1}=\boldsymbol\pi_t P$，画 $\boldsymbol\pi_t$ 随 $t$ 的收敛；(b) 用 `np.linalg.eig(P.T)` 求 $P^T$ 特征值 1 的特征向量、归一化为概率，验证它 = 稳态；(c) 算第二特征值 $\lambda_2$，验证收敛残差每步约乘 $|\lambda_2|$。（巩固 §6.5.2–§6.5.4）

*答案要点*：稳态 $\boldsymbol\pi=(\tfrac23,\tfrac13)$（解 $\boldsymbol\pi P=\boldsymbol\pi$ 或取 $P^T$ 的 $\lambda=1$ 特征向量归一化）。$P$ 特征值为 $1$ 和 $\lambda_2=0.9+0.8-1=0.7$；收敛残差 $\|\boldsymbol\pi_t-\boldsymbol\pi\|$ 每步约乘 $0.7$，指数收敛。**为什么**：$\boldsymbol\pi_0 P^t$ 中 $\lambda=1$ 项不变（稳态）、$\lambda_2=0.7$ 项以 $0.7^t$ 衰减，故收敛速率 = $|\lambda_2|$。**这正是《概率与统计》第 10 章那个 $2\times2$ 链的复刻**——MCMC 混合时间就藏在第二特征值里。*延伸思考*：把 $P$ 改得「更黏」（如对角元 0.99），$\lambda_2$ 逼近 1、谱隙趋零、收敛骤慢——这就是蛋白构象空间高能垒导致 MCMC 混合极慢的数学画像。

**7.（思考·复特征值 = 旋转）** 不算数值，仅凭「对称 / 反对称 / 旋转」判断下列矩阵特征值是实还是复，几何上意味什么：(a) 任意协方差矩阵；(b) 2D 旋转 $R_\theta$（$\theta\ne0,\pi$）；(c) 螺旋矩阵 $\begin{bmatrix}0.9&-0.5\\0.5&0.9\end{bmatrix}$。再说明为什么折叠里你最关心的协方差 / Hessian / 拉普拉斯都是实谱。（巩固 §6.6.1–§6.6.2）

*参考答案*：(a) 实（对称 ⇒ 谱定理 ⇒ 实特征值、正交特征向量，无旋转，纯沿主轴缩放）；(b) 复 $e^{\pm i\theta}$（纯旋转，无实不变方向，模 1 等距）；(c) 复（旋转 + 缩放，模 $=\sqrt{0.9^2+0.5^2}\approx1.03>1$，向外螺旋）。折叠核心矩阵都对称（来自二次型能量 / 方差、或对称成对关系如距离 / 相关 / 接触），故谱定理保证实特征值（能谈正负、定正定性、排序找主成分）、正交特征向量（当干净新坐标）。**为什么**：「对称程度」决定谱的样子——对称 = 纯缩放、旋转 = 纯转、一般 = 混合。*延伸思考*：转移矩阵（§6.5.4）不对称、可有复特征值（链有「转圈」倾向）；这解释了为何 MCMC 谱分析常先用细致平衡把链「对称化」再谈实谱。

**8.（动手·幂法找主特征向量）** 自己写一个幂法：随机初始 $\mathbf x$，反复 $\mathbf x\leftarrow A\mathbf x/\|A\mathbf x\|$，对一个对称正定 $A=\begin{bmatrix}4&1\\1&3\end{bmatrix}$ 跑 30 步，看它收敛到哪个特征向量、用 Rayleigh 商 $\mathbf x^TA\mathbf x/\mathbf x^T\mathbf x$ 估对应特征值。与 `np.linalg.eigh` 对照。（巩固 §6.5.3，预告第 9 章）

*答案要点*：幂法收敛到**最大特征值的特征向量**（这里 $\lambda_{\max}=\tfrac{7+\sqrt5}{2}\approx4.62$），Rayleigh 商收敛到 $\lambda_{\max}$。**为什么**：$A^k\mathbf x_0=\sum c_i\lambda_i^k\mathbf v_i$ 被最大 $|\lambda|$ 项主导，归一化后方向趋向 $\mathbf v_{\max}$，收敛速率由 $|\lambda_2/\lambda_1|$ 决定。**这就是 PageRank / 谱聚类 / essential dynamics 求主模式的底层算法。** *延伸思考*：想求**最小**特征值（如 Hessian 的软模式 / 简正模式低频），对 $A^{-1}$ 做幂法（逆幂法）——最大 $1/\lambda$ 对应最小 $\lambda$；这正是第 9 章大规模特征问题（Lanczos）的入门思想。

- **Gilbert Strang,《Introduction to Linear Algebra》（MIT 18.06）第 5 章（行列式）、第 6 章（特征值与特征向量、对角化、马尔可夫矩阵、微分方程）**：本章 §6.1、§6.3–§6.5 的最佳配套，Strang 把「行列式 = 体积」「对角化 = $A^k$ 解耦」「马尔可夫稳态 = 特征值 1」讲得极直观且例子充足。入门首选，先读它再回看本章折叠连接。
- **Sheldon Axler,《Linear Algebra Done Right》第 5、8 章**：从「不靠行列式」的纯算子视角讲特征值、广义特征向量与 Jordan 形（§6.3–§6.4 的严谨升级），把「特征值是算子的本征属性」讲到骨子里。当你想要更抽象、更结构化的理解（尤其 Jordan 形为什么长那样）时读。
- **Trefethen & Bau,《Numerical Linear Algebra》（Lectures 24–28）**：特征值问题的数值算法（幂法、QR 迭代、Rayleigh 商、Schur 分解），正是 §6.3.2「别解多项式」「用 eig/eigh」、§6.5.3 幂法的「严谨实现版」，也是通往第 9 章的桥。想真懂「特征值到底怎么算出来」时读。
- **Strang,《Introduction to Linear Algebra》§10（马尔可夫矩阵与 Perron–Frobenius）+ 任一本随机过程教材的马尔可夫链章节**：稳态 = 特征值 1 特征向量、收敛 = 第二特征值、Perron–Frobenius 的遍历前提（§6.5.4 的完整出处）。配合《概率与统计》第 10 章一起读，把谱与 MCMC 收敛彻底打通。
- **Papamakarios et al., "Normalizing Flows for Probabilistic Modeling and Inference"（JMLR 2021，综述）**：归一化流的系统综述，雅可比行列式如何成为生成模型引擎、为什么追求三角雅可比（§6.2.3 的权威出处）。当你要做生成式蛋白 / 分子设计、读 Boltzmann generator（Noé et al., Science 2019）时读。
- **姊妹课交叉**：《概率与统计》第 2 章 §2.5（变量替换与雅可比行列式，§6.2 的概率底座）、第 5 章（多元高斯 $\det\Sigma$ 与精度矩阵）、第 10 章（MCMC 稳态 / 第二特征值 / 谱隙 / Perron–Frobenius，§6.5.4 的完整展开）；《信息论》第 8 章（高斯微分熵里的 $\log\det\Sigma$）；《蛋白质折叠》第 9 章（RFdiffusion / 生成式设计，对照 §6.2.3 归一化流与扩散模型两条路线）。

> **下一章预告**：本章我们一再撞见同一个「太好了」的特例——对称矩阵特征值必为实、特征向量可取正交（§6.3 那个 $\begin{bmatrix}2&1\\1&2\end{bmatrix}$、§6.6 的对照、几乎所有折叠核心矩阵）。第 7 章《谱定理、对称矩阵、二次型与正定性》就来把这块红利彻底兑现并展开：先证**谱定理** $A=Q\Lambda Q^T$（对称矩阵 = 沿一组正交主轴的纯实缩放，无旋转），再用它把**二次型** $\mathbf x^TA\mathbf x$ 的几何（椭球、鞍点）和**正定性**（所有特征值 > 0 ⇔ 能量面是稳定极小、协方差合法、Cholesky 存在）讲透——这正是判断蛋白构象是否稳定、协方差 / 精度矩阵是否合法、优化能否收敛的统一判据。而 Hessian 的特征向量将正式登场为**简正模式**：蛋白的集体运动（呼吸、铰链）就是势能面在极小点的本征方向，低频软模式 = 大尺度功能运动。谱视角从本章的「一般矩阵」收窄到「对称矩阵」这片最肥沃的土地，第 8 章的 SVD 与 PCA 便已在地平线上。
