配套《线性代数深度入门》第 8 章「奇异值分解与主成分分析」。核心直觉一句话：任意矩阵 A = UΣVᵀ，几何上无非「输入端转一下 Vᵀ → 沿坐标轴各自拉伸 Σ → 输出端再转一下 U」，把单位圆映成椭圆（半轴长 = 奇异值 σᵢ）；而 PCA = 中心化数据的 SVD = 协方差的特征分解，主方向就是右奇异向量。左标签对应 §8.1 圆变椭圆，右标签对应 §8.5 PCA = 数据 SVD。折叠连接：MD 轨迹 PCA（essential dynamics）用前几个主成分抓住主要构象运动，Kabsch 算法用 SVD 求最优旋转把两个蛋白结构叠合（RMSD 的根）。

正文呼应（§8.5）：对中心化数据 X̃ 做 SVD（X̃ = UΣsvVᵀ），右奇异向量 vᵢ = 主成分方向 = 协方差 Σ=X̃ᵀX̃/(N−1) 的特征向量，解释方差 λᵢ = σᵢ²/(N−1)——三位一体。主轴长按 √λ₁、√λ₂ 缩放，正是协方差椭圆的半轴。降维到 PC₁ 就是把点正交投影到 v₁ 直线上：由 Eckart–Young（§8.3），这是所有 1 维投影里保留方差最多、重构误差最小的；红色残差的平方和 = 丢掉的方差 = λ₂·(N−1)。
与折叠的连接：把 MD 轨迹的 T 帧 × 3M 坐标摊平成长方矩阵，先用 Kabsch（SVD 求最优旋转去掉整体平转）对齐每帧，再做 PCA——前几个主成分就是 essential dynamics（主要集体构象运动），和本图「前几个主轴抓住绝大部分方差」是同一件事。
