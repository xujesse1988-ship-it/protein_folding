⑤ 损失 vs 迭代曲线

纵轴 = 损失 L（自动缩放，发散时切对数刻度）；横轴 = 迭代步。收敛 → 平滑下降至平台；震荡 → 锯齿；发散 → 飞向天花板。

怎么读 · 该看什么（§4.2 / §4.3）

η 太大 → 发散 / 震荡：把 η 拉到右端再跑凸碗，轨迹会越弹越远「蹦出画布」。沿一个方向，GD 是迭代 θ←θ−ηg；当 η 超过 2/L曲率 时步长过冲，每步都跨过谷底落到更高处，损失爆炸。

η 太小 → 爬行：把 η 拉到左端，轨迹一小步一小步，几百步还没到底——慢但稳。调 η 是优化的第一要务。

病态峡谷 → GD 震荡，动量加速：选「病态长峡谷」，两个方向曲率悬殊（条件数大）。GD 横跨窄谷来回弹、沿长轴爬得极慢；切到动量，横向震荡被平均抵消、纵向速度累积，明显更快冲向谷底（§4.2.3）。

非凸 → 起点决定命运：选「非凸」，在左半 / 右半分别点起点运行，会落进不同的局部极小；把起点点在中间鞍点附近，梯度极小、轨迹近乎停滞——这正是深度网络非凸优化的缩影（§4.3.2）。

带噪 SGD：在真实梯度上加高斯噪声（模拟小批量 mini-batch 的随机性）。适度噪声能逃离平坦鞍点 / 浅极小、损失曲线带抖动；噪声过大则永远在谷底乱蹦不收敛（§4.2.2）。
