预设数据（§3.1）

必玩 1·过拟合：选「正弦波」，把阶数 d 推到 8–9，曲线会穿过几乎每个点但在点之间剧烈震荡——训练误差→0 而泛化糟糕（暗线一·泛化）。

必玩 2·正则救场：保持高阶，把 λ 从 0 慢慢拉大，曲线被「拽平」、震荡消失（偏差↑、方差↓，见配套 02_bias_variance.html）。

必玩 3·离群点：选「含离群点」，最小二乘对大残差异常敏感（残差被平方），一个离群点能把直线整体掰歪。

预设数据（§3.3）

必玩 1·线性可分：选「两团」点自动训练，边界稳稳分开两类，准确率→100%、损失→0。

必玩 2·重叠：选「重叠」，两类纠缠 ⇒ 无论怎么训练都无法 100% 分对，损失收敛到正值（线性模型容量不足，暗线三·归纳偏置）。

必玩 3·异或：选「异或」，四个对角块——没有任何一条直线能分开它！这正是单层线性分类器的著名极限（需要非线性 / 核 / 神经网络，见第 5、7 章）。
