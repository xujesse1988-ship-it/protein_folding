# 第 4 章 优化：让模型从数据里学起来

> **本章定位**：暗线二（「表示 + 目标 + 优化」三件套）讲过：任何机器学习方法都由三个零件拼成——你允许模型长什么样（表示）、你用什么尺子衡量好坏（目标 / 损失）、以及——本章的主角——你**用什么算法把那个最优模型找出来**（优化 / optimization）。前三章给了表示（第 3 章线性模型）和目标（第 2 章损失与风险、第 3 章 MLE / MAP），现在我们要回答最实际的一个问题：**给定一个损失函数，怎么真的把参数调到让它最小？** 答案对大多数现代模型只有一种：**迭代优化**，而其核心就是**梯度下降（gradient descent, GD）**及其家族。本章是全课的"引擎舱"——逻辑回归、神经网络、Transformer、扩散模型，无一例外靠这台引擎驱动。我们从"为什么需要迭代"（多数模型没有闭式解）讲起，把梯度下降的几何直觉（在损失曲面上找低谷）和更新式 $\theta \leftarrow \theta - \eta\nabla\mathcal{L}$ 钉清楚；辨明**凸 vs 非凸**（这决定了我们能指望什么、不能指望什么——这里有本章最重要的诚实边界）；讲随机梯度下降（SGD）与小批量为何是深度学习的命脉、它的噪声为何还能帮上泛化的忙；过一遍现代优化器（动量、Adam、学习率调度）；从条件数 / 病态的角度理解收敛快慢（接回《线性代数》第 9 章）；最后给反向传播一个预告，并落到一整节"实战诊断"——梯度检查、学习率搜索、发散 / 震荡 / 停滞 / NaN 怎么救。读完本章，你手里就有了一台能把第 3 章那些目标函数真正"跑起来"的引擎，也学会了在它抛锚时怎么修。配套交互页 `04_gradient_descent.html`：在一个二维损失面上亲手调学习率、开关动量、切换全批量 / SGD，看着小球收敛、震荡或飞出去。

## 4.1 为什么需要迭代优化

### 4.1.1 闭式解是奢侈品，不是常态

回忆第 3 章的线性回归。在平方损失下，最优参数有一个**闭式解（closed-form solution）**——正规方程（normal equation）：

$$
\mathbf{w}^\star = (X^\top X)^{-1} X^\top \mathbf{y}.
$$

你只要做一次矩阵运算就拿到了全局最优，不需要任何"试探 - 改进"的循环。这是机器学习里少有的幸运情形，幸运到值得我们停下来问一句：**它为什么这么幸运？** 答案是两件事凑齐了：(1) 损失是参数的**二次函数**（平方损失 + 线性模型）；(2) 二次函数的最小值点满足一个**线性**方程组（梯度为零），而线性方程组我们会解（《线性代数》第 5 章）。

把这两个条件中任何一个破坏掉，闭式解就没了。而现实里，它们几乎总会被破坏：

- **逻辑回归（logistic regression）**：损失是交叉熵，里面套着 $\log$ 和 $\mathrm{sigmoid}$，对参数求梯度令其为零，得到的是一组**超越方程（transcendental equation）**——没有代数闭式解。逻辑回归虽然是线性分类器、损失也凸，却**只能**靠迭代求解。
- **Lasso（L1 正则）**：目标含不可导的 $\|\mathbf{w}\|_1$，没有处处可导的梯度为零条件，闭式解不存在（坐标下降 / 近端梯度等迭代法登场）。
- **神经网络（neural network）**：损失是参数的高度非线性、非凸函数，梯度为零的方程组既非线性又有天文数字的解，根本无从代数求解。
- **即便闭式解存在，也可能算不起**：正规方程要算 $(X^\top X)^{-1}$，当特征维度 $d$ 很大（比如 $d=10^6$）时，这个 $d\times d$ 矩阵的求逆是 $O(d^3)$，内存和时间都吃不消。这时即使有闭式解，迭代法（如共轭梯度、SGD）反而更划算。

把这些情形抽象出来，结论是：**闭式解是奢侈品，对绝大多数有用的模型并不存在或不实用。** 机器学习的引擎，必须是一种**不需要闭式解、只靠局部信息一步步逼近最优**的通用算法。这台引擎就是梯度下降。

> **给数学 / CS 读者的视角**：你可以把"有没有闭式解"类比成"方程能不能用根式求解"。一元二次方程有求根公式（闭式），五次以上一般方程没有根式解（伽罗瓦），只能数值迭代（牛顿法）。机器学习的优化绝大多数落在"没有公式、只能迭代"这一侧。所以**迭代优化不是退而求其次的妥协，而是这个领域的常态与基本功**——就像数值分析里求非线性方程根、求积分，默认就是迭代 / 数值的。

值得把"为什么逻辑回归没有闭式解、但仍然好解"这件事再咬细一点，因为它体现了一个深刻的分层：**有没有闭式解，和好不好优化，是两件不同的事。** 逻辑回归没有闭式解（梯度为零是超越方程），但它的损失是**凸**的（§4.3），所以梯度下降能稳稳收敛到全局最优——"没有公式"不等于"难解"。反过来，神经网络不但没有闭式解，损失还是**非凸**的，于是"找到最优"本身就失去了保证。这条"闭式 / 凸 / 非凸"的三级阶梯，是理解全章的骨架：闭式（线性回归）→ 无闭式但凸（逻辑回归、SVM）→ 无闭式且非凸（神经网络），难度逐级上升，我们对结果能给的保证逐级减弱。

### 4.1.2 把"学习"翻译成"在损失曲面上找低谷"

第 2 章把学习形式化成了**最小化（正则化）经验风险**：在假设空间里，找一组参数 $\theta$ 使训练损失最小。写成优化问题就是

$$
\theta^\star = \arg\min_{\theta\in\mathbb{R}^p}\; \mathcal{L}(\theta),\qquad \mathcal{L}(\theta) = \frac{1}{n}\sum_{i=1}^n \ell\big(f_\theta(\mathbf{x}_i),\, y_i\big) + \lambda\, R(\theta),
$$

其中 $\ell$ 是单样本损失，$R$ 是正则项（如 $\|\theta\|_2^2$ 或 $\|\theta\|_1$，强度由 $\lambda$ 控制），$\theta\in\mathbb{R}^p$ 是把模型所有可调参数拉平成的一个向量（$p$ 可以从几个到几千亿）。注意正则项 $\lambda R(\theta)$ 也是"目标"的一部分、一同被优化——它**改变了损失地形的形状**（L2 正则相当于给碗加一个二次的"向心力"，让谷底更圆、更靠近原点，从优化角度看是改善条件数、从泛化角度看是偏好简单解、从概率角度看是高斯先验下的 MAP，三个视角说的是同一件事，呼应第 2、3 章与暗线一）。本章只管"给定这个地形怎么找谷底"，地形长什么样是表示与目标的事。

这里有一个贯穿全章的核心意象，请把它刻进脑子：**把 $\mathcal{L}(\theta)$ 想象成一个 $p$ 维参数空间上方的"地形（landscape）"**——每一组参数 $\theta$ 是地面上的一个点，损失值 $\mathcal{L}(\theta)$ 是那个点的"海拔"。我们要找的 $\theta^\star$，就是这片地形里**海拔最低的谷底**。学习，就变成了一个登山者（其实是"下山者"）在浓雾里、看不到全局地形、只能感知**脚下这一点的坡度**的情况下，想方设法走到最低谷的过程。

这个"损失曲面 / 优化地形（loss surface / optimization landscape）"的比喻不是花哨的修辞，它会一路陪我们到本章结束：

- "坡度"就是**梯度（gradient）**——它告诉你脚下哪个方向最陡。
- "凸地形"是只有一个碗状谷底的好地形；"非凸地形"是布满坑洼、山脊、平台、鞍部的复杂地形（§4.3）。
- "学习率"是你每一步迈多大（§4.2）。
- "动量"是你下山时积累的惯性，能冲过小坑、沿峡谷加速（§4.5）。
- "病态 / 条件数"描述这个谷是圆碗还是又长又窄的山沟，决定你走得顺不顺（§4.6）。

配套的 `04_gradient_descent.html` 画的正是一个二维（$p=2$，便于可视化）的损失地形，你能亲眼看小球在上面怎么走。

> **与数学三课的连接**：这一节把第 2 章的"经验风险最小化（ERM）"从一个统计目标，正式交接给数值优化来求解。$\mathcal{L}(\theta)$ 的形状由两部分共同决定——表示（$f_\theta$ 长什么样，第 3 章）和目标（用什么 $\ell$、$R$，第 2、3 章）。**优化不改变你想要什么，只负责把它找出来。** 这正是暗线二三件套里"优化"那一格的职责：表示与目标定义了"地形"，优化负责"在地形里找谷底"。

> **概率视角**：本章"最小化损失"在概率语言里几乎总是"**最大化（对数）似然**"的同一件事的另一种说法。第 3 章已讲过：平方损失 = 高斯噪声下的负对数似然，交叉熵 = 伯努利 / 类别分布下的负对数似然，加 L2 正则 = 加高斯先验做 MAP（最大后验）。所以本章的梯度下降，本质上是在**用迭代法做（带先验的）极大似然估计**——优化器是把《概率与统计》第 7 章（MLE）、第 8 章（贝叶斯 / MAP）那些"该取哪个参数最可信"的统计原则，真正算出来的引擎。每当你写下一个损失，记得问一句"它对应什么噪声 / 先验假设"，你就同时握住了"目标"那一格的统计含义和"优化"那一格的求解对象。

> **要点**：绝大多数有用的模型（逻辑回归、神经网络）没有可用的闭式解，机器学习因此默认靠**迭代优化**。把学习看成"在损失曲面 $\mathcal{L}(\theta)$ 上找最低谷"，是贯穿本章的核心意象——梯度是坡度、学习率是步长、凸 / 非凸是地形好坏。

## 4.2 梯度与梯度下降

### 4.2.1 梯度：最陡上升方向

先把梯度的直觉立住。对一个多元函数 $\mathcal{L}:\mathbb{R}^p\to\mathbb{R}$，它在点 $\theta$ 处的**梯度（gradient）** 是把各个偏导数堆成的向量：

$$
\nabla\mathcal{L}(\theta) = \left(\frac{\partial \mathcal{L}}{\partial \theta_1},\, \frac{\partial \mathcal{L}}{\partial \theta_2},\, \dots,\, \frac{\partial \mathcal{L}}{\partial \theta_p}\right)^\top.
$$

关于它，有三件你必须烂熟于心的事：

1. **梯度指向函数值增长最快的方向（steepest ascent direction）。** 从一阶泰勒展开 $\mathcal{L}(\theta+\boldsymbol{\delta}) \approx \mathcal{L}(\theta) + \nabla\mathcal{L}(\theta)^\top\boldsymbol{\delta}$ 看：在所有长度固定的方向 $\boldsymbol{\delta}$ 里，使 $\nabla\mathcal{L}^\top\boldsymbol{\delta}$ 最大（即上升最快）的，正是与 $\nabla\mathcal{L}$ 同向的那个（柯西-施瓦茨不等式取等）。
2. **梯度的负方向 $-\nabla\mathcal{L}$，就是下降最快的方向。** 这正是我们下山要走的方向。
3. **在极小值点，梯度为零** $\nabla\mathcal{L}(\theta^\star)=\mathbf{0}$（一阶必要条件；称这种点为驻点 / stationary point）。注意"梯度为零"是必要不充分的——它也可能是极大值或鞍点（§4.3）。

这里要厘清一个对数学读者重要、对所有人都易混的点：**梯度依赖于内积（坐标系）的选择。** 我们说"梯度是最陡上升方向"，默认用的是标准欧氏内积——"最陡"是相对于"等距离地度量各方向"而言的。一旦换一个度量（比如各参数尺度不同、或用一个非单位的矩阵定义内积），"最陡方向"就会变。这不是吹毛求疵：它正是 §4.6 预条件、自然梯度的思想源头——**所谓预条件，本质就是换一个更合适的内积 / 坐标系，使得"最陡方向"真的指向谷底而非陡壁。** 把"梯度 = 在某个度量下的最陡方向"记牢，你就不会把梯度当成某种绝对的、唯一的"正确方向"。

> **与数学三课的连接**：梯度是《线性代数》第 4 章意义下，把"沿哪个方向变化最快"这个几何问题用内积回答的产物——方向导数 $D_{\mathbf{u}}\mathcal{L}=\nabla\mathcal{L}^\top\mathbf{u}$ 是梯度与单位方向 $\mathbf{u}$ 的内积，内积最大即两向量同向。梯度还可以正式地理解为损失函数在该点的"线性化"（最佳一阶近似）的系数向量；它和"全微分 / 雅可比"的关系，正是那门课里线性映射与其矩阵表示的关系在标量值函数上的特例。

### 4.2.2 梯度下降：更新式与几何

梯度下降的算法朴素到近乎平庸：**站在当前点，朝最陡下降方向（负梯度）迈一小步，重复。** 更新式是本章最该背下来的一行：

$$
\boxed{\;\theta_{t+1} = \theta_t - \eta\,\nabla\mathcal{L}(\theta_t)\;}
$$

其中 $\eta > 0$ 是**学习率（learning rate）**，控制每一步迈多大；下标 $t$ 是迭代步（iteration）。从初始点 $\theta_0$ 出发，反复套这条式子，就得到一串点 $\theta_0,\theta_1,\theta_2,\dots$，理想情况下损失单调下降、逐渐逼近一个谷底。

为什么这一步一定（在 $\eta$ 不太大时）让损失下降？再看一阶泰勒展开。沿 $-\eta\nabla\mathcal{L}$ 走一步：

$$
\mathcal{L}(\theta_{t+1}) \approx \mathcal{L}(\theta_t) + \nabla\mathcal{L}(\theta_t)^\top(-\eta\nabla\mathcal{L}(\theta_t)) = \mathcal{L}(\theta_t) - \eta\,\underbrace{\|\nabla\mathcal{L}(\theta_t)\|^2}_{\ge 0}.
$$

只要梯度非零且 $\eta$ 足够小（让一阶近似成立），损失就**严格下降** $\eta\|\nabla\mathcal{L}\|^2$。这是梯度下降"能下山"的一行推导骨架。注意"$\eta$ 足够小"这个前提——它正是下一小节学习率问题的根。

几何上：你站在山坡上，闭着眼用脚感受脚下哪边最陡（梯度），朝相反方向（下坡）迈一步，再感受、再迈，直到脚下变平（梯度趋零）。注意一个常被忽略的细节：梯度下降是**贪心的、纯局部的**——它每一步只看脚下这一点的坡度，对整片地形的全局形状一无所知。这既是它的优点（每步只需算一个梯度，便宜），也是它的局限（在非凸地形里它只能保证走到"脚下变平"的某个驻点，看不到远处可能有更低的谷）。这个"局部 vs 全局"的张力，正是 §4.3 凸 / 非凸之辨的根。下图是一个一维示意（横轴参数 $\theta$，纵轴损失），梯度下降像一个小球滚向谷底：

```
  L(θ)
   |  \                         /
   |    \                     /
   |      \      step       /
   |        \   <----     /
   |          \  •      /
   |            \____ /
   |             谷底 θ*
   +-------------------------------> θ
```

### 4.2.3 学习率 $\eta$：太大发散，太小太慢

学习率 $\eta$ 是梯度下降里**最重要、最难调、最先该调**的超参数。梯度只告诉你"往哪个方向走"，$\eta$ 决定"走多远"，而这一步的远近后果天差地别：

- **$\eta$ 太小**：每步挪一点点，损失下降慢得令人发指，迭代上万步还在半山腰。计算白白浪费。
- **$\eta$ 合适**：稳稳地、较快地滑向谷底。
- **$\eta$ 偏大**：在谷底附近来回**震荡（oscillation）**——一步迈过头到对面坡上，下一步又迈回来，反复横跳，收敛缓慢或卡在谷底上方不下去。
- **$\eta$ 太大**：每一步不但没下降，反而越冲越高，损失**发散（divergence）**到无穷（数值上爆成 `inf` / `NaN`）。这是因为 $\eta$ 大到让一阶近似彻底失效。

用最简单的一维二次损失 $\mathcal{L}(\theta)=\tfrac12 a\theta^2$（$a>0$）能把这件事算到底。梯度 $\nabla\mathcal{L}=a\theta$，更新式 $\theta_{t+1}=\theta_t-\eta a\theta_t=(1-\eta a)\theta_t$。于是 $\theta_t=(1-\eta a)^t\theta_0$，收敛与否完全取决于乘子 $|1-\eta a|$：

- $0<\eta a<1$：$0<1-\eta a<1$，单调收敛（稳稳下山）。
- $1<\eta a<2$：$-1<1-\eta a<0$，**震荡收敛**（正负交替但幅度衰减）。
- $\eta a = 2$：$|1-\eta a|=1$，**永久震荡**不收敛。
- $\eta a>2$：$|1-\eta a|>1$，**发散**。

这给出一个干净的结论：**收敛要求 $\eta < 2/a$**，其中 $a$ 是这条抛物线的曲率（二阶导）。推广到多维二次型 $\mathcal{L}=\tfrac12\theta^\top H\theta$，把 $a$ 换成 Hessian $H$ 的**最大特征值** $\lambda_{\max}$：稳定性要求 $\eta < 2/\lambda_{\max}$。这条 $\eta<2/\lambda_{\max}$ 把"学习率上限"和"损失曲面的最陡曲率"直接挂上了钩——它在 §4.6 讲条件数时会再次出场，是理解"为什么病态的曲面逼你用小学习率"的钥匙。

把它推到二维看一眼"之字形"是怎么来的，能让你对学习率与曲率的纠缠有立体的感觉。取 $\mathcal{L}(\theta_1,\theta_2)=\tfrac12(\theta_1^2+a\,\theta_2^2)$（$a>1$，比如 $a=20$）。两个方向解耦，更新分别是 $\theta_1\leftarrow(1-\eta)\theta_1$、$\theta_2\leftarrow(1-\eta a)\theta_2$。为了第二个方向（陡方向，曲率 $a$）不发散，必须 $\eta<2/a$，于是 $\eta$ 被陡方向死死压小；可这么小的 $\eta$ 对第一个方向（缓方向，曲率 $1$）来说，每步只缩 $(1-\eta)$ 一点点，慢得要命。结果就是：小球在陡方向上来回横跳（接近发散边缘），却沿缓方向蜗牛般爬行——轨迹画出来是一条来回穿越谷底的**之字形（zig-zag）**。这正是 §4.6 病态问题的二维缩影，也是配套 `04_gradient_descent.html` 里你能亲手调出来的现象：把损失面拉扁（增大 $a$），再调 $\eta$，看小球如何在"陡方向发散"和"缓方向停滞"之间无处可逃。

> **常见陷阱**：把学习率当成"越小越保险"。小 $\eta$ 确实不会发散，但会慢到训练永远跑不完，而且更隐蔽地——在非凸地形里太小的步子更容易卡在第一个遇到的平庸驻点出不来。**学习率不是越小越好，而是要在"不发散"的前提下尽量大。** 实践中先找到发散的临界 $\eta$，再取它的几分之一，往往是个好起点（§4.8 的学习率搜索）。

> **实战连接（图像分类 / 科学回归）**：学习率是头号超参，这件事跨领域都成立，挑两个非语言的场景看。其一，**图像分类**：在 CIFAR / ImageNet 上从头训一个卷积网络，最常见的翻车就是学习率给大了——loss 在前几十个 batch 里直接冲到 `NaN`，或者训练准确率卡在"瞎猜"水平（十类问题卡在 10% 附近）纹丝不动；把 $\eta$ 砍一个数量级、或加上 warmup，往往立刻就正常下降了。其二，**科学计算里的回归**：拟合一个物理 / 化学量时，输入特征的量纲常常天差地别（温度几百、浓度 $10^{-6}$、能量上万），不归一化就直接梯度下降，损失曲面被某个大量纲方向拉成极扁的峡谷（这正是 §4.6 的病态），逼得你只能用极小的 $\eta$，慢到训练几乎不动——很多人误以为"模型学不动"，其实是没标准化特征 + 学习率被病态卡死。所以工业界 / 科研里训练任何模型，第一件事往往都是先把输入归一化、再做一次"学习率范围测试（LR range test）"找到可用区间（§4.8），需要时配上预热（warmup，§4.5）让训练初期用更小的步子稳住。**"学习率是头号超参"对视觉、语音、表格、科学回归一视同仁，不是语言模型的专利。**

> **要点**：梯度指向最陡上升方向，负梯度是下降最快方向；梯度下降更新式 $\theta_{t+1}=\theta_t-\eta\nabla\mathcal{L}(\theta_t)$ 靠一阶泰勒保证（$\eta$ 不太大时）损失下降。学习率 $\eta$ 太大发散 / 震荡、太小太慢；对曲率 $a$（或 $\lambda_{\max}$）的二次损失，稳定性要求 $\eta<2/\lambda_{\max}$。

## 4.3 凸 vs 非凸：我们能指望什么

这一节是本章的"世界观分水岭"。**一个优化问题是凸的还是非凸的，决定了梯度下降能给你什么样的保证。** 把这件事讲清楚，是守住本章诚实气质的关键。

### 4.3.1 凸函数：局部最优 = 全局最优

一个函数 $\mathcal{L}$ 是**凸的（convex）**，直觉上是说它的图像"碗状向上"——连接图像上任意两点的线段，都在图像上方。形式化：对任意 $\theta_1,\theta_2$ 与 $t\in[0,1]$，

$$
\mathcal{L}\big(t\theta_1+(1-t)\theta_2\big)\;\le\; t\,\mathcal{L}(\theta_1)+(1-t)\,\mathcal{L}(\theta_2).
$$

对二阶可导的函数，凸 $\Leftrightarrow$ Hessian（二阶导矩阵）处处半正定（$H\succeq 0$，呼应《线性代数》第 7 章正定 / 二次型）。

凸性给的最重要保证，一句话：**凸函数的任何局部最小值，都是全局最小值。** （若严格凸，全局最小还唯一。）直觉很简单：碗状地形只有一个谷底，你滚到任何"脚下变平"的地方，那就是最低点，不可能有"在更低处的另一个谷"骗你。对凸问题，梯度下降配合合适的学习率有**收敛到全局最优的理论保证**（凸优化里有干净的收敛速率，比如光滑凸函数下 $\mathcal{L}(\theta_t)-\mathcal{L}^\star = O(1/t)$，强凸下线性收敛；这个 $O(1/t)$ 还能靠动量"加速"到 $O(1/t^2)$，见 §4.5.1）。这是凸优化美好世界的核心红利：**你不用担心"找到的是不是真最优"——找到就是。**

哪些机器学习问题是凸的？这是个值得记住的清单：

- **线性回归 + 平方损失**：凸（且二次，有闭式解）。
- **岭回归（L2 正则）**：凸 + 强凸（正则让 Hessian 更正定）。
- **逻辑回归 + 交叉熵**：凸（交叉熵关于线性打分的参数是凸的，这是个能验证的事实）。
- **Lasso（L1 正则）**：凸（但不光滑，需用次梯度 / 近端方法）。
- **线性 SVM（合页损失）**：凸。

也就是说，**第 3 章那一整章的线性模型 + 凸损失，几乎都是凸问题**——这正是它们好用、可靠、理论干净的根本原因。

为什么逻辑回归是凸的、值得亲手验一次（这是数学读者该有的"不轻信"习惯）。它对单样本的损失（负对数似然）关于线性打分 $z=\mathbf{w}^\top\mathbf{x}$ 的二阶导是 $\hat y(1-\hat y)\ge 0$（$\hat y=\sigma(z)\in(0,1)$），即关于 $z$ 凸；而 $z$ 关于 $\mathbf{w}$ 是线性的，凸函数复合线性函数仍凸，再对样本求和（凸函数之和仍凸）——所以整个交叉熵损失关于 $\mathbf{w}$ 凸。这条"二阶导非负 → 凸 → 局部即全局"的链条，把"为什么逻辑回归只要梯度下降就放心收敛到全局最优"讲到了底。**请记住这条凸性的红线**：逻辑回归是**线性分类器**（决策边界线性）且损失凸，别因为名字里有"逻辑"或用了 sigmoid 就以为它非线性或非凸（第 3 章已强调，这里从优化角度再钉一次）。

凸地形还给了一个常被忽略却很解放的结论：**在凸问题里，优化器的选择（GD / SGD / 动量 / Adam）只影响你多快到达，不影响你到达哪里**——大家最终都收敛到同一个全局最优。所以"换个优化器结果就变好"这种事，在凸问题上不会发生（练习 4.4 会让你亲眼验证）；它只在非凸的深度网络里才成立，而那恰恰是因为非凸地形里"到达哪里"本身就不唯一、优化器的隐式偏好开始起作用（§4.3.3、§4.4.3）。

> **与数学三课的连接**：凸性的二阶判据"Hessian 半正定"直接用到《线性代数》第 7 章的正定 / 二次型语言。强凸（$H\succeq \mu I$，$\mu>0$）对应"碗的最小曲率有下界"，它保证线性收敛速率——这又会在 §4.6 和条件数挂钩。凸优化是一门成熟、优美、有完整理论的学科（推荐 Boyd & Vandenberghe），机器学习的经典半壁江山都站在它上面。

### 4.3.2 非凸地形：神经网络的真实处境

神经网络的损失函数关于参数是**非凸的（non-convex）**——这一点没有商量余地。原因之一直观：神经网络有**参数对称性**，比如交换同一层两个隐藏单元（连同它们的权重）得到的是同一个函数、同样的损失，于是损失曲面上存在大量等价的最优点，碗状假设当场破产；非线性激活的层层复合更让地形坑洼丛生。

非凸地形里有三类"陷阱"，必须分清它们的真实威胁程度：

**(1) 局部极小（local minimum）**——脚下变平、四周都比这里高，但它不是全局最低。经典担忧是"梯度下降会卡在糟糕的局部极小出不来"。但近十几年的理论与实证给了一个**反直觉**的修正：在**高维**的深度网络损失曲面上，**糟糕的局部极小其实不是主要障碍**。原因后面就讲。

**(2) 鞍点（saddle point）**——脚下也变平（梯度为零），但它在某些方向上是极小、在另一些方向上是极大，像马鞍 / 山口。Hessian 在这里有正有负的特征值（不定）。**关键事实：在高维空间里，鞍点远比局部极小多，是梯度下降的主要障碍。** 直觉上为什么？一个驻点要成为局部极小，需要 Hessian 的**所有** $p$ 个特征值都为正；要成为鞍点，只需有正有负。当 $p$ 很大（几百万、几十亿），"所有特征值同号"是个极其苛刻的巧合，而"有正有负"几乎必然——所以高维里驻点压倒性地是鞍点。鞍点的麻烦在于：靠近它时梯度很小，普通梯度下降会**显著放慢**（像在山口的平台上磨蹭），但它毕竟有下降方向，加上随机性（SGD 的噪声）或动量，通常能逃离。

**(3) 平坦区 / 高原（plateau / flat region）**——梯度接近零的大片区域（不一定是驻点），梯度下降在这里几乎停滞。激活函数饱和（如 sigmoid 两端）、初始化不当都会造成大平台，这是第 7 章梯度消失问题的近亲。

这三类陷阱要分清各自的"危险等级"，避免把直觉用错地方：糟糕的**局部极小**在高维深度网络里其实**不是主要威胁**（数量稀少、且许多损失值相近又够好）；**鞍点**才是主要的减速来源（高维里压倒性地多、附近梯度小磨蹭），但它有下降方向、靠噪声和动量通常能逃；**平坦区**则更多是"梯度信号太弱"的工程病，靠好的初始化、不饱和的激活（ReLU）、归一化来预防。把这个排序记住，你就不会再把"非凸"笼统地等同于"会被某个深坑卡死"——真实图景细腻得多。

> **诚实的边界（本章第一处）**：**绝不要声称"SGD 在非凸问题上收敛到全局最优"——这是错的，也没有这样的定理。** 我们对非凸优化能诚实说出的是：(a) 梯度下降 / SGD 在温和假设下能收敛到一个**驻点**（梯度为零的点），但不保证是局部最优、更不保证是全局最优；(b) 大量经验和部分理论表明，**深度网络的众多局部极小往往损失值都相当接近、且足够好**（不是只有一个孤独的全局最优在等你），所以"没找到全局最优"在实践中常常不致命；(c) 真正的中心问题根本不是"找全局最优"——见 §4.3.3。把这三句讲清楚，比给出一个并不存在的"全局收敛保证"诚实得多。

> **给数学 / CS 读者的视角**：判别一个驻点是极小、极大还是鞍点，看 Hessian 的特征值符号（《线性代数》第 6、7 章）——全正是极小，全负是极大，有正有负是鞍点。"高维里鞍点占压倒多数"可以这样直观估计：若把各方向特征值的符号近似看成独立的正负各半，那么一个驻点恰好"全正"（局部极小）的概率约 $2^{-p}$，在 $p$ 巨大时近乎为零。这是一个**纯线性代数 + 概率的洞见**，却深刻改变了我们对神经网络优化困难来源的认识。

### 4.3.3 真正的目标不是全局最优

这里要把 §4.3 的世界观推到它该到的地方，也接回暗线一（泛化）。

我们之所以训练模型，**最终目的不是把训练损失压到全局最小**——训练损失是第 2 章里那个"能测量的代理"，我们真正想要的是**在没见过的数据上表现好（泛化）**。这两件事不仅不等价，过度追求前者还会**伤害**后者：把训练损失压到极致（完美记住每个训练点，包括噪声），往往正是过拟合的写照（第 2 章）。

于是非凸优化在深度学习里的真实任务是：**找到一个泛化好的解，而不是损失值最低的解。** 这彻底重构了我们对"优化"的期待——

- 我们不那么在乎找到的是不是全局最优，**只要它泛化好**。
- 好消息是：深度网络的众多"足够好"的极小，许多确实泛化得不错；而且优化算法本身（SGD 的噪声、隐式正则）会**偏好**其中泛化更好的那些（§4.4）。
- 这也解释了为什么"非凸"在深度学习里没有想象中那么可怕：我们要的不是那个唯一的全局谷底，而是这片宽广地形里**任何一个又低又'宽'的好谷底**——而这样的好谷底，遍地都是。

> **诚实的边界（本章第二处）**：上一段说的"许多极小都泛化得不错""优化偏好泛化好的解"是**经验观察 + 部分理论**，不是已被严格证明的普适定理。它在标准的视觉 / 语言任务上反复被验证，但并非铁律——换了数据、架构、超参，依然可能掉进泛化差的解。所以"非凸不可怕"是有条件、有边界的乐观，而不是免死金牌。把"训练损失"和"泛化性能"始终当成两件事，是不被优化的表面成功骗到的护身符（第 9 章会专门讲深度网络的"泛化之谜"）。

> **要点**：凸问题（线性 / 逻辑回归 + 凸损失）里局部最优 = 全局最优，梯度下降有全局收敛保证；神经网络非凸，地形里有局部极小、鞍点、平坦区，其中**高维下鞍点是主要障碍**（局部极小没那么可怕）。**不要声称 SGD 非凸下收敛到全局最优。** 而且我们真正要的根本不是全局最优，是泛化好的解——这接回暗线一。

## 4.4 随机梯度下降与小批量

### 4.4.1 全批量太贵：用一小撮样本估计梯度

回到更新式 $\theta_{t+1}=\theta_t-\eta\nabla\mathcal{L}(\theta_t)$。损失 $\mathcal{L}(\theta)=\frac1n\sum_{i=1}^n\ell_i(\theta)$ 是 $n$ 个样本损失的平均，所以它的梯度也是 $n$ 个样本梯度的平均：

$$
\nabla\mathcal{L}(\theta)=\frac1n\sum_{i=1}^n \nabla\ell_i(\theta).
$$

这叫**全批量梯度下降（full-batch / batch gradient descent）**：每走一步，都要把**全部 $n$ 个样本**过一遍算梯度。当 $n=10^7$、模型有上亿参数时，这意味着每一步都要做一次全数据集前向 + 反向传播——慢到几乎无法训练，而且整个数据集常常根本装不进显存。

关键洞察：**真正的梯度（在分布 $\mathcal{D}$ 上的期望梯度）我们本来就拿不到，全批量梯度也只是它在 $n$ 个样本上的一个估计。** 既然已经是估计，何不用**更少的样本**做一个更便宜、噪声更大的估计？这就是**随机梯度下降（stochastic gradient descent, SGD）** 的思想：

- **纯 SGD**：每步只用**一个**随机样本 $i$ 算梯度 $\nabla\ell_i(\theta)$，拿它当整体梯度的估计去更新。
- **小批量 SGD（mini-batch SGD）**：每步用一小撮（一个 mini-batch，大小 $B$，常见 $32\sim1024$）随机样本的平均梯度

$$
\hat{\mathbf{g}}_t=\frac1B\sum_{i\in \mathcal{B}_t}\nabla\ell_i(\theta_t),\qquad \theta_{t+1}=\theta_t-\eta\,\hat{\mathbf{g}}_t.
$$

实践中"SGD"几乎总是指小批量版本。把全部数据按小批量过一遍，叫一个 **epoch（轮次）**。

为什么这个有噪声的梯度估计还能工作？因为它是**无偏的**：$\mathbb{E}_{\mathcal{B}}[\hat{\mathbf{g}}_t]=\nabla\mathcal{L}(\theta_t)$（随机均匀抽样下，小批量梯度的期望恰是全批量梯度）。所以平均而言它指向正确的下山方向，只是每一步有随机抖动。**用少量样本估期望——这正是《概率与统计》第 6 章蒙特卡洛 / 大数定律的思想**：样本均值是总体均值的无偏估计，批量越大估计方差越小（方差 $\propto 1/B$）。

实现上有两个细节值得点明。其一，**每个 epoch 开始要打乱（shuffle）数据再切批量**——若按固定顺序喂，批量之间的相关性会让梯度估计带上系统性偏差、收敛变差；随机打乱保证每个 mini-batch 近似是从训练集里无放回随机抽的一把，维持无偏性。其二，**SGD 即使在凸问题上，固定学习率也不会精确收敛到最优点**，只会收敛到最优点附近一个由噪声大小决定的"球"里来回抖（因为到了最优点附近真梯度近零，但单批量梯度仍有非零噪声，把你不停推开）。要让它真正落到谷底，需要**逐步衰减学习率**（learning rate annealing）：经典的 Robbins–Monro 条件要求 $\sum_t\eta_t=\infty$（步子够多能走到任何远处）且 $\sum_t\eta_t^2<\infty$（步子衰减够快能压住噪声），如 $\eta_t\propto 1/t$。这解释了 §4.5.3 学习率衰减的一个理论根：**后期把步长调小，是为了让 SGD 的噪声球收缩、真正停进谷底。**

### 4.4.2 计算 vs 统计的权衡

为什么 SGD 几乎总是赢全批量？因为它在"每步成本"和"每步质量"之间做了一个划算的交易：

| | 全批量 GD | 小批量 SGD（$B\ll n$）|
|---|---|---|
| 每步成本 | $O(n)$，极贵 | $O(B)$，便宜 |
| 梯度质量 | 精确（在训练集上）| 有噪声、无偏 |
| 每个 epoch 的更新次数 | 1 | $n/B$（多得多）|
| 收敛轨迹 | 平滑、单调 | 抖动、整体下行 |
| 显存 | 要装下全数据梯度 | 只需装下一个 batch |
| 逃离鞍点 / 坏极小 | 弱（确定性卡住）| 强（噪声帮忙）|

核心权衡是**计算效率 vs 统计精度（computation vs statistics）**：全批量每步走得"准"但"贵"，SGD 每步走得"糙"但"省"。在固定的计算预算下，**SGD 用同样的算力做了多得多的参数更新**，即使每步方向有噪声，整体下山速度也远快于全批量——这是个"宁可走一百步糙的、不走一步精的"的胜利。小批量还顺手吃到现代硬件红利：GPU / TPU 擅长对一个 batch 做并行矩阵运算，$B$ 取几百时几乎不比 $B=1$ 慢，却把噪声降下来、把硬件喂饱。这就是为什么**深度学习离不开小批量 SGD**：它是唯一能在海量数据 + 海量参数下跑得动的优化方式。

那批量大小 $B$ 该怎么选？这里有一个值得记住的权衡链条。**$B$ 越大**：梯度估计方差越小（$\propto 1/B$）、方向越准、硬件并行越满，但每步算得越久、每个 epoch 更新次数越少，且噪声变小会**削弱隐式正则的泛化好处**（§4.4.3）、有时反而泛化变差（"大批量泛化间隙"现象）。**$B$ 越小**：噪声大、方向糙，但更新频繁、隐式正则强。实践中常见的一条经验是"**线性缩放规则（linear scaling rule）**"：批量翻倍时学习率也大致翻倍（因为梯度更准，可以放心迈更大步），并配合 warmup 稳住初期——这是在大规模分布式训练里把批量做大而不损精度的常用配方（但它有适用边界，批量太大时会失效）。**没有放之四海的最优 $B$**：它是计算、统计、泛化、硬件四方拉扯下的工程选择，常见区间从几十到几千。

### 4.4.3 梯度噪声的隐式正则作用

SGD 的噪声不只是"为了省钱付出的代价"，它还**意外地帮上了泛化的忙**——这是深度学习里最迷人也最微妙的现象之一。

直觉上有两条线索：

- **逃离陷阱**：噪声让 SGD 不会死板地卡在第一个遇到的驻点。在鞍点附近，随机抖动会把它推下某个下降方向；在尖锐的坏极小附近，噪声也容易把它震出来。
- **偏好平坦极小（flat minima）**：这是关键。损失曲面里有"尖锐（sharp）"的窄谷和"平坦（flat）"的宽谷。经验（和部分理论）表明，**平坦极小往往泛化更好**——直觉是：平坦谷底里参数小幅扰动损失变化不大，对应"模型对参数 / 输入的小变化稳健"，这正是泛化好的特征；尖锐谷底则反之，稍偏一点损失就飙升，往往是过拟合训练集的"脆弱"解。而 SGD 的噪声会让它**待不住尖锐的窄谷**（噪声幅度超过窄谷宽度就被弹出），却能稳定停在宽阔的平坦谷里。于是 SGD 像一个天然的"筛子"，在众多极小中**偏向挑出平坦的、泛化好的那个**。这是一种**隐式正则化（implicit regularization）**——没有显式往损失里加正则项，优化算法本身的随机性就起到了正则的效果。

这条线索直接接回第 2 章的双下降（double descent）：在过参数化区，能把训练损失降到零的"插值解"有无穷多个，它们的泛化天差地别——优化算法选中哪一个，就成了泛化好坏的关键。而梯度下降族被发现有一种**隐式偏好最小范数 / 最平滑解**的倾向（例如在某些线性 / 简化设置里，从零初始化的梯度下降会收敛到插值解中范数最小的那个，呼应《线性代数》第 8 章 SVD / 最小范数解）。也就是说，**优化器不只是"找一个解"，它还在无数等价的解里悄悄替你挑了一个**——而它挑的偏好（最小范数 / 最平坦），恰好常常是泛化好的那一类。这正是暗线三（归纳偏置）在"优化"这一格的隐身现形：**优化算法自带的偏好，是一种没写进损失里的隐式先验。**

> **诚实的边界**：上面这套"SGD 噪声 → 偏好平坦极小 → 泛化好"的故事，**是经验观察加上部分理论支持，远未成为干净的普适定理，请勿神化。** 几个诚实的限定：(1)"平坦 = 泛化好"的相关并非铁律，"平坦"本身的定义（对参数重缩放敏感）就有争议，存在反例；(2) 把它说成"SGD 一定收敛到最平坦极小"是过度声称；(3) 隐式正则的精确机理仍是活跃研究课题，目前更接近"有启发、有部分证据的解释框架"而非定论。**正确的态度**：SGD 的噪声经验上有益于泛化，把它当成一个有用的直觉和工程现象，而不是一条可以拿去证明的定理。

> **概率视角**：把 SGD 看成在做**含噪声的随机优化**，它的轨迹近似一个随机过程（连续极限下类比为带噪声的梯度流 / 朗之万动力学）。这里要分清两个**不同口径**的"噪声"，否则极易混淆：(1) **单步梯度估计的方差** $\mathrm{Var}(\hat{\mathbf g}_t)\propto 1/B$——这是 §4.4.1 那个蒙特卡洛事实，只看批量大小、与学习率无关，描述的是"梯度这个量估得准不准"；(2) **参数更新引入的扩散强度 / "温度"** $\propto \eta^2\cdot\mathrm{Var}(\hat{\mathbf g})\propto \eta^2/B$（一步更新 $-\eta\hat{\mathbf g}$ 把梯度方差放大了 $\eta^2$ 倍；按连续时间扩散尺度折算，常把有效温度写成 $\propto \eta/B$），它额外含了 $\eta$，描述的是"参数实际被随机推动得多剧烈"。决定"探索 / 偏向宽谷"的是后者（温度），而不是前者——这也是为什么调小学习率（§4.5.3）能让噪声球收缩、把模型沉进谷底：它压的是更新噪声 $\eta/B$，而不是梯度估计方差 $1/B$。温度越高越爱探索、越偏向宽谷。这个"优化 = 在能量地形上的带噪采样"的视角，把优化和《概率与统计》第 10 章的采样 / MCMC 联系起来，也预告了第 10 章生成模型里"能量 / 得分"的思想。

> **实战连接（推荐系统 / 表格数据）**：SGD 的"省"在工业级推荐系统里是生死线。一个大厂的推荐模型可能有上亿用户 × 上亿物品的交互、特征是极度稀疏的高维 one-hot，训练数据一天就刷新一批——全批量梯度连一步都算不动，也根本装不下。这里几乎只能用小批量 SGD（常配 Adam 类自适应优化器，因为稀疏特征的参数被更新的频率差异极大，逐参数自适应步长正好对症）。同样的逻辑也覆盖梯度提升树（GBDT，第 5 章）训练表格数据时的子采样、以及在线学习（online learning）里"数据一边来一边学"的场景——它们都是 §4.4 计算 vs 统计权衡的不同化身，与视觉 / NLP 平级。**"用一小撮样本估梯度"不是深度学习的专利，而是任何大规模学习的通用引擎。**

> **要点**：SGD / 小批量用一小撮样本的**无偏**梯度估计代替昂贵的全批量梯度，在"计算便宜"与"统计有噪"之间做了划算的交易，是深度学习能跑起来的命脉；其梯度噪声还有**隐式正则**作用（偏好平坦极小、利于泛化），但这是经验 + 部分理论，**别神化成定理**。

## 4.5 改进的优化器

朴素 SGD 在病态地形（又长又窄的山沟、布满鞍点的平台）上走得磕磕绊绊。现代优化器在它之上加了几样"配件"，让下山更快更稳。核心思想就两条：**用历史梯度积累惯性（动量）**，和**为每个参数自动调步长（自适应学习率）**。

### 4.5.1 动量：惯性冲过小坑、沿峡谷加速

**动量（momentum）** 给优化器加了"惯性"。普通 SGD 每步只看当前梯度，像个没有质量的点，遇到平台就停、遇到来回坡就横跳。动量法让更新累积成一个"速度"向量 $\mathbf{v}$：

$$
\mathbf{v}_{t+1}=\beta\,\mathbf{v}_t + \nabla\mathcal{L}(\theta_t),\qquad \theta_{t+1}=\theta_t-\eta\,\mathbf{v}_{t+1},
$$

其中 $\beta\in[0,1)$（常取 $0.9$）是动量系数，相当于"摩擦"的反面——它让过去的梯度以指数衰减的方式累加进当前速度。直觉上 $\mathbf{v}$ 是一个对历史梯度的**指数移动平均**（这里梯度项前的系数是 $1$，是经典的重球 / heavy-ball 写法；另有一种把梯度乘上 $(1-\beta)$ 做成"归一化 EMA"的写法——下一小节 Adam 的一阶矩 $\mathbf{m}$ 就采用后者，两种都对，区别只是把那一份缩放折进 $\eta$ 还是折进系数里，对照不同代码 / 论文时别被这半个常数绊住）。动量带来两个好处：

- **沿峡谷加速**：在又长又窄的山沟里，普通 SGD 在两侧陡壁间来回震荡、沿谷底方向却挪得很慢。动量让来回震荡的分量**相互抵消**（一正一负平均掉），而沿谷底一致的下降分量**持续累加放大**——于是它沿正确方向越走越快。
- **冲过小坑 / 平台**：积累的惯性能带着它冲过浅的局部坑、滑过梯度近零的平台，不容易卡死。

**Nesterov 加速梯度（Nesterov accelerated gradient, NAG）** 是动量的一个聪明变体：先按当前速度"试探性前进"到 $\theta_t-\eta\beta\mathbf{v}_t$，**在那个前瞻点（look-ahead）算梯度**再更新。直觉是"先往前看一眼再决定怎么走"，能更早感知到前方坡度变化、及时刹车。它在凸优化里有一个著名的"加速"结果：**在确定性、用全梯度（full gradient）的光滑凸问题上，Nesterov 把普通梯度下降的 $O(1/t)$ 收敛速率提到 $O(1/t^2)$**，这是这一类问题理论上的最优一阶速率。务必看清这个结论的前提——它是**确定性全梯度**的结论。换到我们日常用的**随机小批量**场景里，梯度本身带噪声，这个干净的 $O(1/t^2)$ 加速率并不能照搬（随机 NAG 没有同样的保证）；深度学习里"用 Nesterov 动量"更多是借它"前瞻刹车"的工程直觉来稳一稳训练，而不是真去兑现那条凸优化的加速定理。把"理论加速"和"实战好用"分开记，是不被速率公式误导的关键。

还有一个量化的直觉值得记住：在一段梯度大致恒定的区域里，$\mathbf{v}$ 这个指数移动平均会累加到约 $\frac{1}{1-\beta}$ 倍的单步梯度。所以 $\beta=0.9$ 时，动量法的"有效步长"约是无动量的 $\frac{1}{1-0.9}=10$ 倍——这就是为什么动量能在一致下降的方向上"越走越快"。但也正因如此，动量过大（$\beta\to1$）会让它**冲过头（overshoot）**、绕着谷底打转才停下，这是练习 4.2 里你会看到的"$\beta$ 太大反而变差"的来源。

> **给数学 / CS 读者的视角**：动量法可以精确类比成**物理里的重球（heavy ball）滚下山**——$\mathbf{v}$ 是动量 / 速度，$\beta$ 是（一减）摩擦系数，梯度是作用力。重球靠惯性冲过小坑、沿势能谷加速，正是优化里我们想要的。这个"重球法"是 Polyak 在凸优化里的经典结果，深度学习只是把它搬了过来。

### 4.5.2 自适应学习率：AdaGrad、RMSProp、Adam

动量解决"方向"，自适应学习率解决"每个参数该用多大步长"。痛点是：不同参数的梯度尺度可能天差地别（有的方向陡、有的方向缓；稀疏特征的参数很少被更新），用同一个全局 $\eta$ 顾此失彼。自适应方法的思路是**为每个参数维护一个根据其历史梯度大小自动缩放的有效步长**——梯度一直很大的方向，步子自动调小（别冲过头）；梯度一直很小的方向，步子相对放大（别磨蹭）。

**AdaGrad** 累积每个参数历史梯度的平方和 $G_t=\sum_{s\le t}\mathbf{g}_s^2$（逐元素），用 $\eta/\sqrt{G_t+\epsilon}$ 当每个参数的有效学习率。它的初衷很对症：**稀疏特征**（如 NLP / 推荐里大量只在少数样本出现的特征）对应的参数极少拿到梯度，$G_t$ 小、有效步长大，于是这些罕见但重要的方向能被充分更新——这是 AdaGrad 在稀疏问题上一度很受欢迎的原因。问题：$G_t$ 单调累加只增不减，有效学习率**单调衰减到零**，训练后期几乎走不动——对需要长时间训练的深度学习不友好。

**RMSProp** 修掉这个毛病：把"累加历史平方"换成"指数移动平均历史平方" $\mathbb{E}[\mathbf{g}^2]_t=\rho\,\mathbb{E}[\mathbf{g}^2]_{t-1}+(1-\rho)\mathbf{g}_t^2$，于是它**只记得最近一段**的梯度尺度，有效学习率不再无限衰减，适合非平稳的深度学习损失。

**Adam（Adaptive Moment Estimation）** 是把**动量 + RMSProp 合在一起**的集大成者，也是今天深度学习最常用的默认优化器之一。它同时维护梯度的一阶矩（动量 $\mathbf{m}$）和二阶矩（梯度平方的 EMA $\mathbf{v}$）：

$$
\mathbf{m}_t=\beta_1\mathbf{m}_{t-1}+(1-\beta_1)\mathbf{g}_t,\qquad
\mathbf{v}_t=\beta_2\mathbf{v}_{t-1}+(1-\beta_2)\mathbf{g}_t^2,
$$

做偏差校正（bias correction，因初始为零需修正）$\hat{\mathbf{m}}_t=\mathbf{m}_t/(1-\beta_1^t)$、$\hat{\mathbf{v}}_t=\mathbf{v}_t/(1-\beta_2^t)$，再更新：

$$
\theta_{t+1}=\theta_t-\eta\,\frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t}+\epsilon}.
$$

常用默认 $\beta_1=0.9$、$\beta_2=0.999$、$\epsilon=10^{-8}$。Adam 的优点是**对学习率不那么敏感、开箱即用、收敛快**，对 Transformer 这类模型几乎是标配（常用其权重衰减解耦的变体 AdamW，把 L2 正则与自适应缩放分开，做法更干净）。

把这一族优化器并排看，脉络就清楚了——它们都是在"方向（动量）"和"步长（自适应）"这两个旋钮上做加法：

| 优化器 | 用动量？ | 逐参数自适应步长？ | 一句话 |
|---|---|---|---|
| SGD | 否 | 否 | 最朴素，纯负梯度，要靠调度和归一化 |
| SGD + Momentum | 是 | 否 | 加惯性，沿峡谷加速、抵消震荡 |
| Nesterov | 是（前瞻）| 否 | 动量的"先看一眼再走"变体 |
| AdaGrad | 否 | 是（累加历史）| 步长单调衰减，后期走不动 |
| RMSProp | 否 | 是（EMA）| 修掉 AdaGrad 衰减过头的毛病 |
| Adam / AdamW | 是 | 是（EMA）| 动量 + RMSProp 合体，常用默认 |

读这张表的正确方式不是背，而是认出：**所有现代优化器都是"负梯度方向"这一基本拍上，叠加'用历史平滑方向'与'用历史校准每个参数步长'两类修正。** 抓住这两条主线，再多的优化器变体你都能一眼看穿它在改哪个旋钮。

> **诚实的边界**：Adam 好用，但**不是"永远最优"**。几个诚实的限定：(1) 在不少视觉任务（如训练 ResNet）上，**调好的带动量 SGD 的最终泛化常常优于 Adam**——自适应方法收敛快，但泛化有时略逊，机理仍有争议；(2) Adam 也有过被发现的收敛性反例（在某些构造的凸问题上不收敛，催生了 AMSGrad 等修补）；(3) 自适应方法不能替代调学习率和调度——它只是让调参容错率高些。**结论：Adam 是极好的默认起点，但"用 Adam 就不用操心优化"是错觉。**

### 4.5.3 学习率调度与 warmup

固定学习率往往不是最优的：训练**初期**希望步子小一点（防止一开始就被随机初始化处的大梯度带飞），**中期**希望步子大些快速下山，**后期**希望步子变小好稳稳收敛进谷底。于是有了**学习率调度（learning rate schedule）**——让 $\eta$ 随训练进程变化：

- **衰减（decay）**：随训练把 $\eta$ 逐步调小，常见有阶梯衰减（step decay，每隔若干 epoch 乘 $0.1$）、指数衰减、余弦退火（cosine annealing，$\eta$ 沿余弦曲线平滑降到接近零）。后期小步长帮助精细收敛、稳定停在谷底。
- **预热（warmup）**：训练**最初**几百到几千步，把 $\eta$ 从一个很小的值**线性升到**目标值，再开始正常调度。为什么需要？训练初期参数随机、梯度统计（尤其 Adam 的二阶矩）还没估准，此时若直接用大学习率极易发散；warmup 给模型一个"暖身"期稳住，再放开步子。**warmup 是训练大模型（尤其 Transformer）几乎必备的技巧。**

一个广泛使用的组合是 "warmup + 余弦衰减"：先线性升温、再余弦降到接近零。

为什么后期衰减不只是"锦上添花"而是常常必需？回忆 §4.4.1 那条结论：SGD 在固定学习率下只会在最优点附近一个由噪声决定的"球"里抖动，球的半径大致随 $\eta$ 增大。如果训练到后期还用恒定的大 $\eta$，loss 就会在谷口反复横跳、永远进不去——这正是很多人观察到的"loss 降到某个值就卡住不再下降"的真凶（误以为是模型容量到顶，其实是学习率没降）。把 $\eta$ 在后期调小，等价于让噪声球收缩、把模型真正"沉"进谷底，loss 往往会再下一个台阶。这也给了"训练末期手动把学习率砍十倍、loss 突然又降一截"这个经典现象一个干净的解释。

**还有一个常被忽略的常识**：不同优化器的"合适学习率量级"差很多。带动量 SGD 常用的 $\eta$（如 $0.1$ 量级，配合归一化）和 Adam 常用的 $\eta$（如 $10^{-3}$ 量级）不在一个数量级上——换优化器时照搬学习率是高频翻车点。永远针对当前优化器重新做学习率搜索（§4.8.2）。

> **实战连接（训练大语言模型）**：训练大语言模型时，学习率调度几乎和模型架构同等重要。典型配方是"线性 warmup 数千步 + 之后余弦衰减"，配 AdamW 优化器。少了 warmup，训练初期极易在大梯度下崩成 `NaN`；少了后期衰减，loss 会在谷口反复横跳收不进去。这套"优化器 + 调度"的配方，是把一个能跑的架构真正训练出好结果的工程内核——架构（表示）选对了只是第一步，优化（调度 + 优化器）跟不上一样前功尽弃。

> **要点**：动量（含 Nesterov）给优化加惯性——沿峡谷加速、冲过小坑（重球类比）；自适应学习率（AdaGrad→RMSProp→Adam/AdamW）为每个参数按历史梯度大小自动调步长，Adam 是常用默认但**非永远最优**（视觉上调好的 SGD 常泛化更好）；学习率调度（衰减 + warmup）让步长随训练进程变化，warmup 是训练大模型的标配。

## 4.6 收敛、条件数与病态

这一节把"为什么有的损失曲面好走、有的难走"讲到曲率的层面，并接回《线性代数》第 9 章的条件数。它是理解 §4.5 那些技巧"为什么有用"的底层原因。

### 4.6.1 曲率、Hessian 与二次近似

在一个驻点附近，把损失做二阶泰勒展开：

$$
\mathcal{L}(\theta^\star+\boldsymbol{\delta})\approx \mathcal{L}(\theta^\star)+\tfrac12\,\boldsymbol{\delta}^\top H\,\boldsymbol{\delta},\qquad H=\nabla^2\mathcal{L}(\theta^\star),
$$

其中 **Hessian（黑塞矩阵）** $H$ 是二阶偏导组成的对称矩阵，描述损失曲面在该点的**曲率（curvature）**。$H$ 是对称的，由谱定理（《线性代数》第 7 章）有实特征值与正交特征向量：**特征向量是损失曲面的"主轴"方向，对应的特征值是那个方向上的曲率**（特征值大 = 该方向陡峭、曲率大；特征值小 = 平缓）。$H$ 正定（所有特征值 $>0$）即此处是局部极小（碗状）。

把损失曲面在极小附近想象成一个椭球碗：各方向曲率不同（特征值不同），碗就被拉成**椭圆**。各方向曲率越悬殊，椭圆越扁长——这正是"病态"的几何画面。

把这件事和梯度下降"踩进"地形的方式对上，就明白病态为什么坑人了。在主轴坐标系（沿 Hessian 特征向量看）里，二次损失解耦成 $p$ 个独立的一维问题，第 $i$ 个方向的曲率是特征值 $\lambda_i$。§4.2.3 已经算过：沿曲率 $\lambda_i$ 的方向，梯度下降的收敛因子是 $|1-\eta\lambda_i|$。要让**所有**方向都不发散，$\eta$ 被最大曲率 $\lambda_{\max}$ 卡住（$\eta<2/\lambda_{\max}$）；可在这个 $\eta$ 下，最小曲率方向的收敛因子是 $|1-\eta\lambda_{\min}|\approx 1-2\lambda_{\min}/\lambda_{\max}=1-2/\kappa$，$\kappa$ 大时它贴近 $1$，意味着那个方向**每步几乎不前进**。一句话：**收敛快慢由最慢（最平缓）的那个方向决定，而它慢成什么样，恰好被条件数 $\kappa$ 量化。** 这就是下一小节要正式登场的主角。

### 4.6.2 条件数与病态：为什么把收敛拖慢

定义这个二次碗的**条件数（condition number）** 为 Hessian 最大与最小特征值之比：

$$
\kappa = \frac{\lambda_{\max}(H)}{\lambda_{\min}(H)}\;(\ge 1).
$$

- $\kappa\approx 1$：各方向曲率相近，碗近似**圆形**——梯度处处指向圆心（谷底），梯度下降一路畅通，收敛快。
- $\kappa\gg 1$（**病态 / ill-conditioned**）：碗被拉成又长又窄的"峡谷"——梯度几乎垂直于谷底方向（指向陡壁而非沿谷向下），梯度下降在峡谷两壁间剧烈**之字形（zig-zag）震荡**，沿谷底方向却挪动极慢。收敛速度被 $\kappa$ 拖累：经典结果是，在强凸光滑问题上**取最优定步长** $\eta=2/(\lambda_{\max}+\lambda_{\min})$ 时，梯度下降的误差以**线性速率**收敛，每步收缩因子约为 $\tfrac{\kappa-1}{\kappa+1}$（即 $t$ 步后误差约 $\big(\tfrac{\kappa-1}{\kappa+1}\big)^t$ 这一量级）——$\kappa$ 越大，这个因子越贴近 $1$，每步进步越小，收敛越慢。请注意这是**最优定步长下的最好情形**：换一个非最优的固定 $\eta$ 只会更慢，所以"病态 → 慢"是个对学习率取法稳健的结论，而不是某个巧合步长才有的现象。

这就是**病态**的核心危害：它不改变最优解在哪，却让梯度下降**极难走到那里**。更糟的是，回忆 §4.2.3 的稳定性上限 $\eta<2/\lambda_{\max}$：为了不在陡方向上发散，学习率被 $\lambda_{\max}$ 卡死在一个小值；可这个小步长对平缓方向（$\lambda_{\min}$ 小）来说又慢得要命。**病态把你逼进"陡方向不许迈大步、缓方向又迈不快"的两难**——这正是它拖慢收敛的本质。

> **与数学三课的连接**：这里的条件数 $\kappa=\lambda_{\max}/\lambda_{\min}$ 与《线性代数》第 9 章解线性方程组的条件数是**同一个概念在优化里的化身**。在那门课里，病态矩阵让线性方程组的解对扰动极敏感、迭代解法收敛慢；在这里，病态 Hessian 让梯度下降在峡谷里磨蹭。二者本质相同：**条件数度量"问题在不同方向上的尺度悬殊程度"**，悬殊越大，数值方法越吃力。

### 4.6.3 归一化 / 预处理为什么有用

理解了病态的来源，"该怎么治"就顺理成章：**把椭圆碗掰回圆碗，即降低条件数**。这正是机器学习里许多"看似玄学的好习惯"的统一解释：

- **特征归一化 / 标准化（feature normalization / standardization）**：把每个输入特征减均值、除标准差，使各特征尺度可比。若不归一化，某个量纲大的特征（如"年收入"以元计）会让对应方向曲率巨大、其他方向（如"房间数"）曲率微小，Hessian 极度病态，梯度下降寸步难行。归一化让各方向尺度拉平、$\kappa$ 变小，于是收敛大大加快。**"训练前先标准化特征"不是仪式，是直接降低条件数、加速收敛。**
- **批归一化 / 层归一化（BatchNorm / LayerNorm）**：深度网络里逐层归一化激活，本质上也是在改善每一层优化的"地形条件"，让训练更稳更快（细节留第 9 章，那里会讲清 BN 与 LN 的区别）。
- **预处理 / 预条件（preconditioning）**：更一般地，用一个矩阵 $P$ 变换坐标，让变换后的 Hessian 接近单位阵（$\kappa\approx1$）。**自适应优化器（Adam 等）的逐参数缩放，可以看成一种廉价的对角预条件**——用梯度平方的统计近似 Hessian 的对角，把各方向尺度大致拉平。这给了 §4.5.2 自适应方法"为什么有用"的一个统一解释：它们在自动对抗病态。

> **实战连接（表格数据 / 图像）**：归一化降条件数这件事，在不同领域有不同长相但同一个内核。**表格数据**（信用评分、房价回归）里特征量纲悬殊是常态——"年收入"以万元计、"贷款笔数"是个位数、"违约率"是 $0\sim1$ 的小数，直接喂给逻辑回归 / 线性模型，Hessian 病态到梯度下降几乎不动；标准化（减均值除标准差）或做对数变换后，$\kappa$ 立刻降下来、收敛快好几倍——这是 sklearn 里 `StandardScaler` 几乎总要先套一遍的根本原因（而且要放进 `Pipeline`、只用训练集拟合，否则就是第 2 章 §2.7 的数据泄漏）。**图像**里则换了个形态：像素值天然在 $[0,255]$、各通道尺度相近，所以"逐特征标准化"的收益不如表格大，但人们仍会把像素缩到 $[0,1]$ 或按数据集均值 / 方差做通道归一化，并在网络内部用 BatchNorm 逐层把激活拉回良态——本质都是在持续给优化"修地形"。一句话：**几乎所有"训练前要不要归一化"的工程直觉，背后都是同一个"降条件数、加速收敛"的故事**，只是表格、图像、深层网络各自的入口不同。

- **去相关 / 白化（whitening）**：标准化只拉平了各特征的"尺度"，若特征之间还高度**相关**，Hessian 仍会病态（相关 = 椭圆碗的主轴是斜的、不沿坐标轴）。更彻底的做法是白化——用 PCA / ZCA 把特征旋转去相关再缩放，使协方差近似单位阵（呼应《线性代数》第 8 章 SVD / PCA）。白化代价更高、在高维里不常全做，但它点明了一条阶梯：标准化治"尺度病态"，白化治"相关 + 尺度病态"，预条件是这条思路在优化器内部的一般化身。

### 4.6.4 二阶方法：用曲率信息，但深度学习为何少用

既然病态来自曲率（Hessian），最直接的对策是**显式用上 Hessian**。**牛顿法（Newton's method）** 把更新方向乘上 Hessian 的逆：

$$
\theta_{t+1}=\theta_t-H^{-1}\nabla\mathcal{L}(\theta_t).
$$

直觉上，$H^{-1}$ 把椭圆碗变换回圆碗，于是无论原问题多病态，牛顿法一步就指向（二次函数的）谷底——它对条件数**不敏感**，收敛极快（近最优处二次收敛）。**拟牛顿法（quasi-Newton，如 BFGS / L-BFGS）** 不算真 Hessian，而是用历次梯度差**近似** $H^{-1}$，省去算二阶导的代价，在中小规模光滑问题上非常高效。

那深度学习为什么几乎不用二阶方法？三条诚实的理由：

1. **代价**：Hessian 是 $p\times p$ 矩阵，深度网络 $p$ 动辄上亿，显式存储（$p^2$）和求逆（$O(p^3)$）是天文数字，根本不可行。L-BFGS 省了存储但仍不适合大批量随机、非凸的深度训练。
2. **随机性不友好**：二阶方法对全批量光滑问题最有效，而深度学习是小批量随机的，Hessian 的随机估计噪声大、不稳定。
3. **非凸下牛顿法会走错**：Hessian 不定（鞍点附近有负特征值）时，$-H^{-1}\nabla\mathcal{L}$ 可能指向**上坡**（朝鞍点的极大方向爬），需要额外修正，反而麻烦。

所以深度学习的主流是**一阶方法（梯度下降族）+ 廉价的近似预条件（自适应优化器）**：用 Adam 这种"对角近似二阶"的廉价手段吃到一部分病态的好处，而不付全二阶的代价。这是一个"够用就好"的工程权衡的典范。介于一阶与全二阶之间，还有一些"用结构化近似 Hessian"的尝试（如高斯-牛顿 / Gauss–Newton、自然梯度 / natural gradient、K-FAC 等），它们用比对角更丰富、又比全 Hessian 便宜的近似去对抗病态，在某些场景有效，但都还没动摇"Adam 式一阶自适应"在主流深度学习里的统治地位——可见**优化器设计的核心矛盾，始终是"用多少曲率信息"与"付多少计算代价"之间的取舍**。

> **常见陷阱**：把"换更高级的优化器"当成万能药。新手常以为 loss 不降就该换 Adam、加动量、调更复杂的调度——但如果根子是数据没归一化、学习率离谱、初始化坏、甚至数据有 `NaN` / 标签错位，再花哨的优化器也救不了；反过来，把数据归一化好、学习率搜对，朴素 SGD 都能跑得很好。**优化器是"够用就好"的工具，不是越复杂越好**；遇到训练问题，先查数据、归一化、学习率、初始化这些"地基"，再谈换优化器。更要分清（§4.8.3）：很多看似"优化"的失败其实是泛化问题（过拟合），那更不是任何优化器能修的。

> **要点**：损失曲面的曲率由 Hessian 描述，其特征值是各主轴方向的曲率；条件数 $\kappa=\lambda_{\max}/\lambda_{\min}$ 大（病态）时碗被拉成峡谷，梯度下降之字形震荡、收敛极慢（接回《线性代数》第 9 章）。归一化 / 预条件通过降低 $\kappa$ 加速收敛，自适应优化器是廉价的对角预条件。二阶方法（牛顿 / 拟牛顿）用曲率收敛极快，但因 $p$ 巨大、随机性、非凸不定等代价，深度学习几乎不用。

## 4.7 反向传播预告

我们已经把整章建立在"算得出梯度 $\nabla\mathcal{L}(\theta)$"这个前提上。但对一个有几亿参数、几十层的神经网络，**梯度到底怎么算？** 这一节给个预告，系统讲解留第 7 章。

神经网络的损失是一个**复合函数（composition）**：输入经过一层层变换（线性 + 非线性）最后接上损失，形如 $\mathcal{L}=\ell\big(f_L(\cdots f_2(f_1(\mathbf{x}))\cdots)\big)$。要对最里层的参数求梯度，靠的是微积分里最朴素的工具——**链式法则（chain rule）**：复合函数的导数是各层导数的乘积。

先用一个最小例子把"链式法则给精确梯度"看实在。考虑一个单层逻辑回归：打分 $z=\mathbf{w}^\top\mathbf{x}+b$，预测 $\hat y=\sigma(z)$（$\sigma$ 是 sigmoid），损失 $\ell=-[y\log\hat y+(1-y)\log(1-\hat y)]$（交叉熵）。要算 $\partial\ell/\partial\mathbf{w}$，按链式法则拆成三段乘起来：

$$
\frac{\partial\ell}{\partial\mathbf{w}}=\underbrace{\frac{\partial\ell}{\partial\hat y}}_{\text{交叉熵导}}\cdot\underbrace{\frac{\partial\hat y}{\partial z}}_{\sigma'(z)=\hat y(1-\hat y)}\cdot\underbrace{\frac{\partial z}{\partial\mathbf{w}}}_{=\mathbf{x}}.
$$

代进去，中间那一串会奇迹般地化简成一个极其干净的结果 $\frac{\partial\ell}{\partial\mathbf{w}}=(\hat y-y)\,\mathbf{x}$——预测误差乘以输入。这个"sigmoid + 交叉熵导出 $(\hat y-y)\mathbf{x}$"的化简不是巧合（softmax + 交叉熵也有完全类似的干净形式），它正是第 3 章那些损失被刻意如此设计的原因之一。现在把网络叠到两层：$\mathbf{h}=\phi(W_1\mathbf{x}+\mathbf{b}_1)$、$z=\mathbf{w}_2^\top\mathbf{h}+b_2$、$\hat y=\sigma(z)$，要算 $\partial\ell/\partial W_1$ 就得把链式法则再往里推一层——误差信号 $(\hat y-y)$ 先乘到第二层、再经过激活的导数 $\phi'$ "反向"传到第一层。**这个"误差从输出端一层层乘着传回输入端"的过程，就是反向传播**（完整手推留第 7 章）。

朴素地对每个参数单独用链式法则求导，代价会爆炸（重复计算大量公共子项）。**反向传播（backpropagation, backprop）** 的精髓是：**按计算顺序先做一次前向传播（forward pass）算出损失并缓存各层中间结果，再从输出端的损失开始、沿计算图反向逐层把梯度乘回去（backward pass），系统化地复用中间结果，一次反向就拿到所有参数的梯度。** 它的总代价只是前向传播的常数倍——这是它能让深度学习成立的关键效率。

两点必须先讲清，免得落入常见误解：

- **反向传播不是一种"近似梯度"，它算的是精确（解析）梯度。** 它只是把链式法则在计算图上组织得极其高效，每个偏导都是精确的。把它和数值差分（有限差分近似梯度）混为一谈是初学常见错误（数值差分慢且有截断误差，只用于 §4.8 的梯度检查）。
- **反向传播 = 计算图上的反向模式自动微分（reverse-mode automatic differentiation）。** 这是它在 CS 里的正式身份——一种系统的、可对任意计算图自动求导的技术。今天 PyTorch / JAX / TensorFlow 的 `autograd` / `autodiff` 就是它的工业实现，你写前向、框架自动给你反向。

> **给数学 / CS 读者的视角**：反向传播就是**计算图（computational graph）上的反向模式自动微分**——把整个前向计算记成一张有向无环图，反向遍历时对每个节点应用链式法则、并复用已算出的下游梯度（动态规划式的子问题复用），避免重复计算。当"输出维度（标量损失）远小于输入维度（海量参数）"时，反向模式比前向模式高效得多——这恰是机器学习的典型情形（一个标量损失对上亿参数求导）。这也是为什么深度学习选反向模式而非前向模式自动微分。

> **要点**：神经网络损失是复合函数，其梯度由**链式法则**给出；**反向传播**通过"前向算损失 + 缓存、反向逐层乘梯度 + 复用"以前向常数倍的代价一次算出全部参数梯度，它是**计算图上的反向模式自动微分**、算的是**精确**梯度（非近似）。系统推导留第 7 章。

## 4.8 实战：梯度检查、学习率搜索与失败诊断

理论讲完，落到地面。这一节是你真正训练模型时的"急救手册"。

### 4.8.1 梯度检查：你的梯度算对了吗

自己手写反向传播（或写自定义层）时，**最该做的第一件事是梯度检查（gradient checking）**：用数值差分验证你的解析梯度对不对。对每个参数 $\theta_j$，用中心差分（central difference）估一个数值梯度：

$$
\frac{\partial\mathcal{L}}{\partial\theta_j}\approx \frac{\mathcal{L}(\theta+\epsilon\,\mathbf{e}_j)-\mathcal{L}(\theta-\epsilon\,\mathbf{e}_j)}{2\epsilon},
$$

取小 $\epsilon$（如 $10^{-5}$），把它和你解析算出的梯度比较**相对误差**：$\frac{\|\mathbf{g}_{\text{解析}}-\mathbf{g}_{\text{数值}}\|}{\|\mathbf{g}_{\text{解析}}\|+\|\mathbf{g}_{\text{数值}}\|}$。若 $<10^{-7}$ 多半对，$>10^{-3}$ 几乎肯定有 bug。要点：用中心差分（误差 $O(\epsilon^2)$，比单边的 $O(\epsilon)$ 准）；$\epsilon$ 不能太小（否则浮点抵消误差吃掉精度）；在含不可导点的函数（如 ReLU 在 0、L1 在 0）附近会失真，要避开。**梯度检查只用于调试，太慢不能用于训练**（每个参数两次前向）；调通后关掉，改用框架的 autograd。

### 4.8.2 学习率搜索

学习率是头号超参，值得专门找。两种实用做法：

- **学习率范围测试（LR range test）**：让 $\eta$ 从极小（如 $10^{-7}$）随训练步**指数增大**，画"$\eta$ - loss"曲线。典型形状：$\eta$ 太小时 loss 几乎不降（平段），进入"合适区"时 loss 快速下降（陡降段），$\eta$ 太大时 loss 爆起（发散）。**取 loss 下降最快那段、略小于发散点的 $\eta$** 当起点，往往很好用。
- **网格 / 对数尺度扫描**：在对数尺度上试几个值（如 $10^{-1},10^{-2},10^{-3},10^{-4}$），各跑少量步看 loss 曲线。**永远在对数尺度上搜学习率**（它跨数量级），别在线性尺度等距试。

一个省时的实践顺序：先用很短的训练（几百步）在对数尺度上粗扫，锁定一个"既不发散又下降快"的量级；再在它附近细调，并配上 warmup 与调度。记住 §4.5.3 的提醒——**换优化器要重搜学习率**，Adam 和带动量 SGD 的合适量级差一两个数量级。还有个容易忽略的耦合：学习率和批量大小、和归一化方式都相互影响（§4.4.2 线性缩放规则、§4.6.3 归一化降条件数），所以理想情况下它们要一起调，而不是孤立地拧一个旋钮。

> **常见陷阱**：调超参（含学习率）时，**只能用训练集 / 验证集，绝不能碰测试集**——拿测试集调学习率就是数据泄漏（data leakage）的一种，会让你对泛化的估计虚高（第 2 章 §2.7"模型选择的纪律"，尤其 §2.7.3 数据泄漏一节反复强调过）。学习率搜索属于"模型选择"，必须在验证集上做。

### 4.8.3 常见失败的诊断

训练出问题时，先看 loss 曲线，对号入座：

| 症状 | 可能原因 | 对策 |
|---|---|---|
| **发散**（loss 飙升 / 变 `inf`）| 学习率太大；初始化太大；数据没归一化 | 调小 $\eta$；加 warmup；归一化输入；梯度裁剪 |
| **震荡 / 锯齿**（loss 上下抖、整体不降）| 学习率偏大；batch 太小噪声大；病态曲面 | 调小 $\eta$；加动量；增大 batch；用自适应优化器 |
| **停滞**（loss 卡住不动）| 学习率太小；梯度消失 / 饱和；困在平台 / 鞍点 | 增大 $\eta$；换初始化 / 激活（ReLU）；检查梯度量级；加噪声 / 动量 |
| **`NaN` / `inf`** | 学习率过大；$\log(0)$ / 除零；梯度爆炸；混精溢出 | 调小 $\eta$；数值稳定的损失实现（log-sum-exp）；梯度裁剪；查输入有无 `NaN` |
| **训练降、验证不降甚至升** | 过拟合（不是优化问题，是泛化问题）| 加正则 / 数据增强 / 早停（第 9 章）；这不是调优化器能解决的 |

最后这一行尤其重要：**不是所有"训练不顺"都是优化问题。** "训练 loss 降得很好、验证 loss 却不降"是泛化问题（过拟合），加再多优化技巧也没用——要去第 9 章找正则、增强、早停。把"优化没收敛"（训练 loss 都降不下去）和"优化收敛了但泛化差"（训练降、验证不降）分清，是诊断的第一步。

几个高频数值技巧也值得记住：

- **梯度裁剪（gradient clipping）**：当整体梯度范数 $\|\mathbf{g}\|$ 超过阈值 $c$ 时，按 $\mathbf{g}\leftarrow \mathbf{g}\cdot c/\|\mathbf{g}\|$ 缩回，保留方向、限制步长。它专治偶发的"梯度尖峰"（某个批量恰好让梯度爆掉，一步把参数甩飞、loss 变 `NaN`），是循环网络（RNN，梯度沿时间连乘易爆）和 Transformer 训练里的常备护栏。
- **数值稳定的损失实现**：用 log-sum-exp 技巧算 softmax 交叉熵（先减去最大值再取 $\exp$），避免 $\exp$ 上溢和 $\log 0$ 的 `-inf`；用 `log1p` / `softplus` 等稳定函数。框架内置的 `cross_entropy` 已帮你做了，但自己手写损失时极易踩坑。
- **检查输入数据**：`NaN` / 缺失值、未归一化的巨大数值、标签错位 / 越界——很多被当成"模型 / 优化器问题"的现象，根子其实是数据问题。**调试的第一步永远是先确认喂进去的数据是干净的。**
- **看 loss 曲线的"形状"而非单点**：训练前期 loss 应明显下降；若一开始就横线、或剧烈锯齿、或某步突然尖峰，分别对应停滞 / 学习率偏大 / 梯度尖峰——把"读曲线形状"练成肌肉记忆，比盯单个数字有用得多。

> **诚实的边界**：本节这套诊断表是经验法则的浓缩，**不是放之四海皆准的算法**。同一个症状可能有多个原因，对策也常需组合尝试；真实调试往往是"看曲线—猜原因—小改—再看"的迭代，没有一键修复。把它当成有结构的排查起点，而不是查表就能解决一切的手册。

> **要点**：手写梯度先做**梯度检查**（中心差分比对解析梯度，只用于调试）；学习率在**对数尺度**上用 range test / 扫描搜索，且只在验证集上做（碰测试集 = 泄漏）；失败诊断对号入座（发散 / 震荡 / 停滞 / `NaN`），并牢记"训练降但验证不降"是泛化问题、不是优化能修的。

## 本章小结

本章把第 2、3 章定义好的"目标函数"真正**跑起来**，补齐了暗线二三件套里"优化"那一格：

- **为什么迭代**：闭式解是奢侈品，逻辑回归、神经网络等绝大多数模型没有或不实用，机器学习默认靠迭代优化；核心意象是"在损失曲面 $\mathcal{L}(\theta)$ 上找低谷"。
- **梯度下降**：负梯度是最陡下降方向，更新式 $\theta_{t+1}=\theta_t-\eta\nabla\mathcal{L}(\theta_t)$ 由一阶泰勒保证（$\eta$ 不太大时）下降；学习率太大发散 / 震荡、太小太慢，稳定性上限 $\eta<2/\lambda_{\max}$。
- **凸 vs 非凸**：凸问题（线性模型 + 凸损失）局部最优 = 全局最优、有全局收敛保证；神经网络非凸，**高维下鞍点是主要障碍**（局部极小没那么可怕），**不能声称 SGD 非凸下达全局最优**；而且真正的目标是泛化好、不是损失最低。
- **SGD / 小批量**：用无偏的小批量梯度估计换计算效率，是深度学习命脉；其噪声有**隐式正则**作用（偏好平坦极小），但属经验 + 部分理论，勿神化。
- **现代优化器**：动量（惯性，重球类比）解决方向，自适应学习率（Adam/AdamW）解决逐参数步长，调度（衰减 + warmup）随进程调步——但 Adam 非永远最优。
- **条件数与病态**：曲率由 Hessian 刻画，$\kappa=\lambda_{\max}/\lambda_{\min}$ 大则峡谷震荡、收敛慢（接《线性代数》第 9 章）；归一化 / 预条件降 $\kappa$ 加速，自适应优化器是廉价对角预条件；二阶方法快但因代价太大、随机、非凸而在深度学习少用。
- **反向传播预告**：复合函数梯度靠链式法则，反向传播 = 计算图上反向模式自动微分，算精确梯度、代价是前向常数倍（详见第 7 章）。
- **实战**：梯度检查、对数尺度学习率搜索、发散 / 震荡 / 停滞 / `NaN` 诊断，并区分"优化没收敛"与"泛化差"。

回扣三条暗线：**暗线二**——本章是三件套里"优化"那一格的主场，表示与目标定义了损失地形，优化负责在地形里找谷底，三者缺一不可。**暗线一**——我们反复强调优化的真正目标不是把训练损失压到全局最小（那常伤泛化），而是找到泛化好的解；SGD 的隐式正则正是优化与泛化的咬合点。**暗线三**——优化算法本身（SGD 噪声、最小范数偏好、自适应缩放）携带着隐式的归纳偏置，它在众多解中"挑哪一个"，本身就是一种结构性先验。优化不是中立的求解器，它也在悄悄塑造你最终学到的是什么。

## 动手与思考练习

**练习 4.1（动手·编程）** 手写最朴素的全批量梯度下降，在一维 / 二维二次损失（如 $\mathcal{L}(\theta)=\tfrac12\theta^\top H\theta$，自取一个对角 $H=\mathrm{diag}(1,a)$）上跑，画出不同学习率下的轨迹与 loss 曲线，复现"太小慢、合适收敛、偏大震荡、太大发散"四种现象。

*参考答案 / 要点*：用 numpy。更新 `theta -= eta * H @ theta`。取 $H=\mathrm{diag}(1, 20)$（条件数 20，病态）能清楚看到沿小曲率方向慢、沿大曲率方向震荡的之字形。逐步增大 `eta`：当 `eta` 超过 $2/\lambda_{\max}=2/20=0.1$ 时发散，验证 §4.2.3 的 $\eta<2/\lambda_{\max}$。
*延伸思考*：把 $H$ 的条件数调到 100，观察之字形如何加剧、需要把 $\eta$ 压多小才不发散——这就预演了 §4.6 病态的危害。

**练习 4.2（动手·编程）** 在练习 4.1 的病态二次损失上，加上动量（$\beta=0.9$）再跑，对比无动量的轨迹。

*参考答案 / 要点*：动量版更新 `v = beta*v + grad; theta -= eta*v`。你会看到：沿陡方向的来回震荡被相互抵消、显著减弱，沿缓方向的下降被持续累加、明显加速，总迭代步数大幅减少。这正是 §4.5.1 "沿峡谷加速、抵消震荡"的直接体现。
*延伸思考*：把 $\beta$ 从 0 调到 0.99，画收敛步数随 $\beta$ 的变化——会发现存在一个甜点，过大反而因惯性过冲而变差。再进一步：二次损失是"教学玩具"，换到**真实的非二次损失**上动量还这么干净吗？拿 sklearn 的手写数字训一个单隐层 MLP（非凸、非二次），对比 SGD 与 SGD+动量的训练曲线，你多半会看到动量仍明显加速，但"甜点 $\beta$"更难预测、且与学习率强耦合——这正是真实地形不是规整椭圆碗、各处曲率随位置变化（Hessian 不再是常矩阵）的直接后果。把"二次损失上的干净结论"当成直觉来源、而非真实网络的精确预言，是用好这些理论的正确姿势。

**练习 4.3（思考）** 为什么说"高维空间里鞍点比局部极小多得多"？给一个基于 Hessian 特征值符号的直观论证。明确这对"梯度下降在非凸下会被坏局部极小卡死"这个担忧意味着什么。

*参考答案*：驻点处 Hessian 对称、有 $p$ 个实特征值。该点是局部极小需**全部** $p$ 个特征值为正；是鞍点只需有正有负。若粗略把各特征值符号看成独立正负各半，"全正"概率约 $2^{-p}$，$p$ 大时趋于零，故高维驻点几乎都是鞍点。含义：在深度网络里，优化的主要障碍不是"被坏局部极小卡死"（它们稀少且许多损失值相近），而是**鞍点附近梯度小导致的减速**；而 SGD 噪声与动量通常能帮助逃离鞍点。
*延伸思考*：这是否说明"非凸完全不用怕"？（不——见 §4.3.3 诚实边界：找的是泛化好的解，"许多极小都够好"是经验而非定理。）

**练习 4.4（动手·编程）** 在一个真实数据集（如 sklearn 的手写数字 / 鸢尾花）上训练逻辑回归，分别用全批量 GD、纯 SGD（batch=1）、小批量 SGD（batch=64），在相同计算预算（相同样本访问总量）下比较 loss 随"已访问样本数"下降的速度，并画出 SGD 的 loss 曲线的抖动。

*参考答案 / 要点*：自己写或用 pytorch。横轴用"已处理样本数"（而非迭代步）才公平。典型结论：在相同样本预算下，小批量 SGD 的 loss 下降**远快于**全批量（每个 epoch 做了 $n/B$ 次更新）；纯 SGD 抖动最大、小批量较平滑、全批量最平滑但慢。这复现 §4.4.2 的计算 vs 统计权衡。
*延伸思考*：逻辑回归是凸问题，三种方法最终都收敛到同一个全局最优——验证这点（最终 loss 几乎相同），并体会"凸问题里优化器只影响速度、不影响落点"。

**练习 4.5（思考）** 同事说："我把学习率调得特别小，这样最稳，肯定能收敛到最好的解。"请指出这句话里至少两个错误。

*参考答案*：(1) 太小的学习率收敛极慢，固定预算下可能根本没走到谷底就停了，"稳"不等于"到位"。(2) 在非凸地形里，过小的步子更易卡在第一个遇到的平庸驻点 / 鞍点 / 平台出不来，反而更难找到好解。(3)"收敛到最好的解"在非凸下本就没有保证——学习率大小不改变这个事实（§4.3）。(4) 还忽略了 SGD 噪声的隐式正则收益：噪声（与 $\eta/B$ 相关）太小可能损失泛化益处。
*延伸思考*：那"学习率越大越好"对不对？（也不对——太大发散；正确口径是"在不发散前提下尽量大"，并配调度。）

**练习 4.6（动手·编程）** 实现梯度检查：对一个自己手写的两层小网络（或任意自定义损失），用中心差分数值梯度与解析梯度比对相对误差，并故意在反向传播里植入一个 bug（如漏乘某层导数），看相对误差如何从 $\sim10^{-8}$ 跳到 $\sim10^{-1}$。

*参考答案 / 要点*：实现 §4.8.1 的中心差分公式，逐参数算数值梯度，与解析梯度算相对误差。正确实现相对误差应 $<10^{-6}$；植入 bug 后会暴涨。注意 $\epsilon$ 取 $10^{-5}$ 量级、用中心差分、避开 ReLU 等不可导点。
*延伸思考*：为什么不直接用数值梯度训练网络？（太慢——每个参数两次前向，$p$ 亿时不可行；且有截断 / 舍入误差。数值梯度只配做调试的"裁判"。）

**练习 4.7（思考）** 解释为什么"训练前标准化特征"能加速梯度下降收敛，用条件数的语言说清楚。并说明这和自适应优化器（Adam）有什么关系。

*参考答案*：不标准化时，量纲大的特征使损失曲面沿对应方向曲率极大、其他方向曲率极小，Hessian 条件数 $\kappa$ 很大（病态），梯度下降之字形震荡、收敛慢，且 $\eta$ 被最陡方向卡死（$\eta<2/\lambda_{\max}$）。标准化让各方向尺度拉平、$\kappa$ 减小、碗变圆，收敛大大加快。关系：自适应优化器逐参数按梯度平方缩放步长，相当于一种廉价的对角预条件，也在自动对抗病态——所以它对"没归一化"更鲁棒一些，但不能完全替代归一化（§4.6.3）。
*延伸思考*：若特征间还高度相关（不只是尺度不同），单纯逐特征标准化够吗？（不够——相关性带来的病态需要 whitening / PCA 之类去相关，呼应《线性代数》第 8 章。）

**练习 4.8（思考）** 给出"训练 loss 一直降不下去"与"训练 loss 降得很好但验证 loss 不降"两种情形各自的诊断方向，说明为什么后者加再多优化技巧也无济于事。

*参考答案*：前者是**优化问题**——查学习率（太大发散 / 太小停滞）、初始化、梯度量级（消失 / 爆炸）、数据有无 `NaN` / 未归一化，对策见 §4.8.3 诊断表。后者是**泛化问题（过拟合）**——优化其实成功了（训练 loss 降了），问题在模型记住了训练集噪声，泛化不了；这要靠正则、数据增强、早停、减容量（第 9 章），调优化器 / 学习率改变不了过拟合的本质。把"优化没收敛"和"收敛了但泛化差"分清，是诊断第一步。
*延伸思考*：有没有可能两者同时存在？（有——大模型上常见先解决优化（让训练降下去）、再解决泛化（控过拟合）；顺序通常是先确保能训起来，再管泛化。）

- *Deep Learning*（Goodfellow, Bengio, Courville）——第 8 章"训练深度模型的优化"系统讲 SGD、动量、自适应方法、初始化与病态，与本章 §4.4–4.6 最贴合。
- *Optimization for Machine Learning*（Bottou, Curtis, Nocedal 的综述 *Optimization Methods for Large-Scale Machine Learning*）——把大规模随机优化的计算 vs 统计权衡讲得最清楚，呼应 §4.4。

**论文 / 讲义（深化与诚实边界）**
- Kingma & Ba 提出 Adam 的工作——§4.5.2 自适应优化器的代表性来源（注意后续对其收敛性的讨论与 AMSGrad / AdamW 等修补）。
- Dauphin 等关于"高维非凸里鞍点是主要障碍"的论述——§4.3.2 那个反直觉结论的代表性来源。
- 关于 SGD 隐式正则 / 偏好平坦极小的一系列工作（如 Keskar 等论 batch 大小与平坦极小、Hochreiter & Schmidhuber 早提"平坦极小"）——§4.4.3 的来源，请配合其争议一起读（"平坦"定义对参数重缩放敏感）。
- 任意一份深度学习课程（如 Stanford CS231n / cs224n）的"优化 / 训练技巧"讲义——把 warmup、调度、梯度裁剪、诊断这些实战内容讲得很接地气，呼应 §4.5.3、§4.8。

**姊妹课交叉**
- 《线性代数》第 7 章（谱定理 / 正定 / 二次型）支撑 §4.3 凸性的 Hessian 判据与 §4.6 曲率 / 特征值；第 9 章（数值线性代数 / 条件数 / 稳定性）是 §4.6 病态与预条件的母本；第 8 章（SVD / 最小范数解）呼应 §4.3.3 优化的隐式偏好与练习 4.7。

> **一句话收束**：优化是机器学习的引擎——它不改变你想要什么（表示与目标定义了损失地形），只负责把它找出来；学会把训练看成"在损失曲面上找一个又低又泛化好的谷底"，并永远记得：凸问题里找到即最优，非凸里我们要的从来不是全局最优，而是泛化好的解。
