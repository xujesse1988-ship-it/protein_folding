# 第 5 章 经典机器学习方法：树、核、近邻与集成

> **本章定位**：前四章我们沿着一条线把机器学习的骨架立了起来——第 2 章把"学习"形式化成在风险下选模型、把泛化（暗线一）与偏差-方差讲透；第 3 章端出第一组具体模型（线性模型），完成了「表示 + 目标 + 优化」三件套（暗线二）的第一次实演；第 4 章把"优化"这台引擎讲透。但到目前为止，我们的"表示"那一格里只装过线性函数（及其基函数变体）。本章我们暂时离开"线性 → 深度"这条主干道，横向巡礼一批**经典（非深度）机器学习方法**：k 近邻、决策树、随机森林与梯度提升、支持向量机与核技巧、朴素贝叶斯。它们不是历史陈列，而是今天工业界天天在用的主力（表格数据上梯度提升至今是王者），更是理解**归纳偏置（暗线三）的最佳教具**——每个方法都对应一种鲜明、可对照的"对世界结构的赌注"：kNN 赌"近朱者赤"、决策树赌"轴对齐的分段常数"、SVM 用核把"线性"偷偷搬进高维、朴素贝叶斯赌"特征条件独立"。把它们摆在一起对照，暗线三会迎来全课第一次集中爆发（§5.7 那张归纳偏置对比表）。本章也会反复回扣偏差-方差（暗线一）——bagging 降方差、boosting 降偏差，是这条暗线最干净的两个对照实验。最后我们会诚实地划出边界：在图像 / 文本 / 语音这类感知数据上，深度学习碾压经典方法；但在表格 / 小数据上，经典方法（尤其梯度提升）未必输——**选哪个，归根到底取决于数据的结构与你的归纳偏置是否对得上**。

## 5.1 为什么今天仍要学经典方法

很容易产生一种错觉：既然深度学习在图像、语言、语音上势如破竹，经典方法是不是该进博物馆了？恰恰相反。一个想"懂为什么、能判断、能改进"的人，比只会调深度模型的人更需要把经典方法吃透。原因有四，每一条都直接服务于本课的三条暗线。

**第一，可解释（interpretability）。** 一棵决策树可以画在一张纸上，逐条 if-else 读给业务方听；逻辑回归的每个系数有明确的"几率比"含义；kNN 的预测可以直接追溯到"是哪几个邻居投的票"。在风控、医疗、信贷这些**需要给监管和当事人一个理由**的场景里，"模型说不行"是不够的，你必须能说"因为收入低于阈值且负债率超过 X"。深度网络的黑箱性在这里是硬伤。经典方法天然带着可解释性，这不是落后，而是另一个维度上的优势。

**第二，小数据上更强、更省。** 深度学习的统治建立在**大数据 + 大算力**之上。当你手里只有几百到几万条样本（这在科学、工业、金融里极其常见），训练一个大网络往往直接过拟合，而一棵正则良好的梯度提升树、一个带核的 SVM、甚至一个朴素贝叶斯，常常又快又稳又准。**样本少时，强归纳偏置（强假设）反而是救命的**——这正是暗线三的核心：偏置不是缺点，是用先验补数据之不足。

**第三，表格数据上梯度提升仍是王者。** 这是必须坦白讲清的一个事实（也是本章的「诚实的边界」之一）：在**结构化 / 表格数据（tabular data）**——每一行是一个样本、每一列是一个有独立语义的特征（年龄、收入、点击率……）——上，以 XGBoost / LightGBM / CatBoost 为代表的**梯度提升决策树（gradient-boosted decision trees, GBDT）** 至今是综合最强的方法，在大量真实业务和数据竞赛里稳压深度网络。原因我们会在 §5.7 讲清：表格特征没有图像的局部 / 平移结构、没有语言的序列结构，深度网络赖以发威的归纳偏置在这里派不上用场，而树的"轴对齐分段"恰好契合表格特征的语义。

**第四，它们是理解归纳偏置的最佳教具。** 这是本章在全课里最独特的价值。线性模型只有一种偏置（线性），不足以让你"对照"。而本章六七种方法，归纳偏置各不相同、强弱分明、擅长场景互补——把它们排成一排，你第一次能**看见**"不同的结构假设导致不同的擅长 / 不擅长"。这就是暗线三说的："机器学习的艺术，就是把归纳偏置和问题的真实结构对上。"没有对照，就理解不了这句话；本章就是那个对照实验室。

还有一条贯穿全章的工程纪律值得先立起来：**任何项目都该先跑一个经典基线（baseline）再上深度模型。** 一个 5 分钟训完的逻辑回归 / 随机森林 / GBDT，能立刻告诉你三件事——这个问题到底有多难（基线准确率多少）、特征里有没有信号、你后面那个大模型有没有真的赚到。无数"深度学习项目"最后发现还不如一个调好的 GBDT，正是因为跳过了这一步。把经典方法当成你的"对照组"和"诚实标尺"，是一个成熟实践者的本能。

> **给数学 / CS 读者的视角**：把经典方法当成数据结构 / 算法课里的"经典算法谱系"来读会很顺手。kNN 像暴力最近邻搜索（可用 KD 树 / 球树 / 近似最近邻加速），决策树是递归的贪心划分（像 quicksort 选 pivot 那样选分裂点），随机森林 / GBDT 是把弱学习器组合的元算法（像分治 / 投票），SVM 是一个带约束的凸二次规划（QP），朴素贝叶斯是一次贝叶斯公式的直接套用。它们各自的"假设空间 + 求解算法"清清楚楚，是练习暗线二（三件套）解剖刀最好的标本。

> **要点**：经典方法不是过时品。它们在**可解释、小数据、表格数据**三个战场上仍是主力（GBDT 在表格上至今最强），更是理解**归纳偏置（暗线三）的最佳对照教具**——把多种不同偏置的方法摆在一起，才能看清"结构假设 = 先验"这件事。

## 5.2 k 近邻：最简单的非参数方法

### 5.2.1 直觉：近朱者赤

k 近邻（k-nearest neighbors, kNN）是整个机器学习里思想最朴素的方法，朴素到几乎不像一个"算法"：**要预测一个新样本，就去训练集里找离它最近的 $k$ 个样本，让这 $k$ 个邻居投票（分类）或取平均（回归）。** 没有公式要拟合，没有参数要优化，没有损失要最小化——它把"学习"几乎完全推迟到了预测的那一刻。

形式化一下。给定训练集 $\{(\mathbf{x}_i, y_i)\}_{i=1}^n$ 和一个距离度量 $d(\cdot,\cdot)$，对新点 $\mathbf{x}$，找出距离最近的 $k$ 个训练点的下标集合 $N_k(\mathbf{x})$，则

- **分类**：$\hat y(\mathbf{x}) = \text{多数票}\big(\{y_i : i \in N_k(\mathbf{x})\}\big)$；
- **回归**：$\hat y(\mathbf{x}) = \dfrac{1}{k}\sum_{i \in N_k(\mathbf{x})} y_i$。

就这么简单。它的归纳偏置（暗线三）可以一句话概括：**假设"邻近的点有相近的标签"，即目标函数在特征空间里是局部光滑、局部相似的。** 这个假设非常弱、非常普适——几乎所有合理的函数都局部连续——这正是 kNN 几乎不挑问题、能当万能基线的原因，也是它一旦遇到"维数灾难"就崩溃的根源（§5.2.4）。

> **概率视角**：kNN 不是"没有理论的土办法"，它有漂亮的概率根基。$k$-NN 分类本质是用"$k$ 个邻居里各类的比例"去估计局部后验 $P(y\mid\mathbf{x})$——这是对**贝叶斯最优分类器（Bayes-optimal classifier）** 的一种非参数估计。著名的渐近结论：当 $n\to\infty$、且 $k$ 随之恰当增长（$k\to\infty$ 但 $k/n\to 0$）时，kNN 的错误率会收敛到贝叶斯最优错误率（理论下界）。特别地，**Cover–Hart 定理**给出：$1$-NN 在大样本下的渐近错误率 $R_{1\text{NN}}$ 满足 $R_{1\text{NN}} \le 2R^*(1-R^*) \le 2R^*$，其中 $R^*$ 是贝叶斯最优错误率——"不超过两倍"是把 $2R^*(1-R^*)$ 放松后的常用上界（更精确的是 $\le 2R^*(1-R^*)$）。这是一个相当强的"几乎不用学就接近最优"的保证。代价当然是：这些保证都假设数据足够稠密，而稠密在高维下需要的样本量是天文数字（又回到维数灾难）。kNN 因此是"理论很美、实践受维度限制"的典型。

### 5.2.2 非参数与"懒惰学习"

kNN 是**非参数方法（non-parametric method）** 的代表。"非参数"不是说它没有任何可调量（$k$ 和距离度量就是要调的），而是说它**不假设目标函数有固定形式、参数个数不固定**——模型的"复杂度"随训练数据量增长。线性回归是参数方法：无论 $n$ 是 100 还是 100 万，它永远只有 $d+1$ 个参数，训练完就可以把数据扔掉。kNN 恰恰相反：它**把整个训练集就当成模型**，预测时必须随身带着全部数据。

正因如此，kNN 被称为**懒惰学习（lazy learning）**：训练阶段它什么也不做（顶多建个加速索引），把所有计算"懒"到预测时才付。与之相对的逻辑回归、神经网络是**急切学习（eager learning）**：训练时辛苦优化、把知识压进参数，预测时一次前向就出结果。这带来一组鲜明的权衡：

| | kNN（懒惰 / 非参数） | 线性 / 神经网络（急切 / 参数） |
|---|---|---|
| 训练成本 | 几乎为零（只存数据 / 建索引） | 高（迭代优化） |
| 预测成本 | 高（每次要搜全集 $O(nd)$） | 低（一次前向） |
| 存储 | 全部训练数据 | 只存参数 |
| 灵活性 | 极高（能拟合任意局部形状） | 受假设空间限制 |
| 数据需求 | 高维下需要海量数据 | 偏置强、小数据更省 |

> **给数学 / CS 读者的视角**：朴素 kNN 预测是一次线性扫描 $O(nd)$。工业上用**空间索引**加速：低维用 KD 树 / 球树（ball tree）把搜索降到近似 $O(\log n)$；高维（KD 树会退化）用**近似最近邻（approximate nearest neighbor, ANN）**，如 HNSW 图、LSH、乘积量化（product quantization）。今天的**向量数据库（vector database）**和大模型 **检索增强生成（RAG）** 的检索层，本质就是大规模高维 ANN——kNN 的思想以"语义检索"的面貌活在最前沿。

### 5.2.3 距离度量的选择：决定一切

kNN 的全部"智能"都藏在那个距离度量 $d$ 里——它定义了"什么叫近"，而"近"决定了一切。常见选择：

- **欧氏距离（Euclidean / $L_2$）**：$d(\mathbf{x},\mathbf{z}) = \|\mathbf{x}-\mathbf{z}\|_2 = \sqrt{\sum_j (x_j - z_j)^2}$。最常用，但对量纲敏感。
- **曼哈顿距离（Manhattan / $L_1$）**：$\sum_j |x_j - z_j|$。对异常维度更鲁棒。
- **余弦相似度（cosine）**：$\frac{\mathbf{x}^\top \mathbf{z}}{\|\mathbf{x}\|\|\mathbf{z}\|}$，只看方向不看长度，文本 / 嵌入向量常用。
- **马氏距离（Mahalanobis）**：$\sqrt{(\mathbf{x}-\mathbf{z})^\top \Sigma^{-1}(\mathbf{x}-\mathbf{z})}$，用协方差矩阵 $\Sigma$ 的逆来"拉正"各方向的尺度与相关性。

这里藏着 kNN 最大的实践陷阱。欧氏距离把所有特征"平等"对待，于是**量纲大的特征会主宰距离**：若一个特征是"年收入"（量级 $10^5$）、另一个是"年龄"（量级 $10$），不做缩放的话，距离几乎完全由收入决定，年龄形同虚设。所以**用 kNN 前几乎总要先标准化（standardization）**（每维减均值除标准差）。

> **常见陷阱**：(1) **不标准化** → 大量纲特征垄断距离，是 kNN 头号坑。(2) **标准化的统计量（均值 / 方差）必须只从训练集算**，再套用到验证 / 测试集——若先在全集上标准化再划分，就发生了**数据泄漏（data leakage）**，测试性能虚高（呼应第 2 章）。(3) $k$ 取偶数在二分类里可能平票；$k$ 太小过拟合（被噪声邻居带偏）、太大欠拟合（把远处不相关的点也拉进来投票）。$k$ 是 kNN 的容量旋钮，用验证集调。

马氏距离值得多说一句：它等价于"先用 $\Sigma^{-1/2}$ 做白化（whitening）变换、再算欧氏距离"。也就是说，**选距离度量 = 选特征空间的几何**，这正是暗线三（归纳偏置）在 kNN 上的化身——你对"什么方向上的差异更重要"的假设，全编码在度量里。更进一步，**度量学习（metric learning）** 就是直接从数据里学一个最好的 $\Sigma$（或一个把样本映射到"语义距离合理"的嵌入空间的映射），让同类近、异类远。

还有一个小而实用的改进：**距离加权投票（distance-weighted kNN）**。朴素 kNN 让 $k$ 个邻居"一票一票平等地投"，但凭什么离得很近的邻居和勉强挤进前 $k$ 名的远邻居权重一样？更合理的做法是按距离的倒数（或高斯权重 $\exp(-d^2/2\sigma^2)$）加权，让近邻说话更响。这一改动让 kNN 对 $k$ 的选择更不敏感（远邻居自动被压低权重），也让预测函数更平滑。值得注意的是，**距离加权 kNN 在 $k\to n$、用高斯权重的极限下，就和 RBF 核方法 / 核密度估计连成了一片**——"看附近的点、按距离加权"是 kNN、RBF-SVM、核回归共享的同一种归纳偏置，§5.7 的对比表会再点这个深层联系。

顺带厘清 kNN 的**决策边界长什么样**：$1$-NN 的决策边界是把空间按"离哪个训练点最近"切成的**Voronoi 图（Voronoi diagram）**——一堆不规则多边形拼块，边界可以任意弯曲、毫无平滑约束。这正是 kNN 假设空间极其灵活（能拟合任意局部形状）却又极易被噪声带偏（$k=1$ 时把每个噪声点都圈成自己的领地）的几何根源。增大 $k$ 相当于对这些拼块做平滑、把边界"磨圆"——$k$ 调的就是边界的粗糙程度，也就是容量。

> **与数学三课的连接**：距离、范数、内积、白化全是《线性代数》第 4 章（内积 / 范数 / 正交 / 投影，[`../linear_algebra_course/04_inner_product_orthogonality.md`](../linear_algebra_course/04_inner_product_orthogonality.md)）的对象。马氏距离里的 $\Sigma^{-1}$ 是《概率与统计》第 5 章多元高斯的**精度矩阵（precision matrix）**——马氏距离正是高斯密度等高线的"半径"，所以它"按数据的协方差结构来量远近"。选度量 = 在特征空间里换一种内积 / 几何。

### 5.2.4 维数灾难：高维下近邻失效

kNN 在低维下近乎完美，在高维下却会戏剧性地崩溃。这个现象叫**维数灾难（curse of dimensionality）**，是高维几何反直觉性的集中体现，也是理解"为什么需要更强结构假设"的关键一课。

核心事实：**在高维空间里，所有点彼此都差不多远，"最近邻"失去意义。** 给一个可量化的版本：设 $d$ 维空间里点均匀分布，考虑一个查询点到所有数据点的距离，记最近距离 $d_{\min}$、最远距离 $d_{\max}$。可以证明（在相当宽的条件下）

$$
\frac{d_{\max} - d_{\min}}{d_{\min}} \xrightarrow{\;d\to\infty\;} 0 .
$$

也就是说，**维度越高，最近点和最远点的相对差距越趋于零**——"谁是邻居"变成了几乎随机的事，kNN 赖以工作的"局部相似"假设彻底瓦解。

再给一个更直观的体积论证。要让一个 $k$ 邻居的小邻域"装下"训练集里固定比例 $r$ 的点，这个邻域在每一维上需要的边长大约是 $r^{1/d}$。当 $d=10$、$r=0.01$（只取 1% 的点）时，每维边长 $\approx 0.01^{0.1}\approx 0.63$——也就是说，为了圈住区区 1% 的数据，你的"局部"邻域在每一维上都要横跨整个数据范围的 63%。**"局部"在高维下根本不局部**，邻居其实离得很远，相似性假设名存实亡。

> **与数学三课的连接**：这正是《线性代数》与《概率与统计》里反复强调的高维几何反直觉——高维球的体积几乎全集中在表层薄壳、高维高斯的质量集中在一层"肥皂泡"上、随机向量几乎两两正交。所有这些都说明：**高维空间是"空旷"的，数据点稀疏到彼此都像在天涯**。kNN 对维度最敏感，因为它是纯粹基于距离的；这也解释了为什么高维任务需要**先降维**（PCA / 自编码器，第 6 章）或用**带强结构假设的模型**（卷积、注意力）来对抗稀疏。

> **诚实的边界**：维数灾难听起来像给 kNN 判了死刑，但现实没那么糟。真实高维数据往往**并不真的填满高维空间**，而是聚集在一个低维的**流形（manifold）**上（流形假设，manifold hypothesis）——比如所有"自然图像"在像素空间里只占极小一隅。在这种情形下，"有效维度"远低于名义维度，kNN（在合适的嵌入空间里）仍可工作。所以更准确的说法是：**kNN 怕的是"高的内在维度"，不是高的名义维度**；先用表示学习把数据嵌入到低维语义空间，再做近邻检索，正是 RAG / 人脸识别 / 推荐召回的标准套路。

> **实战连接（推荐召回 / 以图搜图 / RAG）**：kNN 的思想在今天的大规模系统里无处不在，只是换了名字叫"向量检索"。推荐系统的**召回**阶段把用户和物品都编码成向量，用近似最近邻（ANN）从亿级物品里捞回最相似的几千个；**以图搜图 / 人脸识别**把图片编码成嵌入向量，比的就是嵌入空间里的最近邻；大模型的**检索增强生成（RAG）** 把文档切块编码进向量数据库，回答问题时先检索最相关的几块再喂给模型。它们的共同套路都是 §5.2.4 那条「诚实的边界」的活用——**先用深度模型把原始数据嵌入到低维语义空间（绕开维数灾难），再在那个空间里做 kNN**。经典思想 + 现代表示 = 强大系统。

> **要点**：kNN 是非参数、懒惰学习的代表，归纳偏置是"局部相似"（极弱极普适）。它把整个训练集当模型，$k$ 是容量旋钮。**距离度量决定一切**，用前几乎必须标准化（且统计量只从训练集算，防泄漏）。它对**维数灾难**最敏感——高维下近邻失去意义，但若数据实际位于低维流形，在合适嵌入空间里仍管用。

## 5.3 决策树：递归划分特征空间

### 5.3.1 直觉：一连串 if-else

**决策树（decision tree）** 是把"做决定"这件事画成一棵树：从根节点开始，每个内部节点问一个关于某个特征的问题（"年龄 > 30 吗？""收入 ≤ 5 万吗？"），按答案往左或往右走，直到叶子节点给出预测。它读起来就是一串嵌套的 if-else，是所有 ML 模型里**最贴近人类直觉决策方式**的一个。

它的工作原理是**递归地把特征空间切成一个个矩形盒子（轴对齐的超矩形）**，每个盒子里给一个常数预测（分类是多数类、回归是均值）。所以一棵决策树表达的函数是一个**分段常数函数（piecewise-constant function）**，它的决策边界是一堆**与坐标轴平行的线段 / 超平面**。这就是它的归纳偏置（暗线三）：**假设目标可以用"对单个特征逐次设阈值"的轴对齐分段常数来很好地逼近。**

用暗线二的三件套来解剖：**表示** = 轴对齐的分段常数函数（由树的结构 + 各叶子的取值决定）；**目标** = 让每次分裂后子节点尽量"纯"（同一叶子里样本标签尽量一致）；**优化** = 自顶向下的贪心递归划分（不是全局最优——找全局最优树是 NP 难，所以用贪心）。

值得停一下品味决策树在可解释性上的特殊地位。它和线性模型是两种**不同风味的可解释**：线性模型的解释是"全局的、加性的"——每个特征有一个固定系数，影响在全空间一致；决策树的解释是"局部的、规则式的"——一条从根到叶的路径就是一条人类能读的 if-else 规则（"年龄 < 30 且 月收入 < 5000 且 已有贷款 → 拒绝"）。在需要把判决理由摆给业务方、监管者、甚至当事人看的场景（信贷审批、医疗分诊），这种"能逐条念出来的规则"极其宝贵。这也是为什么即便单棵树预测精度常输给集成，它在"需要可审计、可追责"的地方仍有不可替代的位置——可解释性本身就是一种价值维度（§5.1 第一条）。

### 5.3.2 分裂准则：信息增益与基尼不纯度

树的核心问题是：**每个节点该选哪个特征、哪个阈值来分裂？** 准则是"分裂后让子节点尽量纯"。怎么量化"纯"？两个主流选择，都直接呼应信息论与概率。

设某节点里样本属于 $K$ 类，各类比例为 $p_1,\dots,p_K$。

**（1）熵（entropy）与信息增益（information gain）。** 节点的熵定义为

$$
H = -\sum_{k=1}^K p_k \log_2 p_k .
$$

熵衡量这个节点的"标签混乱程度"：全是一类时 $H=0$（最纯）、各类均匀时 $H$ 最大（最乱）。一次分裂把父节点分成若干子节点，**信息增益**就是父节点的熵减去子节点熵的加权平均：

$$
\text{IG} = H_{\text{父}} - \sum_{c} \frac{n_c}{n} H_c ,
$$

其中 $n_c$ 是子节点 $c$ 的样本数。选信息增益最大的分裂，就是选"最能消除标签不确定性"的那个问题。这正是 ID3 / C4.5 算法的准则。

**（2）基尼不纯度（Gini impurity）。** CART 算法用的另一个准则：

$$
G = 1 - \sum_{k=1}^K p_k^2 = \sum_{k\ne k'} p_k p_{k'} .
$$

它等于"随机抽两个样本、类别不同"的概率，同样是全一类时为 0、均匀时最大。基尼和熵在实践中表现极接近（基尼少算一个 $\log$，略快，是 scikit-learn 默认）。

> **与数学三课的连接**：信息增益就是《信息论》第 3、4 章的对象。父节点熵减子节点条件熵的加权平均，**正是特征 $X_j$（按这个阈值离散化后）与标签 $Y$ 的互信息（mutual information）** $I(Y; X_j)$ 的样本估计！所以"选信息增益最大的分裂"等价于"选与标签互信息最大的特征"——决策树在每一步都在做信息论意义上"最能减少标签不确定性"的提问。基尼不纯度则可看成熵的低阶（一阶 / 线性）泰勒近似——用 $-\ln p \approx 1-p$ 替换熵里的对数，便得到 $\sum_k p_k(1-p_k)=1-\sum_k p_k^2$，正是基尼。详见《信息论》第 4 章（[`../information_theory_course/04_kl_mutual_information.md`](../information_theory_course/04_kl_mutual_information.md)）。

回归树用类似思路，只是把"不纯度"换成**方差 / 均方误差**：选让子节点内部 $\sum (y_i - \bar y_c)^2$ 之和最小的分裂。

**一个手算的小例子，把"分裂准则"落地。** 设一个节点有 10 个样本，6 个正类、4 个负类。它的熵是 $H_{\text{父}} = -0.6\log_2 0.6 - 0.4\log_2 0.4 \approx 0.971$（接近 1，比较乱）。现在考虑两个候选分裂：

- **分裂 A**：左子节点 (5 正, 1 负)、右子节点 (1 正, 3 负)。左熵 $H_L = -\tfrac56\log_2\tfrac56 - \tfrac16\log_2\tfrac16 \approx 0.650$，右熵 $H_R = -\tfrac14\log_2\tfrac14 - \tfrac34\log_2\tfrac34 \approx 0.811$。加权子熵 $= \tfrac{6}{10}(0.650) + \tfrac{4}{10}(0.811) \approx 0.714$，信息增益 $\text{IG}_A \approx 0.971 - 0.714 = 0.257$。
- **分裂 B**：左 (3 正, 2 负)、右 (3 正, 2 负)。两个子节点比例和父节点一样（都是 0.6 / 0.4），毫无信息，$\text{IG}_B = 0.971 - 0.971 = 0$。

算法会选 IG 更大的 A。这个例子让你看清"贪心选分裂"在每个节点干的事：**把所有特征 × 所有候选阈值都算一遍 IG（或基尼下降），挑最大的那个**。这也暴露了树的计算特征——对连续特征，候选阈值通常取相邻样本值的中点，逐个试，所以单次分裂是 $O(\text{特征数} \times \text{样本数} \times \log)$ 量级（排序后扫描）。贪心的代价是：它从不回头，前面的分裂选错了后面也补不回来——这正是单棵树不稳（高方差）、需要集成来救的根源之一。

### 5.3.3 轴对齐决策边界：偏置的优势与局限

决策树的边界永远是轴对齐的台阶状。这带来一组鲜明的优劣：

**优点**：(1) **天然处理特征尺度差异**——树只看"在某特征上是否超过阈值"，对单调变换不变，所以**不需要标准化**（这点和 kNN / SVM 截然相反，是树的一大便利）。(2) **天然处理特征交互**——树的深层分裂是建立在浅层分裂之上的条件判断，自动捕捉"高收入且年轻"这类交互（线性模型必须手动加交互项）。(3) **天然处理混合类型**——数值、类别特征都能切。(4) 对单调特征变换、异常值都相对鲁棒。

**局限**：(1) **难以表达"斜"的边界**。若真实边界是一条 45° 的斜线（如 $x_1 + x_2 > c$），轴对齐的树只能用大量小台阶去逼近它，既低效又容易过拟合。这是树最典型的归纳偏置局限——**对角关系它学得费劲**。(2) **不连续 / 不光滑**——分段常数在边界处突变，对需要平滑外推的回归不友好。(3) **不擅长外推**——叶子是常数，超出训练范围只能给边缘叶子的常数值。

下面这张 ASCII 示意对比了两类边界，帮你把"轴对齐"刻进脑子：

```
   线性模型 / SVM 的边界          决策树的边界（轴对齐台阶）
   x2                              x2
   |        /                      |    ____
   |   A   /   B                   | A |    |__  B
   |      /                        |   |       |__
   |     /                         |___|          |
   |____/_________ x1              |______________ x1
   一条斜直线（可斜）              一串与坐标轴平行的阶梯
```

### 5.3.4 过拟合与剪枝

一棵不加约束的决策树可以一直分裂到**每个叶子只含一个样本**——这时训练误差为零，但它只是把训练集硬背了下来，泛化极差。决策树是**天生容易过拟合**的模型（高方差），这是暗线一的又一个活例子。控制办法：

- **预剪枝（pre-pruning，提前停止）**：限制最大深度（`max_depth`）、叶子最小样本数（`min_samples_leaf`）、分裂所需最小样本数、最小不纯度下降等。简单高效，是实践主力。
- **后剪枝（post-pruning）**：先长一棵大树，再自底向上剪掉"对验证性能贡献不大"的分支。代价复杂度剪枝（cost-complexity pruning）给目标加一项 $\alpha \cdot (\text{叶子数})$，用一个超参 $\alpha$ 在"拟合"和"树的大小"之间权衡——**这本质就是正则化**：$\alpha$ 越大越偏好小树（呼应第 2、3 章的 $\lambda$ 与奥卡姆剃刀）。

> **概率视角**：剪枝里"叶子数"惩罚项可以读成一种**最短描述长度（MDL）/ 奥卡姆先验**——越简单（越少叶子）的树先验概率越高（呼应《信息论》第 6 章的 MDL）。这与 L2 / L1 正则是同一种精神在不同模型上的化身：**控制容量 = 给"简单"一个先验**。

> **常见陷阱**：很多人把树 / 森林给出的**特征重要性（feature importance）** 当成可靠的"因果重要性"来汇报，这有两个坑。(1) **基于不纯度下降的重要性偏向高基数 / 连续特征**——这类特征有更多候选分裂点，天然更容易被选中、刷高重要性，哪怕它其实没那么相关；更稳健的做法是用**置换重要性（permutation importance）** 或 SHAP。(2) **重要性 ≠ 因果**——一个特征重要只说明"模型用它来预测有效"，不代表"改变它能改变结果"（相关 ≠ 因果，呼应第 2 章那条红线）。把特征重要性当解释性参考可以，当因果结论或决策依据要极其谨慎。

> **要点**：决策树递归地把特征空间切成轴对齐的盒子、每盒给常数，是分段常数函数；分裂准则（信息增益 / 基尼）本质是选"按该阈值离散化后与标签**互信息最大**"的特征（呼应信息论）。优点：免标准化、自动捕捉交互与混合类型、可解释；局限：斜边界学得费劲、不光滑、不擅外推。单树高方差、易过拟合，靠**剪枝（= 正则）** 控容量。它的高方差正是下一节集成方法要修的病。

## 5.4 集成方法：把弱者拧成强者

单棵决策树可解释但不稳——换一批训练数据，长出来的树可能面目全非（高方差）。**集成学习（ensemble learning）** 的核心思想是：**把许多个"还行"的模型组合起来，得到一个远比任何单个都强的模型。** 它是经典机器学习里威力最大、最实用的思想，也是 GBDT 至今统治表格数据的根基。集成有两大流派——**bagging（降方差）** 和 **boosting（降偏差）**，恰好是偏差-方差权衡（暗线一）的两个对照实验（另有第三种 **stacking / 堆叠**——用元模型学习如何组合基模型的输出，竞赛常用，本章不展开）。下面我们重点讲 bagging 与 boosting 这两条主线。

### 5.4.1 Bagging 与随机森林：降方差

**Bagging（bootstrap aggregating，自助聚合）** 的逻辑直接来自偏差-方差分解。回忆第 2 章：$M$ 个**独立同分布、各自无偏**的估计量取平均，偏差不变，但方差降为原来的 $1/M$。如果我们能训练出许多"独立的高方差模型"再平均，就能在不增加偏差的前提下大幅降方差——而决策树正是"低偏差、高方差"的理想原料。

可问题是：我们只有一份训练集，哪来许多"独立"的模型？Bagging 的答案是 **bootstrap 重采样**：从原始 $n$ 个样本里**有放回地**抽 $n$ 个，得到一个略有不同的训练集，在它上面训一棵树；重复 $M$ 次得到 $M$ 棵略有差异的树；预测时让它们投票（分类）或平均（回归）。

有放回抽样有个漂亮的副产品。某个样本在一次 bootstrap 中**没被抽到**的概率是 $\left(1-\tfrac1n\right)^n \xrightarrow{n\to\infty} e^{-1}\approx 0.368$——也就是说，每棵树平均只用到约 **63.2%** 的原始样本，剩下约 37% 的样本对这棵树是"没见过"的，称为**袋外样本（out-of-bag, OOB）**。于是我们可以用"每个样本被哪些没见过它的树预测"来做一个**免费的验证估计**：OOB 误差。它几乎等价于交叉验证，却不用额外划分数据、不用重复训练——这是随机森林的一大便利。

**随机森林（random forest）** 在 bagging 基础上再加一招关键的"去相关"：**每次分裂只从随机抽取的一部分特征里选最优分裂**（而非全部特征）。为什么要这样？因为若所有树都能看到全部特征，它们会不约而同地在"那个最强的特征"上先分裂，导致树之间高度相关——而**相关的模型平均起来降方差有限**（方差只降到 $\rho\sigma^2 + \frac{1-\rho}{M}\sigma^2$，相关系数 $\rho$ 越大、降得越少）。随机选特征强行让不同树"看不同的角度"，**降低树间相关性 $\rho$**，从而把平均的降方差威力放出来。这是随机森林比纯 bagging 更强的关键。

随机森林几乎不需要调参就很强、对异常值鲁棒、能给出**特征重要性（feature importance）** 和 **袋外误差（out-of-bag, OOB error）**（用每棵树没抽到的样本免费做验证），是极好的"开箱即用"基线。

> **给数学 / CS 读者的视角**：bagging 降方差的数学骨架就两行。设 $M$ 个模型预测 $\hat f_1,\dots,\hat f_M$，各方差 $\sigma^2$、两两相关系数 $\rho$。平均预测 $\bar f = \frac1M\sum_m \hat f_m$ 的方差是
> $$ \mathrm{Var}(\bar f) = \rho\,\sigma^2 + \frac{1-\rho}{M}\,\sigma^2 . $$
> 第二项随 $M\to\infty$ 消失，但第一项 $\rho\sigma^2$ **不会消失**——这是相关性给降方差设的天花板。纯 bagging 的树共享同一批特征、高度相关（$\rho$ 大），所以这个天花板很高、降方差有限；随机森林靠"随机选特征"把 $\rho$ 压低，天花板随之降低，降方差威力才真正释放。**这一个公式同时解释了"为什么集成有用"和"为什么随机森林比纯 bagging 强"**，是偏差-方差（暗线一、呼应第 2 章）在集成上最干净的落地。注意：平均不改变偏差（$\mathbb{E}[\bar f]=\mathbb{E}[\hat f]$），所以 bagging 是纯降方差、不降偏差的手术——这也正是它要用"低偏差高方差的深树"当原料的原因。

### 5.4.2 Boosting 与梯度提升：降偏差、串行纠错

**Boosting** 走的是完全相反的路。bagging 是**并行**训练一堆独立的强（低偏差高方差）模型再平均来降方差；boosting 是**串行**训练一串很弱（高偏差低方差，如只有一两层的"树桩"）的模型，**每一个都专门去纠正前面所有模型加起来还没拟合好的部分**，靠不断纠错来降偏差。

最现代、最重要的形式是**梯度提升（gradient boosting）**，思想优雅：把"加一个新模型"看成"在函数空间里做一步梯度下降"。设当前的集成模型是 $F_{m-1}(\mathbf{x})$，我们想再加一个弱学习器 $h_m$ 让损失下降。对平方损失，最该拟合的目标恰好是当前的**残差（residual）** $y_i - F_{m-1}(\mathbf{x}_i)$；对一般可微损失 $\mathcal{L}$，则是**负梯度（伪残差，pseudo-residual）**

$$
r_{im} = -\left.\frac{\partial \mathcal{L}(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)}\right|_{F=F_{m-1}} ,
$$

新树 $h_m$ 去拟合这些伪残差，然后以一个小步长 $\nu$（学习率，learning rate / shrinkage）更新：

$$
F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \nu\, h_m(\mathbf{x}) .
$$

每一步都让集成沿着"减少损失最快的方向"挪一小步——**这就是第 4 章梯度下降的思想，只不过下降发生在"函数空间"而非"参数空间"**。GBDT（梯度提升决策树）就是用浅决策树当弱学习器 $h_m$ 的梯度提升。

**一个最小的回归例子，把"串行纠错"看具体。** 设我们要拟合 4 个点 $y = [1, 3, 5, 9]$，用平方损失。第 0 步，集成就是一个常数 $F_0 = \bar y = 4.5$（最优常数预测）。此时残差 $r = y - F_0 = [-3.5, -1.5, 0.5, 4.5]$。第 1 步，训一棵浅树 $h_1$ 去**拟合这些残差**（注意：拟合的是残差，不是原始 $y$）——比如它学到"前两点预测 $-2.5$、后两点预测 $2.5$"。以学习率 $\nu=1$ 更新，$F_1 = F_0 + h_1$ 给出预测 $[2, 2, 7, 7]$，新残差缩小为 $[-1, 1, -2, 2]$。第 2 步，再训 $h_2$ 拟合这批新残差……如此接力，每棵树只负责"把前面所有树加起来还差的那一点"补上。**这就是 boosting 的精髓——不是各干各的（bagging），而是后一个专补前面的窟窿。** 用小学习率 $\nu<1$（如 0.1）时，每棵树只补一小部分、需要更多棵树，但泛化通常更好（步子小、不容易一下子拟合过头）。

> **给数学 / CS 读者的视角**：梯度提升 = **函数空间里的梯度下降**。第 4 章里我们在参数 $\theta\in\mathbb{R}^p$ 上做 $\theta \leftarrow \theta - \eta\nabla_\theta\mathcal{L}$；这里我们把整个函数 $F$ 当成"参数"，每步往负泛函梯度方向加一个弱学习器。学习率 $\nu$ 和第 4 章的 $\eta$ 是同一个旋钮：小 $\nu$ + 多棵树（更多迭代）通常泛化更好，是 boosting 的标配配方。

**XGBoost / LightGBM / CatBoost** 是 GBDT 的高效工程实现，在朴素梯度提升上叠加了：用损失的**二阶信息（牛顿步，呼应第 4 章二阶方法）** 更精准地定分裂、显式的正则项（叶子数 + 叶子权重 $L_2$）、列 / 行子采样（借 bagging 的随机性降方差）、直方图 / 排序优化把训练做快。它们是今天**表格数据竞赛与工业落地的事实标准**。

GBDT 的调参围绕"在持续降偏差的同时别拟合到噪声"展开，几个旋钮要心里有数：**树的数量**（boosting 轮数）越多偏差越低、但过多会过拟合，所以几乎总配**早停（early stopping）**——在验证集误差不再下降时停；**学习率 $\nu$** 越小越稳、需要的树越多（小 $\nu$ + 多树 + 早停是黄金组合）；**树深 / 叶子数**控制每棵弱学习器的复杂度（通常很浅，3–8 层）；**子采样比例**借随机性进一步抗过拟合。注意这和随机森林的调参哲学相反——森林"加树几乎只赚不亏、几乎不用调"，GBDT 则是"加树会过拟合、必须靠早停和小学习率拿捏"，这个差异直接来自二者降方差 vs 降偏差的本质（§5.4.3）。

### 5.4.3 为何集成普遍有效 · bagging vs boosting 的偏差-方差视角

集成普遍有效，可以从三个角度理解：(1) **统计**——把多个差不多好但各有偏好的模型平均，能逼近真实假设、避免押宝在单个可能跑偏的模型上；(2) **计算 / 优化**——单个模型可能卡在不同的局部解，多个起点的平均更稳健；(3) **表示**——多个简单模型的组合能表达单个简单模型表达不了的复杂函数。归根到底，集成是用"多样性"换"稳健与表达力"。

有个经典的量化直觉叫**孔多塞陪审团定理（Condorcet's jury theorem）**：设有 $M$ 个**相互独立**、各自正确率 $p>0.5$（比随机猜好一点）的二分类器，让它们多数投票，则集体正确率随 $M$ 增大而**趋于 1**。例如取 $p=0.6$、$M=101$ 个独立投票者，可推得多数票正确率已约 0.98（远高于单个的 0.6）。这就是 bagging 的灵魂：单棵树只比瞎猜好一点没关系，只要它们**足够独立**，多数票就能把正确率推得很高。但请咬住那个"独立"的前提——若投票者高度雷同（错也错在一处），多数票毫无意义。**这恰恰解释了随机森林为什么要费力降低树间相关性**（§5.4.1）：定理的威力全押在"独立"上，相关性越低，集成越接近这个理想增益。

bagging 与 boosting 的对照，是偏差-方差权衡最干净的一组实验，务必记牢这张表：

| | Bagging / 随机森林 | Boosting / GBDT |
|---|---|---|
| 训练方式 | **并行**，各模型独立 | **串行**，后者纠正前者 |
| 弱学习器 | **低偏差、高方差**（深树） | **高偏差、低方差**（浅树 / 树桩）|
| 主要降低 | **方差**（靠平均去相关的高方差模型）| **偏差**（靠串行逐步纠错拟合残差）|
| 加更多模型 | 不易过拟合（方差饱和）| **可能过拟合**（持续降偏差，要早停 / 小学习率）|
| 调参难度 | 低，开箱即用 | 高，对学习率 / 树数 / 深度敏感 |
| 鲁棒性 | 对异常值 / 噪声更稳 | 对噪声更敏感（会去拟合噪声残差）|
| 并行性 | 天然可并行 | 训练本质串行（但单树内可并行）|

一句话记忆法：**bagging 让一群"学得太狠"的模型互相抵消过拟合（治方差）；boosting 让一队"学得太弱"的模型接力补足拟合（治偏差）。** 这正是暗线一在集成方法上的完美体现——你想降的是偏差还是方差，决定了你该选哪一流派。

> **实战连接（风控 / 信用评分）**：信贷风控是 GBDT 的经典主场。特征是表格化的（收入、负债率、历史逾期次数、查询次数……），样本几万到几百万，既要预测准、又要能向监管解释。XGBoost / LightGBM 在这里几乎是默认选择：准确率高、训练快、能输出特征重要性、还能配合 SHAP 值给单笔决策做归因。**这就是 §5.1 说的"表格数据上 GBDT 仍是王者"的真实战场**——深度网络在这种数据上往往打不过它。

> **实战连接（科学表格数据）**：GBDT 的统治不止于商业。大量**科学计算**问题的数据天然是表格化的——材料科学里用成分 / 工艺参数预测材料性能、生物信息里用基因表达谱（每列一个基因的表达量）做表型分类或药物响应预测、化学里用分子描述符预测活性、天文 / 高能物理里的特征工程后分类。这些"行是样本、列是有独立语义的测量量"的场景，样本常只有几百到几万、特征间没有图像 / 序列那种空间结构，正是 GBDT（及随机森林、SVM）的舒适区，它们至今是科研基线的主力之一。**蛋白质折叠这类前沿科学问题确实由深度模型（AlphaFold）主导（第 8 章会讲），但那是因为其数据有强几何 / 序列结构；更多"普通科学表格数据"上，经典方法依然当家**——这正是"用对结构"的又一例。

> **诚实的边界**：集成不是万能药，要付三笔代价。(1) **可解释性下降**：单棵树能画出来读，几百棵树的随机森林 / GBDT 就成了半黑箱，要靠 SHAP / 部分依赖图等事后解释工具。(2) **计算与存储成本**上升（要存 / 跑很多模型）。(3) boosting **对标签噪声和过拟合更敏感**，必须靠早停、小学习率、正则克制。"集成总比单模型好"是经验规律不是定理——在数据极少或噪声极大时，一个简单正则良好的模型可能反而更稳。

> **要点**：集成把许多"还行"的模型组合成强模型。**Bagging / 随机森林并行训练高方差模型再平均、靠去相关降方差**（随机森林额外随机选特征降树间相关）；**Boosting / GBDT 串行训练弱模型逐步纠错、降偏差**，梯度提升 = 函数空间里的梯度下降。bagging vs boosting = 治方差 vs 治偏差（暗线一）。GBDT（XGBoost/LightGBM）是表格数据的王者，代价是可解释性与计算成本下降、boosting 对噪声敏感。

## 5.5 支持向量机与核技巧

支持向量机（support vector machine, SVM）在深度学习兴起前，是分类问题上的"最强单模型"之一，在深度学习全面接管之前的相当长一段时间里是许多任务的默认选择。它有两个深刻而优雅的核心思想，每一个都值得吃透：**最大间隔（max margin）** 和 **核技巧（kernel trick）**。这两个思想的价值远超 SVM 本身——最大间隔把"泛化"做进了优化目标（暗线一），核技巧给了"在高维隐式工作"一个通用范式（影响了核 PCA、高斯过程等一整类方法）。第 3 章已经预告过最大间隔的直觉与支持向量，这里把它讲完整，并把核技巧从头建立起来。

### 5.5.1 最大间隔分类器与支持向量

考虑一个线性可分的二分类问题（标签 $y_i \in \{-1, +1\}$）。能把两类分开的超平面有无穷多个，SVM 问的是：**哪条最好？** 答案是**离两类样本都最远的那条**——即让"决策边界到最近样本的距离（间隔，margin）"最大的那条。直觉上，间隔越大，边界对扰动越鲁棒、对新样本越可能分对（泛化越好，暗线一）。

形式化。设超平面为 $\mathbf{w}^\top\mathbf{x} + b = 0$，可以推出几何间隔（每侧到边界的距离）为 $1/\|\mathbf{w}\|$。最大化间隔等价于在"所有点都被正确分类且分对至少一个单位"的约束下最小化 $\|\mathbf{w}\|^2$：

$$
\min_{\mathbf{w}, b}\ \tfrac12\|\mathbf{w}\|^2 \quad \text{s.t.}\quad y_i(\mathbf{w}^\top\mathbf{x}_i + b) \ge 1,\ \forall i .
$$

这是一个**凸二次规划（QP）**，有唯一全局最优。最优解只由那些**恰好落在间隔边缘上（约束取等号）的样本**决定，它们叫**支持向量（support vector）**——这是 SVM 名字的由来。其余样本就算挪动（只要不越过间隔）也不改变边界。这种"解只依赖少数关键样本"的稀疏性，是 SVM 一个漂亮的归纳偏置。

为什么"间隔最大"就该泛化好（暗线一）？给两层直觉。**几何上**：间隔越大，就要把新样本推到离边界越远才会被误分，所以对输入的小扰动 / 噪声越鲁棒——边界"留出的安全垫"越厚。**理论上**：统计学习理论里有一类泛化界表明，分类器的复杂度（VC 维 / Rademacher 复杂度的相关量）可以被间隔的大小所控制——**大间隔 ≈ 低有效复杂度 ≈ 紧的泛化界**，与维度关系不大。这一点很关键，它部分解释了为什么核 SVM 把数据升到极高维（甚至无穷维）却不必然过拟合：真正控制泛化的不是维度，而是间隔。换暗线三的话说，**"偏好大间隔解"本身就是一种归纳偏置**，和正则化偏好"小权重"是同一种"偏好简单 / 鲁棒解"的精神（事实上最大间隔就等价于最小化 $\|\mathbf{w}\|^2$，即 L2 正则，下一节会看到）。

### 5.5.2 软间隔：hinge 损失 + L2 正则

现实数据几乎从不线性可分（总有噪声、重叠）。**软间隔（soft margin）** SVM 允许一些样本违反间隔约束，但要为违反付出代价。引入松弛变量后，可以把整个问题等价改写成一个我们熟悉的形式——**经验风险 + 正则**：

$$
\min_{\mathbf{w}, b}\ \underbrace{\frac{1}{n}\sum_{i=1}^n \max\big(0,\ 1 - y_i(\mathbf{w}^\top\mathbf{x}_i + b)\big)}_{\text{hinge 损失}} \;+\; \lambda\, \|\mathbf{w}\|^2 .
$$

第一项是 **hinge 损失（合页损失）**：若样本被正确分类且间隔 ≥ 1，损失为 0（不在乎你分得多对）；否则线性惩罚。第二项就是 **L2 正则**（最大化间隔 = 最小化 $\|\mathbf{w}\|^2$）。**看到没有——SVM 完美落进了第 2、3 章的"损失 + 正则"框架！** 它和逻辑回归的唯一本质区别就在损失函数：逻辑回归用对数损失（处处可微、永远在乎），SVM 用 hinge 损失（分对够远就归零、只关心边界附近的点）。超参 $C \propto 1/\lambda$ 控制"对违反间隔的惩罚有多狠"：$C$ 大 = 正则弱 = 尽量分对每个点（易过拟合），$C$ 小 = 正则强 = 容忍更多错分换更大间隔。

> **实战连接（文本分类）**：在深度学习席卷 NLP 之前，**线性核 SVM 是文本分类的黄金标准**。把文档表示成 TF-IDF 词向量（维度上万、极稀疏），线性 SVM 在这种"高维稀疏、样本中等"的数据上又快又准——它正好命中了 §5.7 表里"线性核 SVM 擅长高维稀疏"那一行。直到今天，做一个文本分类原型，"TF-IDF + 线性 SVM / 逻辑回归"仍是一条极强、极省的基线，常常逼近甚至打平小型神经网络，而训练只要几秒。这提醒我们：上深度模型前，先跑一个经典基线，往往能省下大量算力、还给你一个诚实的对照标尺。

> **概率视角**：hinge 损失没有像对数损失那样干净的概率（似然）解释——这正是 SVM 与逻辑回归在"是否输出校准概率"上的关键差异。逻辑回归输出的 $\sigma(\mathbf{w}^\top\mathbf{x})$ 是一个有意义的概率估计；SVM 的原始输出 $\mathbf{w}^\top\mathbf{x}+b$ 只是个"到边界的带符号距离"，要变成概率得额外做 Platt 缩放（拟合一个 sigmoid）。**想要概率，用逻辑回归更自然；只想要一个鲁棒的硬分类边界，SVM 的 hinge + 间隔很对路。**

### 5.5.3 对偶问题（直觉即可）

求解 SVM 通常不直接解上面的"原问题（primal）"，而是解它的**对偶问题（dual problem）**。用拉格朗日乘子 $\alpha_i \ge 0$（每个约束一个）写出拉格朗日函数

$$
L(\mathbf{w}, b, \boldsymbol{\alpha}) = \tfrac12\|\mathbf{w}\|^2 - \sum_i \alpha_i\big[\,y_i(\mathbf{w}^\top\mathbf{x}_i + b) - 1\,\big] ,
$$

对 $\mathbf{w}$ 求偏导并令其为零，立刻得到下面这个关键关系（对 $b$ 求导给出 $\sum_i \alpha_i y_i = 0$）。把它代回 $L$ 消去 $\mathbf{w},b$，就得到只含 $\boldsymbol{\alpha}$ 与内积的对偶问题。我们不必完整推导，只需记住其最优解的两个性质：

$$
\mathbf{w}^\star = \sum_{i} \alpha_i^\star\, y_i\, \mathbf{x}_i ,
$$

且只有支持向量对应的 $\alpha_i^\star > 0$（其余为零，再次体现稀疏性）。**对偶形式里，数据只以两两内积 $\mathbf{x}_i^\top \mathbf{x}_j$ 的形式出现**——这个看似平淡的观察，是接下来核技巧的全部入口。你不需要会推导对偶，只需记住这个结论：**SVM 的解 = 支持向量的加权组合，且预测和训练都只用到样本之间的内积。**

把这一点再点透：对偶 SVM 的目标函数里，所有训练样本只通过那个 $n\times n$ 的内积矩阵 $G_{ij}=\mathbf{x}_i^\top\mathbf{x}_j$ 进入计算——这个矩阵就是线性代数里的 **Gram 矩阵**。预测时，对新点 $\mathbf{x}$ 的判别值 $\mathbf{w}^{\star\top}\mathbf{x}+b = \sum_i \alpha_i^\star y_i (\mathbf{x}_i^\top\mathbf{x}) + b$ 同样只用到"新点与各支持向量的内积"。**整个 SVM——训练和预测——从头到尾只碰内积，从不单独碰任何一个 $\mathbf{x}$ 本身。** 这就为"把内积换成别的东西"留出了完美的接口，正是核技巧得以登场的结构性原因。

### 5.5.4 核技巧：隐式地在高维做内积

线性 SVM 只能画直边界，遇到"圆形""异或"这类非线性可分的问题就没辙。一个朴素的办法是**显式地**做特征映射 $\phi(\mathbf{x})$ 把数据升到高维（比如加 $x_1^2, x_2^2, x_1 x_2$ 项），让它在高维变得线性可分，再在高维跑线性 SVM。但高维特征可能是几千、几百万维，甚至**无穷维**，显式算 $\phi(\mathbf{x})$ 不现实。

先看一个能把"升维 → 变可分"看透的玩具例子：**异或（XOR）**。四个点 $(0,0),(1,1)$ 属正类，$(0,1),(1,0)$ 属负类——在二维平面上你画不出任何一条直线把它们分开（线性不可分）。关键是**造一个能把两类拉开的新特征**。考虑映射 $\phi(x_1,x_2) = \big(x_1,\ x_2,\ (x_1-x_2)^2\big)$，把数据升到三维：正类两点 $(0,0),(1,1)$ 的第三维都是 $(0-0)^2=0$、$(1-1)^2=0$，即第三维 $=0$；负类两点 $(0,1),(1,0)$ 的第三维都是 $(0-1)^2=1$、$(1-0)^2=1$，即第三维 $=1$。于是**仅凭第三维就能把两类分开**——一个简单的平面 $z=\tfrac12$（即 $(x_1-x_2)^2=\tfrac12$）就把正类（$z=0$）和负类（$z=1$）干净切开。**核心思想就此显现：原空间里线性不可分的数据，升到一个合适的高维后往往变得线性可分。** 注意单靠 $\phi=(x_1,x_2,x_1x_2)$ 这个常见的交叉项还不够（正类第三维是 $0$ 和 $1$、负类是 $0$ 和 $0$，第三维上 $0$ 两类都有，分不开）——这恰恰说明"升维"不是随便加一维就行，**要加上一个能让目标类别在新坐标上分离的特征**。而多项式核 $(\mathbf{x}^\top\mathbf{z}+c)^2$ 隐式展开后同时包含 $x_1^2, x_2^2, x_1 x_2$ 等全部二阶项（$(x_1-x_2)^2=x_1^2-2x_1x_2+x_2^2$ 正是它们的线性组合）——它"免费"地把 XOR 需要的那一组二阶特征都给了你，于是核 SVM 不必你亲手设计就能分开 XOR。

**核技巧（kernel trick）** 的精髓正在这里：既然 SVM（对偶形式）只用到样本间的内积 $\phi(\mathbf{x}_i)^\top\phi(\mathbf{x}_j)$，那我们**根本不需要显式算出 $\phi$，只要有一个函数能直接给出高维内积就够了**。这个函数就是**核函数（kernel function）**：

$$
K(\mathbf{x}, \mathbf{z}) = \phi(\mathbf{x})^\top \phi(\mathbf{z}) .
$$

把对偶 SVM 里所有 $\mathbf{x}_i^\top\mathbf{x}_j$ 换成 $K(\mathbf{x}_i, \mathbf{x}_j)$，就**隐式地在高维特征空间里做了线性 SVM**，而全程只在低维原始空间里算 $K$，从不真正踏进高维。这就是核技巧的"魔法"：**用 $O(d)$ 的核计算，换来了高维（甚至无穷维）特征空间里的线性可分能力。**

代表性核函数：

- **线性核** $K(\mathbf{x},\mathbf{z}) = \mathbf{x}^\top\mathbf{z}$：就是普通线性 SVM。
- **多项式核** $K(\mathbf{x},\mathbf{z}) = (\mathbf{x}^\top\mathbf{z} + c)^p$：对应所有 $\le p$ 阶单项式特征。
- **高斯核 / RBF 核（radial basis function）** $K(\mathbf{x},\mathbf{z}) = \exp\big(-\gamma\|\mathbf{x}-\mathbf{z}\|^2\big)$：对应一个**无穷维**特征空间！它衡量两点的相似度（越近越接近 1，越远越接近 0），是最常用、最强大的核。$\gamma$ 控制"影响半径"：$\gamma$ 大 = 影响范围窄 = 决策边界更弯曲（易过拟合）。

哪些函数能当核？**Mercer 定理**给出条件：$K$ 只要是对称且半正定的（对任意样本集，核矩阵 $K_{ij} = K(\mathbf{x}_i,\mathbf{x}_j)$ 半正定），就一定对应某个特征空间的内积，可以合法地用作核。

> **与数学三课的连接**：核技巧从头到尾是《线性代数》第 4 章（内积 / 范数）的故事。核函数 $K$ 就是某个特征空间里的**内积**；那个由所有样本对组成的对称半正定矩阵 $K_{ij}=K(\mathbf{x}_i,\mathbf{x}_j)$ 就是 **Gram 矩阵（Gram matrix）**——它把"线性代数里两两内积构成的矩阵"直接搬到了机器学习。Mercer 定理的"半正定"条件，正是"Gram 矩阵必半正定"这一线代事实的反向应用。核方法因此也叫"在再生核希尔伯特空间（RKHS）里做线性方法"——一个把无穷维内积玩转的优雅框架。

> **给数学 / CS 读者的视角**：核技巧 = **隐式特征映射（implicit feature map）**。它和 §5.2.3 度量学习、第 3 章基函数其实是同一个主题的不同侧面——都是"换一个特征空间 / 几何，让原本难的问题变简单"。区别在于：基函数是显式造特征，核技巧是隐式用内积绕过造特征。核思想不止用于 SVM——核 PCA、核岭回归、高斯过程（Gaussian process）都建立在同一个核 / Gram 矩阵之上。

> **诚实的边界**：核 SVM 有一个硬伤——**不可扩展到大数据**。它的核矩阵是 $n\times n$，存储 $O(n^2)$、训练通常 $O(n^2)$ 到 $O(n^3)$。$n$ 上到几十万就吃不消了。这正是 SVM 在大数据 / 深度学习时代退居二线的主因之一：核 SVM 在中小数据（几千到几万样本）上极强，但喂不动百万级数据；而深度网络靠 SGD 天然能吃海量数据。此外，核与 $\gamma, C$ 的选择很吃调参与领域知识，没有放之四海皆准的最优核——这又是没有免费午餐（暗线三）。

> **要点**：SVM = 最大间隔 + 核技巧。最大间隔（= 最小化 $\|\mathbf{w}\|^2$）服务泛化、解只由**支持向量**决定（稀疏）。软间隔 = **hinge 损失 + L2 正则**，落进"损失+正则"框架，与逻辑回归只差损失函数（SVM 不天然输出概率）。对偶形式里数据只以内积出现，**核技巧**用核函数 $K=\langle\phi(\mathbf{x}),\phi(\mathbf{z})\rangle$ 隐式在高维（RBF 核为无穷维）做内积而不显式映射，呼应线代内积 / Gram 矩阵。硬伤：核矩阵 $O(n^2)$，不可扩展到大数据。

## 5.6 朴素贝叶斯：生成式分类器

### 5.6.1 生成式 vs 判别式

到目前为止，我们见过的分类器（逻辑回归、SVM、决策树）都是**判别式模型（discriminative model）**：它们直接学习 $P(y\mid\mathbf{x})$ 或直接学一条决策边界，**只关心"给定输入，输出哪个类"**，不去操心数据本身长什么样。

**朴素贝叶斯（Naive Bayes）** 代表另一条路——**生成式模型（generative model）**：它先对每个类别学习"这个类的样本是怎么生成的"，即类条件分布 $P(\mathbf{x}\mid y)$ 和类先验 $P(y)$，再用**贝叶斯公式**反推 $P(y\mid\mathbf{x})$：

$$
P(y\mid\mathbf{x}) = \frac{P(\mathbf{x}\mid y)\,P(y)}{P(\mathbf{x})} \;\propto\; P(\mathbf{x}\mid y)\,P(y) .
$$

分类时，选后验最大的类：$\hat y = \arg\max_y P(\mathbf{x}\mid y)P(y)$（分母 $P(\mathbf{x})$ 与 $y$ 无关，可忽略）。这是《概率与统计》第 8 章贝叶斯推断的最直接应用。

生成式这条路看起来"绕"（要建模整个 $P(\mathbf{x}\mid y)$ 才能做分类），但它换来三样判别式给不了的东西：(1) **能生成数据**——既然学了"每个类的样本怎么来的"，就能从 $P(\mathbf{x}\mid y)$ 采样造出新样本（这正是第 10 章生成模型的远祖思想）；(2) **天然做异常检测**——一个样本若在所有类的 $P(\mathbf{x}\mid y)$ 下概率都极低，就是离群点；(3) **能用未标注数据**——$P(\mathbf{x})$ 的建模不需要标签，半监督学习友好。判别式模型只盯着边界，这三件事它都干不了。这就是生成式 vs 判别式背后更大的图景：**判别式专注"分得准"，生成式追求"理解数据本身"**——本章的朴素贝叶斯是这条路上最简单的一站。

### 5.6.2 "朴素"的条件独立假设

困难在于 $P(\mathbf{x}\mid y)$：$\mathbf{x}$ 是 $d$ 维的，类条件分布是 $d$ 维联合分布，直接估计需要天文数字的数据（又是维数灾难）。朴素贝叶斯的"朴素"就在它用一个**极强的简化假设**砍掉这个困难——**给定类别，各特征条件独立（conditional independence）**：

$$
P(\mathbf{x}\mid y) = P(x_1, x_2, \dots, x_d \mid y) \approx \prod_{j=1}^d P(x_j \mid y) .
$$

这个假设把一个 $d$ 维联合分布的估计，化简成了 $d$ 个一维分布的估计——参数从指数级降到线性级，几条数据就能训练，而且天然抗高维。这就是它的归纳偏置（暗线三）：**赌"特征之间在每个类内部互不相关"。** 根据 $P(x_j\mid y)$ 用什么分布，有不同变体：高斯朴素贝叶斯（连续特征用高斯）、多项式朴素贝叶斯（词频，文本常用）、伯努利朴素贝叶斯（0/1 特征）。

**用垃圾邮件过滤把它走一遍。** 把每封邮件表示成词的集合，特征是"出现了哪些词"。先验 $P(\text{垃圾})$、$P(\text{正常})$ 由训练集里两类邮件的比例估计。对每个词 $w$，从训练集数出"它在垃圾邮件里出现的频率" $P(w\mid\text{垃圾})$ 和"在正常邮件里出现的频率" $P(w\mid\text{正常})$。来一封新邮件，含词 $\{w_1,\dots,w_m\}$，朴素假设让我们把各词证据连乘：

$$
\frac{P(\text{垃圾}\mid \text{邮件})}{P(\text{正常}\mid \text{邮件})} = \frac{P(\text{垃圾})}{P(\text{正常})}\prod_{j} \frac{P(w_j\mid\text{垃圾})}{P(w_j\mid\text{正常})} .
$$

取对数后右边变成一串加法——每个词贡献一个 $\log$ 几率比的"分数"，"免费""中奖"这类词给很大的正分（指向垃圾），日常词给接近零的分，全加起来过阈值就判垃圾。**这正是最早的实用反垃圾邮件引擎的核心**，也直观说明了为什么它快（数频率 + 求和而已）、为什么它适合文本（词数上万维、每封邮件只激活少数词，高维稀疏正是它的舒适区）。

> **与数学三课的连接**：条件独立假设是《概率与统计》第 8 章与《信息论》的核心概念。从信息论看，朴素假设等于断言"给定类别后，特征之间互信息为零"——这几乎总是错的（比如文本里"机器"和"学习"高度共现），但错得"有用"。取对数后，朴素贝叶斯的判别函数 $\log P(y) + \sum_j \log P(x_j\mid y)$ 是各特征证据的**线性叠加**——所以它本质上也是一个**线性分类器**（在合适的特征表示下），这解释了它和逻辑回归的深层亲缘。

### 5.6.3 为何"朴素"却常常好用

条件独立假设几乎总是被违反，按理说朴素贝叶斯该很差——但它在文本分类（垃圾邮件过滤、情感分析）等任务上常常出乎意料地好，而且极快。为什么？

关键洞察：**分类只需要把正确的类排在最前，并不需要 $P(y\mid\mathbf{x})$ 的概率值精确。** 朴素假设会让概率估计有偏（因为重复计算了相关特征的"证据"，后验常常过度自信、接近 0 或 1），但**只要这种偏差不改变各类后验的相对排序，分类决策仍然正确**。换句话说，朴素贝叶斯的概率校准很差，但 $\arg\max$ 往往还是对的。加上它训练 / 预测都极快、对小数据和高维（如词袋）特别友好、几乎不用调参，使它成为文本任务里一个极强的基线。

> **概率视角 / 与逻辑回归的生成式-判别式对比**：高斯朴素贝叶斯（等协方差假设下）和逻辑回归其实是**同一个 sigmoid + 线性 logit 形式**的两种学法——这正是第 3 章 §3.5 「与数学三课的连接」里点过的"两类等协方差高斯 → 贝叶斯公式 → sigmoid"。区别在于：朴素贝叶斯（生成式）通过先建模 $P(\mathbf{x}\mid y)$ 间接得到边界，逻辑回归（判别式）直接优化 $P(y\mid\mathbf{x})$。经典结论（Ng & Jordan）是：**数据少时生成式（朴素贝叶斯）凭强假设学得更快、先达到不错精度；数据多时判别式（逻辑回归）因不受错误假设束缚、渐近精度更高。** 这是生成式 vs 判别式权衡的教科书例子，也是暗线三的又一注脚——强假设是把双刃剑，少数据时是助力、多数据时成束缚。

> **常见陷阱**：(1) **零概率问题**——若某个特征值在训练集里从没和某类一起出现过，$P(x_j\mid y)=0$ 会让整个连乘归零，一票否决。解药是**拉普拉斯平滑（Laplace / additive smoothing）**：给每个计数加一个小常数。(2) 别把朴素贝叶斯输出的"概率"当成可信的概率——它的校准很差（过度自信），只适合用来排序 / 取 $\arg\max$。(3) 别因为它叫"贝叶斯"就以为它是完整的贝叶斯方法——它只是用了一次贝叶斯公式 + 点估计，不做参数的后验积分。

> **要点**：朴素贝叶斯是**生成式分类器**——建模 $P(\mathbf{x}\mid y)P(y)$ 再用贝叶斯公式反推后验。"朴素" = 假设**给定类别下特征条件独立**，把 $d$ 维联合分布拆成 $d$ 个一维分布，抗高维、极快、小数据友好。它本质是线性分类器；与逻辑回归是同一边界形式的**生成式 vs 判别式**两种学法（少数据生成式快、多数据判别式准）。坑：零概率（需平滑）、概率校准差（只配排序）。

## 5.7 归纳偏置对比表：暗线三的集中爆发

我们终于集齐了一整排归纳偏置各异的方法，可以把它们摆上同一张台子对照了。这张表是本章、也是暗线三在全课的第一个高潮——请反复读它，因为**"选模型"的本质，就是在这张表里挑一个其归纳偏置与你的数据结构最匹配的方法**。

| 方法 | 假设空间（表示）| 归纳偏置（对世界的赌注）| 擅长 | 不擅长 | 可解释性 |
|---|---|---|---|---|---|
| **kNN** | 局部分段（由训练点定义）| **局部相似**：邻近点标签相近（极弱、极普适）| 决策边界不规则、低 / 中维、有足量数据 | 高维（维数灾难）、需要外推、大数据预测慢 | 中（可看是哪些邻居投票）|
| **决策树** | 轴对齐分段常数 | **轴对齐分段**：可对单特征逐次设阈值逼近 | 表格数据、特征交互、混合类型、要可读规则 | 斜 / 平滑边界、外推、单树高方差 | **高**（可画成 if-else）|
| **随机森林** | 多棵树投票 / 平均 | 轴对齐分段 + **平均去相关降方差** | 表格、开箱即用、鲁棒、给特征重要性 | 斜 / 平滑边界、外推、模型变大变慢 | 中（黑箱化，靠事后解释）|
| **GBDT** | 浅树串行相加 | 轴对齐分段 + **串行纠错降偏差** | **表格数据之王**、中大数据、追求精度 | 感知数据（图像 / 文本 / 语音）、对噪声敏感、调参重 | 中低（需 SHAP 等解释）|
| **SVM（线性核）** | 线性（最大间隔超平面）| 关系**线性可分**、解由少数支持向量定 | 高维稀疏（如文本词袋）、中小样本 | 强非线性关系、大数据（$O(n^2)$）| 中（看权重 / 支持向量）|
| **SVM（RBF 核）** | 无穷维特征空间里的线性 | **局部相似 + 最大间隔**（RBF 像光滑 kNN）| 中小样本上的复杂非线性边界 | 大数据、需调 $\gamma,C$、不输出概率 | 低（隐式高维，难读）|
| **朴素贝叶斯** | 生成式 + 条件独立 | **给定类别下特征条件独立** | 文本 / 高维稀疏、小数据、极快基线 | 强特征相关、需要校准概率 | 中（各特征证据可加和）|
| **逻辑回归**（对照，第 3 章）| 线性 | 关系线性、对数几率线性 | 可解释基线、需要校准概率、大数据 | 强非线性关系（除非加基函数）| **高**（系数 = 几率比）|

读这张表的几个关键对照，把暗线三钉死：

- **kNN vs RBF-SVM**：两者都靠"局部相似"，但 RBF-SVM 多了最大间隔的正则与支持向量稀疏性，所以在中小样本上通常比裸 kNN 更稳、更省（只记支持向量而非全集）。
- **决策树 vs 线性模型**：轴对齐 vs 斜边界——这是最经典的归纳偏置对照。数据若是"沿坐标轴设阈值"的结构（年龄段、收入档）树赢；若是"特征加权求和"的结构（信号叠加）线性模型赢。
- **随机森林 vs GBDT**：同是树的集成，前者降方差（并行、深树）、后者降偏差（串行、浅树）——偏差-方差权衡（暗线一）的两个方向。
- **朴素贝叶斯 vs 逻辑回归**：生成式 vs 判别式、同一线性边界的两种学法——少数据 vs 多数据的权衡。

> **诚实的边界（本章核心之一）**：**这张表里没有"最好的方法"，只有"最匹配某种数据结构的方法"——这正是没有免费的午餐定理（no free lunch）的活体现。** 该定理的准确表述是"在所有可能的问题上平均，任意两个算法的期望性能相等"；它的意义不是"所有算法实际上一样好"，而是"**任何方法的优势都来自它的归纳偏置恰好对上了真实问题的结构**"。所以"该选哪个模型"这个问题，没有脱离数据的标准答案——它**等价于**问"我的数据真实结构更像哪一行假设"。这就是为什么本课反复强调：理解归纳偏置，比记住任何单一算法都重要。

> **要点**：把七八种方法的"假设空间 / 归纳偏置 / 擅长 / 不擅长 / 可解释性"排成一张表，暗线三第一次变得**可见**。选模型 = 在表里挑归纳偏置与数据结构最匹配的一行；没有最好的方法，只有最匹配的方法（没有免费的午餐）。

## 5.8 诚实的边界：经典方法 vs 深度学习，到底该选谁

本章不能在不把这个问题讲透的情况下结束：既然深度学习这么强，前面这些经典方法到底什么时候还该用？答案干净利落，且完全服务于暗线三——**取决于数据的结构。**

**感知数据（perceptual data）——深度学习碾压。** 图像、文本、语音、视频这类**原始、高维、有强内在结构**的数据上，深度学习对经典方法是降维打击。原因在归纳偏置：图像有局部 / 平移结构（卷积的偏置完美契合，第 8 章），语言有序列 / 关系结构（注意力 / Transformer 的偏置完美契合，第 8 章），而这些结构是 kNN / 树 / SVM **无法表达**的——你不可能让一棵决策树"理解"像素的空间关系。更关键的是，深度网络能**自动学习表示（representation learning）**，把原始像素 / 字符层层抽象成有语义的特征，而经典方法依赖人手工造特征。在这类数据上，没得选，深度学习赢。

**表格 / 小数据——经典方法（尤其 GBDT）未必输，甚至常赢。** 表格数据的每一列是**独立语义的特征**，没有图像的空间结构、没有语言的序列结构——深度网络赖以发威的归纳偏置在这里**无处施展**，而它的高容量在小数据上反而招致过拟合。相反，树的"轴对齐分段"恰好契合表格特征的语义（"年龄 > 30 且收入 < 5 万"这种规则就是树的母语），GBDT 又快又准又能解释。**在表格数据上，GBDT 至今是综合最强的方法之一，大量真实业务和数据竞赛里稳压深度网络**（学界也有不少系统性比较支持这一点）。

这里还藏着一个本章和后续深度学习章节的分水岭，值得单独点明：**特征从哪来。** 经典方法（kNN / 树 / SVM / 朴素贝叶斯）几乎都依赖**人手工设计的特征**——你得自己想清楚"用收入、负债率、年龄段……还是它们的某些组合"，模型再在这些给定特征上学习。在表格数据上这没问题，因为特征本就有现成的语义。但在图像 / 文本 / 语音上，"好特征"是什么没人说得清（哪些像素组合代表"猫"？），手工造特征几十年都没造好。**深度学习真正的革命，是把"造特征"这件事也交给模型自己学**——这叫**表示学习 / 特征学习（representation learning）**，是第 6 章往后的主线。所以"经典 vs 深度"的更深层差异是："你给模型现成特征，还是让模型自己从原始数据里长出特征"——这又回到数据结构：表格数据的特征已经是好特征，深度的自动特征学习派不上用场；感知数据的原始形式（像素 / 字符）不是好特征，必须靠深度去学。

把判据浓缩成一句话：**数据结构匹配深度网络的归纳偏置（局部 / 序列 / 层次）→ 用深度学习；数据是表格化、特征独立语义、样本不多 → 优先经典方法（GBDT / 线性 / SVM）。** 选择从来不是"新 vs 旧""强 vs 弱"，而是"归纳偏置 vs 数据结构"的匹配——这是本章留给你最重要的判断力。

> **实战连接（搜索排序 / 推荐）**：现代搜索与推荐系统是经典与深度**协同**的好例子，而非二选一。召回阶段常用**向量近邻检索（ANN，§5.2 kNN 的工业版）** 从亿级候选里捞回几千个；粗排 / 精排里，**GBDT** 长期是排序模型的主力（特征是表格化的：点击率、停留时长、用户 - 物品交叉特征……），近年逐步与深度模型（如双塔、DIN、Wide&Deep）融合；很多深度排序模型干脆把 **GBDT 的输出 / 叶子编号当作特征**喂给上层。**这说明经典与深度不是替代关系，而是各管一段、互为特征的流水线**——再次回扣"用对结构"。

> **诚实的边界**：上面的"判据"是有用的经验法则，不是铁律。边界正在被研究推动——一方面，针对表格数据的深度模型（如 TabNet、FT-Transformer、TabPFN 这类）在持续进步，"GBDT 永远赢表格"并非定论；另一方面，当表格特征里**也**藏着可学习的结构（如高基数类别、文本字段、时序），深度模型可能反超。请把本节当成"先验"，而非"判决"——真实项目里，**拿你自己的数据做一次诚实的交叉验证对比，才是最终裁判**（且记住别用测试集调参、别数据泄漏）。

> **要点**：经典 vs 深度，判据是**数据结构 vs 归纳偏置的匹配**。感知数据（图像 / 文本 / 语音，有局部 / 序列 / 层次结构）深度学习碾压；表格 / 小数据（特征独立语义）经典方法（尤其 GBDT）未必输、常赢。二者常**协同**（召回用 ANN、排序用 GBDT + 深度融合），不是替代。最终裁判是在你自己的数据上做诚实对比。

## 本章小结

本章横向巡礼了一批经典（非深度）机器学习方法，把它们当作理解**归纳偏置（暗线三）的对照实验室**：

- **kNN**：非参数、懒惰学习，归纳偏置是"局部相似"（极弱极普适）；把训练集当模型，$k$ 是容量旋钮；**距离度量决定一切**、用前需标准化（统计量只从训练集算）；对**维数灾难**最敏感，但数据若在低维流形上、在合适嵌入空间里仍管用。
- **决策树**：递归把特征空间切成轴对齐盒子、给分段常数；分裂准则（信息增益 / 基尼）本质是选"按阈值离散化后与标签**互信息最大**"的特征（呼应信息论）；免标准化、捕捉交互、可解释，但学不好斜 / 平滑边界、单树高方差易过拟合，靠剪枝（= 正则）控容量。
- **集成**：**bagging / 随机森林**并行训练高方差模型再平均、靠去相关**降方差**；**boosting / GBDT** 串行纠错、**降偏差**，梯度提升 = 函数空间里的梯度下降；二者是偏差-方差（暗线一）的两个方向；GBDT 是表格数据之王。
- **SVM**：最大间隔（= 最小 $\|\mathbf{w}\|^2$，服务泛化）+ 支持向量稀疏；软间隔 = **hinge + L2 正则**（落进"损失+正则"框架，与逻辑回归只差损失）；**核技巧**用核函数隐式在高维（RBF 为无穷维）做内积而不显式映射（呼应线代内积 / Gram 矩阵）；硬伤是核矩阵 $O(n^2)$、不扩展到大数据。
- **朴素贝叶斯**：生成式分类器，"朴素" = 给定类别下特征条件独立，抗高维、极快；本质是线性分类器；与逻辑回归是生成式 vs 判别式的同形两学法（少数据生成式快、多数据判别式准）。
- **归纳偏置对比表（§5.7）** 与 **经典 vs 深度的边界（§5.8）**：选模型 = 挑归纳偏置与数据结构最匹配的一行；没有最好的方法，只有最匹配的（没有免费的午餐）。

回扣三条暗线：**暗线三（归纳偏置）** 在本章迎来全课第一次集中爆发——每个方法都是一种鲜明的"对世界结构的赌注"，那张对比表让"结构即先验"第一次变得可见，§5.8 把"该选谁"还原成"哪种偏置对上了数据结构"。**暗线一（泛化）** 贯穿始终：$k$ / 树深 / $\alpha$ / $C$ / $\gamma$ 都是容量旋钮，bagging vs boosting 是治方差 vs 治偏差的经典对照。**暗线二（表示+目标+优化）** 处处可解剖：kNN 把训练集当表示、SVM 软间隔是"损失+正则"目标、梯度提升是函数空间优化、朴素贝叶斯用贝叶斯公式做推断。把这一排方法吃透，你就拿到了一整套"读懂任何方法的归纳偏置、并判断它该不该用"的眼力。

## 动手与思考练习

**练习 5.1（动手·编程）** 用 numpy 从零实现 kNN 分类器（不调库），在 sklearn 的鸢尾花 / 手写数字数据集上跑。(a) 先不标准化、再标准化，对比准确率；(b) 扫 $k=1,3,5,\dots,51$ 画"$k$ - 验证准确率"曲线，找出过拟合（$k$ 太小）与欠拟合（$k$ 太大）两端。

*参考答案 / 要点*：核心是算测试点到所有训练点的距离矩阵、取最近 $k$ 个、多数投票。标准化（`StandardScaler` 仅在训练集上 `fit`、对测试集 `transform`）通常显著提升手写数字这类多量纲数据的准确率，验证 §5.2.3。$k=1$ 训练误差为零但验证抖动大（高方差）；$k$ 极大时把远处不相关点拉进来投票、退化为多数类（高偏差）；中间有一个甜点。
*延伸思考*：若先在全集上 `fit` scaler 再划分，准确率会虚高一点——这就是数据泄漏，解释为什么。

**练习 5.2（思考）** 用"最近 / 最远距离比趋于 1"这件事，解释为什么 kNN 在很高维度下失效。再说明"数据其实在低维流形上"为什么能救它。

*参考答案*：高维下随机点对之间的距离高度集中（相对差距 $\to 0$），"最近邻"与"任意点"几乎一样远，"局部相似"假设失去判别力，投票等于随机。但真实高维数据（图像、文本嵌入）往往集中在一个低维流形上，**内在维度**远小于名义维度；先用 PCA / 自编码器 / 预训练嵌入把数据映到低维语义空间，距离重新变得有意义，kNN（语义检索 / RAG 召回）就活了。kNN 怕的是高的内在维度，不是名义维度。
*延伸思考*：这解释了为什么"在原始像素上做 kNN"很差，而"在 CNN / 嵌入特征上做 kNN"（如人脸识别的特征比对）很强。

**练习 5.3（动手·编程）** 用 sklearn 训练一棵决策树分类一个**人造的对角可分**数据集（如标签 = $\mathbb{1}[x_1 + x_2 > 0]$ 加噪声）。(a) 画出决策边界，观察它如何用台阶逼近 45° 斜线；(b) 在同样数据上训一个逻辑回归，对比边界与所需复杂度。

*参考答案 / 要点*：用 `DecisionTreeClassifier`，画 meshgrid 上的预测着色。决策树会用一串轴对齐小台阶去逼近斜线，需要很深 / 很多分裂才贴合，且边界毛糙；逻辑回归一条斜直线就完美拟合。这直观演示 §5.3.3 的归纳偏置局限：**轴对齐 vs 斜边界的匹配决定谁赢**。
*延伸思考*：把数据换成"沿坐标轴设阈值"的结构（如标签由 $x_1>a$ 且 $x_2>b$ 决定），谁更省？（树更省——这说明没有绝对优劣，只有匹配。）

**练习 5.4（动手·编程）** 在同一个表格数据集（如 sklearn 的 `make_classification` 或加州房价）上对比：单棵深决策树、随机森林、GBDT（可用 `GradientBoostingClassifier` 或 XGBoost/LightGBM）。记录各自训练 / 测试误差，并对 GBDT 扫学习率 / 树数。

*参考答案 / 要点*：典型现象——单深树训练误差近零、测试误差高（高方差过拟合）；随机森林测试误差明显下降（降方差），加更多树趋于饱和、不易过拟合；GBDT 通常测试误差最低，但**树数过多会过拟合**（测试误差先降后升），小学习率 + 早停最稳。这一题把 §5.4 的 bagging（降方差、加树饱和）vs boosting（降偏差、加树会过拟合）对照亲手跑出来。
*延伸思考*：为什么随机森林"加更多树几乎不会过拟合"，而 GBDT"加更多树会过拟合"？（前者每棵树独立拟合全目标、平均只降方差；后者每棵树拟合前面的残差、持续降偏差直至开始拟合噪声。）

**练习 5.5（思考）** 解释随机森林为什么要"每次分裂只随机看一部分特征"，而不是用全部特征。用"相关模型平均降方差有限"的事实论证。

*参考答案*：$M$ 个相关系数为 $\rho$、方差 $\sigma^2$ 的模型平均，方差为 $\rho\sigma^2 + \frac{1-\rho}{M}\sigma^2$；$M\to\infty$ 时余下 $\rho\sigma^2$，**$\rho$ 越大、平均能降的方差越少**。若每棵树都能看全部特征，它们会都先在最强特征上分裂、彼此高度相关（$\rho$ 大），平均降方差有限。随机选特征强行让树"看不同角度"、降低 $\rho$，把平均的降方差威力放出来——这是随机森林优于纯 bagging 的关键。
*延伸思考*：随机选特征会不会让单棵树变弱（偏差变大）？（会一点——这是用"单树略弱"换"树间更独立"的权衡，整体上值得。）

**练习 5.6（思考）** 软间隔 SVM 的目标可写成 hinge 损失 + L2 正则。(a) 把它和逻辑回归（对数损失 + L2）逐项对照，指出唯一本质区别；(b) 解释为什么 SVM 不天然输出概率、逻辑回归却天然输出。

*参考答案*：(a) 两者都是"经验损失 + L2 正则"框架，**唯一本质区别是损失函数**：SVM 用 hinge（分对且间隔 ≥1 则损失为 0，只关心边界附近的点），逻辑回归用对数损失（处处可微、对每个点的置信度都在乎）。正则项同为 $\lambda\|\mathbf{w}\|^2$（SVM 里 $C\propto 1/\lambda$）。(b) 逻辑回归直接建模 $P(y=1\mid\mathbf{x})=\sigma(\mathbf{w}^\top\mathbf{x})$，输出本就是概率（对数损失 = 伯努利 MLE）；SVM 的 $\mathbf{w}^\top\mathbf{x}+b$ 只是"到边界的带符号距离"，hinge 损失没有概率似然解释，要变概率得额外 Platt 缩放（事后拟合一个 sigmoid）。
*延伸思考*：那如果业务既要鲁棒分类又要校准概率，怎么办？（用逻辑回归，或对 SVM 做 Platt 缩放 / 用带概率校准的方法；或干脆评估时用 ROC-AUC 这种只依赖排序、不依赖概率绝对值的指标。）

**练习 5.7（动手·编程）** 用 sklearn 的 `SVC`，在一个**非线性可分**数据集（如 `make_moons` / `make_circles`）上对比 `kernel='linear'` 与 `kernel='rbf'`，并对 RBF 扫 $\gamma$（如 0.1, 1, 10, 100），画决策边界。

*参考答案 / 要点*：线性核画不出弯曲边界、在月牙 / 同心圆上必然差；RBF 核能拟合复杂边界。扫 $\gamma$：$\gamma$ 小边界平滑（欠拟合），$\gamma$ 大边界极度贴合每个训练点、出现孤岛（过拟合）。直观演示 §5.5.4 的核技巧威力与 $\gamma$ 作为容量旋钮。把支持向量标出来，体会"解只由少数样本决定"。
*延伸思考*：把样本数从几百加到几十万，观察 RBF-SVM 的训练时间如何爆炸（$O(n^2)$～$O(n^3)$），亲身体会 §5.5.4「诚实的边界」里"核 SVM 不可扩展"的硬伤。

**练习 5.8（思考）** 朴素贝叶斯的条件独立假设几乎总被违反（文本里词高度共现），为什么它在文本分类上还常常很好用？再说明为什么不该信任它输出的"概率值"。

*参考答案*：分类只需让正确类的后验排在最前（$\arg\max$ 对），**不需要后验概率值精确**。朴素假设会因重复计数相关特征而让概率估计有偏（常过度自信、接近 0/1），但只要这种偏差不翻转各类的相对排序，分类决策仍正确。加上它训练 / 预测极快、对高维稀疏（词袋）和小数据友好、几乎不调参，故成强基线。但正因校准很差（系统性过度自信），它输出的"概率"不可当真实概率用，只配排序 / 取 $\arg\max$。
*延伸思考*：这与"生成式 vs 判别式"的权衡有何关系？（生成式靠强假设少数据学得快但渐近受假设束缚；判别式数据多时渐近更准——朴素贝叶斯是生成式的典型，逻辑回归是其判别式对照。）
