偏差-方差沙盘 · 亲手拖出欠拟合 ↔ 过拟合

从一条真函数 f(x) 加高斯噪声采样出训练点，用多项式最小二乘（带 L2 岭回归）去拟合。拖degree（容量）滑杆：低阶曲线太僵 → 欠拟合（高偏差 bias），高阶曲线追着噪声乱抖 → 过拟合（高方差 variance）。叠加多条「换种子重采样后的拟合」可看见方差（曲线束抖动幅度）。右侧实时读出训练 / 测试 MSE 与那条经典 U 形泛化曲线。这正是《机器学习深度入门》第 2 章核心——暗线一「泛化」的第一个高峰，与偏差-方差分解 E[(y−f̂)²]=Bias²+Var+σ²。

必玩四个现象（§2.4 / §2.5 / §2.6）

① 欠拟合（underfitting）：deg=1 直线穿不过弯曲的真函数，训练 / 测试 MSE 都高且接近——高偏差，曲线束几乎不抖（低方差）。

② 恰好（good fit）：deg=3 与真函数弯曲程度相称，测试 MSE 接近谷底，偏差²与方差大致平衡——这正是 U 形的底部。

③ 过拟合（overfitting）：deg=14、λ=0，曲线穿过几乎每个训练点（训练 MSE→0）却在点间剧烈摆动，测试 MSE 飙升、泛化间隙大——高方差，曲线束抖成一团。

④ 正则救场：保持 deg=14，把 L2 λ 调大，曲线被「拉平、压向 0」——方差↓、偏差略↑，过拟合被抑制（L2 ↔ 高斯先验 MAP，见《概率与统计》第 8 章）。

⑤ 多数据救场：保持 deg=14，把 n 增到 80，同一个高阶模型的方差自然下降——数据是方差的天然解药（与正则互补）。

⑥ 大噪声：把 σ 调到 0.7，不可约噪声 σ² 抬高了整条 U 形的下界，谷底也变浅、最佳复杂度趋于更低——噪声越大越该用简单模型。

怎么读这张图

三件套视角（暗线二）：表示 = 次数 ≤ degree 的多项式（容量旋钮）；目标 = 带 L2 的均方误差 ‖Xw−y‖²+λ‖w‖²；优化 = 正规方程闭式解 w=(XᵀX+λI)⁻¹Xᵀy（这里用增广最小二乘 + 高斯消元自实现）。

归纳偏置（暗线三）：低 degree / 大 λ 都在说「我赌真函数是简单光滑的」。当这个先验和真函数对得上 ⇒ 泛化好；对不上（如用直线拟合正弦）⇒ 偏差大。没有免费的午餐：必须押注。

诚实的边界：① 这里用「测试集 MSE」当泛化误差的代理，真实中不能拿测试集调参 / 选 degree（要用验证集 / 交叉验证）；② σ² 是采样时人为设定的，现实中未知；③ 经典 U 形是低维 / 欠参数化下的图景，超大网络的「双下降」（double descent）会打破它，见第 9 章。
