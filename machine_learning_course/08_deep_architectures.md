# 第 8 章 深度学习的架构动物园：卷积、循环、注意力与图

> **本章定位**：上一章我们搭好了神经网络的骨架——多层感知机（MLP）、反向传播、激活与初始化——并见识了它惊人的表达力：理论上一个足够宽的 MLP 能逼近任意连续函数（通用逼近定理）。但"能逼近"不等于"学得到、学得起"。把一张 $224\times224\times3$ 的图片摊平成十几万维向量、用全连接层去吃，参数会爆炸、样本会不够、训练会失败——MLP 对**有结构的数据**极其低效。本章是暗线三（**归纳偏置，inductive bias**）的高潮：我们将看到，**深度学习的真正威力不在"更深更大"，而在为不同数据结构量身设计的连接模式与权重共享——它把数据的对称性 / 结构作为先验直接焊进网络**。网格数据（图像）有平移结构 → 卷积网络（CNN）；序列数据（文本 / 时间序列）有时序结构 → 循环网络（RNN）与注意力；集合 / 关系数据有置换对称 → 注意力 / Transformer；图数据有任意连接结构 → 图神经网络（GNN）。这是一座"架构动物园"，但本章的目的不是让你认全每只动物，而是交给你一把统一的钥匙：**每种架构 = 一种归纳偏置 = 把某种对称性 / 结构当先验**。沿着暗线二（表示 + 目标 + 优化），这些架构都只是在改写"表示"那一格——目标（损失）和优化（SGD + 反向传播）基本不变。本章重点是**注意力与 Transformer**，它是过去十年最有影响力的架构，统一了 NLP、视觉乃至科学计算（AlphaFold 是其中一个旗舰例子）。本章和《线性代数》咬合最紧——卷积与注意力的等变性直接来自第 10 章的对称性语言，注意力打分就是第 4 章的内积，嵌入相似度就是第 4/6 章的内积几何。读完本章，你看任何一个新架构时，第一个问题不再是"它有多少层"，而是"它假设了数据的什么结构"。

## 8.1 架构即归纳偏置（本章主旨）

### 8.1.1 一个让 MLP 崩溃的例子

先用一个具体例子把问题逼出来。假设我们要做图像分类，输入是一张 $1000\times1000$ 的彩色图片，即 $1000\times1000\times3 = 3{,}000{,}000$ 个像素值。如果第一层是全连接（fully connected）层，只要 $1000$ 个隐藏单元，权重矩阵 $W$ 就有 $3{,}000{,}000 \times 1000 = 30$ 亿个参数——**仅仅第一层**。

这个数字荒谬到能立刻杀死整个想法。三个层面的灾难：

- **统计灾难（泛化）**：30 亿参数要靠数据去定。粗略的经验法则是"参数规模与所需数据量大致同量级"（这只是数量级直觉、不是定理——现代过参数化网络能打破它，见第 9 章双下降），无论如何，用一层去吞 30 亿自由度而几乎没有结构约束，过拟合风险极高（暗线一）。没人有海量到能撑住这一层的标注图片。
- **计算灾难**：每次前向 / 反向都要做这个巨型矩阵乘，内存和算力都撑不住。
- **更深刻的浪费**：MLP 把输入当成一袋**无结构的数字**——它不知道第 17 号像素和第 18 号像素是空间上的邻居，也不知道把整张图平移一格后还是同一只猫。它必须**从零、从数据里**重新学到"相邻像素相关""平移后是同一物体"这些我们早就知道的事实。这是巨大的浪费。

问题的根源是：**MLP 的归纳偏置太弱（几乎只有"光滑""低复杂度优先"）**，对有结构的数据来说，弱归纳偏置意味着把所有结构都推给数据去学。而我们**明明知道**图像有结构。能不能把这些已知结构直接写进网络？

### 8.1.2 对称性 = 先验：把结构焊进连接模式

答案是肯定的，做法就是本章的核心思想。回顾暗线三：**没有免费的午餐——没有归纳偏置就无法泛化；学习的艺术是把归纳偏置和数据的真实结构对上。** 不同数据有不同的结构，而结构常常以**对称性（symmetry）** 的形式出现：

- **图像**：平移对称——把一只猫在图里移动一下，它还是猫；识别"边缘 / 纹理"的规则在图像的任何位置都一样。
- **序列（文本 / 语音 / 时间序列）**：时序结构——有先后顺序，邻近的元素相关，远处的元素可能有长程依赖。
- **集合 / 词袋**：置换对称——元素没有内在顺序，打乱顺序不应改变结果。
- **图（分子 / 社交网络 / 知识图谱）**：置换对称 + 任意连接拓扑——节点编号是任意的，重新编号不应改变结果。

把这些对称性"焊进"网络，有两件最重要的工具：

1. **局部连接（local connectivity）**：一个隐藏单元只看输入的一小块（而非全部）。这编码了"局部性"先验——相关性主要在邻近元素之间。
2. **权重共享（weight sharing / parameter tying）**：不同位置用**同一套**权重。这编码了"同样的规则在不同位置都成立"——比如检测边缘的卷积核在图像各处都用同一个，正是平移对称的直接体现。

> **与数学三课的连接**：对称性的精确语言来自《线性代数》第 10 章（[`../linear_algebra_course/10_geometry_rotations_equivariance.md`](../linear_algebra_course/10_geometry_rotations_equivariance.md)）。那里区分了**不变性（invariance）** 与**等变性（equivariance）**：设变换 $g$（如平移、旋转），映射 $f$ 若满足 $f(g\cdot \mathbf{x}) = f(\mathbf{x})$ 是**不变**（输出不随变换改变），满足 $f(g\cdot \mathbf{x}) = g\cdot f(\mathbf{x})$ 是**等变**（输入怎么变，输出就跟着同样地变）。本章会反复用到这对概念：卷积是平移**等变**，池化带来近似平移**不变**，自注意力是置换**等变**。把"网络应该对某个变换群保持等变 / 不变"作为设计原则，是一整个研究方向——**几何深度学习（geometric deep learning）**——的纲领。

### 8.1.3 权重共享为什么是"更强的先验"也是"更省的参数"

权重共享一举两得，值得单独点透，因为它把暗线一（泛化）和暗线三（归纳偏置）连成一根线。

- **从参数量看**：上面的全连接第一层是 30 亿参数；若改成卷积，用 $64$ 个 $3\times3\times3$ 的卷积核，参数只有 $64\times27 = 1728$ 个——**少了六个数量级**。同一个核扫过整张图，所有位置共享这一套权重。
- **从归纳偏置看**：权重共享不是"为了省参数才凑合的妥协"，而是**一条强假设**——"识别某个局部模式（边缘、角点）的规则，在图像任何位置都一样"。如果这个假设对（对自然图像基本对），那么我们用极少的参数就编码了正确的结构，**泛化会更好**（暗线一）。如果假设错（比如图像不同区域规则完全不同），共享反而会伤害性能。
- **从样本效率看**：共享意味着图里每个位置都在为同一组权重提供训练信号——等效于把数据量放大了。这就是为什么 CNN 在中等规模数据上往往比同等容量的 MLP 学得又快又好。

这正是本章的总旋律的一次预演：**强归纳偏置 = 用更少的数据学得更好，代价是这个偏置必须和数据真实结构对得上。** 后面我们会看到 Transformer 走到光谱的另一端——归纳偏置很弱，所以它吃更多数据，但天花板也更高。

> **给数学 / CS 读者的视角**：权重共享你其实早就熟悉。它就是函数式编程里的 `map`——对一个序列的每个元素施加**同一个**函数。卷积是带局部窗口的 `map`（stencil 计算，跟科学计算里的有限差分、图像处理里的滤波器是同一类操作）。把网络层看成"对结构化数据的某种受限的 `map` / `reduce`"，是理解整座架构动物园的捷径：CNN = 在网格上 `map` 局部核；RNN = 在序列上 `fold`（带状态的左折叠）；GNN = 在图上 `map`-邻居再 `reduce`；注意力 = 对所有位置做加权 `reduce`。

> **要点**：MLP 把输入当成无结构的一袋数字，归纳偏置太弱，对结构化数据（图像 / 序列 / 图）参数爆炸、样本低效。架构设计的核心思想是：**用局部连接 + 权重共享，把数据的对称性 / 结构当作先验焊进连接模式**。不同数据结构 → 不同对称性（平移 / 时序 / 置换）→ 不同架构（CNN / RNN / Transformer / GNN）。强归纳偏置换来更好的泛化与样本效率，前提是它和数据真实结构对得上。

## 8.2 卷积网络（CNN）：为网格数据而生

### 8.2.1 卷积的三件法宝：局部连接 + 权重共享 + 平移等变

**卷积神经网络（Convolutional Neural Network, CNN）** 是为**网格结构数据（grid-structured data）**——图像（2D 网格）、音频频谱（2D）、视频（3D）、甚至一维序列——设计的架构。它的核心操作**卷积（convolution）** 就是上一节"局部连接 + 权重共享"的具体落地。

先看一维直觉。一个卷积核（kernel / filter）是一小段权重 $\mathbf{w} = (w_{-1}, w_0, w_1)$，它沿着输入序列 $\mathbf{x}$ 滑动，每到一个位置就和局部窗口做内积：

$$
y_t \;=\; \sum_{k} w_k \, x_{t+k} \;=\; w_{-1}x_{t-1} + w_0 x_t + w_1 x_{t+1}.
$$

注意两件事：(1) 每个输出 $y_t$ 只依赖输入的一个**局部窗口**（局部连接）；(2) **所有位置 $t$ 用的是同一套 $\mathbf{w}$**（权重共享）。二维图像同理，核变成一个小方块（如 $3\times3$），在图上横竖滑动。

> **给数学 / CS 读者的视角**：纯数学的卷积是 $(\mathbf{w}*\mathbf{x})_t = \sum_k w_k x_{t-k}$（核要翻转）。深度学习框架里的"卷积"实际上是**互相关（cross-correlation）** $\sum_k w_k x_{t+k}$（不翻转）——因为核是学出来的，翻不翻转只是参数的重排，无所谓，大家就直接叫它卷积了。别在面试 / 读论文时被这个术语小坑绊倒。

**为什么卷积是平移等变？** 这是 CNN 最本质的性质，直接呼应 §8.1.2 和《线性代数》第 10 章。设 $T$ 是把输入整体平移一格的操作。卷积运算 $C$ 满足

$$
C(T\mathbf{x}) = T(C\mathbf{x}),
$$

即"先平移再卷积"等于"先卷积再平移"。直觉：因为每个位置都用同一个核，所以输入里的某个模式（比如一条边）移动到哪里，输出里对应的响应（激活）也跟着移动到哪里、形状不变。**这正是等变（equivariance）的定义**：输入怎么变，输出就怎么变。等变是好事——它意味着网络在某个位置学到的特征检测器，自动在所有位置都有效，无需重新学习。这就是 §8.1.3 说的权重共享的另一种说法。

> **与数学三课的连接**：把卷积写成矩阵乘 $\mathbf{y} = W\mathbf{x}$，则 $W$ 的每一行是上一行平移一格的稀疏带状矩阵。要分清两种边界：一般的有限信号、不补环（valid 卷积）时 $W$ 是**Toeplitz 矩阵**（沿对角线常数，但首尾不卷绕）；只有在**周期边界 / 循环卷积**下 $W$ 才是真正的**循环矩阵（circulant matrix）**——此时它能被傅里叶基精确对角化。《线性代数》第 7 章谱定理那章讲过这个对角化视角（把信号在傅里叶基上展开恰是谱分解的同构例子），循环矩阵的特征向量正是傅里叶基、特征值就是核的傅里叶变换。这就是"卷积 = 频域逐点相乘"（卷积定理）的来源，也解释了为什么卷积天然处理"平移"这种对称：循环矩阵正是循环平移群的表示。CNN 的等变性，本质上是把"参数矩阵被约束成循环 / 局部带状结构"这件事，翻译成了网络设计。

### 8.2.2 通道、步幅、填充、感受野

把卷积变成能用的网络层，还要几个工程零件，逐个讲清，它们都会在你读代码 / 调模型时反复出现。

**通道（channel）**。彩色图有 RGB 三个通道，所以输入是 $H\times W\times 3$。一个卷积核实际上是 $k\times k\times C_{\text{in}}$ 的小立方体，它对所有输入通道一起做内积，输出一个数。我们用 $C_{\text{out}}$ 个不同的核，得到 $C_{\text{out}}$ 个输出通道（也叫特征图，feature map）——每个核学一种局部模式（这个核找水平边缘、那个找某种颜色斑块）。所以一个卷积层的权重张量形状是 $k\times k\times C_{\text{in}}\times C_{\text{out}}$，参数量 $= k^2 \cdot C_{\text{in}}\cdot C_{\text{out}}$，**与图像尺寸 $H, W$ 无关**——这是 CNN 能处理大图的关键。

**步幅（stride）**。核每次滑动几格。步幅为 $1$ 输出和输入差不多大；步幅为 $2$ 输出尺寸减半（下采样的一种方式）。

**填充（padding）**。在图像边缘补一圈零（zero padding），让边缘像素也能当窗口中心，从而控制输出尺寸（常用"same padding"使输出和输入同尺寸）。不填充的话每过一层尺寸会缩水、边缘信息会丢。

**感受野（receptive field）**。这是理解深度 CNN 为什么有效的核心概念：**一个深层神经元最终"看到"了输入里多大一块区域**。单层 $3\times3$ 卷积的神经元只看 $3\times3$；但把两层 $3\times3$ 叠起来，第二层的一个神经元看第一层的 $3\times3$，而那 $3\times3$ 每个又看输入的 $3\times3$，于是它实际看到了输入的 $5\times5$。层数越深，感受野越大。这带来 CNN 的**层级特征（hierarchical features）** 直觉：

- 浅层（小感受野）：检测边缘、颜色、纹理等**局部低级特征**；
- 中层：把边缘组合成角点、纹理、简单形状；
- 深层（大感受野）：组合成物体部件（眼睛、轮子）乃至整个物体的高级语义。

这种"从局部到全局、从低级到高级"的层级，是局部连接 + 深度堆叠自然涌现的，和人类视觉皮层的层级组织有耐人寻味的相似——也是 CNN 在视觉上如此成功的归纳偏置根源。

> **给数学 / CS 读者的视角**：堆叠小核扩大感受野，比用一个大核更划算。为了把比较做干净，下面**只数单输入通道、单输出通道**的核内参数（即上一节 $k^2\cdot C_{\text{in}}\cdot C_{\text{out}}$ 公式里令 $C_{\text{in}}=C_{\text{out}}=1$，只看 $k^2$ 那部分）：两层 $3\times3$ 的感受野是 $5\times5$，参数 $2\times(3^2)=18$；直接用一个 $5\times5$ 核参数是 $25$。三层 $3\times3$ 感受野 $7\times7$，参数 $27$ vs $49$。多通道时把每个数乘上同一个 $C_{\text{in}}\cdot C_{\text{out}}$，比值不变，结论一样。**小核 + 深叠 = 更大的有效感受野、更少的参数、更多的非线性（每层之间夹激活函数）**——这正是 VGG 等经典网络坚持只用 $3\times3$ 卷积的理由。

### 8.2.3 三种常被忽视但极常用的卷积变体

上面是卷积层的"标配零件"。但你一读真实代码（ResNet、分割网络、生成网络）就会撞见三种变体，它们都只是在"局部连接 + 权重共享"的主题上换一个旋钮，值得各点透一段。

**1×1 卷积（pointwise convolution）：通道维度上的全连接。** 核大小 $1\times1$ 听起来很怪——它不看任何空间邻居，只在**单个像素位置上**对所有输入通道做一次线性组合（外加激活），输出 $C_{\text{out}}$ 个新通道。换句话说，$1\times1$ 卷积是"逐像素、跨通道"的小型 MLP，作用是**通道融合与升 / 降维**：用它把 $256$ 个通道压成 $64$ 个（降维省算力），或反过来扩张。这正是 ResNet 的**瓶颈块（bottleneck）** 的核心套路——先用 $1\times1$ 把通道压窄、再做昂贵的 $3\times3$、最后用 $1\times1$ 把通道还原，把计算量集中在窄通道上。它的参数量 $1^2\cdot C_{\text{in}}\cdot C_{\text{out}}$ 与空间尺寸无关，几乎不引入空间感受野却能大幅调节通道数，是现代 CNN 控制算力的关键旋钮。

**空洞卷积 / 膨胀卷积（dilated / atrous convolution）：免费扩大感受野。** 普通 $3\times3$ 核取相邻三格；空洞卷积在核元素之间**插入空隙**（dilation rate $r$），让 $3\times3$ 核覆盖 $5\times5$（$r=2$）甚至更大的范围，**却不增加参数、也不增加计算量**（仍是 9 个权重，只是采样点拉开了）。它的价值：在**不下采样、不丢分辨率**的前提下指数级扩大感受野——这对语义分割（要逐像素预测、不能像分类那样狂池化）、音频生成（WaveNet 用空洞卷积一步覆盖很长的时间窗）等需要"大感受野 + 高分辨率"的任务至关重要。代价是采样有空隙，可能漏掉细节（网格状伪影），需小心搭配不同 dilation rate。

**转置卷积 / 上采样（transposed convolution）：把特征图放大。** 前面所有操作要么保持、要么缩小空间尺寸。但分割（输出和输入同样大的像素图）、自编码器解码、生成模型（从小特征图生成大图像）都需要**把尺寸放大**。转置卷积（也被叫作"反卷积 deconvolution"，但这名字有误导——它不是卷积的数学逆运算）做的是步幅卷积的"形状反向"操作：通过在输入间插零再卷积，把 $H\times W$ 放大到 $2H\times 2W$，且放大的方式是**可学习**的（不像双线性插值那种固定上采样）。它常用于编码器-解码器结构（如 U-Net 风格）的解码端。

> **给数学 / CS 读者的视角**：把卷积写成稀疏矩阵 $\mathbf{y}=W\mathbf{x}$（§8.2.1），步幅卷积对应一个"高瘦"的下采样矩阵 $W$；**转置卷积就是用它的转置 $W^\top$ 去做前向**（故得名），形状自然从小变大。它和"卷积的真正逆运算"（解卷积 / 反卷积）不是一回事——$W^\top \neq W^{-1}$。记住这点能省掉读论文时被"deconvolution"一词坑掉的时间。

### 8.2.4 池化：近似平移不变与下采样

卷积是平移**等变**的（模式移动，响应跟着移动）。但很多任务最终要的是平移**不变**：一张图里有猫，无论猫在左上还是右下，分类输出都该是"猫"。从等变到不变，靠的是**池化（pooling）**。

最常见的**最大池化（max pooling）**：把特征图划成不重叠的小窗口（如 $2\times2$），每个窗口只取最大值。它做两件事：

- **下采样（downsampling）**：尺寸减半，减少后续计算与参数，同时增大后续层的有效感受野。
- **近似平移不变（approximate translation invariance）**：如果某个特征在 $2\times2$ 窗口里稍微移动一格，最大值往往不变——所以小幅平移不影响输出。注意是**近似**、**局部**的不变，不是严格全局不变；大幅平移仍会改变结果。

把这个性质讲准非常重要（这是总纲点名的红线）：

> **诚实的边界**：常有人笼统说"CNN 是平移不变的"，这不准确。**卷积层是平移等变（equivariant），不是不变；近似的平移不变性主要由池化（和后续的全局池化 / 大感受野）逐步累积而来，且只是局部、近似的。** 而且这种不变性也有代价：池化丢弃了精确位置信息，对需要精确定位的任务（分割、关键点检测）反而有害，所以这些任务里人们常少用或不用池化、改用步幅卷积或保留位置的设计。更进一步，**普通 CNN 对旋转、缩放并不等变 / 不变**——把猫旋转 90 度，普通 CNN 未必还认得（除非训练时见过旋转样本，即靠数据增强而非靠架构）。想要旋转等变，需要专门的群等变卷积（group-equivariant CNN），这是几何深度学习的内容，普通 CNN 不自带。

一个典型 CNN 因此长成这样：**[卷积 + 激活 + 池化] 堆叠若干次（空间尺寸越来越小、通道越来越多）→ 把最后的特征图摊平 → 全连接层 → softmax 输出类别**。前面的卷积部分是"特征提取器"，后面的全连接是"分类头"。

> **常见陷阱**：把 CNN 当成"旋转 / 缩放也不变"。CNN 的等变 / 近似不变**只针对平移**这一个变换群。"我训练了一个识别交通标志的 CNN，它一定能认出倾斜 30 度的标志吧？"——不一定。普通卷积对旋转既不等变也不变；它能认出旋转样本，靠的几乎全是**数据增强**（训练时把图随机旋转喂进去，让网络"见过"），而不是架构白送的对称性。把"卷积自带平移等变"错推广成"自带各种几何不变"，是部署时栽跟头的高频原因——尤其在医学影像、遥感这类朝向多变的场景。要真正的旋转等变，得用专门的群等变卷积，普通 CNN 不自带。

### 8.2.5 经典脉络：从 LeNet 到 ResNet

CNN 的发展史是理解"为什么这样设计"的活教材。这里只勾代表性的几个里程碑，把握演进逻辑而非记参数细节。

- **LeNet（LeCun 等，1990 年代）**：最早成功的 CNN 之一，用于手写数字识别（邮政编码、支票）。确立了"卷积 + 池化 + 全连接"的基本范式。它证明了卷积思想可行，但受限于当时的算力和数据，没能扩展到大规模问题。
- **AlexNet（Krizhevsky 等，2012）**：在大规模图像分类竞赛（ImageNet）上以巨大优势夺冠，被普遍视为深度学习浪潮的引爆点。关键不是发明了全新原理，而是**把 CNN 做大 + 用 GPU 训练 + ReLU 激活（缓解梯度消失，见第 7 章）+ Dropout（正则，见第 9 章）+ 数据增强**，让深层 CNN 第一次在大数据上真正跑通。它标志着"深度学习实际可行"从信念变成事实。
- **VGG（2014 前后）**：把"简单原则推到极致"——**全部用 $3\times3$ 小卷积核，靠堆深度（十几二十层）扩大感受野**（呼应 §8.2.2）。结构极规整，成为很多后续工作的骨干（backbone）。它揭示：在一定范围内，更深 = 更强。
- **ResNet（残差网络，He 等，2015）**：解决了一个关键难题——**网络太深反而更难训练**（不仅是过拟合，连训练误差都上不去，叫退化问题 degradation）。原因和第 7 章的梯度消失同源：信号穿过几十上百层，梯度在反向传播中衰减。ResNet 的解法极简却深刻：**残差连接（residual connection / skip connection）**，让每个模块学的是"在输入基础上的修正" $\mathbf{x} + F(\mathbf{x})$ 而非直接学 $H(\mathbf{x})$：

$$
\mathbf{y} = \mathbf{x} + F(\mathbf{x}; \theta).
$$

  直觉：如果某层最好什么都别干，它只要学 $F\approx 0$（容易），输出就直接等于输入，信息无损通过。反向传播时，梯度可以经由这条"高速公路"（恒等映射的导数是 $1$）直接回流，**不被层层衰减**——这就缓解了梯度消失，让训练上百层的网络成为可能。

  把这个"梯度高速公路"用一行雅可比写清楚，比文字直觉更有说服力（呼应第 7 章反向传播）。对 $\mathbf{y} = \mathbf{x} + F(\mathbf{x})$ 求对输入的雅可比：

$$
\frac{\partial \mathbf{y}}{\partial \mathbf{x}} = I + \frac{\partial F}{\partial \mathbf{x}}.
$$

  关键在那个 **$I$**。普通堆叠层 $\mathbf{y}=H(\mathbf{x})$ 的雅可比是 $\partial H/\partial \mathbf{x}$，几十层连乘就是一长串这种矩阵相乘，只要它们的奇异值普遍小于 $1$，乘积就指数衰减到 $0$（梯度消失）；而残差块的连乘里每一项都带一个 $I$，展开后**总有一条"全是 $I$ 相乘"的恒等通路**把梯度原样送回浅层，即使 $\partial F/\partial\mathbf{x}$ 很小，梯度也不会塌到 $0$。这不是近似、不是技巧，就是链式法则加上一个恒等项的直接结果——这正是残差让"学恒等映射"和"让梯度活着"同时变容易的数学骨架。残差连接后来成了几乎所有深层架构（包括 Transformer）的标配零件。它配套的归一化（如何稳住每层的数值尺度）我们留到第 9 章。

> **实战连接（视觉与跨领域）**：CNN 至今仍是计算机视觉的主力之一，用于图像分类、目标检测、语义分割、医学影像（如从 X 光 / CT / 病理切片里检测病灶）、自动驾驶的感知、卫星遥感、工业质检。它也不止于"看图"：一维 CNN 用于音频 / 心电信号 / 文本（在 Transformer 之前，文本分类常用 1D-CNN 抓局部 n-gram 模式）；在 AlphaGo 里，棋盘被当成一张"图像"用 CNN 处理（棋盘的平移近似对称是合理先验）。**只要数据有网格 + 局部 + 平移结构，卷积就是强有力的归纳偏置。**

> **要点**：CNN 为网格数据而生。卷积 = 局部连接 + 权重共享，天然**平移等变**；通道决定提取多少种局部模式，步幅 / 填充控制尺寸，感受野随深度增长，催生从低级到高级的**层级特征**。池化做下采样并带来**近似、局部的平移不变**（不是严格不变，也不管旋转 / 缩放）。经典脉络 LeNet → AlexNet（引爆点）→ VGG（深 + 小核）→ ResNet（残差连接破解深网络训练）展示了"如何把卷积这一归纳偏置做大做深"。

## 8.3 循环网络（RNN/LSTM/GRU）：为序列而生

### 8.3.1 序列数据与隐状态

图像是网格，**序列（sequence）** 数据则有先后顺序：一句话是词的序列、一段语音是声学帧的序列、股价是时间点的序列、DNA 是碱基的序列。序列的关键结构是**时序（temporal order）** 与**变长（variable length）**——句子有长有短，而 MLP / CNN 都偏好固定尺寸输入。我们需要一种能处理任意长序列、又对"顺序"这个结构有归纳偏置的架构。

**循环神经网络（Recurrent Neural Network, RNN）** 的想法是引入一个**隐状态（hidden state）** $\mathbf{h}_t$，像一个随时间更新的"记忆"，逐元素扫过序列：

$$
\mathbf{h}_t = \phi\!\big(W_{hh}\,\mathbf{h}_{t-1} + W_{xh}\,\mathbf{x}_t + \mathbf{b}\big),\qquad \mathbf{y}_t = W_{hy}\,\mathbf{h}_t .
$$

每一步：拿上一步的记忆 $\mathbf{h}_{t-1}$ 和当前输入 $\mathbf{x}_t$，算出新记忆 $\mathbf{h}_t$，再（可选）产生输出。注意**权重 $W_{hh}, W_{xh}, W_{hy}$ 在所有时间步共享**——这正是序列版的权重共享，编码了"处理序列的规则不随时间位置改变"这个时序对称先验（类比 CNN 的平移等变）。隐状态 $\mathbf{h}_t$ 原则上压缩了"到 $t$ 为止看到的所有历史"。

> **给数学 / CS 读者的视角**：RNN 就是带状态的左折叠（`fold` / `scan`）：把更新函数 $f(\mathbf{h}, \mathbf{x})$ 沿序列累积，$\mathbf{h}_t = f(\mathbf{h}_{t-1}, \mathbf{x}_t)$。也可以看成一个**离散时间动力系统 / 有限状态机的连续松弛**：$\mathbf{h}$ 是状态，$\mathbf{x}$ 是输入，$f$ 是转移。训练 RNN 时把它**按时间展开（unroll）** 成一个很深的前馈网络（深度 = 序列长度，但每层共享权重），然后照常反向传播——这叫**时间反向传播（backpropagation through time, BPTT）**，本质就是第 7 章的反向传播用在这个展开图上。

### 8.3.2 长程依赖与梯度消失 / 爆炸

RNN 的麻烦也恰恰来自这个"很深的展开图"。考虑梯度从第 $T$ 步回传到第 $t$ 步，要连乘一长串雅可比，其中反复出现 $W_{hh}$ 的幂次。粗略地说，梯度量级 $\sim \|W_{hh}\|^{T-t}$ 量级地变化：

- 若相关特征值 $> 1$：连乘 → **梯度爆炸（exploding gradient）**，训练发散（可用梯度裁剪 gradient clipping 缓解）。
- 若相关特征值 $< 1$：连乘 → **梯度消失（vanishing gradient）**，远处的梯度衰减到几乎为零。

梯度消失的后果很致命：**网络学不到长程依赖（long-range dependency）**。一句话"我在法国长大……（很多词）……所以我说流利的法语"，预测"法语"需要用到很前面的"法国"，但梯度传不回去那么远，RNN 就记不住。这和第 7 章讲的深网络梯度消失是同一个数学根源（连乘小因子），只是这里"深度"等于序列长度。

### 8.3.3 LSTM 与 GRU 的门控直觉

破解长程依赖问题的经典方案是给隐状态加一条"信息高速公路" + 一组可学习的"闸门"。这就是**长短期记忆网络（Long Short-Term Memory, LSTM）** 和它的简化版**门控循环单元（Gated Recurrent Unit, GRU）**。

LSTM 的关键是引入一个**细胞状态（cell state）** $\mathbf{c}_t$，它沿时间的主更新是**加性**的：

$$
\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t,
$$

其中 $\odot$ 是逐元素乘。注意这个结构和 ResNet 的残差连接 $\mathbf{c}_t \approx \mathbf{c}_{t-1} + (\cdots)$ 神似——**加性更新让信息（和梯度）能近乎无损地沿时间流动**，这就是它能记住长程信息、缓解梯度消失的关键。三个**门（gate）** 控制信息流，每个门都是一个取值在 $(0,1)$ 的 sigmoid，像可学习的、软的开关：

- **遗忘门（forget gate）$\mathbf{f}_t$**：决定旧记忆 $\mathbf{c}_{t-1}$ 保留多少（$0$ = 全忘，$1$ = 全留）。
- **输入门（input gate）$\mathbf{i}_t$**：决定新信息 $\tilde{\mathbf{c}}_t$ 写入多少。
- **输出门（output gate）$\mathbf{o}_t$**：决定从细胞状态里读出多少作为对外的隐状态 $\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t)$。

GRU 是更精简的设计，把细胞状态和隐状态合一、用更少的门（更新门 + 重置门），参数更少、常常效果相当。两者的共同直觉：**用可学习的门，让网络自己决定每一步记住什么、忘掉什么、读出什么——而不是像朴素 RNN 那样被迫每步把整个状态重写一遍。**

> **实战连接（NLP / 语音 / 时间序列）**：在 Transformer 出现之前（约 2014–2017），LSTM / GRU 是序列建模的主力：机器翻译（编码器-解码器 + 注意力的早期形态）、语音识别、文本生成、手写识别。今天在很多**流式 / 低延迟 / 长序列 / 小数据**场景，循环模型仍有价值——它对序列长度是线性复杂度（对比注意力的 $O(N^2)$，见 §8.4），适合需要逐步处理的在线任务。时间序列预测（销量、电力负荷、传感器）里循环模型也常用。近年还出现了状态空间模型等"新循环"架构，重新挑战 Transformer 在长序列上的统治。

> **诚实的边界**：LSTM / GRU **缓解**而非**根除**了长程依赖问题——门控让有用信息更容易保留，但对极长序列、需要精确回忆远处某个具体元素的任务，循环模型仍力不从心，因为所有历史都被压进一个**固定大小**的隐状态向量里（信息瓶颈）。而且它的计算**本质串行**：$\mathbf{h}_t$ 必须等 $\mathbf{h}_{t-1}$ 算完，无法在序列维度上并行，这在大规模训练时是致命的效率短板。这两个痛点（固定大小瓶颈 + 串行）正是注意力机制要解决的，也是 Transformer 取代 RNN 的根本原因。

### 8.3.4 双向 RNN、seq2seq 与"注意力的诞生"

在跳到注意力之前，还有两件序列建模的关键拼图，它们既是 RNN 时代的高光，也直接搭起通往 Transformer 的桥。

**双向 RNN（bidirectional RNN）。** 上面的 RNN 只从左往右读，$\mathbf{h}_t$ 只编码了**过去**（$\le t$）的信息。但很多任务里，一个词的含义要靠它**后面**的词才能定（"苹果"是水果还是公司？看下文）。双向 RNN 跑两条 RNN——一条正向、一条反向——把两个方向的隐状态拼起来，使每个位置的表示同时看到左右两侧的上下文。它在序列标注（命名实体识别、词性标注）里曾是标配。注意它要求**整条序列已知**（不能用于一边到达一边预测的在线 / 自回归生成），这是个真实约束。

**编码器-解码器（seq2seq）。** 机器翻译这类任务是"序列进、序列出"，且输入输出长度不同、词序也不对应。经典解法是**编码器-解码器（encoder–decoder, seq2seq）**：用一个 RNN（编码器）把整个源句子读完、压成一个**固定长度的上下文向量（context vector）**，再用另一个 RNN（解码器）从这个向量逐词生成目标句子。它优雅，但有个致命瓶颈——**整句话的全部信息被挤进一个固定大小的向量**，句子越长丢得越多（又是 §8.3.3 的"固定瓶颈"老毛病，这次发生在句子级）。

**注意力最初就是为了解决这个翻译瓶颈而生的。** 这是常被忽略却极重要的历史线：注意力机制（Bahdanau 等，约 2014–2015）**最早不是 Transformer 的零件，而是给 seq2seq 翻译模型打的一个补丁**——与其让解码器只依赖一个被压扁的上下文向量，不如让它在生成每个目标词时，**回头"对齐"并加权查看源句子的所有隐状态**，自己挑出当前最该关注的源词。这就是"注意力作为对齐（alignment）"的原始动机：翻译"猫"时把注意力放在源句的"cat"上。它立刻大幅改善了长句翻译。

到这里，"注意力"已经登场，但还**附着在 RNN 上**（RNN 编码源、RNN 解码、注意力只是两者间的桥）。Transformer 的激进一步是把这个逻辑推到极致——既然注意力这么有用、又能让任意位置直连，那为什么还要那个串行又健忘的 RNN？**干脆把 RNN 整个扔掉，只留注意力。** 这就是论文标题"Attention Is All You Need"的字面意思，也是下一节的起点。

> **要点**：RNN 用随时间更新、跨时间步共享权重的**隐状态**处理变长序列，编码"时序"先验；它本质是带状态的左折叠 / 离散动力系统，训练用按时间展开的 BPTT。朴素 RNN 因梯度连乘而**梯度消失 / 爆炸**，学不到**长程依赖**。LSTM/GRU 用**加性的细胞状态 + 门控**让信息近乎无损沿时间流动，缓解（非根除）该问题。双向 RNN 让每个位置看到双侧上下文；seq2seq 编码器-解码器处理"序列进序列出"，但受困于固定上下文向量瓶颈——**注意力最初正是为修补这个翻译瓶颈、做源-目标对齐而生**，随后被推到极致、甩掉 RNN，催生 Transformer。痛点（固定瓶颈 + 串行不可并行）为注意力埋下伏笔。

## 8.4 注意力与 Transformer（本章重点）

### 8.4.1 从"固定瓶颈"到"直接查看全部"

承接 §8.3.4：注意力最初是 seq2seq 翻译里"让解码器回看源句所有位置"的对齐补丁。把这个想法从"两条序列之间"推广到"一条序列对自己"，就得到自注意力，也就是 Transformer 的核心零件。它的直觉一句话：RNN 把整个历史压进一个固定大小的隐状态，远处信息既难保留又难精确取用；**不如不压缩，让每个位置在需要时直接"查看"序列里所有其他位置，并按相关程度加权地取用信息。** 这就是**注意力（attention）** 的核心直觉。

打个比方：你在读一句话理解某个词时，会不自觉地把注意力放在和它相关的其他词上——理解"它"指代谁，你会回看前文的名词。注意力机制就是把这种"按相关性动态聚焦"形式化：对每个位置，**根据内容计算它和所有位置的相关性权重，再用这些权重对所有位置的信息做加权平均**。关键是这些权重由内容动态决定（不像卷积核是固定的、与内容无关），且任意两个位置无论隔多远都能一步直连——长程依赖不再需要逐步传递。

### 8.4.2 自注意力逐块拆解：$\mathrm{softmax}(QK^\top/\sqrt{d})V$

我们把**自注意力（self-attention）** 这个公式一块一块拆开，确保你理解每一项的形状和动机。设输入是 $N$ 个 token，每个是 $d_{\text{model}}$ 维向量，堆成矩阵 $X\in\mathbb{R}^{N\times d_{\text{model}}}$。

**第一步：线性映射出 Query / Key / Value。** 用三个可学习的权重矩阵把每个 token 投影成三种角色：

$$
Q = XW_Q,\qquad K = XW_K,\qquad V = XW_V,
$$

形状 $Q,K\in\mathbb{R}^{N\times d_k}$，$V\in\mathbb{R}^{N\times d_v}$。直觉：每个 token 同时扮演三个角色——**Query（查询）** = "我想找什么"，**Key（键）** = "我能提供什么（用来被匹配）"，**Value（值）** = "如果你匹配上我，你拿到的实际内容"。这套"查询-键-值"的比喻直接借自数据库 / 字典检索（用 query 去匹配 keys，取出对应的 values），只不过这里是软的、加权的检索。

**第二步：打相似度分。** 用 $Q$ 和 $K$ 的内积衡量两两相关性：

$$
S = QK^\top \in \mathbb{R}^{N\times N},\qquad S_{ij} = \mathbf{q}_i\cdot\mathbf{k}_j .
$$

$S_{ij}$ 是"第 $i$ 个 token 的查询"和"第 $j$ 个 token 的键"的内积——**内积大 = 方向接近 = 相关性高**（这正是《线性代数》第 4 章内积作为相似度度量的几何）。$S$ 是一个 $N\times N$ 的相似度矩阵，第 $i$ 行表示 token $i$ 对所有 token 的关注打分。

**第三步：缩放 $\sqrt{d_k}$。** 除以 $\sqrt{d_k}$：

$$
\tilde S = \frac{QK^\top}{\sqrt{d_k}}.
$$

为什么要除？设 $\mathbf{q},\mathbf{k}$ 各分量近似独立、零均值、单位方差，**且 $\mathbf{q}$ 与 $\mathbf{k}$ 相互独立**（这一条不能少：否则 $\mathbb{E}[q_l k_l]\neq 0$，下面的方差估计就不成立），则内积 $\mathbf{q}\cdot\mathbf{k}=\sum_{l=1}^{d_k} q_l k_l$ 是 $d_k$ 个零均值、方差为 $1$ 的独立项之和（每项 $\mathbb{E}[q_l k_l]=\mathbb{E}[q_l]\mathbb{E}[k_l]=0$，$\mathrm{Var}(q_l k_l)=\mathbb{E}[q_l^2]\mathbb{E}[k_l^2]=1$），其**方差约为 $d_k$**、标准差约 $\sqrt{d_k}$。当 $d_k$ 较大时，$S_{ij}$ 的取值范围会很大，喂给 softmax 后会**饱和**——几乎全部权重压到一个位置上，其余接近 $0$，梯度也随之消失，训练困难。除以 $\sqrt{d_k}$ 把内积的标准差拉回 $\approx 1$ 的尺度，让 softmax 处在梯度良好的区间。这个 $\sqrt{d_k}$ 不是随便凑的常数，是有方差分析支撑的（总纲点名的红线）。

**第四步：softmax 归一化成权重。** 对每一行做 softmax，得到每个 query 对所有 key 的注意力权重（非负、每行和为 $1$）：

$$
A = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)\in\mathbb{R}^{N\times N},\qquad \sum_j A_{ij}=1.
$$

$A_{ij}$ = token $i$ 应该把多少注意力放在 token $j$ 上。

**第五步：加权求和 Value。** 用权重对 values 做加权平均，得到每个位置的新表示：

$$
\mathrm{Attention}(Q,K,V) = A\,V = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V \in\mathbb{R}^{N\times d_v}.
$$

第 $i$ 行 $= \sum_j A_{ij}\mathbf{v}_j$——token $i$ 的新表示，是它**最关注**的那些 token 的 value 的加权混合。整套操作的语义：**每个 token 看遍全场，按内容相关性从所有 token 那里"取信息"，融合成自己的新表示。** "自"注意力的"自"，指 $Q,K,V$ 都来自同一个输入序列（相对地，编码器-解码器之间的注意力叫交叉注意力 cross-attention）。

> **与数学三课的连接**：注意力的每一步都是线性代数。$Q,K,V$ 是线性变换（《线性代数》第 3 章）；$QK^\top$ 是 Gram 矩阵式的两两内积（第 4 章内积 = 相似度）；softmax 把分数变成概率分布（《信息论》第 3 章 / 概率统计——softmax 也正是最大熵下的指数族形式，见《信息论》第 10 章）；最后的 $AV$ 是把 values 当基、用注意力权重做的**凸组合**（落在 values 的凸包内）。整个自注意力，就是"用数据自己算出来的相似度矩阵，对自己做一次加权重组"。

> **概率视角**：每一行注意力权重 $A_{i,:}$ 是一个**离散概率分布**（非负、和为 1），所以 $\sum_j A_{ij}\mathbf{v}_j$ 正是"在这个分布下对 value 求期望" $\mathbb{E}_{j\sim A_{i,:}}[\mathbf{v}_j]$。可以这样读：把"token $i$ 当前最该从哪里取信息"看成一个隐变量 $z$，注意力分数 $\tilde S_{ij}=\mathbf{q}_i\cdot\mathbf{k}_j/\sqrt{d_k}$ 就像各位置的对数相容度，softmax 把它归一成 $z$ 的**后验** $p(z=j\mid i)\propto e^{\tilde S_{ij}}$，输出则是按这个后验对 value 做的**期望 / 混合**。从这个角度，注意力是一种"软检索"——不像硬 argmax 只取最相关的一个，而是按后验概率把所有候选混合起来。这也呼应了 softmax = 最大熵指数族（《信息论》第 10 章）：在"给定一阶相容度"的约束下，最大熵的取信息分布恰是这个指数形式。

### 8.4.3 复杂度 $O(N^2)$ 与它的代价

注意力的威力有明确的计算代价。相似度矩阵 $S=QK^\top$ 是 $N\times N$ 的，算它和存它都是 $O(N^2)$（更精确地 $O(N^2 d)$）。这意味着：

- **每对位置都直接交互**——这是优点：长程依赖一步直达，没有 RNN 的逐步衰减；信息路径长度是 $O(1)$ 而非 $O(N)$。
- **但开销随序列长度平方增长**——这是缺点：序列翻倍，计算和显存涨四倍。这就是为什么早期大模型的上下文长度（context length）受限，也是大量后续研究（稀疏注意力、线性注意力、FlashAttention 等高效实现）要攻克的方向。
- **可并行**：与 RNN 不同，所有位置的注意力可以一次矩阵乘并行算出来——没有时序依赖。这正是 Transformer 能在 GPU 上高效大规模训练的关键，也是它击败 RNN 的工程根因（§8.3.3 的伏笔在此收线）。

> **常见陷阱**：把注意力当成"严格更优、可无脑替换 RNN"的零件，而忽视那个 $O(N^2)$。RNN 对序列长度是**线性** $O(N)$，注意力是**平方** $O(N^2)$。在很长的序列（长文档、高分辨率信号、基因组）或显存 / 延迟吃紧的在线场景，朴素全注意力会直接爆显存或慢到不可用——这正是稀疏 / 线性注意力、FlashAttention、以及"新循环"状态空间模型仍在活跃发展的原因。"用了注意力就一定更好"是错的；该问的是"我的序列多长、算力多少、长程依赖是否真的关键"。把复杂度的代价记在心里，才不会在落地时被显存账单教育。

### 8.4.4 多头注意力

只用一套 $Q,K,V$，模型只能学一种"关注方式"。**多头注意力（multi-head attention）** 让模型并行地学多种：把 $d_{\text{model}}$ 维切成 $h$ 个"头"，每个头有自己的 $W_Q^{(i)}, W_K^{(i)}, W_V^{(i)}$（维度 $d_k = d_{\text{model}}/h$），各自独立做一遍注意力，再把 $h$ 个头的输出拼接、过一个线性层融合：

$$
\mathrm{MultiHead}(X) = \big[\mathrm{head}_1;\dots;\mathrm{head}_h\big]\,W_O,\qquad \mathrm{head}_i = \mathrm{Attention}(XW_Q^{(i)}, XW_K^{(i)}, XW_V^{(i)}).
$$

直觉：不同的头可以学到不同类型的关系——有的头关注句法依赖（动词找主语），有的关注共指（代词找指代对象），有的关注局部邻接。这有点像 CNN 一层里有多个卷积核各抓一种模式。多头几乎不增加总计算量（因为每头维度变小了），却显著增强表达力。

### 8.4.5 置换等变与位置编码

这是注意力一个微妙而重要的性质，也是总纲点名要讲准的红线。**自注意力本身是置换等变（permutation-equivariant）的**：如果你把输入 token 的顺序打乱（用置换 $P$），输出也只是相应地被打乱，**计算结果不依赖位置、只依赖内容**。形式上 $\mathrm{Attn}(PX) = P\,\mathrm{Attn}(X)$。

这是个双刃。好处：它把序列当成一个**集合（set）** 来处理，天然适合本无顺序的数据（集合、图的节点）。坏处：对**有顺序**的数据（语言！"狗咬人"和"人咬狗"完全不同），置换等变是错的——纯自注意力分不清词序。

解决办法是**位置编码（positional encoding）**：把每个位置的"序号信息"显式加 / 注入到 token 表示里，让模型能利用顺序。经典 Transformer 用固定的正弦 / 余弦函数（不同频率的 sin/cos 编码位置），后来也有可学习的位置嵌入、以及作用在注意力打分上的相对位置编码（如 RoPE 一类）。要点在于理解**为什么需要它**：因为自注意力本身对顺序视而不见，顺序必须靠位置编码额外注入。

> **给数学 / CS 读者的视角**：把"自注意力 = 置换等变的集合算子"这件事吃透，就理解了整个架构家族的统一图景。CNN 的归纳偏置是平移等变（强假设：网格 + 局部 + 平移）；自注意力的归纳偏置是置换等变（弱假设：只是"一堆元素两两可交互"，不假设任何几何 / 顺序结构）。**正因为注意力假设最少，它最通用——你想要什么结构（顺序、局部性、图连接），都通过额外的"偏置"显式加进去**：加位置编码 → 变回序列模型；加注意力掩码（只让相邻 token 互看）→ 模拟局部性；按图的邻接做掩码 → 变成图注意力网络。Transformer 之所以能横扫各领域，正因为它是一块"几乎无偏置的画布"，可以按需添加结构。

### 8.4.6 Transformer 整体结构与为何统治 NLP、扩散到视觉与科学

把上面的零件组装起来就是 **Transformer**（Vaswani 等，2017，论文题目"Attention Is All You Need"）。一个标准 Transformer 块（block）= **多头自注意力 + 残差连接 + 层归一化（LayerNorm）+ 一个逐位置的前馈网络（FFN, 即对每个 token 独立作用的 MLP）+ 再一次残差 + 归一化**。把若干这样的块堆叠起来，配上输入嵌入（§8.5）和位置编码，就是现代大模型的骨架。整体数据流可以画成一张图：

```
输入 token ──► 嵌入(§8.5) ──► + 位置编码(§8.4.5)
                                   │
                                   ▼
        ┌──────────  Transformer 块  × N ──────────┐
        │   ┌───────────────────────────────────┐  │
        │   │  多头自注意力 (§8.4.4)             │  │
        │   └───────────────────────────────────┘  │
        │            │ + 残差        ▼ LayerNorm     │
        │   ┌───────────────────────────────────┐  │
        │   │  逐位置前馈网络 FFN (每 token 一个 MLP) │
        │   └───────────────────────────────────┘  │
        │            │ + 残差        ▼ LayerNorm     │
        └───────────────────┬───────────────────────┘
                            ▼
                    输出表示 ──► 任务头(分类 / 下一词预测 …)
```

注意 FFN 是**逐位置（position-wise）** 的：同一个两层 MLP 独立作用在每个 token 上（位置间不交互），它负责"在每个位置上做非线性变换 / 升维再降维"，而**位置之间的信息混合全靠自注意力那一层**。一个常被点透的分工直觉：**注意力负责"在 token 之间搬运、混合信息"，FFN 负责"在每个 token 内部加工信息"**，两者交替堆叠。

**编码器 vs 解码器 vs 因果掩码。** 原始 Transformer 是为翻译设计的编码器-解码器结构，但后续模型按用途分成了三种范式，区别只在"每个 token 能看到谁"——也就是注意力的**掩码（mask）**：

- **纯编码器（encoder-only，如 BERT 类）**：每个 token 能看到序列里**所有**位置（双向，无掩码）。适合"理解 / 表示"任务（分类、检索、序列标注）——它本质是双向 RNN 的注意力版（§8.3.4），看全文再下判断。
- **纯解码器（decoder-only，如 GPT 类）**：用**因果掩码（causal mask / 自回归掩码）**——每个 token **只能看到自己和它左边的位置**，看不到未来。这通过把注意力分数矩阵 $\tilde S$ 的上三角（$j>i$ 的位置）设成 $-\infty$（softmax 后权重变 $0$）实现。这正是**自回归生成（autoregressive generation）** 的要求：逐词生成时，预测第 $t$ 个词只能用前 $t-1$ 个，绝不能偷看答案。今天主流的生成式大模型几乎都是这一类。
- **编码器-解码器（encoder–decoder，如翻译 / 摘要）**：编码器双向读源序列，解码器用因果掩码自回归生成目标序列，并通过**交叉注意力（cross-attention）**——解码器的 Query 去查编码器输出的 Key/Value——回看源序列（这恰是 §8.3.4 那个"对齐"补丁的 Transformer 版）。

> **常见陷阱**：把因果掩码当可有可无的细节。训练自回归语言模型时若漏了因果掩码，每个位置就能看到它要预测的未来词——模型会学到"直接抄答案"，训练损失漂亮地降到接近 0，可一旦真正逐词生成（此时未来不可见）就彻底崩溃。这是一种隐蔽的**数据泄漏**（暗线 / 红线），症状是"训练完美、生成全废"，新手极易踩。掩码不是优化技巧，是定义任务正确性的一部分。

> 这里出现了**残差连接**（§8.2.5 见过）和**层归一化（LayerNorm）**。为什么 Transformer 用 LayerNorm 而不是 CNN 常用的 BatchNorm？因为 BN 依赖一个批次内的统计量，对变长序列和小批次不友好、且训练 / 推理行为不同；LN 对每个样本自己的特征维做归一化，不依赖批次。归一化和残差的细节（含 BN vs LN 的精确区别）是第 9 章的内容，这里只点到为止：**它们是让深层 Transformer 训得动的"训练润滑剂"，不改变架构的归纳偏置本质。**

**为什么 Transformer 统治了 NLP？** 综合前面的拆解：(1) 任意两个 token 一步直连，**长程依赖建模能力**远胜 RNN；(2) 计算**高度可并行**，能在海量文本上大规模训练；(3) 归纳偏置弱、容量大，**给足数据就能不断变强**——这条性质直接催生了"缩放"路线。基于 Transformer 的预训练语言模型（如 BERT、GPT 系列）几乎重写了整个 NLP，并演化成今天的大语言模型（LLM）。

**为什么它扩散到视觉与科学？** 因为 §8.4.5 说的"几乎无偏置的画布"特性，让 Transformer 能套用到任何"一堆元素 + 它们之间有关系"的数据上：

- **视觉（Vision Transformer, ViT）**：把图像切成一个个小块（patch），每块当一个 token，加位置编码，喂给标准 Transformer。它丢掉了 CNN 的局部 / 平移先验，**在足够大的数据上反而能学得更好**（因为不被人为先验束缚），但在小数据上常打不过 CNN——这是归纳偏置强弱权衡的活样本。
- **多模态 / 语音 / 时间序列 / 推荐**：同样的"token 化 + Transformer"配方四处开花。
- **科学计算（不止折叠）**：把"网格 / 粒子 / 测站 token 化 + Transformer"也广泛用于**天气与气候预报**（把地球网格点当 token，学大气演化，近年的数据驱动天气大模型即此路）、**材料与化学**（晶体 / 分子的原子当 token，预测性质、加速筛选）、**偏微分方程代理模型**等。蛋白质结构预测的 AlphaFold 是这一类里最闪亮的旗舰之一（下一段克制地点一笔），但它和气象、材料是平级的科学应用，不是唯一。

> **实战连接（科学应用：蛋白质折叠 AlphaFold）**：本课反复强调，蛋白质折叠是众多应用里**一个**闪亮的例子，与视觉 / NLP 平级。AlphaFold（DeepMind）把"注意力 + 几何深度学习"用在了"从氨基酸序列预测三维结构"上：它在残基之间、序列与序列比对之间反复施加注意力，让任意两个残基的关系能直接交互（恰是注意力的长程优势）；同时把三维几何（旋转 / 平移等变，呼应《线性代数》第 10 章 SE(3)）作为先验融入结构模块。它是"把正确的归纳偏置（关系型注意力 + 几何等变）对上问题真实结构"的范例。想看它如何嵌进折叠科学的全貌，见《蛋白质折叠》课程相关章节（[`../protein_folding_course/`](../protein_folding_course/)）。这里点到为止——它是本章思想的一个高光应用，不是本章的主角。

> **诚实的边界**：Transformer 的强大恰恰来自它**归纳偏置弱**——它几乎不对数据结构做假设，所以通用、上限高。但这同一枚硬币的另一面是：**它必须靠海量数据 + 大算力把那些 CNN/RNN 用架构白送的结构"用数据学回来"**。在小数据、强结构的问题上，带正确先验的专用架构（CNN 之于图像、专门的等变网络之于分子）常常更样本高效、更好。所以"Transformer 一统天下"是有前提的（数据 / 算力充足）；**架构选择永远是归纳偏置强弱的权衡（trade-off）**，没有放之四海皆优的架构——这正是没有免费午餐定理（暗线三）在架构层面的回响。此外，$O(N^2)$ 的复杂度是真实约束，长上下文仍是活跃的工程 / 研究战场。

> **要点**：自注意力 $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$ = 把每个 token 线性映射成 Query/Key/Value，用 $QK^\top$ 算两两相似度、$\sqrt{d_k}$ 缩放防 softmax 饱和、softmax 成权重、加权求和 Value。它复杂度 $O(N^2)$ 但长程一步直达且可并行；多头并行学多种关系；**自身置换等变**，故需位置编码注入顺序。Transformer（注意力 + 残差 + LayerNorm + FFN 堆叠）凭长程建模 + 并行 + 弱偏置高容量统治 NLP，并以"几乎无偏置的画布"扩散到视觉（ViT）与科学（AlphaFold）。代价：弱偏置 → 吃大数据；架构选择是权衡。

## 8.5 嵌入（embedding）：把离散符号变成向量

### 8.5.1 离散符号的困境与嵌入的想法

到这里有个一直被略过的问题：神经网络吃的是**连续向量**，可文本是**离散符号**——词、字符、token，乃至商品 ID、用户 ID、分子里的原子类型。怎么把"狗"这个词喂进网络？

最朴素的做法是**独热编码（one-hot encoding）**：词表有 $V$ 个词，第 $k$ 个词就是一个第 $k$ 位为 $1$、其余为 $0$ 的 $V$ 维向量。但这糟糕透顶：(1) 维度等于词表大小（动辄几万几十万），稀疏且巨大；(2) 任意两个不同词的独热向量都正交，内积为 $0$——**"猫"和"狗"的距离，等于"猫"和"汽车"的距离**，编码里完全没有语义相似性。

**嵌入（embedding）** 的想法：为每个离散符号学一个**稠密的、低维的实数向量**（如 $300$ 维），让语义相近的符号在向量空间里也相近。技术上，嵌入层就是一个 $V\times d$ 的可学习查找表（lookup table）——给一个符号的 ID，取出对应的那一行向量。它等价于"独热向量乘以嵌入矩阵"，但实现上直接查表，免去稀疏乘法。这些向量是**学出来的**：在完成某个任务（语言建模、分类、推荐）的过程中，反向传播会调整每个符号的向量，使得对任务有用的语义结构自然浮现。

### 8.5.2 表示学习与"相似度 = 内积"

嵌入是**表示学习（representation learning）** 最直接的体现（呼应第 6 章 §6.8）：我们不手工设计特征，而是让模型自己学到"什么样的向量表示对任务有用"。学好的词嵌入有一个著名的迷人性质——**语义关系变成了向量的几何关系**。经典例子（来自 word2vec 一类方法）：

$$
\text{vec}(\text{“国王”}) - \text{vec}(\text{“男人”}) + \text{vec}(\text{“女人”}) \approx \text{vec}(\text{“女王”}).
$$

"性别"这个语义维度，竟对应到向量空间里一个大致固定的方向。这不是被刻意设计的，而是从"用上下文预测词"的训练目标里**涌现**出来的——分布假说（distributional hypothesis）："一个词的意义由它出现的上下文决定"，落到了几何上。

而衡量两个嵌入有多相似，标准工具就是**内积 / 余弦相似度（cosine similarity）**：

$$
\text{sim}(\mathbf{u},\mathbf{v}) = \frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\,\|\mathbf{v}\|}.
$$

这把我们带回《线性代数》第 4 章和第 6 章：**内积衡量方向的接近程度，是相似度最自然的几何度量**。注意 §8.4.2 里注意力的打分 $QK^\top$ 正是这个内积相似度——所以"嵌入 + 注意力"在数学上是同一套内积几何的两次使用：先把符号嵌成向量，再用内积衡量它们该互相关注多少。

> **与数学三课的连接**：嵌入空间里"相似度 = 内积"直接是《线性代数》第 4 章（[`../linear_algebra_course/04_inner_product_orthogonality.md`](../linear_algebra_course/04_inner_product_orthogonality.md)）的内积几何，第 6 章里也反复用它做相似度检索。而"为什么从'预测上下文'能学出有意义的嵌入"，可以从《信息论》第 4 章的互信息（[`../information_theory_course/04_kl_mutual_information.md`](../information_theory_course/04_kl_mutual_information.md)）来看：好的表示应当最大化"表示与上下文 / 标签之间的互信息"——这正是现代对比学习（contrastive learning，如 InfoNCE）的理论底色，留到第 10 章细讲。

> **诚实的边界**：上面 word2vec 式的嵌入是**静态（static）** 的——每个词不论在什么句子里都用同一个向量，于是"苹果"（水果 vs 公司）、"bank"（河岸 vs 银行）这种**一词多义**只能被压成一个折中向量，分不开。现代做法是**上下文嵌入（contextual embedding）**：词的向量由它所在的整句话动态算出（正是 §8.4 的 Transformer 编码器在做的事），同一个词在不同句子里向量不同。此外两点要诚实：(1) "国王−男人+女人≈女王"这类类比**并非处处成立**，它在精选的语义维度上漂亮，在很多词对上会失败，别把它当铁律；(2) 嵌入是从语料里学的，会**继承语料中的偏见**（性别 / 种族刻板印象会编码进向量的几何方向），直接用于招聘 / 信贷等决策有公平性风险——这是一个真实且重要的伦理边界（详见第 11 章）。

> **实战连接（推荐 / 检索 / 多模态）**：嵌入是现代 AI 系统的通用货币，远不止于词。**推荐系统**：把用户和物品都嵌成向量，用户向量和物品向量内积大 = 推荐（矩阵分解、双塔模型的核心）。**搜索 / 检索增强（RAG）**：把文档和查询嵌成向量，存进向量数据库，检索 = 找内积最大的向量（近似最近邻搜索）。**多模态**：把图像和文本嵌到**同一个空间**（如 CLIP），就能"用文字搜图"——文本嵌入和图像嵌入内积大即匹配。**实体 / 知识图谱**：把实体和关系嵌成向量做链接预测。**只要你需要"相似""检索""匹配"，背后几乎都是嵌入 + 内积。**

> **要点**：嵌入把离散符号（词 / ID / 原子）映成稠密低维向量，是一张可学习的查找表，取代了又大又稀疏、还丢失语义相似性的独热编码。它是表示学习的直接体现：语义关系会涌现为向量的几何关系（方向 = 语义维度）。**相似度 = 内积 / 余弦**，直接呼应《线性代数》内积几何，并与注意力打分同源。嵌入是推荐、检索、多模态、知识图谱的通用基础设施。

## 8.6 图神经网络（GNN）：为关系结构而生

### 8.6.1 图数据与置换对称

很多数据天然是**图（graph）**：节点 + 边。分子（原子 = 节点，化学键 = 边）、社交网络（人 = 节点，关系 = 边）、知识图谱（实体 + 关系）、交通路网、程序的抽象语法树、推荐系统的用户-物品二部图。图既不是网格（节点没有规则的空间排列、邻居数不固定），也不是序列（没有线性顺序），所以 CNN 和 RNN 都不直接适用。

图的关键结构是**任意连接拓扑 + 置换对称**：节点的编号是任意的——把节点 1 和节点 2 的标号互换、同时相应地换边，得到的是**同一个图**。因此图上的模型必须**置换等变 / 不变**：对节点的预测应当随节点重排而相应重排（等变），对整张图的预测应当与节点编号无关（不变）。这又是 §8.1.2 那对对称性概念，只不过群变成了节点的置换群——和自注意力的对称性同源（§8.4.5）。

### 8.6.2 消息传递：图上的局部计算

**图神经网络（Graph Neural Network, GNN）** 的主流范式是**消息传递（message passing）**。直觉极简单：**每个节点反复地从它的邻居收集信息、聚合、更新自己的表示。** 一轮消息传递分三步（对每个节点 $v$）：

1. **消息（message）**：每个邻居 $u\in\mathcal{N}(v)$ 根据自己的表示（和边的信息）算出一条要发给 $v$ 的消息 $\mathbf{m}_{u\to v}$。
2. **聚合（aggregate）**：把所有邻居的消息用一个**对置换不变**的算子（求和 / 平均 / 取最大）汇总——必须置换不变，因为邻居没有顺序！
3. **更新（update）**：节点 $v$ 用聚合后的消息更新自己的表示 $\mathbf{h}_v^{(l+1)} = \text{UPDATE}\big(\mathbf{h}_v^{(l)}, \text{AGG}_{u\in\mathcal{N}(v)}\,\mathbf{m}_{u\to v}\big)$。

一个简洁的代表（图卷积，GCN 风格）写出来是：

$$
\mathbf{h}_v^{(l+1)} = \phi\Big(W^{(l)}\sum_{u\in\mathcal{N}(v)\cup\{v\}} \frac{1}{c_{vu}}\,\mathbf{h}_u^{(l)}\Big),
$$

其中 $c_{vu}$ 是归一化系数、$\phi$ 是激活。注意所有节点共享同一套权重 $W^{(l)}$——这是图上的权重共享（类比 CNN 的核共享、RNN 的跨时间共享），编码"处理节点的规则与节点编号无关"的置换对称先验。堆叠 $L$ 轮消息传递，每个节点就能"看到" $L$ 跳（hop）以内的邻域——这恰是 CNN 感受野概念在图上的版本（§8.2.2）。

> **给数学 / CS 读者的视角**：GNN 和 CNN、Transformer 是同一个家族的不同特例，统一在"对邻域做置换不变聚合 + 共享权重更新"之下。**CNN = 在规则网格上、邻域是固定的 $k\times k$ 窗口的特殊 GNN；自注意力 = 在全连接图上、用注意力权重做加权聚合的 GNN（图注意力网络 GAT 把两者显式连起来）。** 把这三者看成"消息传递的不同邻域定义 + 不同聚合方式"，整座架构动物园就坍缩成一个统一框架——这正是几何深度学习的核心洞见。聚合算子必须置换不变（sum/mean/max 都是），否则就破坏了图的根本对称性。

> **诚实的边界**：GNN 有几个真实的局限要诚实交代。其一，**过平滑（over-smoothing）**：堆太多层消息传递，所有节点的表示会趋同（反复平均的不动点是均匀），所以 GNN 通常很浅（2–4 层），这限制了它捕捉长程图结构的能力。其二，**表达力有上限**：经典消息传递 GNN 的区分能力不超过某种图同构启发式（Weisfeiler–Lehman 检验），存在它分不出的不同图。其三，大图上的可扩展性、邻域爆炸等工程难题。GNN 不是万能的"图上 Transformer"，它的强归纳偏置（局部消息传递）在某些任务上反而是束缚——又一次印证架构选择是权衡。

> **实战连接（分子 / 社交 / 知识图谱）**：GNN 在**药物发现 / 化学**里用于从分子图预测性质（毒性、溶解度、活性）——分子天然是图，置换等变是必须的正确先验。**社交 / 推荐**：在用户-物品图上做推荐、好友推荐、社区发现。**知识图谱**：实体关系推理、链接预测、问答。**物理模拟**：把粒子 / 网格当节点，用 GNN 学动力学。**交通**：路网上预测拥堵。凡是"实体 + 它们之间的关系"且关系拓扑不规则的数据，GNN 都是首选的归纳偏置。

> **要点**：图数据 = 节点 + 任意边，核心结构是**置换对称**，CNN/RNN 不直接适用。GNN 用**消息传递**——每个节点反复地从邻居收集消息、用**置换不变**算子（sum/mean/max）聚合、共享权重更新；堆 $L$ 层看到 $L$ 跳邻域（图上的感受野）。它与 CNN（网格邻域）、自注意力（全连接图）统一在消息传递框架下。局限：过平滑（故通常很浅）、表达力有 WL 上限——强局部偏置既是力量也是束缚。

## 8.7 统一表：数据结构 ↔ 对称性 ↔ 架构 ↔ 归纳偏置

现在收束暗线三。本章的全部内容，可以压进一张表——它就是"架构 = 归纳偏置"这句话的展开：**先看数据有什么结构 / 对称性，再选把这种对称性焊进去的架构。**

| 数据结构 | 典型例子 | 关键对称性 / 结构 | 架构 | 归纳偏置（焊进去的假设） |
|---|---|---|---|---|
| **网格**（grid） | 图像、音频谱、视频 | 平移（translation）；局部性 | **CNN** | 局部连接 + 权重共享 → 平移**等变**；池化 → 近似平移不变；层级特征 |
| **序列**（sequence） | 文本、语音、时间序列 | 时序顺序；变长 | **RNN/LSTM/GRU** | 跨时间步权重共享；隐状态压缩历史；时序就近相关；门控保长程 |
| **集合 / 序列**（set / seq） | token 集合、句子 | 置换（无序时）；任意长程关系 | **Transformer / 自注意力** | 内容相关的两两交互；**置换等变**（+ 位置编码注入顺序）；弱偏置、高容量 |
| **图**（graph） | 分子、社交网、知识图谱 | 节点**置换**；任意连接拓扑 | **GNN（消息传递）** | 局部消息传递 + 置换不变聚合 + 权重共享 → 置换**等变 / 不变** |

读这张表的正确方式，是把它当成一台"诊断仪"：拿到一个新问题，先问**我的数据是什么结构、有什么对称性是我确信的**，再据此选架构（或设计新架构）。这就是几何深度学习的纲领，也是本课暗线三给你的最实用工具。

再叠加暗线二（表示 + 目标 + 优化）看一遍：**这四种架构，区别全在"表示"这一格——它们规定了假设空间的形状（连接模式 = 焊进去的对称性）。而"目标"（交叉熵 / MSE 等）和"优化"（SGD + 反向传播）在四者间几乎一模一样。** 换句话说，深度学习这十几年最重要的创新，大多发生在"表示"这一格——发明更好的归纳偏置、把更对的对称性焊进网络。这正是为什么本章是暗线三的高潮。

最后用暗线一（泛化）压一句：**焊进去的偏置对不对，最终由泛化来打分。** 偏置和数据真实结构对上（CNN 之于图像、GNN 之于分子），就用更少数据学得更好；对不上（用 CNN 硬套无空间结构的表格数据），强偏置反而有害。强弱之间没有免费午餐——这就是三条暗线在架构层面的合流。

> **诚实的边界**：这张"四象限"表是**有用的脚手架，不是不可越界的铁律**。真实前沿一直在打破象限边界：ViT 把图像当 token 序列喂 Transformer（放弃网格先验）、图注意力把注意力搬上图、状态空间模型用"新循环"挑战注意力、卷积与注意力的混合体层出不穷。表的价值在于让你**先想清楚数据的对称性、再有意识地选择保留还是放弃某个先验**——而不是机械地"图像就必须 CNN、文本就必须 Transformer"。把这张表当思考的起点，不是终点。

> **要点**：一张表收束本章——**网格↔平移↔CNN、序列↔时序↔RNN、集合↔置换↔Transformer、图↔节点置换↔GNN**，每个架构都是把对应对称性当先验焊进连接模式。叠加暗线二：四者只在"表示"格不同，目标 / 优化基本共享；叠加暗线一：偏置对不对由泛化打分，对上则省数据、对不上则有害——没有免费午餐。表是诊断起点不是教条，前沿不断跨越象限。

## 本章小结

- **架构即归纳偏置（本章主旨，暗线三高潮）**：MLP 把数据当无结构的一袋数字，对结构化数据参数爆炸、样本低效。架构设计的核心是用**局部连接 + 权重共享**，把数据的**对称性 / 结构**当先验焊进连接模式——这是把已知结构白送给模型、换取更好泛化与样本效率的关键。
- **CNN（网格 / 平移）**：卷积 = 局部连接 + 权重共享 → 平移**等变**；通道 / 步幅 / 填充 / 感受野是工程零件；池化带来**近似、局部**的平移不变（非严格、不管旋转缩放）；LeNet→AlexNet→VGG→ResNet（残差连接破解深网络训练）。
- **RNN/LSTM/GRU（序列 / 时序）**：隐状态 + 跨时间共享权重处理变长序列；朴素 RNN 梯度消失 / 爆炸学不到长程依赖；LSTM/GRU 用加性细胞状态 + 门控缓解（非根除）；痛点是固定瓶颈 + 串行不可并行。
- **注意力与 Transformer（本章重点）**：$\mathrm{softmax}(QK^\top/\sqrt{d_k})V$——Q/K/V 线性映射、$QK^\top$ 算两两相似度、$\sqrt{d_k}$ 防 softmax 饱和、softmax 成权重、加权求和 V；$O(N^2)$ 但长程一步直达且可并行；多头学多种关系；**自身置换等变**故需位置编码；Transformer 凭弱偏置 + 高容量 + 可并行统治 NLP，扩散到 ViT 与科学（AlphaFold 一例）。
- **嵌入**：离散符号 → 稠密低维向量（可学习查找表），表示学习的直接体现，**相似度 = 内积 / 余弦**，是推荐 / 检索 / 多模态的通用基础。
- **GNN（图 / 置换）**：消息传递 = 收集邻居消息 + 置换不变聚合 + 共享权重更新；与 CNN / 注意力统一在消息传递框架下；局限是过平滑与 WL 表达力上限。
- **统一表**：数据结构 ↔ 对称性 ↔ 架构 ↔ 归纳偏置一张表收束暗线三。

三条暗线在本章合流：**暗线三（归纳偏置）是全章主角——每种架构都是一种焊进网络的对称性先验**；**暗线二（表示+目标+优化）告诉我们这些创新几乎全发生在"表示"这一格，目标与优化基本共享**；**暗线一（泛化）是终极裁判——偏置和数据真实结构对上则省数据、学得好，对不上则有害，没有免费午餐**。Transformer 的弱偏置 / 高容量与 CNN/GNN 的强偏置 / 高样本效率，正是这个权衡光谱的两端。

## 动手与思考练习

**练习 8.1（思考）** 为什么把 $1000\times1000\times3$ 的图像用全连接层处理是个坏主意？请从参数量、泛化、和"浪费了什么已知结构"三个角度回答，并说明卷积如何分别改善这三点。

*参考答案*：参数量上，全连接第一层（即便只 1000 个隐单元）就有约 30 亿参数，卷积用几十个 $3\times3$ 核只需上千参数（与图像尺寸无关）。泛化上，参数越多越易过拟合且需要海量数据（暗线一）；卷积参数少、且权重共享等效放大数据。浪费的结构是平移对称与局部性——全连接要从零学到"相邻像素相关""平移后是同一物体"，卷积用局部连接 + 权重共享直接把这两个先验焊进去。*延伸思考*：什么样的"图像"上卷积的平移等变假设反而错？（提示：若图像不同区域语义规则不同，如人脸的固定区域布局，纯卷积的全局权重共享未必最优——这也是为什么有些任务用位置敏感的设计。）

**练习 8.2（思考）** 严格区分：卷积层是平移**等变**还是**不变**？池化提供的是哪一种？普通 CNN 对旋转是等变 / 不变吗？

*参考答案*：卷积层是平移**等变**（输入平移，输出特征图同样平移）。池化提供**近似、局部**的平移不变（小窗口内的小幅平移不改变最大值）。普通 CNN 对旋转**既不等变也不变**——除非训练时见过旋转样本（靠数据增强而非架构），想架构层面的旋转等变需专门的群等变卷积。*延伸思考*：分类任务最终想要平移不变，那"等变的卷积 + 池化逐步累积不变"这个设计，比"直接造一个全局平移不变的层"好在哪？（提示：等变保留了位置信息供深层组合，过早丢弃位置会伤害需要定位的任务。）

**练习 8.3（动手·编程）** 用 numpy 实现一个 1D 卷积（互相关）：输入 `x`（长度 $N$）、核 `w`（长度 $k$），输出 `y[t] = sum_j w[j]*x[t+j]`（valid padding，无填充）。然后验证平移等变性：构造 `x` 和它右移一格的 `x_shift`，比较 `conv(x_shift)` 与 `conv(x)` 右移一格是否一致（除边界）。

*参考答案要点*：
```python
import numpy as np
def conv1d(x, w):
    k, N = len(w), len(x)
    return np.array([np.dot(w, x[t:t+k]) for t in range(N-k+1)])
x = np.random.randn(20)
w = np.random.randn(3)
y = conv1d(x, w)
x_shift = np.concatenate([[0.0], x[:-1]])   # 右移一格
y_shift = conv1d(x_shift, w)
# 等变：y_shift[1:] 应约等于 y[:-1]（内部区域）
print(np.allclose(y_shift[1:], y[:-1]))      # True（忽略边界）
```
核心是看到"输入平移 → 输出平移"。*延伸思考*：把 `w` 换成全 $1/k$（均值滤波），观察输出如何"平滑"输入；再想：步幅设为 2 时输出长度怎么变？感受野如何随两层堆叠扩大？

**练习 8.4（思考）** 自注意力公式里为什么要除以 $\sqrt{d_k}$？如果不除会发生什么？给出方差层面的论证。

*参考答案*：设 $\mathbf{q},\mathbf{k}$ 各分量独立、零均值、单位方差，**且 $\mathbf{q}$ 与 $\mathbf{k}$ 相互独立**（保证 $\mathbb{E}[q_l k_l]=0$），则内积 $\sum_{l=1}^{d_k} q_l k_l$ 的方差约为 $d_k$、标准差约 $\sqrt{d_k}$。$d_k$ 大时分数取值范围很大，softmax 会**饱和**——几乎全部权重集中到一个位置、其余近 $0$，对应梯度也趋于 $0$，训练困难。除以 $\sqrt{d_k}$ 把标准差拉回 $\approx 1$，使 softmax 处在梯度良好的区间。*延伸思考*：多头注意力里每头维度 $d_k=d_{\text{model}}/h$ 更小，缩放因子也相应变小，这与"多头各自关注更细的子空间"如何自洽？

**练习 8.5（思考）** 论证自注意力（不含位置编码）是置换等变的：把输入序列用置换矩阵 $P$ 重排后，输出会怎样？由此说明为什么处理语言时必须加位置编码，而处理无序集合时反而不必。

*参考答案要点*：$Q,K,V$ 逐行由 $X$ 线性映射，$X\to PX$ 使 $Q\to PQ$ 等；$QK^\top \to PQK^\top P^\top$（行列同被置换），softmax 逐行进行不改变这种结构，最终 $\mathrm{Attn}(PX)=P\,\mathrm{Attn}(X)$——输出只是被同样地重排，计算与位置无关、只依赖内容。所以纯自注意力分不清词序（"狗咬人"="人咬狗"的 token 集合相同），语言有序，必须用位置编码注入顺序；而集合本无序，置换等变恰好是正确先验，不需位置编码。*延伸思考*：图注意力（GAT）通过注意力掩码只让相邻节点互看，这相当于在"全连接图的注意力"上加了什么先验？它和置换对称如何共存？

**练习 8.6（动手·编程）** 用 numpy 实现单头自注意力：给定 `X`（形状 $N\times d$）和权重 `Wq, Wk, Wv`，输出注意力结果。打印注意力权重矩阵 `A`，验证每行和为 1。

*参考答案要点*：
```python
import numpy as np
def softmax(z):                       # 沿最后一维，数值稳定
    z = z - z.max(axis=-1, keepdims=True)
    e = np.exp(z); return e / e.sum(axis=-1, keepdims=True)
def self_attention(X, Wq, Wk, Wv):
    Q, K, V = X@Wq, X@Wk, X@Wv
    dk = Q.shape[-1]
    A = softmax(Q@K.T / np.sqrt(dk))  # N x N
    return A@V, A
N, d, dk = 4, 8, 8
X = np.random.randn(N, d)
Wq, Wk, Wv = (np.random.randn(d, dk) for _ in range(3))
out, A = self_attention(X, Wq, Wk, Wv)
print(A.sum(axis=1))                  # 每行≈1
```
*延伸思考*：把 `X` 的行随机置换，验证 `out` 也被同样置换（练习 8.5 的数值版）；再给 `X` 每行加一个不同的"位置向量"，看置换等变性如何被打破。

**练习 8.7（思考）** 独热编码和嵌入相比，差在哪？为什么说"嵌入里相似度 = 内积"把我们带回了线性代数？

*参考答案*：独热编码维度 = 词表大小、稀疏巨大，且任意两词正交（内积 0）——丢失了语义相似性，"猫"到"狗"和"猫"到"汽车"距离一样。嵌入是稠密低维、可学习，语义相近的符号向量也相近，语义关系涌现为几何关系（方向 = 语义维度）。相似度用内积 / 余弦衡量方向接近度，正是《线性代数》第 4 章内积作为相似度的几何；它还与注意力打分 $QK^\top$ 同源。*延伸思考*：在推荐 / 检索里"找最相似" = 找内积最大的向量（最大内积搜索 / 近似最近邻），这把语义匹配变成了几何搜索问题——为什么这让系统能扩展到上亿条目？

**练习 8.8（思考·综合）** 给定四个场景，各选最合适的架构并说明你确信的对称性 / 结构：(a) 分子毒性预测；(b) 一句话的情感分类；(c) X 光片病灶检测；(d) 一段心率信号的异常检测。再各说一个"该架构归纳偏置可能失效"的情形。

*参考答案要点*：(a) 分子 = 图 → **GNN**，确信节点置换对称；失效：需要长程图依赖时过平滑限制浅层 GNN。(b) 句子 = 有序序列 → **Transformer**（小数据也可用轻量模型/LSTM）；失效：数据极少时弱偏置吃不饱，专用 / 带先验模型更稳。(c) 图像 = 网格 → **CNN**，确信局部 + 平移结构；失效：病灶位置 / 朝向高度多变且数据大时，ViT 可能更优，或需旋转等变设计。(d) 一维时序 → **1D-CNN 或循环 / 注意力**，确信时序 + 局部模式；失效：若关键是极长程依赖，CNN 感受野不够、需注意力。统一逻辑：先确认数据结构与对称性，再选把它焊进去的架构，并清醒架构选择是权衡（暗线三）。*延伸思考*：表格数据（无空间 / 时序 / 图结构）为什么至今常被梯度提升树（第 5 章）打败深度网络？（提示：表格几乎没有可供深度架构利用的对称性，强架构偏置反成束缚。）

**练习 8.9（动手·编程）** 把练习 8.6 的 numpy 自注意力与 PyTorch 的官方实现对齐验证。用 `torch.nn.functional.scaled_dot_product_attention`（或 `nn.MultiheadAttention`）对同一组 $Q,K,V$ 算一遍，和你的 numpy 结果对比，确认数值一致；再实现一个**因果掩码**（上三角设为 $-\infty$），验证加掩码后每个位置的输出只依赖它及左侧。

*参考答案要点*：
```python
import numpy as np, torch
import torch.nn.functional as F
N, dk = 4, 8
Xq = torch.randn(N, dk); Xk = torch.randn(N, dk); Xv = torch.randn(N, dk)
# PyTorch 官方（内部已含 1/sqrt(dk) 缩放）
out_torch = F.scaled_dot_product_attention(Xq, Xk, Xv)        # 无掩码
# numpy 版对照
def softmax(z):
    z = z - z.max(-1, keepdims=True); e = np.exp(z); return e / e.sum(-1, keepdims=True)
S = (Xq @ Xk.T / np.sqrt(dk)).numpy()
out_np = softmax(S) @ Xv.numpy()
print(np.allclose(out_torch.numpy(), out_np, atol=1e-5))      # True
# 因果掩码：上三角(未来)置 -inf
out_causal = F.scaled_dot_product_attention(Xq, Xk, Xv, is_causal=True)
mask = np.triu(np.ones((N, N)), k=1).astype(bool)
Sm = S.copy(); Sm[mask] = -np.inf
out_np_causal = softmax(Sm) @ Xv.numpy()
print(np.allclose(out_causal.numpy(), out_np_causal, atol=1e-5))  # True
```
要点是亲手确认两件事：(1) 官方实现就是你拆解的那个公式（含 $1/\sqrt{d_k}$）；(2) 因果掩码如何把"看不到未来"变成上三角 $-\infty$。*延伸思考*：把 `is_causal=True` 时第 0 行的输出和"只用 token 0"的结果比，验证第 0 个位置确实只看自己；再想：训练自回归模型时若忘了这个掩码，为什么训练损失会假性变好而生成崩溃（呼应 §8.4.6 的「常见陷阱」）？
