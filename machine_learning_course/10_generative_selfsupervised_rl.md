# 第 10 章 超越监督学习：生成模型、自监督与强化学习

> **本章定位**：到此为止，本课讲的几乎都是**监督学习（supervised learning）**——给一堆带标签的样本 $\{(\mathbf{x}_i,y_i)\}$，学一个映射 $f:\mathbf{x}\mapsto y$。但这只是机器学习版图的一角，而且很可能不是最大、最深刻的那一角。世界上绝大多数数据**没有标签**：互联网上的万亿词文本、海量未标注图像、海洋般的蛋白质序列、机器人与环境的交互轨迹。要让机器从这些数据里学习，必须越过"等人来贴标签"的范式。本章带你走出监督学习的舒适区，看现代 ML 最活跃的三块前沿：**生成模型（generative models）**——不学 $P(y\mid \mathbf{x})$ 而直接学数据本身的分布 $P(\mathbf{x})$，于是能采样、能补全、能检测异常（自回归 / VAE / GAN / 扩散，以及大语言模型）；**自监督学习（self-supervised learning）**——从无标签数据里**自己造**监督信号（对比学习、掩码预测），它是当代表示学习与基础模型的真正引擎；**强化学习（reinforcement learning, RL）**——智能体在与环境交互中靠**奖励**而非标签学习，目标是最大化长期回报。这三块看似各异，却被三条暗线和三门数学课牢牢串起：生成模型的核心是**极大似然 / 采样 / MCMC**（呼应《概率与统计》第 7/10 章）与 **KL / 互信息 / 率失真**（呼应《信息论》第 4/9 章）；自监督的对比损失就是**互信息的下界**（信息论第 4 章）；它们仍然逃不出"表示 + 目标 + 优化"的解剖（暗线二），仍然在和**归纳偏置**与**泛化**较劲（暗线三、一）。本章也是全课"诚实气质"最该发光的地方：生成模型**难以评估**、GAN/RL **训练不稳、样本效率差**、大模型的**对齐与安全是开放问题**——这些边界，我们会反复点明。读完本章，你将拥有看懂当代 AI 论文标题的词汇表，并且知道每个漂亮结果背后真正的代价在哪里。

## 10.1 判别式 vs 生成式：到底在建模什么

### 10.1.1 两种世界观

监督学习里，我们其实一直在偷偷做一件事：建模**条件分布 $P(y\mid \mathbf{x})$**。逻辑回归输出"给定图像 $\mathbf{x}$，它是猫的概率"；softmax 回归输出类别上的条件分布。这类模型叫**判别式模型（discriminative model）**——它只关心"给定输入，输出是什么"，从不操心输入 $\mathbf{x}$ 本身是怎么来的、长什么样。

**生成式模型（generative model）** 换了一套世界观：它要建模**数据本身的分布 $P(\mathbf{x})$**（或联合分布 $P(\mathbf{x}, y)$）。它问的不是"这张图是不是猫"，而是更野心勃勃的问题——"猫的图片整体上是个什么样的分布？我能不能**画出**一张从没存在过、但看起来确实是猫的图？"

用一个比喻：判别式模型像一个**鉴定师**，看一幅画就能说"这是真迹 / 赝品"；生成式模型像一个**画家**，能动手**画出**一幅以假乱真的新画。鉴定不需要会画，画却内含了对"什么是真迹"的深刻理解——这是生成式模型更难、也更有潜力的根源。

形式化地，二者由贝叶斯定理相连：

$$
\underbrace{P(y\mid \mathbf{x})}_{\text{判别式直接学}} = \frac{\overbrace{P(\mathbf{x}\mid y)\,P(y)}^{\text{生成式学这两块}}}{P(\mathbf{x})}.
$$

判别式模型抄近路，直接逼近左边；生成式模型走远路，建模 $P(\mathbf{x}\mid y)$ 与 $P(y)$（朴素贝叶斯就是这一路，见第 5 章），再用贝叶斯定理"反推"分类。本章关注的"现代生成模型"更激进——它们大多直接攻 $P(\mathbf{x})$ 本身（无条件生成），或 $P(\mathbf{x}\mid \text{条件})$（条件生成，如"按这句话画图"）。

为什么"画家比鉴定师难"？因为分类只需找到一条**决策边界**——把"猫的高密度区"和"非猫的高密度区"分开就够了，对边界两侧分布的内部形状一无所知也没关系。而生成必须刻画分布的**整个形状**：猫脸的几何比例、毛发纹理、光照如何随姿态变化……漏掉任何一块，生成的图就会"哪里不对"。维度灾难（curse of dimensionality）让这件事雪上加霜——一张普通图像是几十万维，可能的像素组合数是天文数字，而"看起来像真图"的那些只占其中极其微小、形状极其复杂的一块**流形（manifold）**。生成模型的全部技艺，就是用有限样本把这块高维流形的形状学出来。

> **给数学 / CS 读者的视角**：可以把生成模型类比成一个**会"反向运行"的程序**。普通分类器是 $\mathbf{x}\to y$ 的单向函数；生成模型则要构造一个**采样器**——一个能反复输出"合法 $\mathbf{x}$"的随机过程。从这个角度，自回归模型像一个状态机逐步吐出 token，VAE / GAN 像把简单噪声 $\mathbf{z}$ 经一个确定网络"解码"成数据（一种可微的伪随机数到数据的映射），扩散像一条把噪声逐步"整理"成数据的迭代算法。换句话说，生成建模 = 学一个把易采样的简单分布**搬运（transport）** 到复杂数据分布的映射，这也是"最优传输（optimal transport）"等数学工具进入生成模型的入口。

### 10.1.2 为什么要建模分布本身

直接学 $P(\mathbf{x})$ 听起来比分类难得多——它确实难。那为什么还要做？因为一旦握有 $P(\mathbf{x})$（哪怕只是能从中采样），你就解锁了一整套监督学习给不了的能力：

- **采样 / 生成（sampling）**：从 $P(\mathbf{x})$ 抽样，造出全新的、像真的一样的样本——生成图像、写文章、合成语音、设计分子。
- **补全 / 修复（completion / inpainting）**：给定一部分 $\mathbf{x}$，对剩下部分按条件分布采样——补全句子、修复破损图像、填补缺失的传感器读数。
- **异常检测（anomaly detection）**：$P(\mathbf{x})$ 很低的样本就是"罕见 / 异常"的——欺诈交易、设备故障、医学影像里的离群病灶。这是判别式分类器天然不擅长的（它没见过的异常类根本没法分类）。
- **表示学习（representation learning）**：为了学好 $P(\mathbf{x})$，模型被迫理解数据的内在结构（物体、语法、物理规律），中间表示往往对下游任务极有用——这正通向 §10.3 的自监督。
- **密度估计与不确定性**：知道每个样本的概率（或相对似然），能支撑更可靠的决策与不确定性量化。

> **与数学三课的连接**：本节是《概率与统计》与《信息论》在 ML 里最直接的汇合点。"建模 $P(\mathbf{x})$" 就是《概率与统计》第 7 章的**密度估计 / 极大似然**问题搬到高维、复杂数据上；"从 $P(\mathbf{x})$ 采样" 在高维下几乎必然要用《概率与统计》第 10 章的**蒙特卡洛 / MCMC**思想（扩散模型的反向过程、自回归的逐步采样都是它的后裔）。而"学得多好"的度量——模型分布 $p_\theta$ 与真实分布 $p_{\text{data}}$ 的差距——天然用《信息论》第 4 章的 **KL 散度**衡量：极大似然 $\Leftrightarrow$ 最小化 $\mathrm{KL}(p_{\text{data}}\,\|\,p_\theta)$（见第 3 章交叉熵那一节）。

> **要点**：判别式模型学 $P(y\mid\mathbf{x})$（鉴定师），生成式模型学数据分布 $P(\mathbf{x})$（画家）。建模分布本身解锁了采样 / 补全 / 异常检测 / 表示学习等监督学习给不了的能力，代价是问题更难。它的数学母语是概率（密度估计 / 采样 / MCMC）与信息论（KL / 互信息）。

## 10.2 生成模型谱系：四条技术路线

要建模高维分布 $P(\mathbf{x})$，没有"一招通吃"的办法——有四条主流路线，每条都是对"如何表示并训练一个高维分布"的不同回答。它们的根本张力在于：**我们想要可计算的似然、想要高质量且快速的采样、想要稳定的训练——但这几样很难同时拿满。** 下面逐一看，最后用一张对比表收束这个权衡。统一地看（暗线二），四者都在改写"表示分布的方式"与"训练目标"，优化器大多还是 SGD 家族。

先给一张**谱系树**，把四条路线放回它们共同的根上——别把它们当成四个孤立发明，而是同一棵"如何刻画 $P(\mathbf{x})$"大树上的分枝：

```
                         生成模型：如何刻画 P(x)？
                                   │
        ┌──────────────────────────┼──────────────────────────┐
   显式似然（写得出密度）                          隐式（不写密度，只会采样）
        │                                                      │
   ┌────┴─────────┐                                            │
 精确似然        近似 / 下界似然                                  │
   │               │                                           │
 自回归 AR     ┌───┴──────┐                                  GAN
（链式法则     VAE        扩散 Diffusion                  （生成器 vs 判别器
 逐步条件）  （1 层连续    （T 层隐变量，                    的 min-max 博弈，
   │          隐变量，      每层"编码"=固定加噪，                隐式定义 p_G）
  GPT/LLM    优化 ELBO）    优化化简后的 ELBO                      │
  像素/音频      │          =去噪回归）                       早期图像 SOTA
  自回归     异常检测/压缩      │
            /隐空间表示    图像/分子/蛋白生成
```

看这张图的关键是左侧主干：**自回归、VAE、扩散全在"极大似然 / 变分推断"这一支上**（自回归精确、VAE 与扩散用变分下界 ELBO），只有 GAN 走了"不写密度、纯靠对抗采样"的隐式右支。下文 §10.2.4 的「概率视角」会把 VAE 与扩散的亲缘关系讲透。

### 10.2.1 自回归模型：把联合分布拆成一串条件

**自回归模型（autoregressive model）** 用一个朴素却威力巨大的恒等式起手——**概率的链式法则（chain rule）**，把高维联合分布**精确地**分解成一串一维条件分布的乘积：

$$
P(\mathbf{x}) = P(x_1, x_2, \dots, x_T) = \prod_{t=1}^{T} P(x_t \mid x_1, \dots, x_{t-1}) = \prod_{t=1}^{T} P(x_t \mid \mathbf{x}_{<t}).
$$

这一步没有任何近似——它对任意分布都成立。它的妙处在于：把"建模一个 $T$ 维联合分布"这个吓人的问题，**降维**成"$T$ 个一维条件分布"，而每个 $P(x_t\mid \mathbf{x}_{<t})$ 都是一个我们已经会做的、普通的预测问题（给定前文，预测下一个）。我们用**同一个**神经网络 $f_\theta$（权重共享，呼应第 8 章序列架构）来输出每一步的条件分布。

**训练：极大似然。** 目标是最大化训练数据的对数似然，等价于最小化每一步的交叉熵——这就是熟悉的监督学习损失，只不过"标签"是数据**自己的下一个元素**（这已经带有自监督的味道）：

$$
\mathcal{L}(\theta) = -\sum_{t=1}^{T} \log p_\theta(x_t \mid \mathbf{x}_{<t}).
$$

每一步用真实的前缀作为输入来预测下一个（训练时叫 **teacher forcing**），整段并行计算、一次反向传播。

**生成：逐元素采样。** 训练好后，从 $p_\theta(x_1)$ 采一个，喂回去得到 $p_\theta(x_2\mid x_1)$ 再采，如此**一个接一个**生成，直到结束。

**代表：语言模型 / GPT。** 文本天然是符号序列，自回归 + Transformer 解码器（第 8 章）就是当代**大语言模型（large language model, LLM）** 的骨架——把"预测下一个词"做到极致，就涌现出惊人的语言能力。像素级自回归（逐像素生成图像）、音频波形自回归也属此类。

**采样的"温度"与多样性。** 逐步采样时，可以不直接按 $p_\theta(x_t\mid\mathbf{x}_{<t})$ 抽，而是引入一个**温度（temperature）$\tau$** 调节随机性：把 softmax 前的 logits 除以 $\tau$。$\tau\to 0$ 时退化为贪婪（每步选最可能的，输出确定但单调重复）；$\tau=1$ 是原分布；$\tau>1$ 更随机、更"天马行空"但也更易出错。这就是文本生成里"调温度"的来历，也提醒我们：**会算似然不等于会采样得好**——采样策略本身是门手艺。

- **优点**：**似然可精确写出并优化**（链式法则无近似），训练稳定（就是交叉熵），是当前文本生成的绝对主流。（对**离散**数据如文本，每步条件分布就是类别分布，似然完全精确；对**连续**数据如像素，得配合离散化或混合密度等手段把"连续值上的密度"写成可优化的形式，否则"精确似然"要小心解读。）
- **缺点**：**采样慢**——必须串行生成，长序列要跑 $T$ 次前向，无法像 VAE/GAN 那样一次出整张图。还要人为规定一个生成顺序（文本天然有序，图像的"逐像素顺序"则有点别扭）。另一个微妙陷阱是**曝光偏差（exposure bias）**：训练时每步喂的是真实前缀（teacher forcing），生成时喂的却是模型自己产生的、可能带错的前缀，误差会沿序列累积。

> **概率视角**：自回归模型是"老实的极大似然学徒"。它直接、精确地优化 $\log p_\theta(\mathbf{x})$，没有下界、没有对抗、没有近似——这也是它训练最稳的根源。代价是它把"分布"完全寄托在"逐步条件预测"上，采样的串行性是与生俱来的。

> **实战连接（NLP / 时间序列）**：自回归是当代文本生成的统治范式，但它的应用远不止聊天。任何"按历史预测未来一步、再把预测接回去续推"的任务都属此类：语音 / 音频波形合成、时间序列预测（销量 / 电力负荷的多步外推就是自回归地滚动预测）、代码补全、乐谱生成。它们共享同一个软肋——**误差会沿生成步累积**（上面的曝光偏差），所以多步预测越往后越不可靠，这在时间序列预测里是人尽皆知的痛点。

### 10.2.2 变分自编码器（VAE）：隐变量 + 证据下界

**变分自编码器（Variational Autoencoder, VAE）** 走的是**隐变量模型（latent variable model）** 的路。它假设每个观测 $\mathbf{x}$ 背后有一个低维**隐变量（latent variable）$\mathbf{z}$**——可以理解为"生成这张图的内在配方 / 风格码"——先从一个简单先验 $p(\mathbf{z})$（通常取标准高斯）采一个配方，再由解码器 $p_\theta(\mathbf{x}\mid \mathbf{z})$ 把配方"画"成数据：

$$
p_\theta(\mathbf{x}) = \int p_\theta(\mathbf{x}\mid \mathbf{z})\, p(\mathbf{z})\, d\mathbf{z}.
$$

麻烦来了：这个积分**算不出来**（高维、$p_\theta(\mathbf{x}\mid\mathbf{z})$ 是神经网络），所以似然 $p_\theta(\mathbf{x})$ 无法直接优化。VAE 的破局之道是引入一个**编码器（encoder）$q_\phi(\mathbf{z}\mid \mathbf{x})$** 去近似真正难算的后验 $p_\theta(\mathbf{z}\mid \mathbf{x})$，然后优化对数似然的一个**下界**——**证据下界（Evidence Lower BOund, ELBO）**：

$$
\log p_\theta(\mathbf{x}) \;\ge\; \underbrace{\mathbb{E}_{q_\phi(\mathbf{z}\mid\mathbf{x})}\big[\log p_\theta(\mathbf{x}\mid \mathbf{z})\big]}_{\text{重构项：把 }\mathbf{x}\text{ 编码再解码，重建得多准}} \;-\; \underbrace{\mathrm{KL}\big(q_\phi(\mathbf{z}\mid\mathbf{x})\,\big\|\,p(\mathbf{z})\big)}_{\text{正则项：编码分布别偏离先验太远}} \;=\; \mathrm{ELBO}.
$$

这道下界的一行推导骨架（用 Jensen 不等式或直接拆 KL）值得记住：

$$
\log p_\theta(\mathbf{x}) = \mathrm{ELBO}(\theta,\phi;\mathbf{x}) + \mathrm{KL}\big(q_\phi(\mathbf{z}\mid\mathbf{x})\,\|\,p_\theta(\mathbf{z}\mid\mathbf{x})\big) \;\ge\; \mathrm{ELBO},
$$

因为右边那个 KL 非负。**最大化 ELBO 同时干两件事**：把下界顶高（逼近真实似然），并让编码器 $q_\phi$ 逼近真后验。两项的含义很美：第一项要求"编码—解码"能忠实重建数据（自编码器的本职）；第二项是一个**正则化**，逼迫编码分布贴近先验 $p(\mathbf{z})$，从而让隐空间**连续、规整、可采样**——你才能在生成时直接从 $p(\mathbf{z})$ 抽配方。

**重参数化技巧（reparameterization trick）** 是 VAE 能用梯度训练的关键。问题是：ELBO 里有个对 $\mathbf{z}\sim q_\phi(\mathbf{z}\mid\mathbf{x})$ 的期望，而 $\mathbf{z}$ 是**随机采样**来的——你没法对"采样"这个操作求导。技巧是把随机性"挪到外面"：若 $q_\phi$ 是高斯 $\mathcal{N}(\boldsymbol\mu_\phi(\mathbf{x}),\,\boldsymbol\sigma_\phi^2(\mathbf{x}))$，就写

$$
\mathbf{z} = \boldsymbol\mu_\phi(\mathbf{x}) + \boldsymbol\sigma_\phi(\mathbf{x}) \odot \boldsymbol\epsilon, \qquad \boldsymbol\epsilon \sim \mathcal{N}(\mathbf{0}, I).
$$

现在随机性全在与参数无关的 $\boldsymbol\epsilon$ 上，$\mathbf{z}$ 对 $\phi$ 是**可微的确定函数**，梯度可以一路反传穿过采样层。这是个朴素却深刻的技巧：把"对随机变量的期望的梯度"变成"对确定变换的梯度的期望"。

> **与数学三课的连接**：ELBO 里的 KL 正则项就是《信息论》第 4 章的 KL 散度，它在这里扮演**信息瓶颈（information bottleneck）** 的角色——限制隐变量 $\mathbf{z}$ 能从 $\mathbf{x}$ 携带多少信息，逼模型只保留最有用的、可压缩的表示。这与《信息论》第 9 章的**率失真（rate–distortion）** 是同一枚硬币：重构项 = 失真（要小），KL 项 = 码率（要小），ELBO 就是在做"花多少比特描述 $\mathbf{z}$，能换来多准的重构"的权衡。而 ELBO 这个"用下界绕开难算的边际似然"的范式，是《概率与统计》第 8 章变分推断思想的直接落地。

- **优点**：似然有**下界可估**、训练**稳定**、隐空间**结构化**（可插值、可做表示）、采样**快**（一次解码）。
- **缺点**：样本往往**偏模糊**——常见解释是高斯解码器 + 像素级重构损失偏好"平均化"（把多个合理重构平均成一个糊的），以及优化的是下界而非真似然。还有**后验坍缩（posterior collapse）**——当解码器过强时，模型可能干脆忽略 $\mathbf{z}$、让 $q_\phi$ 直接退化成先验，隐变量形同虚设。

> **实战连接（异常检测 / 压缩 / 表示）**：VAE 的价值常不在"生成好看的图"，而在它**规整的隐空间**与**可估的似然**。工业上用它做**异常检测**——正常样本重构误差小、似然高，异常样本（设备故障信号、欺诈交易、罕见病灶）重构差、似然低，于是落在分布尾部就报警。它的"重构 + 码率"结构天然是一种**有损压缩**（呼应率失真）。在科学领域，它能把高维测量压成低维、可解释的隐表示供下游分析。这些用途和"画图"平级，且往往更贴近真实工程需求。

### 10.2.3 生成对抗网络（GAN）：一场博弈

**生成对抗网络（Generative Adversarial Network, GAN）** 彻底抛弃了"显式写出似然"的想法，改用一场**博弈**来逼出好样本。两个网络对抗：

- **生成器（generator）$G$**：吃一个噪声 $\mathbf{z}\sim p(\mathbf{z})$，吐出一个假样本 $G(\mathbf{z})$，想骗过判别器。
- **判别器（discriminator）$D$**：吃一个样本，输出"它是真数据"的概率，想分清真假。

二者在玩一个 **min-max 博弈（极小极大博弈）**，目标函数是：

$$
\min_{G}\max_{D}\; \mathbb{E}_{\mathbf{x}\sim p_{\text{data}}}\big[\log D(\mathbf{x})\big] + \mathbb{E}_{\mathbf{z}\sim p(\mathbf{z})}\big[\log\big(1 - D(G(\mathbf{z}))\big)\big].
$$

$D$ 想最大化它（把真的判真、假的判假），$G$ 想最小化它（让 $D$ 把假的也判真）。直觉上这是"造假者 vs 验钞员"的军备竞赛：验钞员越精，造假者被逼着越逼真；理论上的**纳什均衡（Nash equilibrium）** 是——生成分布等于真实分布 $p_G = p_{\text{data}}$，此时 $D$ 怎么猜都只能蒙 $1/2$（彻底分不清真假）。

这个均衡可以一行推导骨架看清。固定 $G$，对 $D$ 逐点最大化目标，可解出**最优判别器**：

$$
D^*(\mathbf{x}) = \frac{p_{\text{data}}(\mathbf{x})}{p_{\text{data}}(\mathbf{x}) + p_G(\mathbf{x})}.
$$

把 $D^*$ 代回目标，$G$ 要最小化的量就化简为 $p_{\text{data}}$ 与 $p_G$ 之间的 **Jensen–Shannon 散度（JS 散度）**（差一个常数）——它当且仅当 $p_G=p_{\text{data}}$ 时取最小。于是 GAN 又被拉回了"最小化分布间距离"的大框架——只不过它用的是**隐式**、对抗式的方式，从不写出 $p_G$ 的密度，全靠判别器这个"会学习的散度估计器"提供训练信号。这也解释了它的脆弱：当两个分布几乎不重叠时，JS 散度饱和、给不出有用梯度（后来 Wasserstein GAN 等改用更平滑的距离正是为治此病）。

- **优点**：样本**质量 / 锐度高**（曾长期是图像生成 SOTA），采样**快**（一次前向）。
- **致命缺点**：训练**极不稳定**——两个网络的对抗是动态平衡，很容易一方碾压另一方导致梯度消失或震荡；最臭名昭著的是**模式崩溃（mode collapse）**——生成器发现只要反复生成少数几种"必能骗过 $D$"的样本就行，于是放弃了数据分布的多样性（比如只会画一种猫）。而且 GAN **没有显式似然**，连"它学得多好"都难以直接度量。

> **常见陷阱**：别把 GAN 的训练目标和 VAE 混为一谈。VAE **最大化一个似然下界**（ELBO），有明确的优化目标、单调可监控；GAN 是**两个网络的对抗博弈**，没有单一被最小化的损失曲线——判别器损失下降未必意味着生成质量提升，看损失曲线判断 GAN 训练好坏几乎无效，得直接看生成样本。三种模型的目标各不相同：自回归=精确极大似然；VAE=似然下界（ELBO）；GAN=对抗 / 隐式散度。下一节的扩散模型表面上又是另一套（去噪 / 得分匹配），但**其实仍长在似然 / 变分推断这棵大树上**——下一节末的「概率视角」会点明它本质是一个多层 VAE 的 ELBO，只是被化简成了干净的去噪损失。所以这些路线是同一框架下的不同分枝，不是互不相干的发明。

### 10.2.4 扩散模型：先把数据揉碎，再学着复原

**扩散模型（diffusion model）** 是近年图像、音频乃至分子 / 蛋白生成的当家路线，思想极其优雅。它分两个过程：

**前向过程（forward / diffusion）——固定的、不用学的"加噪"。** 从一张真实数据 $\mathbf{x}_0$ 出发，分许多步（如几百上千步）**逐步往里掺高斯噪声**，每一步把图揉糊一点点：

$$
q(\mathbf{x}_t \mid \mathbf{x}_{t-1}) = \mathcal{N}\big(\mathbf{x}_t;\ \sqrt{1-\beta_t}\,\mathbf{x}_{t-1},\ \beta_t I\big),
$$

走到最后一步 $\mathbf{x}_T$，数据被彻底揉成**纯高斯噪声**——什么信息都没了。这个过程没有任何可学参数，是预先设定的。

**反向过程（reverse / denoising）——要学的"去噪"。** 既然前向把数据一步步变成噪声，那只要学会**反着走**——从纯噪声出发，一步步去噪，就能"无中生有"地生成数据。我们训一个网络 $\boldsymbol\epsilon_\theta(\mathbf{x}_t, t)$ 来预测"第 $t$ 步里掺进去的噪声"，训练目标简洁得惊人——就是个回归（去噪）损失：

$$
\mathcal{L}(\theta) = \mathbb{E}_{\mathbf{x}_0,\,t,\,\boldsymbol\epsilon}\Big[\big\|\boldsymbol\epsilon - \boldsymbol\epsilon_\theta(\mathbf{x}_t, t)\big\|^2\Big],\qquad \mathbf{x}_t = \sqrt{\bar\alpha_t}\,\mathbf{x}_0 + \sqrt{1-\bar\alpha_t}\,\boldsymbol\epsilon.
$$

即：随机取一个数据、一个时间步 $t$、一份噪声，按公式糊成 $\mathbf{x}_t$，让网络把那份噪声预测出来。生成时则从 $\mathbf{x}_T\sim\mathcal{N}(0,I)$ 起步，反复用网络去噪、逐步走回 $\mathbf{x}_0$。

这里有个值得点透的小魔法：前向虽然分许多步，但因为每步都是线性高斯，可以**一步到位**地从 $\mathbf{x}_0$ 直接采任意时刻的 $\mathbf{x}_t$（上式右边那个闭式，$\bar\alpha_t=\prod_{s\le t}(1-\beta_s)$），所以训练时**不需要真的一步步加噪**——随机抽个 $t$、用闭式糊出 $\mathbf{x}_t$、让网络预测噪声即可，训练高度并行。慢的只是**生成**（反向必须一步步走）。

这与一个叫**得分匹配（score matching）** 的视角等价：网络学的实质是数据分布对数密度的梯度 $\nabla_{\mathbf{x}}\log p(\mathbf{x})$（称为**得分 / score**），它指向"数据更可能的方向"，生成就是沿着得分往高密度区"爬"再加点随机扰动（朗之万动力学，本质是 MCMC，呼应《概率与统计》第 10 章）。"预测噪声"与"估计得分"只差一个已知的缩放——预测出第 $t$ 步掺进的噪声 $\boldsymbol\epsilon$，就等于知道了把 $\mathbf{x}_t$ 往高密度区拉回去的方向，反向迭代就是不断"沿得分爬一点、再退一点点噪声"。理解这一点，就理解了扩散为何稳：它把"生成一个复杂分布"拆成了**许多个简单的去噪回归子问题**，每个都好学、好优化——这是它在**训练稳定性上**对 GAN 对抗博弈的优势。（注意这只是一个维度的优势，不是全面碾压：扩散**采样慢**得多，在某些任务上质量也未必胜过精调的 GAN——见 §10.2.5 的对比表。）

> **概率视角**：扩散模型可以严格地看成一个**有 $T$ 层隐变量的 VAE**——前向加噪是固定（不可学）的"编码器"，反向去噪是要学的"解码器"，它的训练目标同样是一个 ELBO，只不过被巧妙地化简成了上面那个干净的去噪回归损失。所以"自回归 / VAE / 扩散"并非三个互不相干的发明，而是**同一棵极大似然 / 变分推断大树上的三根枝条**：自回归把似然按时间链式拆开，VAE 引入一层连续隐变量并优化下界，扩散把隐变量层数推到很多、且每层的"编码"固定为加噪。看清这点，谱系就不再是要背的清单，而是一张有逻辑的地图。

- **优点**：样本**质量与多样性俱佳**（少有模式崩溃），训练**稳定**（就是个回归损失，没有对抗）——它在很多生成任务上取代了 GAN。
- **缺点**：**采样慢**——要跑几十到上千步去噪（虽有大量加速采样的工作）；似然只能近似（变分界）。

> **实战连接（科学计算 / 蛋白与分子设计）**：扩散模型不只会画图。在科学领域，它正成为**结构生成（structure generation）** 的利器——把"原子坐标 / 蛋白主链"当作要生成的对象，前向加噪、反向去噪，就能**设计出全新的、物理上合理的分子或蛋白结构**（如设计满足特定功能的蛋白骨架）。这是生成模型在《蛋白质折叠》课里最闪亮的科学应用之一（与第 8 章 Transformer 驱动的 AlphaFold 互补：一个预测结构，一个生成结构）。但请克制地看待——它和"按文字画图""作曲""生成语音"是**平级**的应用，扩散的数学内核（加噪 / 去噪 / 得分）对所有领域是同一套。

### 10.2.5 四条路线的对比

四种模型在四个关键维度上各有取舍，没有谁全面占优——这正是"想要的几样很难同时拿满"的体现：

| 维度 | 自回归 (AR) | VAE | GAN | 扩散 (Diffusion) |
|---|---|---|---|---|
| **似然可算** | 精确（链式法则） | 下界（ELBO） | 无显式似然 | 近似（变分界） |
| **采样质量** | 高（文本最强） | 中（偏模糊） | 高（锐利） | 很高（质量+多样） |
| **采样速度** | 慢（串行 $T$ 步） | 快（一次解码） | 快（一次前向） | 慢（多步去噪） |
| **训练稳定性** | 好（交叉熵） | 好（ELBO 单调） | 差（对抗、模式崩溃） | 好（回归损失） |
| **代表 / 旗舰** | GPT 等语言模型 | 异常检测 / 压缩 / 隐空间表示 | 早期图像生成 | 图像 / 分子 / 蛋白生成 |

一句话记忆：**自回归用精确似然换采样速度，VAE 用模糊换稳定与结构化隐空间，GAN 用不稳定换锐利样本，扩散用慢采样换高质量与稳定训练。** 而且边界在融合——许多前沿系统把它们拼起来用（如先用自编码器压到隐空间、再在隐空间跑扩散）。

> **诚实的边界**：生成模型最大的痛点不是训练，而是**评估**。"这个模型生成得好不好"出奇地难量化：似然高不等于样本好看（VAE 似然可比 GAN 高但更糊），样本好看不等于覆盖了全部模式（GAN 可能漏掉大半数据分布却样本精美）。业界用的指标（如图像的 FID、文本的困惑度 perplexity）各有盲区，常常要靠人工评测兜底。**没有任何单一数字能完整刻画一个生成模型的好坏**——看到论文里只报一个指标就说"SOTA"时，要多留个心眼。

> **要点**：四条生成路线 = 四种"表示并训练高维分布"的方式：自回归（链式分解 + 精确极大似然 + 串行采样）、VAE（隐变量 + ELBO 下界 + 重参数化 + KL 信息瓶颈）、GAN（生成器 vs 判别器的 min-max 博弈 + 模式崩溃风险）、扩散（前向加噪 + 学反向去噪 / 得分 + 多步采样）。它们在似然可算 / 采样质量 / 采样速度 / 训练稳定上各有取舍，且评估生成质量本身就是开放难题。

## 10.3 自监督学习：从无标签数据里造监督信号

### 10.3.1 核心思想：把数据的一部分藏起来去预测它

监督学习卡在标签上：标注昂贵、稀缺、且把人类的偏见与口味灌进了数据。但**无标签数据是几乎免费且海量的**。**自监督学习（self-supervised learning, SSL）** 的核心洞见是——**数据内部的结构本身就是免费的监督信号**：把数据的一部分藏起来（或变换一下），让模型用剩下的部分去预测它，**"标签"是从数据自身自动构造的**。

这看似只是个聪明的省钱招数，实则是**表示学习**的引擎。为了完成"预测被藏起来的部分"这个看似琐碎的任务（预测下一个词、补全被遮的图块），模型被迫学会数据的深层结构——语法、语义、物体、纹理、物理常识。学到的表示拿去做下游任务（分类、检索、问答），常常只需极少标签微调就效果惊人。当代几乎所有**基础模型（foundation model）** 都建立在自监督预训练之上。

自监督的两大流派：**生成式 / 预测式**（预测被遮蔽的内容，§10.3.2 的掩码预测、以及前面的自回归语言模型其实都属此类）和**对比式**（学"什么样本该相似、什么该不相似"，§10.3.3）。

注意一个常被混淆的区分：自监督**不是**无监督学习（第 6 章）的同义词。无监督（如聚类、PCA）通常不构造"预测目标"，只挖掘数据的内在几何 / 分组结构；自监督则**人为设计一个有标准答案的预测任务**（答案来自数据自身），把无监督问题伪装成监督问题来解——所以它能直接复用监督学习成熟的损失、优化、网络。这是个朴素却极具杠杆的转译：**把"没有标签"的困境，转成"标签免费且无穷多"的红利**。

> **给数学 / CS 读者的视角**：自监督的"造任务"很像软件工程里的**属性测试（property-based testing）** 或**自洽性约束**——你不写死每个测试用例的期望输出，而是声明一条"输入与输出之间必须成立的关系"（如"打乱再还原应等于原值""遮住一块再补回应接近原图"），让数据自动生成无数个满足该关系的训练样本。设计自监督任务的艺术，就是**设计一条既免费可验证、又逼模型学到有用结构的约束**。约束太松（如"预测一个常数"）学不到东西，太死（如"逐像素记住训练图"）只会过拟合——这又是暗线一（泛化）与暗线三（归纳偏置）在新设定下的回响。

### 10.3.2 掩码预测：BERT 与 MAE

**掩码预测（masked prediction）** 是最直接的自监督：随机遮住输入的一部分，让模型把它**填回来**。

- **掩码语言模型（Masked Language Model, MLM）/ BERT**：在文本里随机遮住约一小部分词（用特殊 token `[MASK]` 占位），让模型**双向**地看上下文、预测被遮的词。这和自回归语言模型（GPT，只能看左侧）的关键区别是：MLM 能同时利用左右两侧上下文，特别适合学**理解型**表示（用于分类、抽取、检索）；自回归适合**生成**。
- **掩码自编码器（Masked Autoencoder, MAE）/ 掩码图像建模**：把图像切成小块（patch），随机遮住一大部分（可高达大多数），让模型重建被遮的像素。遮得越多，模型越不能靠局部插值蒙混，越被逼去理解全局结构。

掩码预测把"理解"伪装成"填空"——而填空题的答案，数据自己就知道，无需任何人工标注。值得玩味的是 NLP 与视觉在"该遮多少"上的差异：语言信息密度高，遮一小部分就够难（遮多了上下文不足）；图像像素冗余大、相邻像素强相关，必须遮掉**一大片**才逼得模型去理解全局而非靠邻域插值蒙混。同一个"填空"思想，落到不同模态要按其**信息密度与冗余结构**调校——这又是归纳偏置要对上数据结构的体现（暗线三）。

预训练学到表示后，下游用法有两条：把预训练模型当**特征提取器**（冻结，只在上面训个小分类头，特征探测 / linear probing），或**微调**整个模型。前者快、省、检验表示本身好不好；后者上限更高、但需要更多下游数据与算力——这正是第 9 章迁移学习权衡的再现。

### 10.3.3 对比学习：把相似的拉近、不相似的推远

**对比学习（contrastive learning）** 不预测具体内容，而是学一种**表示空间**，让"语义相似"的样本在其中靠得近、"不相似"的离得远。怎么在没有标签的情况下知道哪些该相似？靠**数据增强（data augmentation）** 造**正样本对**：同一张图的两种不同裁剪 / 颜色扰动，理应映到相近的表示（它们是"同一个东西"的两个视角）；而**其它图**就是**负样本**，该被推远。

最常用的损失是 **InfoNCE**（也叫 NT-Xent），它本质是一个"在一堆候选里把正样本认出来"的 softmax 分类：

$$
\mathcal{L}_{\text{InfoNCE}} = -\log \frac{\exp\big(\mathrm{sim}(\mathbf{z}_i, \mathbf{z}_i^{+})/\tau\big)}{\exp\big(\mathrm{sim}(\mathbf{z}_i, \mathbf{z}_i^{+})/\tau\big) + \sum_{j}\exp\big(\mathrm{sim}(\mathbf{z}_i, \mathbf{z}_j^{-})/\tau\big)},
$$

其中 $\mathrm{sim}$ 通常是余弦相似度（内积，呼应《线性代数》第 4 章），$\tau$ 是温度超参。最关键的理论事实是——

> **与数学三课的连接**：InfoNCE 是**互信息（mutual information）的一个下界**。最小化 InfoNCE 损失 $\Leftrightarrow$ 最大化"一个样本的两个视角之间共享的信息"。这把对比学习直接接到了《信息论》第 4 章的互信息：我们其实在显式地让模型保留"同一对象不同视角间不变的那部分信息"，丢掉视角特有的噪声。这也是为什么对比学习学到的表示对下游任务这么有用——它抓住的是数据里"本质的、跨视角不变的"信息。⚠ 注意 InfoNCE 是下界而非互信息本身，且界的紧度依赖负样本数量（负样本越多界往往越紧），这正是很多对比方法依赖大批量 / 记忆库的原因。

这里 $\tau$（温度）也很关键：它控制对"难负样本"的关注度——太大则区分不开、太小则过度纠结于极少数最难的负样本。而**数据增强的选择**决定了你想要模型对什么**不变（invariant）**：用颜色抖动当增强，模型就学会"颜色无关"的表示；用裁剪，就学会"对局部缺失鲁棒"。换句话说，**增强的设计 = 把你想要的不变性当先验注入**（暗线三）——这也是对比学习既强大又危险的地方：增强选错（让模型对其实该敏感的东西不变），学到的表示就会在下游崩坏。

近年也出现**无需负样本**的自监督方法（靠预测一致性 + 防坍缩技巧），说明"对比"只是手段之一，核心始终是"造正确的不变性先验"（暗线三）。

> **常见陷阱**：自监督最隐蔽的坑是**"作弊捷径"（shortcut learning）**——模型常会发现一条与你真实意图无关、却能轻松完成预训练任务的捷径，从而学到没用的表示。经典例子：让模型预测两个图块的相对位置，它可能不去理解内容，而是钻图像 JPEG 压缩留下的边界伪影；对比学习里若正样本对之间有某种"泄漏"特征（如两个裁剪都带同一水印 / 同样的边框），模型就用那个特征轻松匹配，绕过了真正的语义。设计自监督任务时，**必须假想"模型会不会用某条蠢捷径蒙混过关"并堵死它**——这和监督学习里的数据泄漏（第 2 章）是同一类警惕。

> **实战连接（跨领域）**：自监督已是当代 ML 的发动机，且远不止 NLP。视觉里，对比 / 掩码预训练让模型在百万级未标注图像上学通用视觉表示，下游只用少量标注微调即可；语音里用自监督在海量未转写音频上预训练，大幅降低对昂贵转写数据的依赖；推荐 / 检索里用对比学习对齐"查询—物品"嵌入；科学领域，在海量未标注蛋白质序列上做掩码预测（蛋白语言模型），学到的表示能迁移到结构 / 功能预测——这是自监督在科学应用里的一个旗舰例子，与视觉 / NLP 平级。

> **要点**：自监督学习从无标签数据自动构造监督信号——把数据一部分藏起来去预测（掩码预测：BERT / MAE）或学"谁该相似谁该不同"（对比学习：InfoNCE = 互信息下界）。它是现代表示学习与基础模型的引擎，跨 NLP / 视觉 / 语音 / 科学，呼应第 6 章的表示学习与《信息论》第 4 章的互信息。

## 10.4 基础模型与缩放定律

### 10.4.1 预训练 + 适配：新范式

自监督把海量数据变得可学，催生了 ML 的一次范式转移。旧范式是"为每个任务从头训一个模型"；新范式是**预训练 + 适配（pre-train then adapt）**：

1. **预训练（pre-training）**：在超大规模、宽领域的无标签数据上，用自监督目标训一个巨大的通用模型——这就是**基础模型（foundation model）**（大语言模型是其代表，视觉、多模态、科学领域也都有）。
2. **适配（adaptation）**：把这个通用模型用到具体任务上，主要有几种方式：
   - **微调（fine-tuning）**：在下游小数据上继续训练（全部或部分参数），是第 9 章迁移学习思想的极致化。
   - **提示（prompting）/ 上下文学习（in-context learning, ICL）**：完全不改参数，只在输入里用自然语言 + 几个示例"告诉"模型要做什么，模型即兴完成——这是大语言模型一个相当反直觉的能力。

**上下文学习长什么样？** 举个具体的小例子——做一个表格式的二分类（判断一条简短客户评论是正面还是负面），不微调、不改一个权重，只把"任务说明 + 几个带答案的示例 + 一个新问题"拼成一段文本喂给模型：

```
任务：判断评论情感，输出 正面 或 负面。
评论：物流很快，包装也完好。      → 正面
评论：用了三天就坏了，差评。        → 负面
评论：客服态度好，但发货太慢了。    → 负面
评论：性价比超高，会回购。          →            ← 模型在这里续写："正面"
```

模型并没有"训练"——它只是在做老本行（预测下一个 token），却**从上下文里的几个示例"现学"了任务的输入输出格式与判别规则**，对最后一行给出合理答案。这就是"少样本（few-shot）上下文学习"。把示例换成几道两位数加法、或几行"英文→法文"的对照，同一个模型就能即兴做算术、做翻译。它反直觉在于：传统观念里"学一个新任务"必须改参数（梯度下降），而这里**学习发生在前向传播的激活里、不留任何权重改动**。一个流行的解释是：海量预训练让模型见过无数"示例—答案"格式的文本，于是把"按给定示例的模式补全"本身学成了一种通用能力。但要诚实——ICL 对示例的措辞 / 顺序 / 数量相当敏感，效果不稳定，远非"喂几个例子就万无一失"。

这个范式之所以成立，根基正是暗线一与第 9 章的**迁移学习**：在足够大、足够宽的数据上学到的表示是**通用**的，对新任务是极好的起点，从而把"每个任务都要海量标注"的负担转移到"一次性的大规模预训练"上。

**参数高效微调（parameter-efficient fine-tuning）。** 全量微调一个庞大基础模型代价高、且每个下游任务都得存一份完整副本。于是出现了一类只动**极少量参数**的适配技巧——冻结绝大部分预训练权重，只训练插入的小模块（如低秩适配器把权重更新约束在低秩子空间，呼应《线性代数》第 8 章的低秩结构）。它用很小的存储与计算代价，把一个通用模型快速"特化"到许多任务，是当前把大模型用起来的关键工程手段。

**多模态（multimodal）基础模型。** 同一套自监督 + 大规模预训练思路不限于单一模态。最干净的例子是**图文对齐**：用一个图像编码器和一个文本编码器，把海量"图片—配文"对（互联网上几乎免费、天然成对）用**对比学习**（§10.3.3 的 InfoNCE）拉到同一个向量空间里——配对的图与文相互靠近，不配对的相互推远。训完之后，图和文住进了同一个语义空间，神奇的能力就来了：

```
   图片 ──►[图像编码器]──► z_图 ┐
                                ├─►  同一向量空间，配对的拉近、错配的推远
   文字 ──►[文本编码器]──► z_文 ┘            （余弦相似度 = 内积，呼应线代 §4）

  训练：一个 batch 里 N 张图、N 句配文 → N×N 相似度矩阵
        对角线(真配对)该最大，其余该小 → 对每行/每列做 InfoNCE 分类

  零样本分类：给一张待分类图，把候选类别写成
        "一张{猫/狗/飞机}的照片" 三句文本各编码，
        谁和图片的 z 最近 → 就判它是哪类（无需为这些类训练过！）
```

这就是"**零样本（zero-shot）分类**"：模型从没在"猫 / 狗 / 飞机"这个特定标签集上训练过，却能靠"图—文同空间"把图片和类别名的文本描述比相似度来分类。把文本、图像、音频进一步统一进**同一个序列建模框架**（都切成 token 喂给一个 Transformer），就是当前多模态大模型的雏形。背后始终是同一逻辑：**用海量弱标注 / 自然配对数据做自监督，学出跨模态通用表示**——注意这条主干和"在蛋白序列上做掩码预测""在图像上做对比预训练"完全同源，只是把"配对"从"同一对象的两个视角"换成了"图与它的文字描述"。

### 10.4.2 缩放定律与能力涌现

一个经验观察主导了近年大模型的发展：**缩放定律（scaling laws）**——当**模型规模、数据量、计算量**一起按一定比例增大时，模型的预训练损失会沿着相当**平滑、可预测**的趋势持续下降（在很宽的范围内近似幂律关系）。这意味着"更大 + 更多数据 + 更多算力"在很长一段路上确实**可预期地**更好——这是过去几年大模型军备竞赛的经验依据。

更微妙的是**能力涌现（emergent abilities）**：某些能力（如多步推理、按指令执行）在小模型上几乎看不到，规模越过某个门槛后却"突然"出现。这个现象很迷人，但也要审慎看待——部分"涌现"可能与所用评测指标的非线性（如全对才得分的离散指标）有关：底层能力其实在平滑提升，只是一个"全有或全无"的指标把它显示成了"突变"。学界对"涌现是真实的相变还是度量的假象"仍有争论，这也再次提醒：**结论高度依赖你怎么度量**——这是贯穿生成模型评估、能力涌现、RL 奖励设计的同一条暗线。

为什么"更大"在很长一段路上确实更好？一个直觉是：自监督的预训练目标（如预测下一个词）是个**几乎无限难的任务**——要把这个任务做到极致，模型不得不学会语法、事实、常识、逻辑乃至浅层推理，因为这些都是"更准地预测下一个词"所需要的。任务本身的丰富性给了规模"有处可去"的空间。但这只是直觉，不是保证——它什么时候到顶、哪些能力靠堆规模堆不出来，仍无定论。

> **诚实的边界**：关于大模型，请守住几条诚实底线。第一，**不要编造精确数字**——参数量、训练数据规模、具体性能数字变化极快且常被夸大，本课一律不给精确数字，宁可说"大致""量级上"。第二，缩放定律是**经验规律不是物理定律**，它在某些范围成立，但数据 / 算力终有限，外推到无穷并无保证。第三，"涌现"不等于"理解"——模型能流畅完成任务，不证明它内部有人类意义上的理解或推理；它也会**自信地胡说**（所谓幻觉 / hallucination）。第四，大模型的**对齐、安全、偏见、可解释性、环境成本**都是悬而未决的真问题，下一节我们会看到 RLHF 是对齐方向的一步，但远非终点。

> **给数学 / CS 读者的视角**：把基础模型类比成一个**预编译的通用库**——预训练像是一次代价高昂的"编译"，产出一个携带海量世界知识的二进制；微调 / 提示像是针对具体应用做"链接 / 配置"。从复杂度角度看，缩放定律的幂律意味着**边际收益递减**——损失每降一个固定增量，所需算力可能要翻倍式增长，这是工程上判断"再堆规模值不值"的关键直觉。

> **要点**：自监督催生"预训练 + 适配"新范式——在超大无标签数据上自监督预训练出通用基础模型，再用微调 / 提示适配到下游。缩放定律给出"规模换性能"的经验趋势，并伴随有争议的能力涌现现象。但精确数字勿信勿造，缩放是经验非定律，涌现非理解，对齐与安全是开放问题。

## 10.5 强化学习入门：从交互与奖励中学习

### 10.5.1 一个全新的学习设定

前面所有方法——监督、生成、自监督——都假设有一堆**给定的数据**摆在那里学。**强化学习（reinforcement learning, RL）** 是根本不同的设定：一个**智能体（agent）** 在一个**环境（environment）** 里**行动**，环境根据它的行动给出**奖励（reward）** 与新的**状态（state）**，智能体要通过**试错**学出一套行为策略，使**长期累积奖励最大**。没有人告诉它"正确动作是什么"，只有"这一步做得好不好"的稀疏反馈。下棋、机器人控制、游戏、资源调度、对话策略，都是这一类。

它与监督学习有几条**根本区别**，每条都让 RL 难得多：

- **没有 i.i.d. 的标签**：监督学习有 $(\mathbf{x},y)$ 对告诉你正确答案；RL 只有奖励信号，且**没人告诉你最优动作**——你得自己试出来。
- **数据不是独立的，是自己行为产生的**：你采取的动作决定了你接下来会遇到什么状态、收集到什么数据（非 i.i.d.，分布随策略漂移）。
- **奖励延迟且稀疏（delayed, sparse reward）**：下了一步好棋，可能几十步后才赢；奖励来得晚，难以归因到底是哪一步的功劳（**信用分配问题，credit assignment**）。
- **探索 vs 利用（exploration vs exploitation）**：你该利用已知的好动作捞奖励，还是去探索没试过的、可能更好的动作？这个两难是监督学习里根本不存在的。

### 10.5.2 马尔可夫决策过程（MDP）：RL 的数学骨架

RL 的标准形式化是**马尔可夫决策过程（Markov Decision Process, MDP）**，由五元组刻画：

- **状态空间 $\mathcal{S}$**、**动作空间 $\mathcal{A}$**；
- **转移概率 $P(s' \mid s, a)$**：在状态 $s$ 做动作 $a$，转到 $s'$ 的概率；
- **奖励函数 $R(s, a)$**：即时奖励（本章为简洁起见设奖励只依赖当前的状态—动作对 $(s,a)$；更一般的形式是 $R(s,a,s')$，奖励还依赖落到的下一状态，此时下文贝尔曼方程里的 $R$ 须挪进对 $s'$ 的期望内，写成 $\sum_{s'}P(s'\mid s,a)\,R(s,a,s')$）；
- **折扣因子 $\gamma \in [0,1)$**：未来奖励的"贴现率"。

**马尔可夫性（Markov property）** 是核心假设：下一步只依赖**当前状态与动作**，与更早的历史无关——当前状态已浓缩了决策所需的全部信息（呼应《概率与统计》第 10 章 MCMC 所依赖的马尔可夫链）。

智能体的行为由**策略（policy）$\pi(a\mid s)$** 描述——在每个状态下选各动作的概率。它要最大化的是**回报（return）**，即折扣累积奖励：

$$
G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \cdots = \sum_{k=0}^{\infty}\gamma^k R_{t+k}.
$$

$\gamma$ 越接近 1 越"有远见"（重视长远）；$\gamma<1$ 保证无穷和收敛，也体现"近的奖励比远的值钱"。

举个最小的具体例子帮直觉落地：一个**网格世界（grid world）**，智能体在格子里上下左右移动，撞墙不动，到达终点格得 $+1$、其余每步得 $0$（或一个小负值催它快走），掉进陷阱格得 $-1$。状态 = 当前格子坐标、动作 = 四个方向、转移 = 移动（可能带点滑动的随机性）、奖励如上、$\gamma$ 略小于 1。智能体要学的"策略"就是"在每个格子里该往哪走"，使从起点走到终点的折扣回报最大。所有 RL 概念——价值（每个格子"有多好"）、策略（每个格子的箭头）、探索（要不要试没走过的路）、信用分配（终点的 $+1$ 怎么"传播"回前面的格子）——都能在这个玩具里看得一清二楚。

### 10.5.3 价值函数 vs 策略：两种刻画"好"的方式

怎么衡量"处在某状态有多好"或"某状态做某动作有多好"？用**价值函数（value function）**：

$$
V^\pi(s) = \mathbb{E}_\pi\big[G_t \mid S_t = s\big],\qquad Q^\pi(s,a) = \mathbb{E}_\pi\big[G_t \mid S_t = s,\, A_t = a\big].
$$

$V^\pi(s)$ 是"按策略 $\pi$ 行事、从状态 $s$ 起的期望回报"；$Q^\pi(s,a)$ 是"在 $s$ 先做 $a$、之后按 $\pi$ 行事的期望回报"。它们满足递归的**贝尔曼方程（Bellman equation）**——把"现在的价值"拆成"即时奖励 + 折扣后的未来价值"：

$$
Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'\mid s,a)\sum_{a'}\pi(a'\mid s')\,Q^\pi(s', a').
$$

（这里把 $R(s,a)$ 提到了对 $s'$ 的求和之外——这正用到了上面"奖励只依赖 $(s,a)$"的约定；若用更一般的 $R(s,a,s')$，即时奖励本身也要进入对 $s'$ 的期望，写成 $\sum_{s'}P(s'\mid s,a)[R(s,a,s')+\gamma\sum_{a'}\pi\,Q^\pi(s',a')]$。两种写法在 $R$ 不依赖 $s'$ 时一致。）

这条递归是整个 RL 的引擎：它把"无穷远的未来回报"折叠成"一步即时奖励 + 下一状态的价值"，从而可以**自举（bootstrapping）** 地迭代求解。对**最优**价值 $Q^*$，把对策略的期望换成取最优动作的 $\max$，就得到**贝尔曼最优方程（Bellman optimality equation）**：

$$
Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'\mid s,a)\,\max_{a'} Q^*(s', a').
$$

它的解唯一，且最优策略就是"每步选 $\arg\max_a Q^*(s,a)$"。当环境（转移 / 奖励）**完全已知**时，反复套用这条方程更新价值直到收敛，就是动态规划里的**价值迭代（value iteration）**；而 RL 的难处恰恰在于环境**未知**，只能从交互样本里估计——这就逼出了下面的两大算法家族。

RL 的两大算法家族正对应"先学价值还是先学策略"两条思路。

**价值方法 / Q-learning（off-policy, 时序差分 TD）。** 思路：学出最优动作价值 $Q^*(s,a)$，则最优策略就是"每步选 $Q$ 最大的动作"。Q-learning 用**时序差分（temporal difference, TD）** 更新——不等一整局结束，用"下一步的估计"来更新"这一步的估计"（自举 bootstrapping）：

$$
Q(s,a) \leftarrow Q(s,a) + \alpha\Big[\,\underbrace{r + \gamma \max_{a'} Q(s', a')}_{\text{TD 目标（用了 }\max\text{）}} - Q(s,a)\Big].
$$

注意更新里用了 $\max_{a'}$——它瞄准的是**最优**策略的价值，而不管你实际是怎么探索的，所以 Q-learning 是 **off-policy（异策略）**：用一套（带探索的）行为策略收集数据，却在学另一套（贪婪最优）目标策略。把 $Q$ 用神经网络近似，就是深度 Q 网络（DQN）那一类。

**策略方法 / 策略梯度（on-policy）。** 思路：跳过价值，**直接**参数化策略 $\pi_\theta(a\mid s)$，用梯度上升优化期望回报 $J(\theta)=\mathbb{E}_{\pi_\theta}[G_0]$。**策略梯度定理（policy gradient theorem）** 给出梯度的优雅形式：

$$
\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\Big[\sum_t \nabla_\theta \log \pi_\theta(a_t\mid s_t)\cdot G_t\Big].
$$

直觉极其漂亮：**让带来高回报的动作的概率上升，低回报的下降**——回报 $G_t$ 充当每个动作"该被强化多少"的权重。这就是"试错学习"最朴素的数学表达：做了，看结果好坏，按好坏调整以后做这件事的倾向。因为期望是在**当前策略**下取的、且更新后策略就变了、旧数据作废，策略梯度通常是 **on-policy（同策略）**。它天然处理连续动作空间，是机器人控制等任务的主力。

朴素策略梯度有个大毛病：用整段回报 $G_t$ 当权重，**方差极大**（一局的随机性全压在梯度估计上），训练慢且抖。下一节的 Actor–Critic 正是为治这个病而生。

> **常见陷阱**：别把 Q-learning 和策略梯度搞混。Q-learning 学**价值**、是 **off-policy**（更新里有 $\max$，可复用旧数据 / 经验回放）、更适合**离散**动作；策略梯度学**策略**、是 **on-policy**（必须用当前策略采的数据）、天然处理**连续**动作、但梯度估计方差大、样本效率低。"off/on-policy"的判据是：你更新用的目标，是否对应你实际采数据的那套策略——Q-learning 学的是与采集无关的最优策略（off），策略梯度学的就是正在用的策略（on）。

> **与数学三课的连接**：折扣回报 $\sum\gamma^k R$ 是个无穷级数，$\gamma<1$ 保证收敛——这是分析里的几何级数；价值函数全是**期望**，贝尔曼方程是对随机转移取期望的递归（《概率与统计》第 3 章期望、马尔可夫链）。策略梯度定理里的 $\nabla_\theta\log\pi_\theta$ 是**得分函数（score function）**，与统计里 MLE 的得分、以及 §10.2.4 扩散模型的"得分"是同一个数学对象的不同化身——见到 $\nabla\log p$ 就该亲切。求解 MDP 的策略迭代 / 价值迭代是动态规划，呼应 CS 里的最优子结构。

### 10.5.4 Actor–Critic：把价值与策略合到一起

上节末说朴素策略梯度方差极大。两个标准的"降方差"招数，正好把价值方法与策略方法两家的长处缝在一起，长成现代深度 RL 的主干结构——**Actor–Critic（演员—评论家）**。

**招数一：减基线（baseline）。** 关键观察是：从策略梯度里减去任何**只依赖状态、不依赖动作**的基线 $b(s_t)$，都**不改变梯度的期望**（无偏），却能大幅降低方差。证明骨架只用一行——因为 $\mathbb{E}_{a\sim\pi}[\nabla_\theta\log\pi_\theta(a\mid s)]=\sum_a\nabla_\theta\pi_\theta(a\mid s)=\nabla_\theta\sum_a\pi_\theta(a\mid s)=\nabla_\theta 1=0$，所以乘上一个与 $a$ 无关的 $b(s)$ 后求期望仍是 $0$。于是把权重从 $G_t$ 换成 $G_t-b(s_t)$ 不引偏，只削方差。最自然的基线就是状态价值 $b(s_t)=V(s_t)$："这个状态平均能拿多少回报"。

**招数二：用优势函数（advantage）。** 减去 $V(s_t)$ 后，权重变成

$$
A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s),
$$

即**优势函数**——"在状态 $s$ 选动作 $a$，比该状态的平均水平好多少"。它的含义极漂亮：只奖励"**超出预期**"的动作（$A>0$ 才推高其概率），不被回报的绝对大小带偏。策略梯度于是变成

$$
\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\Big[\sum_t \nabla_\theta \log \pi_\theta(a_t\mid s_t)\cdot A^\pi(s_t,a_t)\Big].
$$

**但 $A$ 我们并不知道**——它含真实价值 $Q,V$。这就轮到"评论家"登场：

- **演员（actor）** $\pi_\theta(a\mid s)$：要学的策略，按上式做梯度上升。
- **评论家（critic）** $V_\mathbf{w}(s)$：另一个网络，估计状态价值，专门给演员算优势。

评论家怎么估优势？这里有个常被正文略过、但务必点破的关键：实践中**几乎不真的去单独学 $Q$**，而是用一步**自举（bootstrapping）** 把 $Q$ 就地近似掉——用即时奖励加上对下一状态价值的估计 $r_t+\gamma V_\mathbf{w}(s_{t+1})$ 充当 $Q(s_t,a_t)$，于是优势估计为

$$
\hat A(s_t,a_t) = \underbrace{r_t + \gamma V_\mathbf{w}(s_{t+1})}_{\approx\,Q(s_t,a_t)} - V_\mathbf{w}(s_t)
= \underbrace{r_t + \gamma V_\mathbf{w}(s_{t+1}) - V_\mathbf{w}(s_t)}_{\text{正是 TD 误差 }\delta_t}.
$$

注意右边方括号正是 §10.5.3 Q-learning 更新里见过的那种"目标减当前"的差，称为 **TD 误差 $\delta_t$**（只是把 Q-learning 里的 $\max_{a'}Q$ 换成了评论家的 $V(s')$）！于是 Actor–Critic 的回路闭合得很优雅：评论家用 TD 学 $V_\mathbf{w}$（最小化 $\delta_t^2$），同一个 $\delta_t$ 又当作优势喂给演员去调策略。"用一步估计去更新这一步"的自举思想（Q-learning 里见过）在这里被两个网络共享。

**代价与取舍。** Actor–Critic 把价值方法的低方差自举与策略方法处理连续动作的能力合一，是各类现代策略优化算法（如带信赖域 / 裁剪约束的策略优化）的骨架。但自举是**有偏**的（评论家估不准就把偏差注入演员），换来的是方差骤降——这又是一处"偏差 vs 方差"的经典权衡（暗线一），与第 2 章那条主线一脉相承。纯蒙特卡洛回报 $G_t$ 无偏高方差，一步 TD 自举有偏低方差，中间还有"多步回报"可调，是 RL 工程里反复出现的旋钮。

> **诚实的边界**：Actor–Critic 看似集两家之长，实则也**继承了两家的脆弱**——它同时要训演员和评论家两个相互依赖的网络，谁先学歪都会拖垮另一个；评论家的自举偏差、演员的策略漂移耦合在一起，使它对超参、网络初始化、奖励尺度异常敏感，"理论上优雅、实践中难调"是它的真实写照。

> **要点**：Actor–Critic = 策略梯度（演员）+ 价值估计（评论家）。基线 $V(s)$ 不引偏只降方差；优势 $A=Q-V$ 只奖励"超出预期"的动作；实践中用 TD 误差 $\delta_t=r+\gamma V(s')-V(s)$ 同时充当优势（喂演员）与评论家的学习信号。它以"自举的偏差"换"方差骤降"，是现代深度 RL 的主干，但两网络耦合使其难调。

### 10.5.5 探索 vs 利用，以及 RLHF

**探索 vs 利用**的两难必须由算法显式处理。最朴素的办法是 **$\epsilon$-贪婪（$\epsilon$-greedy）**：以概率 $1-\epsilon$ 选当前最优动作（利用），以概率 $\epsilon$ 随机探索；常让 $\epsilon$ 随训练衰减（先多探索、后多利用）。更精巧的方法用不确定性来引导探索（多试"没把握但可能很好"的动作）。

> **实战连接（游戏 / 控制 / 推荐 / 运筹）**：RL 的旗舰战绩多在**有明确奖励、可大量模拟交互**的领域：棋类与电子游戏（自我对弈 + 价值 / 策略），机器人与连续控制（在仿真器里跑海量交互再迁移到实物），数据中心散热 / 电网 / 库存等运筹调度（把成本写成负奖励），以及交互式推荐（把长期用户参与当回报，而非只优化单次点击）。共同前提是**能廉价、安全地大量交互**——一旦交互昂贵或危险（真实医疗、真实自动驾驶上路），RL 的样本效率短板就会致命，这也是它落地远比监督学习窄的根本原因。

RL 一个高曝光的现代应用是**人类反馈强化学习（Reinforcement Learning from Human Feedback, RLHF）**，用于**对齐（alignment）** 大语言模型。大致三步：(1) 先有一个自监督预训练的语言模型；(2) 收集人类对模型不同回答的**偏好**比较，训一个**奖励模型（reward model）** 来预测"人类更喜欢哪个回答"；(3) 用 RL（策略梯度家族）以这个奖励模型为奖励，微调语言模型，使其输出更符合人类偏好（更有用、更安全、更少胡说）。这里语言模型是"智能体"、生成回答是"动作"、奖励模型给"奖励"——把对齐问题套进了 MDP 框架。为什么不直接用监督学习（让模型模仿人写的好回答）？因为"好回答"难以穷举地标注，而"两个回答里哪个更好"这种**相对偏好**对人类容易得多、也更可靠；用偏好训出奖励模型、再用 RL 去优化它，能让模型探索出人没明说但符合偏好的回答方式。RLHF 是近年让大模型从"会续写"变成"会听话、肯帮忙、少胡说"的关键一步。

> **诚实的边界**：RL 是 ML 里最迷人也最难驯服的分支。第一，**样本效率极差**——很多 RL 算法需要海量交互才学得动，现实世界里（机器人、医疗）交互昂贵甚至危险，这是落地的最大障碍之一。第二，**训练不稳定、对超参与随机种子高度敏感**，结果常难复现。第三，**奖励设计是艺术也是陷阱**——奖励写得稍有偏差，智能体就会"钻空子"（reward hacking）去刷分而非达成你真正想要的目标。第四，RLHF 让大模型显著更可用，但它**不解决根本的对齐问题**：奖励模型只是人类偏好的不完美代理，人类偏好本身也未必一致或正确——对齐与 AI 安全仍是开放的研究与社会问题，不要被"已对齐"的说法误导。

> **要点**：RL 是智能体在环境中靠奖励试错学习，形式化为 MDP（状态 / 动作 / 转移 / 奖励 / 折扣 + 马尔可夫性），目标是最大化折扣回报。两大家族：Q-learning（学价值、off-policy、TD、离散动作）与策略梯度（学策略、on-policy、连续动作），二者合流为 Actor–Critic（演员给策略、评论家用 TD 误差当优势降方差）。它与监督学习的根本区别是无 i.i.d. 标签、奖励延迟稀疏、要权衡探索与利用。RLHF 把对齐套进 MDP，但样本效率、稳定性、对齐安全都是真问题。

## 本章小结

- **判别式 vs 生成式**：判别式学 $P(y\mid\mathbf{x})$（鉴定），生成式学数据分布 $P(\mathbf{x})$（创作）。建模分布解锁采样 / 补全 / 异常检测 / 表示学习，它的母语是概率（密度估计 / 采样 / MCMC）与信息论（KL / 互信息）。
- **四条生成路线**：自回归（链式分解，精确极大似然，串行采样，语言模型）；VAE（隐变量，ELBO = 重构 − KL，重参数化，KL 即信息瓶颈 / 率失真）；GAN（生成器 vs 判别器的 min-max 博弈，纳什均衡，模式崩溃与不稳）；扩散（前向加噪 + 学反向去噪 / 得分，图像 / 分子 / 蛋白生成 SOTA，采样慢）。四者在似然 / 质量 / 速度 / 稳定上各有取舍，且**评估生成质量本身是开放难题**。
- **自监督学习**：从无标签数据造监督信号——掩码预测（BERT / MAE）与对比学习（InfoNCE = 互信息下界）。它是当代表示学习与基础模型的引擎。
- **基础模型与缩放定律**：预训练 + 适配（微调 / 提示）新范式；规模换性能的经验趋势与有争议的能力涌现。精确数字勿造，缩放非定律，涌现非理解。
- **强化学习**：MDP 框架、折扣回报、价值（Q-learning，off-policy，TD）vs 策略（策略梯度，on-policy）、二者合一的 Actor–Critic（用优势 / TD 误差降方差）、探索 vs 利用、与监督学习的根本区别、RLHF 用于对齐。

回扣三条暗线：**暗线二（表示 + 目标 + 优化）** 是本章最好用的解剖刀——四种生成模型其实只是换了"如何表示分布"与"用什么目标训"（精确似然 / ELBO / 对抗 / 去噪），优化大多还是 SGD；自监督换的是"目标"（自造的预测 / 对比损失）；RL 换的是整个"目标"（最大化回报而非拟合标签）。**暗线三（归纳偏置）** 仍在：隐变量先验、对比学习的不变性、MDP 的马尔可夫假设都是结构先验。**暗线一（泛化）** 升级为更大的命题——预训练 + 适配本质是"在海量数据上学通用表示以泛化到无穷下游任务"，而本章处处的「诚实的边界」提醒：能采样 / 能涌现 / 能对话，都还不等于真正可靠地泛化与理解。

*参考答案*：自回归——最大化精确对数似然 $\sum_t\log p_\theta(x_t\mid\mathbf{x}_{<t})$（交叉熵）；VAE——最大化似然下界 ELBO（= 重构项 − KL）；GAN——生成器与判别器的 min-max 对抗目标，等价于最小化某种分布散度（JS）；扩散——最小化去噪 / 噪声预测的回归损失。**GAN 没有显式似然**（隐式定义生成分布）。**GAN 最不稳定**——两网络对抗是动态平衡，易梯度消失 / 震荡 / 模式崩溃，且无单一损失曲线可监控。*延伸思考*：为什么"似然高"和"样本好看"会脱钩？（提示：VAE 似然可能高于 GAN 但更糊；GAN 样本精美却可能漏掉大半模式。这正说明评估之难。）

**练习 10.2（思考）** 写出 VAE 的 ELBO，逐项解释含义，并说明：(a) 为什么需要重参数化技巧；(b) KL 项为什么是"信息瓶颈"，它和《信息论》率失真如何对应。

*参考答案*：$\log p_\theta(\mathbf{x})\ge \mathbb{E}_{q_\phi(\mathbf{z}\mid\mathbf{x})}[\log p_\theta(\mathbf{x}\mid\mathbf{z})]-\mathrm{KL}(q_\phi(\mathbf{z}\mid\mathbf{x})\|p(\mathbf{z}))$。第一项是重构对数似然（编码再解码要重建得准），第二项是把编码分布拉向先验的正则。(a) ELBO 含对 $\mathbf{z}\sim q_\phi$ 的期望，采样操作不可导；重参数化写 $\mathbf{z}=\boldsymbol\mu_\phi+\boldsymbol\sigma_\phi\odot\boldsymbol\epsilon,\ \boldsymbol\epsilon\sim\mathcal N(0,I)$，把随机性挪到与参数无关的 $\boldsymbol\epsilon$，梯度即可穿过采样。(b) KL 限制 $\mathbf{z}$ 能从 $\mathbf{x}$ 携带的信息量，逼模型只留最有用的可压缩表示；对应率失真——重构项=失真、KL=码率，ELBO 即"花多少比特换多准的重构"的权衡。*延伸思考*：若把 KL 项乘一个 $\beta>1$（β-VAE）会怎样？（提示：更强信息瓶颈→隐表示更解耦但重构更糊，正是率失真曲线上的滑动。）

**练习 10.3（动手·编程）** 用 numpy 实现一个最小的"自回归"思想验证：在一个二元序列数据集（如人造的、第 $t$ 位有偏地依赖第 $t-1$ 位）上，用计数估计 $P(x_t\mid x_{t-1})$，然后按链式法则**生成**新序列并采样。验证生成序列的一阶统计接近训练数据。

*参考答案要点*：
```python
import numpy as np
rng = np.random.default_rng(0)
# 造数据：x_t 以 0.8 概率等于 x_{t-1}
def gen(n=2000, T=20):
    X = np.zeros((n, T), int)
    for i in range(n):
        X[i,0] = rng.integers(2)
        for t in range(1,T):
            X[i,t] = X[i,t-1] if rng.random()<0.8 else 1-X[i,t-1]
    return X
X = gen()
# 计数估计条件分布 P(x_t=1 | x_{t-1})
p1 = (X[:,1:][X[:,:-1]==1]).mean()   # P(x=1|prev=1)
p0 = (X[:,1:][X[:,:-1]==0]).mean()   # P(x=1|prev=0)
print(p1, p0)                        # 应≈0.8, 0.2
# 链式法则生成
def sample(T=20):
    s=[rng.integers(2)]
    for _ in range(T-1):
        p = p1 if s[-1]==1 else p0
        s.append(int(rng.random()<p))
    return s
print(sample())
```
核心是体会"建模一串条件分布 → 逐步采样生成"。*延伸思考*：把这个二阶（依赖前两位）会怎样改写条件表？这与神经自回归"用网络替代计数表"有何本质关系？

**练习 10.4（思考）** Q-learning 的更新里有个 $\max_{a'}Q(s',a')$，策略梯度里没有。请由此论证为什么 Q-learning 是 off-policy、策略梯度是 on-policy，并各举一个它们更合适的场景。

*参考答案*：Q-learning 的 TD 目标 $r+\gamma\max_{a'}Q(s',a')$ 瞄准的是**贪婪最优**策略的价值，与你实际用来采数据的（带探索的）行为策略无关——故 off-policy，可复用历史 / 经验回放数据。策略梯度的目标 $J=\mathbb E_{\pi_\theta}[G]$ 期望取在**当前策略**下，更新后策略一变旧数据即失效——故 on-policy。合适场景：Q-learning 适合**离散动作**且想复用数据（如棋类 / 离散控制 / Atari）；策略梯度适合**连续动作**（如机器人关节控制）。*延伸思考*：经验回放（experience replay）为什么能用在 Q-learning 而较难直接用于纯策略梯度？

**练习 10.5（思考）** 解释 InfoNCE 为什么是"互信息的下界"在直觉上意味着什么，以及为什么很多对比方法要用很大的批量 / 很多负样本。

*参考答案*：InfoNCE 本质是"在一堆候选里把正样本（同一对象的另一视角）认出来"的 softmax 分类损失；最小化它等价于最大化同一对象两视角间共享信息的一个下界，即逼模型保留"跨视角不变的本质信息"、丢弃视角特有噪声。负样本越多，这个"认出正样本"的任务越难、下界往往越紧，对互信息的估计 / 优化越有效——所以需要大批量或记忆库提供大量负样本。*延伸思考*：近年有无需负样本的自监督方法靠"预测一致 + 防表示坍缩"工作，这说明"对比 / 负样本"是手段而非目的，真正核心是什么？（提示：构造正确的不变性先验，暗线三。）

**练习 10.6（动手·编程）** 实现一个最小的**前向加噪**过程来体会扩散模型：对一张 2D 数据点云（如两个月牙），按 $\mathbf{x}_t=\sqrt{\bar\alpha_t}\,\mathbf{x}_0+\sqrt{1-\bar\alpha_t}\,\boldsymbol\epsilon$ 逐步加噪，画出 $\bar\alpha_t$ 从 1 降到 0 时点云如何从"有结构"糊成"纯高斯"。

*参考答案要点*：
```python
import numpy as np, matplotlib.pyplot as plt
rng=np.random.default_rng(0)
# 造两个月牙状 2D 数据 x0 (N,2)，此处用两高斯简化
N=500
x0=np.vstack([rng.normal([-2,0],0.3,(N,2)), rng.normal([2,0],0.3,(N,2))])
for ab in [1.0, 0.8, 0.4, 0.05, 0.0]:        # \bar alpha_t 递减
    eps=rng.normal(size=x0.shape)
    xt=np.sqrt(ab)*x0 + np.sqrt(1-ab)*eps
    plt.figure(); plt.scatter(xt[:,0],xt[:,1],s=3); plt.title(f"abar={ab}")
plt.show()
```
观察：$\bar\alpha_t=1$ 时是原始结构，逐步退化，到 $0$ 时彻底变成标准高斯——这正是前向过程"信息被噪声吞没"的可视化。*延伸思考*：训练的网络要从 $\mathbf{x}_t$ 预测加进去的 $\boldsymbol\epsilon$；为什么"预测噪声"等价于"学会去噪 / 学得分 $\nabla_\mathbf{x}\log p$"，进而能逆着这个过程生成？

**练习 10.7（动手·编程）** 用 numpy 在一个一维"走廊"网格世界上实现表格 Q-learning：状态 $0,1,\dots,N-1$，终点在最右端给奖励 $+1$、其余 $0$，动作为左 / 右，用 $\epsilon$-贪婪探索。训练若干回合后打印学到的 $Q$ 表，验证它学会了"一路向右"。

*参考答案要点*：
```python
import numpy as np
rng = np.random.default_rng(0)
N, gamma, alpha, eps = 6, 0.95, 0.5, 0.2
Q = np.zeros((N, 2))                       # 动作 0=左, 1=右
for ep in range(2000):
    s = 0
    while s != N-1:                        # 到终点结束
        a = rng.integers(2) if rng.random() < eps else int(Q[s].argmax())
        s2 = min(s+1, N-1) if a == 1 else max(s-1, 0)
        r = 1.0 if s2 == N-1 else 0.0
        Q[s, a] += alpha * (r + gamma * Q[s2].max() - Q[s, a])  # TD 更新含 max → off-policy
        s = s2
print(Q.round(2))
print("各状态最优动作:", Q.argmax(axis=1))  # 应几乎全是 1(向右)
```
核心是看到 TD 更新里的 $\max$ 把终点的 $+1$ 逐步"传播"回前面状态（信用分配），且越靠近终点价值越高（被 $\gamma$ 折扣）。*延伸思考*：把 $\epsilon$ 设为 0（纯利用、不探索）会怎样？把 $\gamma$ 设很小（如 0.1）对远处状态的价值有何影响？这个更新为什么是 off-policy（与你用 $\epsilon$-贪婪采数据无关）？
