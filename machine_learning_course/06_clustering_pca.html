K-means 是什么（三件套）

表示：k 个质心 + 硬指派，把空间切成 Voronoi 多边形（每点归最近质心）。目标：最小化簇内平方和 SSE = Σ‖xᵢ−μ_{c(i)}‖²。优化：Lloyd 算法交替两步——固定质心求最优指派、固定指派求最优质心（= 簇均值）。每步都不增大 SSE，故必收敛，但只到局部最优（§6.1.1）。

质心 = 簇均值正是「平方误差下的最优代表点」，这与最小二乘同源（见《线性代数》第 4/5 章投影 / 正规方程）。

概率视角：K-means ≈ 各向同性、等方差、协方差→0 极限下的高斯混合模型 GMM 的硬指派 EM（§6.2）。所以它隐含「球状簇」假设。

诚实的边界：① 需预先定 k；② 非球状 / 不等大小簇会切错；③ 对初始化与离群点敏感（实践用 k-means++ 初始化 + 多次重启取最小 SSE）。

PCA 是什么（三件套）

表示：一组正交主轴（主成分 principal components），按所携方差从大到小排。目标：找投影方向使投影后方差最大（等价于重构误差最小，毕达哥拉斯）。优化：对样本协方差矩阵做特征分解，PC1=最大特征值的特征向量。

三句等价：PCA = 协方差矩阵的特征分解 = 去均值数据矩阵的奇异值分解 SVD。本页对 2×2 协方差用闭式特征分解（与左侧特征值探索器同一套数学）。降维 = 只留前几根主轴的坐标，丢掉小方差方向（见《线性代数》第 8 章 SVD/PCA、第 7 章谱定理）。

主轴长度 ∝ √λ（标准差），所以画出的两根轴长度比 = √(λ₁/λ₂)；轴越长 = 该方向数据越「铺得开」。注：画面里两轴一律放大 2×（画到 ±2√λ）仅为肉眼可见，比例不变，别拿尺子量绝对长度。

诚实的边界：PCA 只抓线性方向、且把「方差大」当「重要」——若信息藏在小方差里、或结构是弯曲的（如左边的弯月），PCA 会丢掉它，要用核 PCA / t-SNE / 自编码器（§6.4）。
