# 机器学习与深度学习深度入门课程

> 同一个模型有两种读法：把它读成一个**能跑出结果的黑箱**（喂进数据、调几个旋钮、看准确率涨上去），还是把它读成**「表示 + 目标 + 优化」三个零件的拼装**（你允许它长什么样、你用什么尺子衡量好坏、你用什么算法把最优的那个找出来）。前一种读法让你会炼丹，后一种读法让你看懂——而当你真的看懂了，岭回归的 $\lambda$、Dropout 的比例、注意力的 $\sqrt{d}$、扩散模型的噪声表，就不再是一堆要背的 trick，而是同一套逻辑在不同场景下的自然推论。这门课要做的，是反复逼问一个所有方法都绕不开的中心问题——**泛化**：我们能测的永远是训练误差，我们真正想要的却是在没见过的数据上表现好，这条鸿沟才是机器学习全部困难的来源。学会用"泛化、三件套、归纳偏置"这一套语言去拆解任何方法，你会发现线性回归、决策树、卷积网络、Transformer、VAE、强化学习——本就是同一门学问在回答同一个问题的不同侧面。

## 这门课会把你带到哪里

很多人把机器学习当成一门"会调库、会调参、能把指标刷上去就行的手艺活"。但当你打开一篇论文的 `Method`，看到 "we minimize the cross-entropy with weight decay"、"attention is softmax(QK^T/√d)V"、"we optimize the ELBO with the reparameterization trick"、"the model is trained with a contrastive objective"、"we observe double descent as model size grows"——这些**不是工程黑话，而是机器学习的标准语言**，每一个背后都站着一条清晰的逻辑链：某个表示的归纳偏置、某个损失对应的概率假设、某个优化器对泛化的影响。读不懂它们，你就只能"会跑别人的代码、会复现别人的 trick"，却无法判断一个方法为什么这样设计、一个改进从哪里下手、一个漂亮结果背后真正的代价在哪。这门课的目的，是把你从"会调库炼丹的人"培养成"懂为什么、能判断、能改进的人"。

**先把这门课最重要的观念二分说清楚——模型作为"黑箱"vs 作为"三件套"。** 它们是同一个对象的两面：

- **模型作为黑箱 / 炼丹炉（model as black box）**：输入数据、调旋钮、看指标。这种读法让你**能很快跑出一个结果**——但当结果不好时，你只能盲目地换模型、加层、调学习率，靠运气。
- **模型作为「表示 + 目标 + 优化」三件套（model as anatomy）**：任何一个 ML 方法都能拆成三个零件——(1) **表示 / 假设空间**：你允许模型长什么样（线性？树？神经网络？这同时编码了归纳偏置）；(2) **目标 / 损失**：你用什么标准衡量"拟合得好不好"（最小二乘？交叉熵？最大似然？带不带正则项？）；(3) **优化 / 推断**：你用什么算法去找到目标最优的那个模型（闭式解？梯度下降？EM？采样？）。学会在任何论文 / 方法里一眼看出这三个零件，是本课交给你的"万能解剖刀"。从"会调库"升级到"懂机器学习"，分水岭就在你能不能随时切换到这一面。

这门课为**数学 / CS 基础很强、数理成熟度高、会编程，但机器学习尚未系统化或只零散接触过**的读者而写。你的最大优势是数理与代码能力，最大的潜在陷阱恰恰也来自它：你太擅长把东西跑起来，于是容易**把 ML 读成"调库炼丹、记一堆 trick"**，而忘了它从头到尾是关于**如何从有限带噪的数据中学到能泛化的规律**的科学。这门课对你的价值，不是教你怎么 `model.fit()`（你会调，文档比我清楚），而是**反复把抽象的算法拉回三件套与泛化这两个观念**——让你看到 L2 正则其实是高斯先验、交叉熵其实是负对数似然、卷积其实是把平移对称性焊进了网络、SGD 的噪声其实在悄悄帮你泛化。

**这门课和那四门姊妹课，到底是什么关系？** 一句话：**三门数学课（线性代数 / 概率与统计 / 信息论）是地基与语言，本课是把这套语言变成"会从数据中学习的机器"的引擎与汇合点；而蛋白质折叠（第四门课、AlphaFold）只是本课无数应用中的一个旗舰科学例子。** 机器学习不悬浮在空中，它就坐落在这三门数学之上——

- **损失 = 负对数似然，正则 = 先验。** 平方损失是高斯噪声下的极大似然、交叉熵是伯努利 / 类别分布的极大似然、L2 正则是高斯先验的 MAP、L1 正则是拉普拉斯先验——全是《概率与统计》的对象（第 3 章呼应概统第 7、8 章）。
- **PCA = SVD = 协方差特征分解。** 降维、主成分、白化，骨子里都是《线性代数》的谱分解与奇异值分解；神经网络的每一层就是一次矩阵乘 + 非线性（第 6、7 章呼应线代第 8 章）。
- **交叉熵 = KL + 熵，对比学习 = 互信息下界。** 分类损失、信息瓶颈、VAE 的 KL 项、最大熵导出 softmax——全是《信息论》的语言（第 3、10 章呼应信息论第 4、9、10 章）。
- **优化 = 数值线性代数 + 概率采样。** 条件数决定收敛快慢、Hessian 是二阶曲率、采样 / MCMC 驱动生成模型（第 4、10 章呼应线代第 9 章、概统第 10 章）。

换句话说：你在隔壁三门数学课里反复打磨的"向量 / 矩阵 / 谱、似然 / 先验 / 采样、熵 / KL / 互信息"，**到了这门课里全部上场，被组装成一台会学习的机器**；而你在《蛋白质折叠》课里见到的 AlphaFold，不过是这台机器最闪亮的一个应用——它和视觉、NLP、推荐、表格数据平级，不是目的地。

**写作约定**：全程**简体中文**；所有术语**首次出现给出英文原词**，方便你查文献、读论文、跑代码；先直觉、后严谨、再动手——"严格而够用"是本课的尺度：在该严谨处给定义、给定理、给一行推导骨架（如偏差-方差分解、ERM、反向传播、最大间隔对偶、EM 单调上升、ELBO），但**不假设你学过测度论 / 凸分析 / 泛函分析全套**，真正需要更高深机械的几个角落会被清晰标出、留待将来回填。每章以"本章定位"引用块开场，全章布满「实战连接」「与数学三课的连接」「给数学 / CS 读者的视角」「常见陷阱」「概率视角」「诚实的边界」「要点」等方框，章末固定四块：本章小结、动手与思考练习、深入阅读指引、下一章预告。

## 中心问题与两个核心观念

这门课不是一堆算法的拼盘。把它读薄，只剩**一个中心问题**和**两个核心观念**，其余全是它们在不同场景下的展开。

**中心问题：泛化（generalization）。** 机器学习的全部困难**不在"拟合训练数据"**（那叫记忆，背答案的学生也会），而在**从有限的、带噪的训练数据，推广到没见过的新数据**。我们能测量的（训练误差）和我们真正想要的（泛化误差 / 测试误差）之间，永远隔着一条**泛化差距（generalization gap）**。过拟合 vs 欠拟合、偏差-方差权衡、容量 / 复杂度、正则化、双下降（double descent）——全是这一个问题的不同侧面。每当本课讲一个方法，都在问同一句话：**它如何在"拟合得够好"与"不要死记训练集"之间取得平衡？**

**核心观念一：「表示 + 目标 + 优化」三件套——任何方法的解剖学。** 上一节已说清：表示（假设空间，藏着归纳偏置）+ 目标（损失，常常就是某个负对数似然）+ 优化（找最优的算法）。这是你拆解任何论文的万能刀。

**核心观念二：归纳偏置（inductive bias）——没有免费的午餐，结构即先验。** 没有任何假设，就无法从数据中学到任何能泛化的东西（没有免费的午餐定理，no free lunch）。每个方法都在**对世界做假设**：线性模型假设关系线性、卷积假设平移等变与局部性、注意力假设关系型结构、决策树假设轴对齐的分段常数、正则化假设"简单 / 光滑更可能对"、贝叶斯先验是显式的归纳偏置。**机器学习的艺术，就是把归纳偏置和问题的真实结构对上。** 这两个观念如何与中心问题咬合：**三件套是解剖任何方法的框架；归纳偏置解释"表示"那一格里藏着的假设、以及为什么必须有假设；泛化是检验这一切的终极标准——你选的表示 / 目标 / 优化，最终都要用"能不能泛化"来打分。**

## 三条贯穿全课的暗线

上面的中心问题与两个核心观念，在全课里以三条暗线的形式不断回响。每章都会自然地"认出老朋友"。

- **暗线一：泛化——机器学习的中心问题。** 它在**第 2 章**正式登场、达到第一个高峰（ERM、偏差-方差分解、双下降），在**第 5 章**（bagging 降方差、boosting 降偏差）、**第 9 章**（过参数化网络泛化之谜、平坦极小、彩票假设）再度回响，在**第 11 章**收束。它是检验一切方法的终极标准。
- **暗线二：「表示 + 目标 + 优化」三件套——任何方法的解剖学。** 在**第 1 章**登场，**第 3 章**第一次完整实演（线性模型 = 线性假设空间 + 最小二乘/交叉熵 + 闭式解/梯度下降），此后**贯穿每一章**——看任何新方法，先拆这三个零件。
- **暗线三：归纳偏置——没有免费的午餐，结构即先验。** 它和数学三课咬合最紧（等变性来自线代、先验来自贝叶斯、MDL / 最短描述来自信息论）。在**第 5 章**（经典方法的归纳偏置对比表）第一次集中爆发，在**第 8 章**（架构 = 归纳偏置：CNN=平移、注意力=关系、GNN=置换）达到高潮。

此外有一条**贯穿性的"概率视角"**（非独立暗线）：尽量在合适处点出"学习 = 在数据下做（近似）极大似然 / 贝叶斯推断"——平方损失 ↔ 高斯噪声 MLE、交叉熵 ↔ 伯努利 / 类别 MLE、L2 正则 ↔ 高斯先验 MAP、L1 正则 ↔ 拉普拉斯先验。它用「概率视角」方框承载，处处呼应《概率与统计》。

## 两条推荐学习路径（并排对照）

## 给数学 / CS 背景学习者的建议与心态

你的最大优势是数理成熟度与编程能力，最大的潜在陷阱是**把机器学习读成调库炼丹、记一堆 trick，而忘了它是关于"如何从有限带噪数据中学到能泛化的规律"的科学**。下面把"该重投入"与"够用就行"分清楚。

**够用就行（不必死磕、不必全）**

- **每个算法的全部实现细节**：Adam 的偏差校正项的精确推导、LSTM 三个门的每一根连线、某个分解的具体数值迭代——掌握"它在解决什么问题、保证什么、何时该用"即可，实现细节用时一查 `sklearn` / `pytorch` 文档即得。机器做得又快又对。
- **追平最新模型清单**：今年最强的某某模型有多少参数、刷了哪个榜——这些月月在变，背它们性价比极低。**底层逻辑（三件套、归纳偏置、泛化）十年不变，比榜单值钱得多。**
- **高深理论的全套机械**：测度论概率、凸分析全套、PAC 学习的精细界、统计学习理论的完整证明——本课只在"严格而够用"的尺度上给推导骨架（偏差-方差、ERM、反向传播、ELBO、最大间隔对偶），需要更深机械的角落会被点明边界，知道它们在那儿即可。

**硬通货（这些是真护城河，值得花时间）**

- **泛化与偏差-方差（第 2、9 章）**：把"训练误差 ≠ 测试误差""容量 vs 泛化""$\text{Bias}^2 + \text{Var} + \sigma^2$（别漏不可约噪声）"刻进直觉。这是判断任何结果可不可信的尺子——也是你和"会炼丹但不知道自己在自欺"的人之间最大的分水岭。
- **「表示 + 目标 + 优化」三件套（第 1、3 章起）**：把它练成看任何方法的第一反应。能一眼拆出三个零件，你读论文的速度和深度会质变。
- **损失 ↔ 似然、正则 ↔ 先验的对应（第 3 章）**：平方损失=高斯 MLE、交叉熵=伯努利/类别 MLE、L2=高斯先验、L1=拉普拉斯先验=稀疏。内化它，你就不会再把损失函数当"凭空规定的公式"。
- **反向传播 = 计算图上的反向模式自动微分（第 7 章）**：它不是"近似梯度"，是链式法则的系统化高效组织。能手推一个两层网络的梯度骨架，你才算真正"拥有"了深度学习引擎，而不是租用。
- **架构 = 归纳偏置（第 8 章）**：CNN=平移等变+局部性、注意力=关系结构+置换等变、GNN=置换对称。看任何新架构先问"它假设了数据的什么结构"，这是从"认模型"到"懂为什么这样设计"的关键一跃。

**心态提示——警惕机器学习的五个高频陷阱，这是本课最该刻进肌肉的纪律。**

1. **炼丹心态**：把调参当玄学，靠运气堆 trick，不问"为什么这样改进"。解药是三件套与泛化——任何一个 trick，都该能被翻译成"它在动表示/目标/优化的哪一格、如何影响泛化"。
2. **用测试集调参 / 选模型**：测试集一旦参与了任何决策（选超参、选模型、早停），它就被"偷看"了，报出来的指标是骗自己的。**测试集只能用一次，在最后。** 调参用验证集 / 交叉验证（第 2、9 章）。
3. **数据泄漏（data leakage）**：训练时用了推理时拿不到的信息（未来数据、标签的代理、在划分前就做了全局标准化……）。这是实战里**最隐蔽、最致命**的错误——指标好得不真实，上线就崩。第 2、11 章反复盯它。
4. **把"通用逼近"当"可学习"**：通用逼近定理说 MLP "能"逼近任意连续函数，但**不保证你能优化到、不告诉你需要多大数据 / 多大网络**。"能表示"≠"训得动"≠"泛化好"，这三道关卡各有各的拦路虎（第 7、9 章）。这是纯数学训练最容易踩的坑——定理成立不等于实践可行。
5. **相关 ≠ 因果**：模型学到的几乎全是相关性（甚至是数据集里的虚假捷径，shortcut）。把相关当因果，会让你在分布漂移、干预、公平性问题上栽大跟头（第 11 章）。

> **一句话**：纯数学/CS 训练不仅不能帮你自动避开这五个坑，有时反而让你更自信地踩进去——你太会把东西跑出漂亮的数字了。把这五件事想透，你就抓住了从"会炼丹"到"懂为什么、能判断、能改进"的关键一跃。

## 如何与《线性代数》《概率与统计》《信息论》《蛋白质折叠》四门课配合使用

这门课不是孤立的算法课，它是同仓库其余四门课的**汇合点**。五门课刻意设计为可以交叉阅读，各占一个不可替代的位置：

- **机器学习（本课）= 把数学语言变成"会学习的机器"的引擎与汇合点**：回答"如何从有限、带噪、有限的数据中，学到一个能泛化到新数据的模型"。它坐落在下面三门数学课之上，把它们的对象（向量/矩阵/谱、似然/先验/采样、熵/KL/互信息）组装成监督/无监督/自监督/强化的具体方法。**它是数学与应用之间的桥。**
- **[`../linear_algebra_course/`](../linear_algebra_course/)《线性代数》= 空间、变换、几何与谱的语言**：回答"数据与运动如何用向量、矩阵、子空间、谱、旋转去表示与变换"。
- **[`../probability_statistics_course/`](../probability_statistics_course/)《概率与统计》= 从数据反推规律的推断引擎**：回答"给定带噪、有限的数据，如何反推规律、如何采样、如何诚实地说出把握"（估计 / 检验 / 采样 / 建模）。
- **[`../information_theory_course/`](../information_theory_course/)《信息论》= 度量与编码语言**：回答"信号里的信息、模型的'懂'、压缩与冗余，如何用熵 / KL / 互信息去度量"。
- **[`../protein_folding_course/`](../protein_folding_course/)《蛋白质折叠》= 一个旗舰科学应用**：回答"蛋白质如何折叠、AlphaFold 在做什么"。它是本课无数应用中**最闪亮的一个**，与视觉 / NLP / 推荐 / 表格**平级**——不是本课的目的地。

五门课的总关系：**三门数学课 = 地基与语言 → 本课 = 把语言变成会学习的机器（引擎 / 汇合点）→ 折叠课 = 一个旗舰科学应用。**

**交叉阅读建议**：

- **本课 ↔ 线性代数**：本课第 6、7 章的 **PCA / 神经网络层**，骨子里就是《线性代数》第 8 章的 SVD / 协方差特征分解、第 3 章的矩阵=线性变换；本课第 4 章优化的**条件数 / 病态**接《线性代数》第 9 章；本课第 8 章**卷积 / 注意力的等变性**直接调用《线性代数》第 10 章的对称性与等变语言。读到"层就是矩阵乘""注意力就是内积""降维就是找主轴"时，两课对照看。
- **本课 ↔ 概率与统计**：本课第 2、3 章的 **MLE / MAP / 偏差-方差**正是《概率与统计》第 7、8 章的极大似然 / 贝叶斯推断 / 期望与方差；本课第 6 章 **GMM/EM** 直接调用其第 5 章多元高斯；本课第 10 章生成模型的**采样 / MCMC** 接其第 10 章。读到"损失=负对数似然""正则=先验""ERM 靠大数定律"时两课对照看，你会同时拿到"算法骨架"与"概率含义"。
- **本课 ↔ 信息论**：本课第 3 章的**交叉熵损失** = 《信息论》第 4 章的 KL + 熵；本课第 10 章**对比学习** = 其第 4 章互信息的下界、**VAE 的信息瓶颈** = 其第 9 章率失真、**softmax / 逻辑回归**的另一来源 = 其第 10 章最大熵；正则 / 奥卡姆 = 其第 6 章 MDL / 最短描述。读到"交叉熵""信息瓶颈""最大熵"时拐去信息论。
- **本课 ↔ 蛋白质折叠**：当折叠课讲到 **AlphaFold 的注意力 / Transformer / 几何深度学习**时，回到本课第 8 章；讲到**结构生成（扩散模型）/ 蛋白设计**时，回到本课第 10 章；讲到**共进化的统计学习**时，回到本课第 5、6 章并配《概率与统计》。折叠只是本课的旗舰应用之一，本课的方法（泛化、三件套、归纳偏置、训练手艺）**通用于一切领域**。

**一个推荐的总闭环**：先在三门数学课里**把向量/矩阵/谱、似然/先验/采样、熵/KL/互信息握在手里** → 来本课**把它们组装成会学习的机器（第 1–11 章）**，沿三条暗线把监督/无监督/自监督/强化串成有机整体 → 带着"三件套 + 泛化"的眼光，挑一个你关心的应用深入（视觉、NLP、推荐，或——如果你立志做计算生物——折叠课的 AlphaFold / 生成设计章节） → 在五门课各自的第 11 章（路线图）里对照论文精读清单与开放问题，订一份属于你自己的自学时间表。

> **强调**：本课**通用、普适**，主线是机器学习本身，跑例横跨视觉 / 文本 / 表格 / 推荐 / 时序 / 语音与科学计算。蛋白质折叠是被克制引用的旗舰例子之一，绝非主线——无论你将来做哪个领域，这门课交给你的"泛化、三件套、归纳偏置、训练手艺"都同样管用。

> 机器学习是少有的、同时具备**简洁的结构之美**（一切归结为"表示 + 目标 + 优化"这三个零件，去回答"如何泛化"这一个问题）、**深刻的统一力量**（线性回归 / 决策树 / 卷积网络 / Transformer / VAE / 强化学习都在说同一种"从数据中学规律"的语言）和**直接的应用价值**（从一张图片的分类，到一条蛋白链的折叠）的学科——而对带着数理与代码、立志看懂并改进这些会学习的机器的你，它的大门此刻正敞开。它不要求你记住更多 trick，只要求你学会问那三个问题：**它的假设空间是什么？它在最小化什么？它会不会泛化？** 从第 1 章开始，一步一步来。**欢迎入坑，祝你学习愉快。**
